## C-01　全7工程・本体3水準

JOINT の `path_error.reequilibrate_endpoints` を明示選択した。粗終点・中点・細終点の通常の釣合い解について、自由力残差比が P1 の独立平衡の停止値 1e−10 を超える場合だけ、元の親状態から同じ外力・自由度・材料・接触則で別途 Newton 求解する。材料状態や変位を初回解から引き継がず、組立と線形解法を再実行する。細解の親は補正後の中点。初回と補正の線形履歴を保存する。一般の力判定 1e−8、真線形判定 1e−10、事象検査、すべり・散逸の判定式は従来どおり。補正は独立に開始する本体求解であり、P1 の Python 参照実装を呼ぶものではない。

## C-02　独立した接触面積分

各三角形を辺方向に2・4・8分割し、それぞれの小三角形上で正の対称7点5次則を用いた。基準三角形の5次までの単項式積分、要素両側の節点対応、定数場のジャンプ、面積総和を検査した。接触面の形状関数・法線・面積重み・仮想仕事・接線の積分を別実装とし、体積作用素、外荷重、接触更新、剛性、平衡ループは元のものを共用した。元の面における水圧は一定。全7工程448座標の場を同じ Q6 観測点で受動再生し、面積積分履歴は各経路の能動求積点で評価した。

提案する参照精度幅は **0.1%**。面の細分、時間刻み、変位次数を個別に変え、面積重み付きの符号付きすべり場と符号付き面積積分履歴の相対 L2 差をそれぞれ測る。分母は細かい側の同じ量のノルム。この幅は計測前に設定し、連続解への誤差上限や採用済みの基準とはしていない。

## Kirsch　ユーザー判断による認定格子

a/r 等分、周方向22×半径方向21の格子を採用した。元の4求解、元の固定12点、所属 Tet4 の生応力、30 MPa 正規化の等重み RMS は **2.47664490%** で、元の3%基準を通過。12点の生テンソル・採点値は P1 と一致した。旧24×16格子の13.603%、帯内に再配分した旧20×24格子の5.831%ほかの未達記録を保持した。原因は、要素一定応力を読む位置と半径方向の分割への感度。今回認定した格子と12点の採点は完了した。別格子への一般化には別途検証が必要。[固定12点の生値](kirsch-raw.json)・[4求解と採点](kirsch.json)・[旧格子の成績](../2026-11-25-approved-six/README.ja.md)

## 再現と試行上限

リポジトリ直下のロック環境で以下を実行する。C-01 の生の全場は一時出力に展開し、`c01_score.py` が各バイナリ列の形状・ハッシュ・座標・受理散逸アンカーを検査する。格納したマニフェストは各列の SHA-256 を含む。NC の状態列は、アーカイブの初期状態に対し活動材料点だけを置き換えて復元できる。局所弧長には荷重係数の数値単位として 1 m を用いた。NC 親状態の生成に要する既報約580秒は今回の短区間の時間に含まない。

```bash
set -eu
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
p=interim/2026-11-25-remaining5-p2
p1=interim/2026-11-25-remaining5-p1
w=$(mktemp -d)
cargo build --release --locked --lib --bin soil-fem-3d --example c01_methods
for n in 256 512 1024; do
  timeout 23h python "$p/c01_native.py" "$w/c01/n$n" "$n" target/release/examples/c01_methods
done
python "$p/c01_score.py" "$w/c01" "$w/c01-results"
python interim/2026-11-22-impl-linear-solver/prepare_inputs.py "$w/inputs" --cloud-original
lib=(target/release/deps/libsoil_fem_3d-*.rlib)
json=(target/release/deps/libserde_json-*.rlib)
rustc --edition 2024 -O -Dwarnings "$p/nc_map.rs" -L dependency=target/release/deps \
  --extern soil_fem_3d="${lib[0]}" --extern serde_json="${json[0]}" -o "$w/nc-map"
for ds in 0.0008 0.0004 0.0002; do
  timeout 23h python "$p/nc_continue.py" "$w/inputs" "$w/nc-map" "$w/nc/$ds" "$ds"
done
python "$p/nc_fold.py" "$w/inputs" "$w/nc-map" "$w/nc/0.0002" > "$w/fold.json"
python "$p/nc_audit.py" "$w/inputs" "$w/nc" > "$w/nc-audit.json"
for spec in '3 2 256' '3 4 256' '3 8 256' '3 8 512' '4 8 256'; do
  read -r degree divisions n <<< "$spec"
  python "$p/c02_face.py" "$w/c02/p$degree-d$divisions-n$n" "$degree" "$divisions" "$n"
done
python "$p/c02_compare.py" "$w/c02" > "$w/c02-summary.json"
python "$p1/physical_fold.py" --physical-fold > "$w/t7.json"
python interim/2026-11-25-approved-six/kirsch_refinement.py . "$w/kirsch" \
  --registered-grid inverse-radius-22x21 > "$w/kirsch-cli-and-score.log"
python "$p1/kirsch_samples.py" "$w/kirsch" > "$w/kirsch-raw.json"
python "$p/decisions.py"
```

工程試行予算は B(E)=ceil(2065E/12)。C-01 の12要素は2,065以内、C-02 の12要素は最大512試行／工程。NC は既定2,000以下かつ B(96)=16,520以内。16／32／64増分に加えた折れ点の局所求根も最細経路で7平衡評価。T7 は12／24／48／96梁で各66／73／87／226試行と近接点各3、Kirsch は2,772 Tet4 の4求解。768／6,144要素メッシュは使用していない。実行環境のメモリ上限は16 GiB。1経路の最長は本体 N1024 の約561秒。[初回の停止記録](checks/initial-attempts.txt)・[本体試験](checks/joint-path.log)
