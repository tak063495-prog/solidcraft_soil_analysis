## 排水 MCC の独立実装による検証

圧縮を正とし、側圧を 5 kPa に保つ。軸対称経路では q=3(p′−5)、εₐ=εᵥ/3+εₛ。体積弾性率 K=vp′/κ、せん断弾性率 G=250 kPa。初期 pc=8、40 kPa の各降伏点を側圧直線と MCC 楕円との交点から求める。弾性域の v=v₀−κ ln(p′/5) と εₐ=ln(v₀/v)/3+q/(3G) を使い、降伏位置を分割点の内部でも合わせる。

塑性域では f=q²+M²p′(p′−pc)=0、A=∂f/∂p′、B=∂f/∂q、D=A/3+B。関連流れと d ln pc=v dεᵖᵥ/(λ−κ) から H=M²p′pc v A/(λ−κ)、C=1/(9K)+1/(3G) と置く。軸ひずみ当たりの変化は dq/dεₐ=H/(CH+D²)、dεᵥ/dεₐ=(dq/dεₐ)/(3K)+DA/(CH+D²)。v=v₀ exp(−εᵥ)。独立ドライバはこの2変数の微分方程式を4次 Runge–Kutta 法で直接積分する。FEM の応力・ひずみ履歴は参照解を生成した後の照合に用いる。

8ケースの各512受理点で p′・q・v・軸・側方・体積ひずみそれぞれを同じ軸載荷座標で照合する。軸ひずみは載荷座標のチェック、側方ひずみは側圧制御の解。体積ひずみは軸と側方の和から求める。各点の分母はその点の参照値の絶対値。初期状態は共通入力、最初の比較点は 0.5/512。各量の点別最大が既存の終端基準 2% 未満かを評価する。ゼロ近傍でも履歴最大値による正規化は行わない。参照自身は一出力区間8、16、32分割で比較し、最後の刻み差に FEM 判定幅の 1/100 を要求する。公開例との終端比較、論文全履歴との比較は元の判定行に記録されている。[Itasca 公開例](https://docs.itascacg.com/flac3d700/flac3d/zone/test3d/VerificationProblems/TriaxialCompressionTest/TriaxialCompressionTest.html)・[参照刻み差・ケース別最大誤差](mcc.json)・[全比較点](mcc-history.json.gz)

## C-03 の独立実装による検証

12 Tet10 の m0c1、m1c0、m1c1 本体を既存の観測用プローブで解く。先行調査で材料分類差を観測した GP108、143、152、182、185、273 を選ぶ。各点の種応力から、7工程×32受理点を通してその点自身の6成分ひずみ増分を与える。独立履歴は工程や受理点で FEM 応力へ戻さずに積算する。FEM 側の各材料内増分は既存の観測プローブで再生し、終端状態が当該 GP の受理状態と完全一致した増分だけを使う。各工程32試行すべて受理され、12要素の工程予算2,065内。再構成した直接仕事と本体が主応力系で累積した塑性仕事との最大差は4.17×10⁻¹⁷ kPa未満。

独立ドライバは各点に等方弾性予測を適用し、試行主応力を昇順に並べる。MC 塑性ポテンシャルの勾配は最小・最大主応力へ作用する。乗数を固定したとき、隣接主応力が逆順になる組を平均すると稜線へのリターンになる。面、二つの稜線、頂点それぞれの平均射影 P に対し、整合条件 f(P(σ試行−Δγ C∂g))=0 から乗数を解き、非負性、主応力順序、射影の相補条件を検査する。弾性コンプライアンスから塑性増分を回収する。弾性・面・稜線・頂点の比較には既存の主応力識別幅 10⁻¹⁰ × 応力スケールを用いる。対象材料は引張カットオフなしの非関連 MC。[局所材料データと先行分類](../2026-11-24-c03-return-classification/README.ja.md)

主量は終端有効応力による直接仕事 Wₚ=Σσ′:Δεᵖ。体積仕事 Σp′Δεᵖᵥ とせん断仕事 ΣqΔεᵖₛ も各内増分から別々に求める。Δεᵖₛ=√(2 dev(Δεᵖ):dev(Δεᵖ)/3)。Voigt の工学せん断をテンソルに戻して内積を取る。非関連 MC では偏差方向の不一致により内訳の和と直接仕事に差が生じ得る。単一材料点の仕事密度の単位は kPa（kJ/m³）。

この局所検証の提案幅は、各仕事量について「累積履歴の最大絶対差／同じ点・同じ量の参照累積絶対値の最大」が **1% 以下**。全経路で到達した仕事の大きさに対して百分の一を分解する工学的な比較目標とした。ゼロから始まる累積仕事と除荷を含むため、終端1点の誤差のみで採点しない。刻み誤差の割当は比較目標の1割（0.1%）以下。各受理区間を32、64、128等分し、仕事または分類がこの確認を満たさなければ倍増して最大1,024等分まで調べる。分類は最細2水準の安定および FEM との全224点完全一致を要求する。分類・直接・体積・せん断仕事の各判定を記録する。公刊の許容幅を意味しない。[対照入力・FEM 側の仕事と分類](c03-inputs.json.gz)・[独立参照の全履歴](c03-history.json.gz)・[点別誤差・分類差・判定](c03.json)

## 再現

リポジトリルートでロック済み依存関係を使う。出力先は新規ディレクトリを指定する。

```bash
set -eu
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
d=interim/2026-11-24-independent-local-references
out=runs/independent-local-references
mkdir -p "$out"
cargo build --locked --release --example t9d_mcc --example c03_bulk_cause_probe --example c03_bulk_return_trace
python "$d/assess_wall.py" "$out/wall.json"
target/release/examples/t9d_mcc --constant-g --strain-history > "$out/native-mcc.json"
python "$d/mcc_history.py" interim/2026-11-24-t9d-benchmarks/criteria.json "$out/native-mcc.json" interim/2026-11-24-approved-four/mcc-constant-g.json "$out/mcc-history.json.gz" "$out/mcc.json"
```
