ボディ側では新設土の材料、配置時の有効応力・参照座標・単位重量、必要な水理初期場を入力で確定し、旧土の場を保持する。拘束・露出外面・自重・圧力を更新して初期平衡を組み直す。旧土の荷重や接触力を新設土へ自動複写する規約は未確認。

**受入試験。** 2小面の片方だけを撤去・再設置し、既知の活動面積、面積×一定 traction の力、残存側の累積仕事、失活側の凍結値、新世代の参照 jump と初期力を別積分する。両側非活動、片側だけ活動、全面復旧、実開離・再接触を通す。ボディ跨ぎ A/B は独立体積積分で重量・応力内力・全自由節点平衡を求める。領域重複・所有側欠落・凍結上書き・再開時の二重誕生は拒否する。

## 2　引張または摩擦円外の初期力

乾燥、非粘着の現行則で、法線 n は a→b、開口正、q は有効 traction [kPa]。p=−q·n、τ=q+p n とし、p≥0 かつ ‖τ‖≤μp を要求する。開口で接触力を解放する増分則と、既に平衡に使った力を移行する A の出生条件を区別する。[R1,4,5,6]

|案|採用例・適用範囲|利点、欠点、本コードとの相性|
|---|---|---|
|A　不適格な力移行を拒否（推奨）|本コードの厳密 cone 検査 [R1]。他製品が BIRTH で同じ拒否を行うかは未確認。|施工者が保持機構・解放工程を指定できるまで直前平衡を保存する。引張を支えた仮設材を外す施工には別工程が要る。|
|B　その場で開口・接線戻し|FLAC3D は界面の節点せん断力を強度で制限 [5]。Giannakopoulos の摩擦積分 [6] と Simo・Hughes の塑性積分の一般論 [16]、Code_Aster の JOINT 則 [7] も増分更新の先例。BIRTH 時の自動修正は未確認。|局所的には許容値内になる。圧縮力を固定した接線方向の径方向戻しと、法線まで動く円錐への最近点射影は別の規約。いずれも元の全節点力を一般には再現しない。|
|C　仮設保持力を明示して段階解放|Abaqus の撤去境界力ランプ [1]、ZSoil の掘削力の関数 [8] が近縁。Abaqus の干渉解消 [9] は距離を制御する別の先例。|実在する支持・撤去工程を表せる。履歴・経路依存、計算費用が増す。引張を摩擦接触だけで支えることはできない。|

**推奨 A の実装範囲と受入試験。** A が失敗した時点でイベントを棄却し、原因 GP、要求・再現節点力、補正前 p・τ、強度超過を単位付きで出す。B への自動切替は行わず、独立に指定された B の保持力と再平衡も照合する。法線圧縮100 kPa、μ=0.3 の手計算で接線 0、30、40 kPa を比較する（限界30、超過10 kPa）。引張、p=0 で非零せん断、円内・境界・円外、回転・ULP 対照を含む。式を直接与える1点試験と、節点から逆算する3D試験を別にする。境界上の解析値と実際の浮動小数表現を記録し、クリップや許容幅の追加で通さない。

## 3　力差の仕事、散逸、再平衡

|案|採用例・適用範囲|利点、欠点、本コードとの相性|
|---|---|---|
|A　棄却を非確定の試行として記録（論点2Aと併用）|本コードの棄却時保持・世代再開 [R1,R2]。|力不足を隠さず、棄却前後で履歴が変わらないことを検査できる。施工後の解は得られない。|
|B　保持力・解放率・仕事を独立に記帳（解放工程を明示する場合の推奨）|ZSoil の unloading function [8]、Abaqus の撤去力 [1]、FLAC3D の段階掘削 [10] は荷重経路の例。Laursen・Simo [11] は仮想仕事の離散化。T3 の全記帳項目を備える製品は未確認。|捨てた力がどこへ移ったか復元できる。仮設支持の意味と経路が必要で、既存の GP 仕事だけでは足りない。|
|C　追加外荷重を加えず再平衡する1工程|PLAXIS の plastic nil-phase [4]。|初期応力の不釣合いを変位・応力の変化として観測できる。初期状態や拘束を定めずに不適格力を消した場合、その由来と仕事は復元できない。|

**実装範囲。** A では確定場への加算をゼロ件とし、仕事を評価していない試行を「散逸 0 の受理」と記録しない。B では初期形状で必要な**外部保持荷重の符号**を、内部力 I、物理外力 F、保持外力 H とする釣合い I=F+H から決める。接触内力を f_req から f_adm に替え、他項が同じなら H₀=f_adm−f_req（節点ベクトル）。実在する支持にこの荷重を帰属できる場合だけ、指定した λ∈[0,1] で H=(1−λ)H₀ を解放し、各受理点で変位と反力を解き直す。一般の土 BIRTH では自重・初期応力・拘束変更も最初から再組立する。終点で H=0、全自由残差が既存基準内となることを要求する。

保存単位は力 kN、変位 m、仕事 kN·m。イベント前後で要求力・実現力・保持力・支持者・反力と適用時の配置を記帳する。変位固定の瞬時の力変更では力差による変位仕事は零だが、弾性蓄積の差には供給元または搬出先が要る。未成立の試行力に蓄積エネルギーを割り当てない。受理増分ごとに外力、保持力、強制変位の反力の各終点仕事（例 W_H=Σ Hᵢ·Δuᵢ）を別積算し、土内力と接触内力の仮想仕事へ照合する。接触側は Σw qᵢ·Δjump を、既存の誕生時エネルギーを基準とした蓄積変化、塑性摩擦散逸、離散時間積分の数値散逸に分ける。誕生時の蓄積移行と撤去時の持出しは世代ごとに一度だけ計上する。節点側と GP 側は同じ仕事の二通りの評価である。[R1,8,11]

**受入試験。** 1自由度の線形ばね k に H を与えて零まで外すと Δu=−H₀/k、蓄積変化は −H₀²/(2k)。連続仕事と離散終点和の両方を手計算し、刻み細分で差を分離する。定圧 p の単調すべりでは単位面積の摩擦損失 μpΔs、固着では塑性損失零。符号反転・保持仕事の二重計上・再開による二重解放・同じ合力で異なる節点残差を故意に混ぜて検出する。3D では全受理点で独立解の節点・GP・反力・仕事と照合し、荷重分割を変えた比較を別に行う。不釣合いのノルムをエネルギーとみなさない。

**推奨 A の実装範囲と受入試験。** 物理節点 ID と面の両側を対応付ける。面の弱形式は q·(δu_b−δu_a) であり、同一節点の係数は −N+N=0。土の体積内力・外力・拘束反力は各々一度組み立てる。非共有点の対力は作用反作用として保存する。自由先端に非零の残差があれば、その成分を拒否理由とし、近傍要素や拘束反力に付け替えない。拘束先端なら規定拘束の反力を独立に照合する。上下面の等分割りや最大番号の面への一括帰属に物理的な根拠は未確認。試験は一定 traction の平面パッチ、自己対の除外、合力もモーメントも零の旧 1 kN 反例、側・要素列の置換、拘束／自由先端。全節点3成分の再組立と任意の許容仮想変位による仕事一致を検査する。

## 5　初期力投影の一意性と隣接面の一致条件

|案|採用例・適用範囲|利点、欠点、本コードとの相性|
|---|---|---|
|A　全節点を制約した面積重み付き GP 最小ノルム（推奨）|本コードの二段階 SVD [R1] が直接例。DIANA の GP traction と局所軸 [2]、Abaqus cohesive の GP 方向 [15] は評価位置の近縁例。|作用反作用・全節点力を検査できる。選んだ離散化に依存し、一様な元 traction が逆算で一様に戻る保証はない。|
|B　節点で法線・接線に分解し、代表面積で面へ配分|FLAC3D の節点初期化は要素面応力と概ね適合する力を与える [5]。OpenSees は節点接触方向を指定 [13]。|実装が小さい。折れ面では法線選択が非一意で、Tri6 の GP 再組立や全節点仕事の一致を別途示す必要がある。|
|C　共通の mortar 乗数場を両面へ写す|Puso・Laursen [14]。|非適合で両側の弱い仕事整合を課せる。離散空間・積分域・安定性の追加検証が必要。GP で同じ値を得ることまで保証しない。|

**推奨 A の実装範囲。** 配置・単位・両側順序と GP を固定する。第一段で、未接合拘束の零空間 T と非共有節点の対力行列 P から TᵀPλ=Tᵀr を最小ノルムで解き f=Pλ を作る。第二段で jump 行列 C、正の面積重み w に対し Σ Cᵍᵀwᵍqᵍ=f の下で Σwᵍ‖qᵍ‖² を最小化する。実行可能なら目的関数は狭義凸で代表解は一つ。像の外の f は拒否し、行列のランク・特異値・切断値と元の節点残差を示す。各 GP の cone はその後で検査する。この順序では、別の cone 内の可行解が存在するかは判定していない。[現行の式・単位・予算](../2026-11-25-joint-birth-projection-a02/SPEC.ja.md)

正規化した面法線 n の向きは a→b。qₙ=q·n、接線ベクトルは q−qₙn。局所2成分が必要なら、向きを固定した参照辺を接平面へ射影・正規化して t₁、t₂=n×t₁ とし、退化辺・零面積を診断する。面の両側交換では n と q、jump がともに反転し、圧縮量と仕事は不変。接線基底だけを回転した場合は成分を回して世界座標ベクトルで照合する。隣接面の同じ物理点で値を比較できる条件は、共通の幾何・配置、同じ向きへの変換、同じ物理 traction のトレースがあること。逆問題の代表解まで一致させるには同じ力制約・積分空間・重み（または等価な写像）も要る。折れ面では同一応力 σ でも σn が変わる。異なる面積分・GP 間を最近点で同一視せず、共通パッチの節点力と仕事で比較する。

**受入試験。** 正の重みで具体的な f を順組立し、独立 QR/SVD で逆算、全物理節点の再現、零空間方向への摂動でノルムが増すことを照合する。平行移動・剛体回転・両側交換・接線基底回転・要素宣言順の置換、平面隣接／折れ面、零面積、像空間外、cone 境界の ULP を含める。既存の絶対 1e−10 kN（自由節点／全物理節点）、SVD 切断値 1e−12 と厳密 cone をその適用範囲で保持する。ランク変更や面分割で結果が変われば生差を示し、一意性の成立条件外として扱う。

## 採用後の検証規模と判定

GPD WIN Max 2（使用可能メモリ約48 GB）で、手計算1点・1自由度、2小面、既往の81節点・24 Tet10・648材料 GP・32接触 GP までを順に1経路ずつ実行する。計画上限は1経路の親子合計ピーク 8 GB、経過2時間とし、上限到達で打ち切って未判定を記録する。時間・メモリは予算であり実測値ではない。

本体と独立3D参照に同じ入力・工程分割を事前指定し、独立側は本体の変位、受理列、接線を読まず全場を求解する。各受理点で全節点内力・荷重・反力、材料場、全接触 GP、負担面積、世代・参照 jump・仕事を照合する。撤去直前・直後、解放途中、再設置後からの別プロセス再開を連続実行と比較し、再封印した世代・所有・初期力の改変も拒否する。既存ゲートは対応する物理量だけに用い、新たな経路全体の許容値・参照値をこの調査で設定しない。未定の合否基準や独立経路の欠落は受入保留。既往の追加二分の反復、大規模メッシュへの移管は計画しない。
