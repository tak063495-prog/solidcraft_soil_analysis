## 3. (a) 測り方の監査

点量の単位は、塑性すべり m、散逸/弾性接触エネルギー kPa m。面積重みを掛けた界面総量は kN m。
元の全履歴L2は、粗い水準の全7工程・実在する全 `i/N`・全GP・ベクトル全成分をプールした
`sqrt(sum((a-b)^2)) / max(sqrt(sum(b^2)), 1e-12)`。細かい方を分母とする。
比較時刻を工程と進行度で対応させ、補間・工程端点だけの抽出・参照の外挿はしない。
差方向余弦は同じ3水準共通座標の絶対差で測る。相対L2の数値だけを割って次数や方向を作らない。
再計測では封印した実GP配置・重みを入力として再使用し、Jacobi固有値問題をプラットフォームごとに解き直さない。
全ての新規ノルム/内積集計は固定C順の `math.fsum`、平方根/対数は80桁Decimalとし、Windowsの集計順差を許容値で吸収しない。

本体 `joint_law.rs` の実装は、各閉接触の内部区間で return mapping 後の
`ΔD = max(t_T,new · Δg_T^p, 0)` を累積する。弾性接触エネルギーは
`E = q_n²/(2 k_n) + ||t_T||²/(2 k_t)`。
閉区間の後退端点仕事 `ΔW = q_new · Δg_closed` と、`ΔN = max(ΔW-ΔE-ΔD,0)` の数値散逸を別に保持する。
開閉の平面交差で内部区間を分け、開いたままの区間は仕事を足さない。
ここでの散逸は増分仕事であり、既に積算された値へさらに `Δt` を掛けたり、工程毎にリセットしたりしない。

同じ保存解から、次の独立な後処理を行った。

- traction・法線・ばね剛性だけから各GPのEを再計算する。
- `D_balance = W-E-N` を再計算する。この収支は有用な整合検査だが、Nも保存量なので単独では構成則の独立検証ではない。
- 本体は観測した実分割数、独立側は保存済みの分割数を使い、Pythonのスカラー実装で各局所return mapping・開閉交差・`t_T·Δg_T^p` を独立に再計算する。新しい全体平衡解は作らない。
- 元の非重み付きL2に加え、GP面積重み付き、各工程の進行度に対する台形積分（工程開始値は前工程終値、初期値は0）を併記する。実時間は入力されていないので秒の積分とは呼ばない。
- 受理された全体端点だけで `t_T,new·Δg_T^p`、`(t_T,old+t_T,new)/2·Δg_T^p` を積算した診断も保持する。符号を消して値を整えない。

最後の二つの端点診断は、内部区間の散逸とは一般に等しくない。
開いた最終端点のtractionが0でも、その前の閉じた区間では正の散逸があり得る（解析的回帰試験あり）。
全体端点で台形則を使うだけでは内部の開閉・方向転換や圧力変化を復元できない。
台形診断の単調化を元の散逸の合格へ転用しない。

実際の分割数を使ったスカラー再計算では、元の非単調な散逸系列を丸め誤差程度で再現した。
両制御系列で本体の再計算散逸の最大差は1.249000902703301e-16 kPa m、Eは差0だった。
面積/進行度重みを加えても、2026-12-11本体の散逸再増加、弾性接触エネルギーの初期の再増加は残る。
したがってこの固定ケースの保存・累積・L2集計の誤りを主因とする証拠は得られなかった。
定義依存性の存在と、元の定義での未達は区別する。全精度値は `measurement-switch.json` / `measurement-path.json`。

## 4. (b) 接触離散化

`geometry.json` に32点の位置・面番号・法線・面積重みを保存した。

## 6. その他：本体の固定内部分割と局所経路

一方、誤差制御N64/128/256では「実分割が端点下限より多く、かつ散逸増分が正」の点増分は全て0だった。
