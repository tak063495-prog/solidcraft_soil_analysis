## 1　付着参照点と中央面上の節点

ここで中央点 p は T4/T5 が定める板厚中央面の点を指す。材料積層や有限交差域に固有の応力中立軸は別途モデル化を要する。

|選択肢|採用例・出典|利点、欠点と本コードとの相性|
|---|---|---|
|A　適合面の同一点・同じ自由度を共有|現行の共有構造 ID [R1]、OpenSees equalDOF [4]|腕が同一で結合が剛なら最小の自由度で済む。位置の異なる二点へ並進等置を使うと剛体回転でも偽の反力を生む。|
|B　面別節点と明示継手線、剛体腕の MPC（推奨）|Code_Aster LIAISON_COQUE の向かい合う辺の式(7)(8) [3]、Abaqus BEAM／kinematic coupling [2]、DIANA eccentricity tying [5]、偏心補剛材の変換 [13]|位置と符号を保持し、消去形で既存剛性を利用できる。対にする辺・端点順・中間節点と、線が実物のどこを表すかが入力に要る。|
|C　独立節点を保持し、同じ適合式を乗数またはペナルティで課す|拘束処理の実例は OpenSees の Lagrange／Penalty [4]。B と同じ線拘束での併用は本調査案。|乗数は継手反力の独立参照を与えるが不定系・拘束行の従属に注意する。ペナルティは有限のずれと人工蓄積を生む。物性ばねと別管理し、既定の係数は置かない。|
|D　有限幅の継手要素・局所3D交差域|交差部を spine とした殻／立体比較 [9,10]、Code_Aster の直交板の切詰め [3]|接合部内のねじり・変形を表せる。実幅・材質・板の終端と重複体積の定義が必要。旧ゼロ幅線の剛結と比較すると物理問題が変わる。|

**採用時の実装範囲。** 初回は小回転、直線の適合する折れ辺または段差辺。継手線上の点 J、各側 i の付着点 sᵢ、中央点 pᵢ=sᵢ−eᵢdᵢ を入力／既存幾何から識別する。各側の回転 θᵢ で uₛᵢ=uⱼ+θᵢ×(sᵢ−J)、uₚᵢ=uₛᵢ+θᵢ×(pᵢ−sᵢ)。sᵢ が土と付着する場合はその土節点の並進との適合を同じ拘束系で解く。既存の共有土並進と新しい腕の式がヒンジを意図せず固定する場合は、拘束行の階数と対象 ID を示して拒否する。固定腕の写像を T として残差・荷重には Tᵀ、接線には TᵀKT を使う。3面以上は一つの J に各側を一回割り当て、閉じた循環拘束を作らない。段差幅・面の切詰め・線の所有者が指定できない入力を最近接点や平均法線で補完しない。

**受入試験。** 正負・零の腕、法線と e の同時反転、片側だけの反転、平行段差、直角と鈍角、3面・異厚・宣言順反転を用意する。各面の元の座標で6剛体基底と6荷重基底の仕事を外積で検算する。消去系と独立乗数系の変位・反力、従属／矛盾拘束の拒否、旧入力の受理／拒否を比較する。有限厚が重なる場合は切詰めの寸法・所有体積を明示できる例だけを対象とする。

## 2　折れ線で共有・解放する回転

|選択肢|採用例・出典|利点、欠点と本コードとの相性|
|---|---|---|
|A　剛結。全体空間で相対回転ゼロ（連続継手の推奨）|Code_Aster の等回転 [3]、PLAXIS の構造間剛結 [6]|連続板として指定したときの角度を保てる。剛結を実際の溶接の局部ねじり剛性とみなすには別の裏付けが要る。|
|B　線ヒンジ。線軸 ℓ 回りのみ自由|Abaqus HINGE の JOIN＋REVOLUTE [2]、FLAC3D の二重節点 [7]、MIDAS の局所解放 [8]|曲げ解放を機構として検査できる。局所軸を取り違えると意図した成分にモーメントが残る。|
|C　線軸の相対回転にばね|FLAC3D の回転リンク [7]、PLAXIS custom connections [6]|半剛接の物性・単位を指定できる。試験／同定した剛性と有効長が必要。履歴ばねには別の散逸・世代則が要る。|
|D　並進だけ共有し全回転を独立にする|同じ土点の別構造 ID [R1]、選択 DOF の等置 [4]|既存の独立板対照として使える。ヒンジが伝える直交2成分の偶力も解放される。|

**採用時の実装範囲。** 面群ごとの dᵢ を保持し、剛結でも初期 director を一つに平均しない。各面の厚さ線変分は θᵢ×dᵢ。小回転で Δθ=θ₂−θ₁、線の有向単位接線を ℓ とする。B は (I−ℓℓᵀ)Δθ=0 の独立な2式、ℓ·mⱼ=0。C は同じ並進・直交拘束に φ=ℓ·Δθ と単位長当たりの線モーメント kφ を加える。蓄積は ∫kφ²/2 dL。節点集約ばねなら長さを二度掛けない。複数翼ではどの翼が剛体群をなし、どの群の対が回るかを明示する。

**受入試験。** 線軸と直交2軸を個別に強制回転し、剛結の相対回転、ヒンジの線軸偶力、ばねの両側対力・蓄積を手計算と比較する。線軸の向きと面順を入れ替えたときの符号、自由パッチの機構数（剛な2翼の理想ヒンジなら共通6＋相対1）と支持後の機構を検査する。各翼を同時に回す場合の仕事も照合する。

## 3　一方の曲げ回転が他方の drilling になるとき

|選択肢|採用例・出典|利点、欠点と本コードとの相性|
|---|---|---|
|A　6自由度・全体3回転、面別の相対 drilling 安定化（推奨）|T5 [R4]、Abaqus shell drill constraint [1]、OpenSees ShellMITC4 [4]|全体節点への力・偶力を保持できる。人工剛性が角継手のねじりを担う危険を係数感度と仕事で検出する必要がある。|
|B　5自由度の接線回転を独立未知量とし、継手で必要な回転だけ再構成|T5 の5自由度対照 [R4]、Maunder ほかの非共面・折れ線の回転論 [9]|人工仕事に依存しない対照を作れる。単独の面は法線回りを観測できず、ほぼ平行な2面では再構成の条件が悪い。|
|C　回転を膜補間・独立回転場に組み込む要素|Allman、Hughes–Brezzi、Ibrahimbegović ほか [11,12]、OpenSees ShellDKGT [4]|面内回転の近似そのものを改良できる。T5 の膜・せん断 tying、パッチ、既存出力を再検証する別の要素開発となる。|

**採用時の実装範囲。** Pᵢ=I−dᵢdᵢᵀ とし、曲げには Pᵢθ、drilling 安定化には dᵢ·θ と面内枠の回転との差を用いる。直交板では面1の接線回転が面2で法線回転となる。面2の人工反力で実継手のねじり剛性を同定しない。5/6自由度混在では面の接線基底に J の回転を射影し、転置で抵抗偶力を戻す。観測不能成分を零固定して剛性を作らない。解放軸と射影後の拘束階数が指定継手と両立しなければ未対応とする。

**受入試験。** T5 の既測 α=10⁻⁵, 10⁻⁴, 10⁻³ を感度系列として再利用し、別解法の5自由度対照を置く。α=0 は未処理の特異行列を解く設定にせず、零空間を明示して対照を組む。平面・直角・ほぼ平行の剛結／ヒンジを全体座標で回転し、固有空間、余剰零モード、支持変位、線ねじり、U膜・U曲げ・Uせん断・U人工を生値で比較する。物理仕事が零の場合は比を定義しない。人工仕事だけが伝達を支えるケース、解の係数依存が大きいケースに一般の合格を与える基準は未定。

## 4　何をどの位置・座標・平均化規則で比べるか

|選択肢|採用例・出典|利点、欠点と本コードとの相性|
|---|---|---|
|A　共通線の全体量と、面側で分けた局所量（推奨）|Abaqus HINGE の出力端・方位 [2]、Code_Aster の局所断面軸 [3]、折れ板の断面 GH [9]|力・偶力を同一点に移して釣合いを照合でき、断面の片側極限も残る。点・原点・軸・単位を保存する必要がある。|
|B　各面の中央面だけで比較|B-03 の中央面回復と T4 の断面力 [R2,R3]|既存 N・M・Q と直接照合できる。異なる中央点の反力をそのまま足せず、継手の偶力は再構成を要する。|
|C　節点へ外挿・平均した値で比較|Abaqus/CAE の領域別平均表示 [14]|格子の異なる可視化に便利。折れ目、材料境界、世代境界をまたぐと片側の跳びや符号差が消える。受入には生値も要る。|

**採用時の実装範囲。** 観測キーは施工世代、受理状態、継手 ID、有向辺の弧長位置、面群／翼、厚さ座標、面側。全体 XYZ の J・s・p で u [m]、θ [rad]、力 [kN] と偶力 [kN·m] を出す。線反力の密度と節点集約力を別列にする。面側は (ℓ,dᵢ×ℓ,dᵢ) の右手系（ℓ は面接線）で膜 N・横せん断 Q [kN/m]、曲げ M [kN·m/m] と方向を記録する。断面値は切断の外向きと基底を指定し、T4 の符号では Mₛ=Mₚ−eN。節点偶力の原点変換とは単位が異なる。二つの側で反力を比較するときは同じ J・基底・作用反作用の向きに揃える。剛結反力は各翼の消去前残差から求め、乗数解で検算する。

**受入試験。** 共通物理点へ各メッシュの面別場を補間し、点値、符号付き差、最大絶対差と面積／線長重み付き L2 を併記する。参照ノルム零は絶対差とし、相対欄を未定義にする。GP 生値は各格子に残す。平均が要る場合は同一面側、同一基底・参照面へ変換した同一領域内で ∫v dA/∫dA を計算する。折れ目上は左右二値を保存する。規則／歪み格子、座標回転、要素順・折れ線の向きの反転後に、スカラーエネルギーと変換したベクトル／断面テンソルを照合する。

## 5　作用面と、継手を横切る力・仕事の所有

|選択肢|採用例・出典|利点、欠点と本コードとの相性|
|---|---|---|
|A　実際の作用位置で積分し、腕で戻す（推奨）|T4 平面・T5 曲面 [R3,R4]、Code_Aster INF/MOY/SUP/MAIL と荷重移送 [3]、Abaqus 分布荷重 [14]|接線荷重・偏心反力・体積自重の偶力が残る。面側、厚さ積分、土との対、重複体積を指定する必要がある。|
|B　中央面の合力・等価偶力を入力|T4 の板 traction・重心自重と断面出力 [R3]、Code_Aster の面選択 [3]|平板・均質厚で既知の等価荷重を使いやすい。偶力や曲面の面積比を省くと別の荷重になる。元の作用面を記録しない入力では面別の仕事は未確認。|
|C　継手線に線力・線偶力を直接与える|公刊折れ板の部分辺上の線荷重 [9]、Abaqus の edge traction／edge moment [14]|実際の線載荷なら力の単位と積分区間が明確。隣り合う面の分布荷重をすべて線へ集約すると面の変形仕事が失われる。|

**採用時の実装範囲。** 面圧・接線 traction は宣言した面、土反力は tie の付着面または接触する物理面、板自重は材料体積の ρg に与える。T4 の均質平板では自重の合力は中央面。T5 では X=xₛ+(z−e)d の面／体積 Jacobian を使い、面の圧力方向はその面の法線から定める。厚さ写像が反転・重複する範囲は未対応。作用点 a の力 F、固有偶力 Mₐ を点 b へ戻す式は Mᵦ=Mₐ+(xₐ−xᵦ)×F。これは qᵦ=Tᵀqₐ であり、仮想仕事は各作用点と継手線で一致する。

土側・部材側・世代・面領域・相手・成分・荷重 ID で組立の所有者を決める。面 traction の境界は面積積分で零測度だが、明示線荷重は辺上で一回だけ積分する。有限厚の交差では面積・体積の重複は零とは限らない。切詰めた面と交差部材の範囲を別々に積分し、所有者不明なら保留する。tie の等反力、内部継手の対力は内部移送、接触は片側 traction と相対変位の仕事。土 RHS に移した同じ板荷重を「土荷重」に再加算しない。

**受入試験。** 一定接線力の腕偶力、腕と平行な荷重、純偶力、曲面の表裏圧力、自重と左右逆順の二面負担を個別に手積分する。任意仮想変位で元積分と全節点の和を照合する。剛結・理想ヒンジの許容相対運動で拘束仕事は零、線ばねには蓄積がある。各受理区間で外力・支持反力の台形仕事、物理ひずみエネルギー、ばね、接触の蓄積・散逸、drilling、残差を別欄に置く。瞬間 q·u と累積仕事を分け、設置値を含む q·u と設置後の増分からの内部仕事を混同しない。無応力新設時には現在の J・s・p、回転・d、ばね基準角を保存する。撤去の力の解放と累積値はイベント前後で分割し旧世代を凍結、再設置は新世代。途中棄却と同世代の別プロセス再開で全状態を照合し、腕・所有面・旧世代を書き換えた履歴の拒否を確認する。

**包括判定の提案。** 解の定義と参照値の適用条件が一致し、全節点の自由残差・拘束残差、全体合力・共通原点のモーメント、各翼の境界力、物理／人工仕事の内訳が独立再組立と整合することを要求する。絶対値、単位、正規化の分母を保存する。既知解誤差 E(h)>0 には p=log(E(h₁)/E(h₂))/log(h₁/h₂) を隣接区間ごとに表示する。既知解がない場合は共通点の隣接解差を別列にし、等比3格子で同じ場・同じ向きの減少を確認できた場合だけ自己収束次数を診断値とする。特異な端点は観測集合と距離を固定し、面別 L2 と局所ピークをともに報告する。ゼロ、符号反転、非単調、2水準のみ、参照の不確かさを解像できない場合は次数や数値受入を保留する。既存ゲートを元の対象で再実行し、B-03 用の量別許容値・必要次数・人工仕事許容割合は実装の結果を見る前に別途承認を得る。

**規模上限。** GPD WIN Max 2（利用可能メモリ約48 GB）で各経路を逐次実行する計画。格子ごとに自由度、行列格納量・分解時のメモリ、粗格子の実測時間から次水準の上限を見積もる。40 GB 超または1経路1日超となる経路は組まない。768／6144要素メッシュ、旧土系列の次水準や上限外の公刊細分化の再現は **規模上限のため確認不可・未達**。上限内で3水準を揃えられなければ2水準の差を保存する。非零偏心段差＋土付着＋施工まで同条件の公刊厳密解は未確認。旧数値、包括許容値の未定義、B-03 の未達判定をこの調査で更新する根拠はない。
