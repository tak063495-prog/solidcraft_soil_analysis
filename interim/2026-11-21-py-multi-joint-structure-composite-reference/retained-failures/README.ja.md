# 保持した既存試験・準備の失敗

既存Pythonの通常群初回は旧証拠未配置とCargo PATHで停止した。元Git blobへ一致する旧ファイルを配置し、通常2群を全件再実行した。初回の成功分は最終数へ加算しない。

平均応力・空間の封印証拠群は元の厳密条件で準備エラーとなった。各4メソッドの未実行をskipや成功にしない。平均応力は元archive/SHA照合後の分配の完全一致、空間は元測定JSONとのバイト一致が失敗箇所である。生差・再計測JSON・終了ログ・ID一覧を保存した。原因未確認で、旧参照や試験は編集しない。

ダウンロード中のIncompleteReadも復元ログに残す。再取得は指定コミットのGit blobと照合し、不完全なファイルを使わなかった。これらは数値停止・CI時間切れ・成功した解析件数ではない。初期の未絞込みfetchと省略blobを読もうとしたcheckoutの転送は準備段階で中止し、必要データだけを元blobへ照合して配置した。試験・解析のキャンセルを成功へ転用していない。
