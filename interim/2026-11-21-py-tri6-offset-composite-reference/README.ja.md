## オフセットの独立導出

局所右手系をx,y,z、法線 `n=(0,0,1)` とし、各節点の未知数を
`d_s=(u_s,v_s,w,θx,θy,θz)` とする。座標は付着面、板中立面は `x_p=x_s−e n`。
小回転の剛体アームより `u_s=u_p+θ×(e n)`、したがって

```text
u_p=u_s−e θy,  v_p=v_s+e θx,  w_p=w_s
T_i = [[I, e[n]×], [0,I]],   d_p=T d_s
δd_p=T δd_s
U=1/2 d_pᵀK_p d_p=1/2 d_sᵀ(TᵀK_pT)d_s
δW=f_pᵀδd_p=(Tᵀf_p)ᵀδd_s
K_s=TᵀK_pT,  f_s=Tᵀf_p
```

`β=(θy,−θx)` とおく。板厚方向座標ζを中立面から測ると、面内変位は
`(u_s,v_s)+(ζ−e)β`。工学せん断ひずみを使い、

```text
ε_s=(u_s,x, v_s,y, u_s,y+v_s,x)
κ=(βx,x, βy,y, βx,y+βy,x)
γ=(w,x+βx, w,y+βy)
C=E/(1−ν²) [[1,ν,0],[ν,1,0],[0,0,(1−ν)/2]]
A=Ct,  D=Ct³/12,  S=(5/6)Gt,  G=E/[2(1+ν)]
U_area=1/2(ε_s−eκ)ᵀA(ε_s−eκ)+1/2κᵀDκ+1/2 S γᵀγ
[N;M_s]=[[A,−eA],[−eA,D+e²A]][ε_s;κ]
M_p=Dκ,  M_s=M_p−eN
```

これは一定eの場合の式であり、段差・法線の不整合・曲面には使用しない。
引張正の板の符号と、圧縮正のMCCの符号を混ぜない。eの単位はm、許可範囲は有限 `|e|≤t/2`。

ν=0、幅1m、一定の付着面軸力Nと付着面曲げMを与える板帯では

```text
κ=(M+eN)/D,   ε_s=N/(Et)+eκ
片持ち: θy=κx,       w=−κx²/2,       u_s=ε_s x
単純支持: θy=κ(x−L/2), w=κx(L−x)/2, u_s=ε_s x
```

片持ちはx=0の全6自由度を固定し、x=LにN,Mを整合分配する。
単純支持は両端w=0、左端u_s=0、面内横変位と横回転・drillingを固定し、**両端に−M,+M**を与える。その他の辺は自然境界。面内Poisson連成を避けるためν=0を明示した板帯であり、一般νの自由側辺板に梁式を無条件適用しない。

## 別実装の小型数値参照

`reference.py`は、頂点3＋辺中点3の二次Lagrange多項式から36自由度の平面三角形を組み立てる。
膜・曲げ・せん断を全積分し、平面内の中立面スピンとのdrillingペナルティ
`(0.01 S)/2 [θz−(v_p,x−u_p,y)/2]²`を加える。この0.01は本参照器の数値定義で、本体の係数を変更したものではない。
本体MITCの結び条件・縮約・既存Python要素をコピーしない。
全積分による薄板lockingの可能性を残すため、厚さを固定したh系列だけを評価する。
固有値の零判定 `1e−10 max|λ|` と剛体残差は倍精度の数値診断であり、工学的受入許容値ではない。

`direct_energy`はT・B行列・Kを使用せず、`(ζ−e)β`の変位勾配を板厚3点積分してエネルギーを別評価する。
荷重を0→最終値まで比例載荷した仕事は `W=1/2 fᵀd`。板・Winkler・アンカーの弾性エネルギーをすべて含む総Uと比較し、ばね分も別欄に出す。
自由節点の残差を反力へ付け替えず、拘束反力と地盤/アンカーからの力を含めて全節点力・合力・付着面座標まわりのモーメントを検査する。
JSONの `all_node_force_residual_max_kn` と `all_node_moment_residual_max_kn_m` は並進・回転を別単位で保存する。

### Winkler：二次元の閉形式

領域L=2m,H=1m、E=200000kPa,ν=0.3,t=0.2m,k=100kN/m³、
`q=q0 sin(ax)sin(by)`、a=π/L,b=π/H、q0=1kPa。
境界はhard simply supported (`w=0, β_t=0, M_nn=0`)。
中立面の面内変位とdrillingを0とする膜自由の部分空間を、付着面では `u_s=eβx,v_s=eβy` の明示MPCで表す。
本体の土との付着拘束を代用する境界ではない。

```text
w=W sin(ax)sin(by)
βx=−a R cos(ax)sin(by),  βy=−b R sin(ax)cos(by)
ℓ²=a²+b², D0=Et³/[12(1−ν²)]
U/(LH/8)=D0 ℓ⁴ R²+Sℓ²(W−R)²+kW²
Π=U−q0 LH W/4
R=W/(1+D0ℓ²/S)
W=q0/[k+D0ℓ⁴/(1+D0ℓ²/S)]
```

W,Rの2変数に関する停留条件から得た式であり、PDE・境界条件への代入も新規検査で確認する。
数値側は三角形nx=2n,ny=n、h=H/n。L2誤差は節点だけでなく各要素内の別GL6積分で測る。
剛性・荷重の積分はGL5を固定。別に固定n=2でGL4/5/6を変え、積分誤差をhの次数へ混ぜない。静的線形問題であり、時間/荷重履歴刻みの系列は存在しない。

### 単純アンカー：ばね/トラス1本

ν=0の片持ち板帯、L=2m、幅1m、先端の合力P0=1kN。
中立面の曲げ剛性D=Et³/12、せん断剛性S=(5/6)Gt、端変位の柔性は
`c=L³/(3D)+L/S`。これは先端力による `M_s(x)=P(x−L)` と `γ=P/S` を積分して得る。
単純アンカーの軸剛性を `k_a=EA/L_a=100kN/2m=50kN/m` とし、
`w_tip=c P0/(1+k_a c)`, `P_anchor=k_a w_tip`。
板の付着面に作用するばね力を端辺へ一様に伝える、仕事共役の分配器を仮定する。
その伸びは幅平均 `gᵀd`、剛性はランク1の `k_a ggᵀ`。
端辺の各節点へ別々のばねを置いたモデルでも、集中点アンカー付きの一般2D板でもない。
単一部材の線形軸伸びだけを検証し、実アンカーの引張専用履歴、埋込み地盤、ロックオフ、塑性土との同時応答は未達。

### 水圧の等価節点力

単位直角三角形(0,0),(1,0),(0,1)上で、局所yを高さ、荷重方向を−zとする。
γw=9.81kN/m³。数値側は水面で湿潤多角形を切り出して三角形へ分け、元のTri6多項式を積分する。
解析側は各形状関数をx,yの単項式へ展開し、0≤y≤min(h,1),0≤x≤1−yで

```text
I_ab = ∫ x^a y^b (h−y) dxdy
     = 1/(a+1) Σ_{j=0}^{a+1} (−1)^j binom(a+1,j)
       [h hwet^(b+j+1)/(b+j+1) − hwet^(b+j+2)/(b+j+2)]
f_iz=−γw Σ c_ab I_ab
```

を評価する。乾燥、ちょうど接触、部分水没、全水没、上方水位を分け、全6節点の値と二次仮想変位の仕事を照合する。
中立面死荷重の付着面まわりの偶力は `(-e n)×(-p n)=0`。
**法線水圧では非ゼロeでも新たな節点偶力は生じない**。膜曲げ連成による変位と、面圧の幾何学的レバーアームを区別する。
一般接線tractionなら `(-e n)×traction` が生じるが、今回の水参照は法線圧だけである。

## 将来の本体CSV/JSON比較

`compare.py --reference ... --candidate ... --output ...`を用いる。
対応する同じ入力・同じnの独立JSONを参照にする。JSONまたは`metadata.json,nodes.csv,sections.csv`の3ファイルからなるディレクトリーを読める。
出力形式の実例は`results/reference/reference-output.json`と`reference-csv/`。

- 節点値は付着面の局所座標、変位3成分、回転3成分、支持が板へ作用する反力/モーメント各3成分。断面値は要素重心のr,sとN3、Mp3、Ms3、Q2。IDの重複・欠落・余分な点・列・NaNを拒否する。平均・補間・単位自動換算はしない。
- メタデータに要求方式と実際の方式を両方書く。`mindlin_tri6_offset`以外、方式欠落、旧CST/DKTや`mindlin_tri6`への黙示切替はe=0でも拒否する。e、厚さ、符号規約、単位、局所右手基底、法線、材料、荷重、拘束、設置基準、完了/キャンセル状態を照合する。
- `Ms=Mp−eN`の出力恒等式に反する曲げ基準・符号の取り違えも拒否する。この検査の128ε機械精度は丸め誤差用で、変位/断面力の受入値ではない。恒等式の検査には十分な桁数の生CSVを使う。
- 正常比較は全場の絶対差/RMS/相対L2/符号付き差を保存して**exit 2、accepted=null**。契約違反は**exit 1、accepted=false**。数値差が0でも合格にしない。差が非ゼロの場合も許容値を創作して不合格にしない。
