## スペクトル：零方向2本とFDの微小剛性

以下は再組立の2最小特異値（大きい方／小さい方）。単位はkN/m。

|接線|50桁|80桁|
|---|---|---|
|解析|6.0013e-47 / 5.8436e-47|1.9125e-76 / 8.0165e-77|
|FD h|4.01420399966445e-8 / 7.6585e-47|4.01420399966445e-8 / 8.3536e-77|
|FD h/2|1.00355100982493e-8 / 3.7825e-46|1.00355100982493e-8 / 1.5581e-76|
|FD h/4|2.50887753075535e-9 / 1.0630e-46|2.50887753075535e-9 / 4.8434e-76|

解析の3番目に小さい特異値は約0.103075655469。
50→80桁の解析行列差は約1.153e-44、FD行列差は最大約4.38e-43。
したがって最小値を1e-76という物理剛性へ固定しない。精度とともに0へ下がる方向である。
中央剛体空間に対する解析接触作用の非零特異値は約146087.466、4591.399、649.267、1.146755。
残る2方向は約1e-76。中央土塊には6剛体自由度があり、2点の最終すべり接線（各rank2）が4方向を拘束する。
この構造と残る46非零値の精度安定性から、**解析接線の真の零方向は2本**と分離できる。
両右方向の中央剛体空間との重なりは80桁で1。人工的な支持として認定していない。

FDでは2点のせん断半径方向に微小剛性ができ、中央剛体作用rankは5となる。
2点を結ぶ直線まわりの回転に対応する1方向はなお零。
非零の微小値のh→h/2比は3.9999999605、h/2→h/4比は3.9999999901。
50/80桁で一致し、**打切り誤差によるO(h²)のFD微小剛性**と判断する。
枝が固定されたCoulombの正規化trialせん断を中央差分する局所式とも整合する。
これは接触則の実際の半径方向剛性や新しい許容値ではない。

保存予測子前行列を**そのまま**SVDした倍精度対照では、ベクトル付き最小値は4.42841845e-11、
特異値のみは1.20592112e-11。同一配列でもSVD演算の丸め域にある。
元binary64行列を80桁へ正確に昇格しただけでは最小値5.13432195809e-12が残り、
JSON十進トークンを正確な実数とした行列では1.77104465343e-12となる。
既に行列に入った丸めはSVD精度だけでは除去できない。
高精度**再組立**では上表のように零へ下がるため、旧約4.43e-11を物理剛性とする解釈は支持されない。
12-20の約1.21e-11は過去の保存値として引用するだけで、今回の値へ付け替えない。

高精度FD hと元行列との差ノルムは約5.86e-7、解析と元行列の差は約1.01e-6。
同じ48DOFを維持した局所・バルクの丸めの差であり、新しい全体解ではない。
数値rank cutoff（n·eps·sigma_max）は精度ごとの**観測分類**。受入許容値ではない。
真の零の説明は構造・精度系列・残りのスペクトルを合わせたもの。

## 荷重投影と可解性

すべり接線は非対称なので、可解性には**左**零空間を使う。右投影も別記し混ぜない。
符号は本体保存値と同じ `r=外力−内力`。高精度再組立rと保存rの差は約7.4044e-14 kN。
解析2零方向は縮退しており、50/80桁で個々の基底は回転し得る。2次元の射影行列・投影ノルムを比較する。
各ベクトルの符号は右ベクトル最大絶対成分を正に固定し、生の符号付き成分も保存した。

|ベクトル|解析の左零空間2方向へのノルム kN|FD hの左真零方向1本へのノルム kN|
|---|---:|---:|
|最後の保存縮約残差|1.28440824292903936|1.27000127000190468|
|外力|1.28440824292904010|1.27000127000190551|
|誕生時の初期保持力|1.28440824292904414|1.27000127000190929|
|停止時に実際に有効な誕生保持力|0|0|
|再組立バルク内力|約1.56e-79|約3.52e-79|
|再組立接触内力|約3.93e-81|約4.72e-81|

初期保持力は約105.484 kN（この本体停止点の縮約値）。12-28の独立BIRTHの105.75888 kNとは別物であり上書きしない。
停止はBIRTH後のopen工程なので、初期保持力は解放済み。大きさが近いことだけで原因とせず、有効係数0を明記する。
解析基底での保存rの符号付き成分は約 `+1.273027863327314 / −0.170600684923465` kN。
FD hでは微小非零方向に約−0.191836667780819 kN、真零方向に約+1.270001270001905 kN。
外力・内力の符号付き投影の釣合い誤差は約1e-80、入力表現を替えてもkN規模の投影が残る。

**凍結した活動枝の線形化ではrが値域に入らず、Newton補正で打ち消せない。**
FDは片方だけを微小剛性で持ち上げ、もう1方向の不整合荷重は残す。
実際に解法へ渡された既存予測子後の丸め行列は形式上full rankだが、最小値は約3.8079e-8。
旧GMRES停止はその悪条件な系で発生した。今回、予測子を再実験したり高精度全体解で完走したりはしていない。

停止の局所機構は、開口・2点すべりで残った運動への**非零荷重投影**と、それを覆うFD微小剛性・丸めの相互作用である。
丸めは元行列の最小値・SVD値・悪条件な線形停止に寄与するが、荷重投影そのものを説明する単独原因ではない。
互いに相関する寄与を足して100%の原因割合にはしない。
