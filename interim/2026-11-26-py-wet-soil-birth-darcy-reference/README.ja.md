## 自由水面の問題・導出・独立離散化

断面積A=1 m²、底z=0、天端T=2 m、旧土/新土界面b=.7 m。
未知自由水面z=sは新設層の途中にある。飽和水理領域は0≤z≤s、乾いた上載土はs<z≤T。
K(z)=10⁻⁵ exp(αz) m/s、α=.5 または−.25 /m、底H(0)=1 m、
自由水面に流入r=10⁻⁶ m/sを明示指定し、p(s)=0、q(s)=−rとする。
側面は無流束、S=0。水面の位置は入力しない。

これは毛管帯・サクションを無視し、未計算の上部通過帯からの給水を**境界流束として与える**1D自由境界問題である。
乾いた上載土の透水/保水曲線やRichards降雨過渡を解いたものではない。
乾燥域p=0は領域定義であり、飽和解の負圧の切り捨てではない。
2D浸出面の相補条件・斜面地下水・一般3D自由水面の受入へ広げない。

確認済みDarcy式からq=−r一定、H′=r/Kとなるため、閉形式は

```
H(z) = 1 + (r/K0)(1−exp(−αz))/α
H(s)−s = 0
p(z) = γw(H(z)−z)       (0≤z≤s)
```

`exact_head/exact_surface` はこの式を評価する。
数値側は頂点中心の有限体積法を別組立し、区間面のKを中点評価、
T_i=K((z_i+z_{i+1})/2)/(z_{i+1}−z_i)、q_i=−T_i(H_{i+1}−H_i)とする。
内部行は流束差0、最上行は流入r、最下点は固定H。
SciPy疎直接解法で全Hを求め、外側Brent法でH_n(s)−s=0を解く。
閉形式の積分抵抗や水位を数値組立へ渡さない。n=8/16/32/64。
誤差は数値点の**同じ物理座標**で閉形式と比較し、次数はlog₂(E_n/E_2n)。
水位誤差と水頭RMSを別表示し、水理流束は水頭の中点Kと同じ保存的面流束を使う。

## 土BIRTH：1D独立静力学

γdry=17、γsat=20、γw=9.81 kN/m³、天端上載全圧P=3 kPa。
圧縮正の全鉛直応力を重量積分から、有効鉛直応力を数値pから別々に作る。

```
σv(z) = P + γdry[T−max(z,s)] + γsat max(s−z,0)
σv′(z) = σv(z)−p(z)
σtotal = σeffective + p
effective_body_z = −γ − dp/dz
                  = −γ + γw − γw dH/dz   (飽和域)
buoyancy_z = +γw;  seepage_z = −γw dH/dz
```

自作P1の仮想仕事で、旧土0..bと新土b..Tをそれぞれ組立する。
水理区間・水面・bで分割し、数値Hの区間線形再構成を明示的に使う。
この再構成でpとσv′は区間線形なので体積積分は端点平均で厳密にできる。
圧縮正→物理z方向力の符号変換は

```
I_eff = −∫ N′ σv′ A dz; I_p = −∫ N′ p A dz
F_weight = −∫ N γ A dz
F_p = −N p n A; F_eff = −N σv′ n A       (各境界で独立評価)
I_eff + I_p = F_weight + F_p + F_eff
I_p − F_p = ∫ N dp/dz A dz
```

全節点・合力を保存し、底反力を外力合計の負値から作らない。
浮力＋浸透力は有効応力式を使う別表現で、`F_weight+F_p`へもう一度加えない。
この1D静力学の鉛直応力は指定荷重下の厳密平衡場であり、変位・水平K0・接触すべり・塑性履歴の構成則解ではない。
力残差は丸め誤差域なので機械側の収束次数は未定義/null。水理の約2次を機械精度の次数に転用しない。

旧/新界面は機械節点IDを分け、水頭の共有と変位の接着を区別する。
活動面監査は**同じ誕生後水圧トレースを固定した位相監査**で、
旧露出面−pAを内部の旧側−pA/新側+pAへ再生成し、古い露出面荷重を残さない。
誕生前Darcyの再求解、地質形成、既存履歴の進展、保持力解放の施工経路は計算しない。

SOILはこの柱の鉛直不透水側壁（法線x、法線流量0、土側p・構造内部p=0）のトレースとして扱える。
水平のCONTINUOUS界面は水頭一致・両側水圧力対、PRESCRIBEDは同じ明示全水頭を与える場合を監査する。
`policies()`は意味と競合拒否だけを返す。SOIL水平障壁を通る鉛直流れ、異なる固定水頭での内部貯水槽再求解、
三方針の本体BIRTH成功を示すものではない。
