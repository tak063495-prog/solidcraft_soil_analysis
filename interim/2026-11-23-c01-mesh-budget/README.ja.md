# C-01 空間メッシュ比例の工程試行予算

開始時に取得した origin/codex/plastic-spatial-convergence の先端 SHA は `331328faf6c8a1f6abcffc74fa3ebfb40ad6fa79`。

2026-11-23 19:57 JST の決定に従い、`settings.attempt_budget_policy = "mesh_proportional"` を指定した工程の上限を `ceil(2065 × E / 12)` とした。E は入力メッシュの体積要素数（tetrahedra の行数）。Tet10 の角節点接続と高次接続は同じ要素を示すため1回だけ数える。未指定・`"fixed"` は2,000回。初期平衡と各施工工程で別々に適用し、受理・棄却の双方を数える。本体の再開時にも保存した入力と現在の工程回数を同じ規則で照合する。

湿潤経路の入力は12 Tet10、32接触GP、7工程で、N は各工程の荷重進捗の基準分割数。event4 はイベント予測と最少4内分割、WS は同じ event4 に粗経路変位の補間と能動集合 Newton を追加した方式。WS の初期変位は同じ実装の一段粗い従来予算の event4 完走解から得た。元の材料・接触履歴、力残差、すべり・散逸誤差の受理条件と基準点を保持した。[旧2,000回の全記録](../2026-11-23-c01-method-improvements/README.ja.md)・[再現手順](REPRODUCE.ja.md)
