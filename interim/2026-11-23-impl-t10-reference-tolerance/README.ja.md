### 比較方法と根拠

B-01 は T8 のハッシュ付き全18観測の符号付き変位を読み、円筒だけを EDF の独立な幅で再判定した。符号付き差は (測定−参照)/|参照|。屋根・半球の表の値は各原例の一貫単位系で記した。

B-02 は元の10×5区画を200枚の平面 Tri6 に分けた。厚さ各0.4 m、符号付き腕 ±0.2 m の層を既存 Rust 殻カーネルで別々に積分し、基準面で共有する6自由度へ組み立てた。L14を固定し、反対辺に −1 kN/m を一度だけ作用させた。A1 には各層1要素が接する。面内でアフィンな写像のため、膜・曲げ・横せん断の場は面座標で高々二次であり、非共線の6求積点で決まる二次多項式をA1で評価した。EDF の線形 DST は EFGE_ELNO の計算点に節点を選ぶ。本例でも指定節点・材料 x 軸・基準面まわりの M−eN を使い、層を足し合わせずに比較した。EDF は QUAD4/DST、本例は Tri6 の有限格子値である。[Rust 二層試料](../../examples/t10_layered_cantilever.rs)・[EDF の節点選択・固定版 72–83 行](https://github.com/Krande/code-aster-copy/blob/5f2556a0cb71bae14871734e76f2efba1e58d4af/bibfor/elements/dsqedg.F90#L72-L83)

B-03 は T6 の同一入力で本体の拘束消去と独立な乗数法を照合した。全体コンプライアンス fᵀu は本体と独立解の順に剛結 0.000142862／0.000142862、ヒンジ 0.000398515／0.000398515、ばね 0.000257868／0.000257868 kN·m。各法の翼別 N・M・M−eN・Q、線の変位・偶力、全体節点差は JSON に保存した。拘束角、解放偶力、ばねの積分の基準は既存の試験に従う。[T6 パッチ試験](../../tests/test_t6_offset_kink.py)

C-04 の EDF 入力から、モードIIの FT の3時点（5、15、20）の解析力と EDF 回帰値を再集計すると、符号付き差は +0.041100%／−0.009816%／+0.016237%。付着を持つ EDF 試料と理想 Coulomb パッチは個別の比較である。湿潤系列では同じ受理座標・水位・荷重係数を確認し、元の面・求積順でギャップ、有効圧、両面の法線・接線の内力寄与（b側 +w t、a側 −w t）、両系それぞれの最終小刻みの試行余裕・戻り後余裕、不可逆すべり増分、区間・累積散逸を比較した。[C-04 原票索引](../2026-12-19-c04-transient-water-cause-diagnosis/archive-index.json)

A-03 は T1b の各刻み e=ΔM+N−P、D=(P+N+|ΔM|)/2 を再集計し、|e|≤max(a,rD) を検査した。累積は独立端点差 |E| と Σ|e| の双方を max(a,r累積ΣD) で検査。検証用 (r各刻み,r累積,a)=(10⁻⁷,10⁻⁸,10⁻¹² m³)、実用用 (10⁻³,5×10⁻⁴,10⁻⁹ m³)。施工は137収支行のうち全域7行、固定土柱は3024収支行のうち全域112行。各プロファイルの超過0件。終端の全域累積 |E|／Σ|e| は施工6.22×10⁻²²／6.22×10⁻²² m³、固定土柱4.27×10⁻¹⁵／4.36×10⁻¹⁵ m³。[T1b 実装](../../tools/t1_water_balance.py)・[T2 配置と過渡施工の原票](../2026-11-20-impl-t2-soil-birth-hydraulic-init/README.ja.md)
