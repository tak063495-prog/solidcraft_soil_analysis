## 比較範囲と写像

既存の小さい固定水位 0.75 m、CONTINUOUS 静水圧、MC の**弾性バルク枝**と塑性すべりを持つ JOINT を使用する。初期平衡、shear、open、recontact、reverse、reload、return の全前史を毎回入力から新規求解し、確定した全受理点の全場を保存する。履歴場を細メッシュの初期値へ転写しない。

|---|---:|---:|---:|---:|---:|
|h0|12|54|324|32|1|
|h1|96|250|2592|128|1/2|
|h2|768|1458|20736|512|1/4|

`refine_tet10.refine` の一様 8 分割を 2 回適用した。親要素の子は連続した 8 要素、親面の子は連続した 4 面であり、元の要素・面の祖先を保持する。材料/領域・上下ボディ・拘束面・物理形状を維持する。分離面で同じ座標を持つ別節点を座標一致だけで結合しない。

- 接触の共通点は **全 3 水準の全接触 GP の和集合 672 点**。元の親面 ID と物理座標を保持し、各水準でその点を含む子面を親面内の重心座標から決める。同じ点を別の GP の位置へ近接移動しない。共有子辺は最小面 ID を選ぶ。局所 Tri6 面座標を `(r,s)`、collapsed 座標を `u=r, v=s/(1-r)` とし、16 GP から `u,v` 各 3 次の tensor Lagrange 多項式を一意に定義する。元の GP 自身では全接触履歴の標本を再現する。全 traction・jump・塑性すべり・累積すべり・仕事/散逸・水圧を同じ演算子で評価する。
- 全節点変位は **最細 1458 節点**の同一物理座標で比較する。各節点の祖先要素とボディ側を保持し、他水準の該当要素の Tet10 形状関数で評価する。細メッシュ節点を粗メッシュ節点だけへ間引かない。
- 材料の共通点は **全水準の全材料 GP の和集合 23652 点**。祖先要素を保持し、その点を含む子要素の自然座標を求める。各要素の全 27 GP から総次数 2 の最小二乗多項式で保存場を評価する。祖先要素を跨いで材料場を平均しない。応力・ひずみ・間隙比・間隙水圧・塑性ひずみを比較する。保存された全材料状態の相当塑性ひずみ・塑性仕事ゼロ、`last_return=elastic` も別に全件監査する。
- 開閉は共通点の再構成 gap の**厳密な符号**で比較する。元の GP の open/stick/slip enum は全て保存し、共通点では各子面内の最近 GP の**カテゴリ**として別に比較する。enum の数値補間や混合状態は作らない。両方法の不一致と、切替の前後区間を隠さない。区間中の厳密な切替時刻を主張しない。
- 節点力・反力は変位と双対の離散量であり、変位のように補間して点場とはしない。同一メッシュの本体対独立系では元の 18 場全てを比較する。異なるメッシュの水圧荷重は変位 prolongation の転置による**節点力の restriction**で照合する。

`common-coordinates.json` は全点・全節点の物理座標・親 ID と幾何再現誤差を含む。欠落・祖先外の点・非有限値・履歴欠落を拒否する。全 GP を含む quadratic patch、元接触 GP の標本再現、祖先を跨ぐ不連続場、領域外拒否を追加試験した。

## ノルム・次数と補間誤差の区別

各場を別々に、同じ物理点集合・同じ工程進行度集合・成分について `sqrt(sum((a-b)^2))/sqrt(sum(b^2))` と集計する。全点・全受理時刻を等重みとする**離散点 L2**で、面積分平均でも連続体積 L2 でもない。ゼロ参照の表示は既存と同じ分母下限 `1e-12` を使い、絶対差ノルム・二乗和・最大成分差を必ず併記する。異なる物理場の単位を混ぜて一つのノルムにしない。工程別・全点別の差/参照二乗和・最大絶対差も `*-entities.npz` に SHA と点数付きで保存する。

比較時刻は各経路の受理列の共通部分のみ。例えば同時細分化は全 3 経路を各工程 `i/16` に制限する。時間補間・イベント時刻整列は使わない。次数は同じ共通座標に制限した絶対差から `p=log2(||x0-x1|| / ||x1-x2||)`。差の方向余弦も保存する。同時系列の p は h と荷重経路刻みを合わせた傾きであり、純粋な空間次数ではない。外挿場・Richardson 補正値・新しい許容値は作らない。

**接触履歴は GP 間で厳密な連続場として定義されていない。** cubic 再構成は診断用の定義であり、開閉境界を跨ぐと traction の摩擦円・開口時ゼロ条件を保存しない。最近 GP による別再構成との差、共通点での法則違反の大きさを別欄に保存する。この差は補間感度であり、真の補間誤差の上界ではない。したがって表の接触 L2 を純粋な離散化誤差と断定せず、点ごとの収束認定にも使わない。

一方、このケースのアフィン Tet10 の弾性ひずみ・応力は要素内一次であり、総次数 2 の再構成で再現できる。間隙比は `(1+e0)exp(tr ε)-1`、間隙水圧は入力の `γ max(0.75-z,0)` を共通点で直接評価する対照も出す。保存 GP 多項式との差を測れば、これらの場の補間誤差とメッシュ差を分離できる。特に水位を跨ぐ粗要素の GP 圧力補間差を、affine-cut の物理荷重誤差へ読み替えない。

旧 [2 水準の親面平均](../2026-11-15-wet-joint-convergence/README.ja.md)（約 0.05976 / 0.06415 / 0.05160）は別の診断のまま保持する。今回の点 L2 と置換しない。

## 計算の範囲・失敗の扱い

本体は h0/h1 を全体 16/32/64/128/256、h2 を 32/64。独立参照は h0/h1 の同じ全体刻みを入力だけから求解する。固定空間系列 32・64、同時系列 12/16 → 96/32 → 768/64 を比較する。全体刻み 256 の h0/h1 は細かい時間の対照であり、「十分細かい」ことが証明された条件とはしない。h2 の 128/256 以上・最細独立 dense 系・6144 要素は PC 手順に回す。

初回 h2/32 は 900 秒予算で途中停止した。失敗 JSON・ログ・途中全場・実 checkpoint を `native-interrupted-raw` に保持し、その経路を成功へ変更していない。別プロセスが最後の封印済み checkpoint から完了まで続行し、停止前に既に保存されていた重複区間の全状態を照合する。完成した比較用履歴は checkpoint 前の確定 prefix と再開 suffix から構成し、由来・SHA・重複照合件数を `continuation-provenance.json` に記録する。最細 h2/64 の別プロセス再開一致はこれと別に検査する。

ビルド前の初期化は実行版未配置で失敗し、途中入力と失敗 JSON を保持した。旧証拠の取得前に始めた Python 群も証拠未配置で失敗した。正式全件検証は取得完了後に行い、これらを成功件数へ含めない。続行後の時間メタデータ出力では局所変数 `old` と参照モジュール名が衝突した。修正前ソース・失敗 JSON・ログを保持し、求解・保存場監査の完了を確認したうえで保存済み provenance から欠けた時間メタデータだけを復旧した。数値場は再作成・書換えしていない。
