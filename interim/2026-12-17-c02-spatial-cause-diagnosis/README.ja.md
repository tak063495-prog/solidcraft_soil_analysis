## 測定の定義と既存記録の保持

旧記録は [2026-11-19](../2026-11-19-wet-joint-spatial-convergence/README.ja.md)。固定32の塑性すべり点L2は **0.0699569→0.0418454、p=0.7350**、固定64は **0.0869719→0.0498609、p=0.7874** のまま。新しい集計の丸め差や別演算子の値で旧 JSON を置換しない。

同じ 12/96/768 Tet10、32/128/512 接触 GP の保存履歴を使う。全3水準の GP 和集合672物理点（親面 ID を維持）、全7工程、共通受理進行度のみ。時間補間・イベント時刻の整列・求解への履歴転写をしない。各物理量を分離し、差・参照の絶対ノルム、相対点 L2、最大差、3水準の差方向余弦を記録する。外挿・Richardson 補正・新しい受入許容値は使わない。

最近接 GP は所属する子面内で物理距離最小、同距離なら最小 GP ID。親面 cubic は collapsed 座標 u=r,v=s/(1-r) の tensor 多項式。P2 は子面内の全 GP と物理面積重みから総次数2の最小二乗 L2 投影。子面共有辺は最小面 ID。祖先を跨いで平均しない。カテゴリは最近接 GP の gap の厳密な符号として別保存し、enum を補間しない。

点 L2 に加え、全3水準の各 GP 面積重みを1/3ずつ配した共通測度による面積重み L2 を別欄に出す。この測度も有限個の求積点による観測で、厳密連続面積 L2 や元定義の代替ではない。多項式再構成が開口中 traction=0、摩擦円、散逸非負を破る量も記録する。方法間の差は補間感度であって、真の補間誤差の上界ではない。

全ノルム・内積は工程、受理時刻、共通点、成分を C 順に固定し `math.fsum` で集計する。Windows の集計順差を許容値変更で吸収しない。文書・テキストの照合は読み込み時の CRLF→LF 正規化を明示し、封印バイナリ SHA は生バイトで照合する。

## 768 Tet10 / 512 GP の参照水準としての信頼性

768を厳密解として扱わず、水準差と既存の入力のみの独立実装を分けて評価した。h0/h1の同一メッシュ・同一時間刻みの本体/独立比較では、N256の塑性すべり相対L2は2.21530e−6 / 2.24789e−6、tractionは1.17079e−6 / 1.89224e−6（元GPでの比較）。一方Dは0.00252156 / 0.00295661で、局所分割経路の差も残る。離散実装間一致を連続解の精度へ転用しない。

最細768では、既存N32→64のすべり相対L2が0.0569285885で、時間依存を除去できていない。3水準のtraction差は縮小しても方向が逆で、同じ先導誤差場を仮定する漸近領域は確認できない。768の独立全体dense系、N128/256以上、6144の追加水準は今回クラウドで求解していない。最細水準の誤差上界・参照解の収束は**未確認**。水準差だけで768を真値に置換しない。独立最細denseと6144の実行コマンド・予算・見る値は `REPRODUCE.ja.md`。
