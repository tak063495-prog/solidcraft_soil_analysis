## 閉形式・単位・境界条件

z上向き、圧縮応力正、長さm、応力kPa、重量kN/m³。幅1 m・奥行1 mの水平柱で
底z=0、既存/新設境界z=1.2、新設層上面T=3、K0=0.55を**入力指定**。
γdry=17、γsat=20、γw=9.81、上載有効圧s=5 kPa。K0の材料則は同定しない。

静水位wに対し、`p(z)=γw max(w-z,0)`。
`Lwet=max(min(T,w)-z,0)`, `Ldry=T-z-Lwet`から

```
σv(z) = s + γw max(w-T,0) + γdry Ldry + γsat Lwet
σv'(z) = σv(z)-p(z)
σh'(z) = K0 σv'(z),  σh(z)=σh'(z)+p(z)
```

これは水平層・明示水位・サクション0のベンチマークであり、自由水面や不飽和有効応力を解くモデルではない。
水位より上の水頭は不適用（JSON null／CSV空欄）。p=0は明示した乾燥領域の仮定で、未定義水圧の自動補完ではない。
完全水没w=3.8、部分水没w=2.1（**新設層の途中**）、w=1.2（境界）、w=0.6（新設層乾燥）を別ケースにした。
例えばw=2.1の新設層底ではp=8.829、σv=38.3、σv'=29.471、σh'=16.20905 kPa。

飽和Darcyは源項0、底H0・上HLをPRESCRIBED全水頭、側面無流束。
各層`[ai,bi],ki`に対し、保存則からq一定、`dH/dz=-q/ki`なので

```
R = Σ (bi-ai)/ki
q = (H0-HL)/R
H(z) = H0-q Σ clip(z-ai,0,bi-ai)/ki
p(z) = γw (H(z)-z)                 # 負圧なら拒否、maxで切らない
dp/dz = γw(-q/ki-1)
seepage_z = -γw dH/dz = γw q/ki
```

2層は境界z=1、k=(1e-5,4e-5) m/s、H0=4.4・HL=3.6でq=+5.333333333333e-6 m/s。
上下頭を交換した下向き流と、z=(0,.7,1.8,3)、k=(1e-5,6e-5,2e-5)の3層も評価する。
Darcy柱は全域飽和、`σv=s+p(T)+γsat(T-z)`。静水圧の部分水没柱とは別問題で、部分不飽和Darcyを作らない。
K0付き水平応力は**指定静力学場**であり、変位や塑性履歴を求める構成則解ではない。

## 全節点力・誕生面・水収支

矩形Q4をx-z断面に独立実装し、単位奥行で全節点x/z力を保存する。
機械側の旧土上面と新土底面は節点を分離し、CONTINUOUSでも変位を接着しない。
圧縮正応力を引張正の力積分へ変換して

```
I_p = -∫Ω grad(N) p dΩ,       F_p = -∫∂Ω N p n dΓ
I_p-F_p = ∫Ω N grad(p) dΩ
I_eff + I_p = F_weight + F_p + F_effective_boundary
effective_body_z = -γ - dp/dz = -(γsat-γw) + seepage_z  # 飽和
```

各積分は水位・透水境界・数値水頭要素境界で分割し、同じ未分割積分則の偶然の相殺を避ける。
側面K0トラクション、底の支持トラクション、上載圧を境界応力から別積分する。
底反力を単に外力合計の負値で定義しない。全節点恒等式、合力、原点回りモーメントを別々に出す。

部分水没w=2.1の旧土上面は誕生前に各節点`Fz=-4.4145 kN`の露出面圧。
同じ**明示水圧トレースを固定した位相監査**では、誕生後に旧土側-4.4145、新土側+4.4145へ内部化され、物理的な対応節点で相殺する。
旧露出面を外力にも残す二重計上をしない。独立な水平辺閉形式と新活動領域の面積分を照合する。
これは誕生前のDarcy再求解や接触開閉・変形・保持力解放の解ではない。

SOILでは明示した土側からpを取得し、反対の構造内部p=0と面荷重を分ける。
CONTINUOUSは両側の明示水頭一致を要求し、平均しない。
PRESCRIBEDは明示水頭と競合を検査する。内部水頭H=4をz=1.2に与えた別例では
底流出=-3.333333333333e-6、上流出=+8.888888888889e-6、貯水槽への流出=-5.555555555556e-6 m³/s。
最後の貯水槽交換を含めて収支0となる。CONTINUOUSの源項0と混同しない。
これらはトレース・力・流量の参照であり、三方針の本体BIRTHを受け入れた証拠ではない。
水収支は固定した活動領域の定常流入出を対象にする。BIRTH瞬間に新設間隙へ持ち込む水量・初期飽和度・水源の仕様は未定義で、
新領域の水量移送や過渡貯留まで閉じたとはしない。間隙率や初期水量を旧土から補完しない。

## 本体出力比較・拒否・許容値

`compare.py`は将来の出力を`wet-soil-birth-export/1`のJSONまたはCSV束へ明示変換して比較する。
単位・圧縮正・全水頭・z上向き・完了状態・世代・節点ID/座標/ボディ対応・全節点力を要求する。
水圧欠落・非有限値・未定義出典・補完/クリップ/旧履歴転用フラグ・不適用水頭の捏造・重複ID/JSONキーは拒否する。
`--history-before`は出力とは別に保存した入力スナップショット（`old`全状態と`new_ids`全ID集合）。
旧履歴の変更、新設ID欠落、旧ID流用、source_id付き転用、非ゼロ新設塑性履歴を拒否する。
自己申告の出典を偽造した秘密の補完まではCSVだけでは立証できない。本体アダプターは元出力と入力のハッシュ・実生成経路を別途保存する必要がある。
付属例のproducerは`SYNTHETIC_REFERENCE_ONLY`であり、本体と比較済みとはしない。

旧限定受入文書には再組立1e-10、非線形釣合い1e-8、線形1e-10、独立弾性相対1e-7、水頭差1e-8 m等の定義がある
（上記旧記録の「独立参照と保存再開」およびacceptance.json/tolerances）。これを保持する。
**A-03拡張の節点水頭・応力・節点力・流量・収束次数の比較へ適用する仕様は未定義**なので、
比較の各許容値欄は「未定義」、各`accepted`と総合`accepted`はnull。
数値が一致しても正常診断のexit codeは2、入力拒否は1。試験内部の丸め誤差チェック値は参照実装の健全性検査であり、本体受入値ではない。
局所的に相殺する改変力も全節点誤差で可視化し、収支だけで合格にしない。

MCCは既存文書の`p=tr(σ')/3`, `q²=3s:s/2`, `F=q²+M²p(p-pc)`だけを実装。
明示pc/e/M/応力を必須にし、無応力からpc/eを自動生成しない。K0からpc、鉛直OCRからpcへの推定はしない。
新設MCCのBIRTH初期化、古い材料の応力再配分・進展則、無応力MCC誕生、地質形成史は**仕様未定義**として残す。
旧履歴のJSON値・点IDの保存照合はできるが、その履歴の物理的妥当性・新工程での構成則進展を認定しない。
既存のMC/MCC構成則一般が未定義という意味ではない。「仕様未定義」はA-03拡張BIRTHにおける初期化・結合・履歴移送の契約を指す。
