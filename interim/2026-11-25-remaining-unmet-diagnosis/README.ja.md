各格子の全段階で最大自由力残差は4.35e−15以下。角度方向のみを倍にした4×2→8×2では生応力の差は改善しなかった。半径方向を倍にすると両角度水準で応力・変位が改善した。有限外周には各段で閉形式に整合するトラクションを与えており、今回の対照で変化したのは空間近似。場の未達には局所解像度と、場の受入幅が未決定という二つの理由がある。

1. 既存の物理境界と荷重を使い、半径方向の最初の帯を優先して細分する。次いで角度分割を片軸で増やし、a〜2.5aの共通点と帯の面積重みでσrr、σθθ、τrθ、ur、uθを個別に照合する。対称軸のゼロ量には固定物理尺度の絶対差を用いる。小型格子1個につき4線形求解。参照は閉形式なので同じ点の再採点は求解不要。精度改善の見込みは高いが、数値受入には場専用の量・尺度・許容幅の事前承認が必要。
2. 半径細分の効果が頭打ちなら円弧上の中間節点を持つ曲線二次要素を同条件で比較。曲面、変位補間、応力回復の寄与を分け、回復前の応力も採点。1要素の変位自由度は12→30、局所剛性の成分数は約6.25倍、全体系の時間は要計測。別入口と小型の比較だけを承認対象とする。Itascaは同じ二軸応力で閉形式・通常四面体・高次要素を比較している。COMSOLの孔周り局所細分はメッシュ設計の参考で、公刊モデルの遠方境界・許容幅を本件に転用しない。[Itasca、式と検証モデル](https://docs.itascacg.com/itasca950/3dec/docproject/source/examples/CylindricalHoleInAnIEM.html)・[COMSOL の Kirsch 例](https://doc.comsol.com/6.3/doc/com.comsol.help.models.sme.kirsch_plate/kirsch_plate.html)

## C-02　独立参照の成立条件

承認済みの二つの主量は接触面の面積重みL2と、各時点の符号付き面積積分の差の履歴L2。点L2は局所診断用。親面2枚・面積1 m²・共通160点、7工程×64時点で照合済み。本体の N128・12→96 Tet10 の塑性すべり差は点8.9233%、面積重み8.3128%、積分7.1746%。独立側で8.9232%、8.3127%、7.1746%。同じ96格子でN64→128の時間刻み差も面積重み6.8746%、積分3.6142%。同じ二格子、同じ投影・同じ有限時刻の二実装が近いことだけでは、両者に共通する離散化誤差を測れない。原票の連続参照・空間次数・GCIはいずれも空欄。実際の湿潤・反転履歴を再現する公刊値と受入幅は未確定。[比較原票](../2026-11-23-impl-root-causes-c/c02-results.json)・[承認済みの範囲](../2026-12-06-p6-01-status-reconciliation/ledger-ac-20261123.ja.md)

1. **独立した数値参照は条件付きで作成可能**。同一の初期条件、湿潤荷重、有限の法線・接線剛性、開閉・摩擦・すべり履歴を仕様から別実装し、体積側を高次要素、界面側を独立面積求積で解く。小型幾何で次数を2→3→4と変え、時間刻みを別軸で細分化する。既存の三次再構成や本体のすべり値を境界入力として流用せず、2親面・同じ448時点の2主量を直接求積。先に固着・滑り・反転の局所問題で符号・仕事を検算し、共通点の局所履歴も確認する。物理的なすべり面をまたぐ点で分類が割れたら位置の幅を残す。面積量への参照を得る見込みは中程度、切替線近傍の点値は低め。Puso・Laursenの重なり面の積分と、その二次要素への拡張は独立な求積法の根拠になる。市販・公開コードの既定の接触則をそのまま適用できる根拠にはならない。[摩擦付き面積分](https://www.sciencedirect.com/science/article/pii/S0045782504002518)・[高次要素への拡張](https://www.sciencedirect.com/science/article/abs/pii/S0045782507003477)・[GetFEM の弱形式](https://getfem.org/userdoc/model_contact_friction.html)
2. まず12要素相当・2時間水準×2次数で4経路、各7工程。必要な場合だけ第3次数と面積求積の追加水準を採る。次数を上げると四面体の局所スカラー自由度は10→20→35、密な局所行列の格納は概ねその二乗比。96要素までに限り、時間・空間・求積誤差を分けて保存する。限られた計算内で参照の不確かさを抑えられなければ参照待ちを継続する。専用の閉形式は確認できていない。参照解の生成と、要求精度・参照誤差配分の決定は別の承認事項。観測済みの8%や壁の3%から許容幅を決めない。

## 再現方法

Linuxでリポジトリルートから実行する。ロック済みのRust・Python環境を使用する。出力先は新規ディレクトリ。MCCの2圧密状態のうち再生対象はOCR 8のみ。KirschとT7の1経路ずつを逐次実行する。

```sh
set -eu
d=interim/2026-11-25-remaining-unmet-diagnosis
out=$(mktemp -d)
export OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 OMP_NUM_THREADS=1
cargo build --locked --release --lib --bin soil-fem-3d
rustc --edition=2024 -O -Dwarnings "$d/probe.rs" -L dependency=target/release/deps \
    --extern soil_fem_3d=target/release/libsoil_fem_3d.rlib -o "$out/probe"
mkdir "$out/trace"
"$out/probe" "$out/trace"
python "$d/analyze.py" . "$out/trace" > "$out/mcc.json"
python "$d/mesh_probe.py" . "$out/mesh"
python "$d/arch_probe.py" . > "$out/arch-run.jsonl"
python "$d/hole_probe.py" . "$out/hole"
python "$d/archive_metrics.py" . > "$out/archive-metrics.json"
```

T7は既存の分類関数が返るときだけ診断用に変数を読み、受理点・刻み選択・元判定を維持する。Kirschの物理座標の結果は `$out/hole/summary.json`。同じ外周荷重と平面ひずみ拘束を用いる。MCCは元の粗・細履歴との照合、全増分の座標、塑性誤差分解の和、独立求積との終端照合に失敗すればスクリプトが停止する。
