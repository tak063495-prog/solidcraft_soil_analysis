## 原因の切り分けと修正範囲

1. **局所MC return**：本体の同じ旧状態・ひずみ増分・保存分割数で独立局所積分を再評価した16,128材料GP更新の最大差は、応力6.36647e-12 kPa、塑性ひずみ2.53162e-17、相当塑性ひずみ2.45030e-17、塑性仕事5.10703e-15 kPa、間隙比3.10863e-15。これは保存状態を使う局所診断であり、新規独立3D求解へ数えない。
2. **接触更新と仕事**：同じ旧jump/traction・終点・実分割数で全8,064接触GP更新を再評価。traction最大1.13687e-13 kPa、塑性すべり4.60786e-19 m、累積すべり2.22262e-18 m、物理散逸7.97973e-17 kPa m。更新順・局所法則の不一致を示す証拠はこのケースではない。
3. **水圧荷重**：全受理点の物理水圧・水荷重は時間不変、入力からの独立荷重との差は丸め程度。本体対独立のGP水圧・接触物理水圧差0。今回の差を過渡水圧の誤差としない。
4. **実分割数の決定**：本体は予測変位で必要数を増やす際に2倍へ拡大し拘束開始へ戻る。独立系は収束候補から必要数を増やす別の方針。接触baselineの本体実数は1/4/6で、独立と一致しない。両方1の対照と同一分割の局所診断で差が消えることから、実分割方針・端点間履歴の寄与を分離した。ただし分割ポリシーを全3Dで完全に入替えた反実仮想試験は未実施で、一般の唯一原因とは断定しない。
5. **checkpoint状態欠落**：後述の全状態・全Run完全一致を確認した。今回の差の原因が保存漏れだとする根拠はない。

生産ソルバーの修正・明示オプション追加は採用しない。新規の観測用 `mc_plastic.py` は既存独立 `mc_reference.py` の派生で、投影乗数の非負値を直接代入し、収束検査を2e-11/1e-13から1e-13/1e-16へ**厳格化**した。主応力順序・yield・非負乗数の検査を保持する。独立線形解には元の真の相対残差1e-10を維持した反復改善を追加した。旧参照実装・参照値はそのまま。未収束・主応力順序停止・3.78e-10の線形残差失敗は保持し、緩和して通していない。
