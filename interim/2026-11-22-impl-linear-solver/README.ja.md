# NC 96 Tet10 の線形残差停止

PR #13 の作業起点は `518912cbf80b31e7a9b5736e338c8aa724681d77`。クラウドで停止付近を再現した。最後の棄却接線には弱い方向があり、LU の後退誤差は倍精度の丸め規模だった。同じ行列・右辺に補正を一度加えると、元の真残差は **1.09925e−10 → 3.04602e−11** になった。線形精度が棄却に寄与している。物理的な極限荷重は未確定で、NC-01 は未達・分類 D。

## 96 要素の停止位置と行列

[T9](../2026-11-22-spec-survey-t9-nc01-spec/README.ja.md) の PC 転記は実行版 e6181bae、受理176回、最後の受理進捗0.5647306442260742、残差1.093e−10、538秒・49 MB。PC の行列と入力 SHA は転記されていない。今回は指定 SHA に固定した観測用チェックアウトで既存の読取り専用 LU 観測器をビルドした。前後で82本の数値ソースの SHA-256 が一致した。実装は別チェックアウトに置いた。元入力の `inputs('midpoint')` を一回細分化し、250節点・96 Tet10 とした。既往の96要素手順で 100 kPa の面集合を上下・側面に分けた対照でも、棄却7件の行列・右辺・解・残差の JSONL は全バイト一致した。

元入力のクラウド経路は初期平衡8、載荷4、除荷2、撤去164の計178増分を受理した。最終受理 λ=0.5647292137145996 から λ=0.5647294521331787 を試み、真残差超過で二分を使い切った。この棄却で確定状態は不変。7件の線形棄却を各試行の記録と残差値で一対一に照合した。12要素の局所 fold 約0.95140には異なる離散化と履歴が対応する。

## 手法の選定と合否

**採用理由**　既存の部分ピボット LU と元の式をそのまま使い、既往12要素の棄却行列で一回の補正が従来ゲートを通ったため、超過時だけ補償残差を使う一回反復改良を選んだ。[12要素の既往実験](../2026-11-08-nc-compensated-linear-replay/README.ja.md)

|候補|判断の根拠|
|---|---|
|行列の平衡化|LAPACK DGESVX は行・列尺度に応じて平衡化し、条件を推定する。96終端の行最大値の比は約32。座標を変更せずに元基準を通せるかを先に検査した。[DGESVX](https://github.com/Reference-LAPACK/lapack/blob/6ec7f2bc4ecf4c4a93496aa2fa519575bc0e39ca/SRC/dgesvx.f)|
|同じ因子で残差を補正|LAPACK DGERFS は元の式の残差を計算し、既存因子に対する三角求解で修正量を得る。本実装では FMA で各積の丸め誤差を回収し、Neumaier 型補償和で b−Ax を評価する。分解・解ベクトルは binary64 のまま。[DGERFS](https://github.com/Reference-LAPACK/lapack/blob/6ec7f2bc4ecf4c4a93496aa2fa519575bc0e39ca/SRC/dgerfs.f)・[Ogita, Rump & Oishi, Accurate Sum and Dot Product, 2005](https://doi.org/10.1137/030601818)|
|真残差の再計算|PETSc のモニタは反復内のノルムと元の真残差を別々に取得する。NC の dense LU は既に後者を検査しているため、補償値を合否の分子に代入せず、補正後も同一の nalgebra 行列積で再検査する。[PETSc](https://github.com/petsc/petsc/blob/acdd273352fb8c470d1b112f768a3c3c17a9c41f/src/ksp/ksp/interface/iterativ.c)|
|前処理強化・直接法への切替・ピボット変更|対象は直接法で、Krylov 反復履歴はない。実ピボットと独立 LU の因子成長を計測でき、元の因子の再利用で全7件を検証できた。別の分解や前処理は導入しなかった。|

段階入力で `settings.dense_lu_refinement=true` を明示する。省略または false が従来経路で、false はシリアライズ時も省略する。疎 GMRES と同時指定すると入力エラーになる。新方式もまず既存と同じ LU 解を得る。その元残差が有限で許容超過のときだけ Aδ=b−Ax を同じ因子で解き、x+δ を検査する。合否は従来どおり **||Ax−b||₂/max(||b||₂, 1e−30) ≤ 1e−10** と有限解を要求する。特異・非有限・補正後超過は棄却。補正のために工程試行・Newton・二分の上限、物理入力、拘束、人工項を変更していない。

新しい最終試行の目標は 0.5647790431976318。通常 LU の 3.16599e−10 が補正後も **1.08826e−10** となり、既存のゲートで棄却された。確定状態は不変。クラウドと PC は初期入力のバイト・実行版が同一と確認できていないので、PC の進捗と残差をこのクラウド結果で上書きしない。

新方式でも観測器を別にビルドし、補正後にゲートを超えた4系を採取した。バイナリ SHA と実行時間を除いて全 Run が通常ビルドと一致した。最終接線はランク348/348、κ₂=3.529e6、σmin=0.01665、次の特異値6.136、独立 LU の最小絶対 U ピボット1.974。既定終端より弱方向が強まり、条件数は約3倍になった。保存した補正解の80桁残差は3.15883e−11、後退誤差は1.859e−17だった。補正解には元の行列積の評価丸めも効いており、既定の真残差判定では未達である。棄却接線から物理分岐・崩壊は同定できない。[新終端の行列・右辺・補正解](refined-terminal.jsonl)
