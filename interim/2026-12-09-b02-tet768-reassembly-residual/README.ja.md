# B-02：768 Tet10の再組立残差と空間細分化差の診断

**B-02全体は未達、`passed=false`。診断であり、合格化ではない。生産src、既定値、既存ゲート、参照、NCコード/設定、旧hash/snapshotは変更していない。**

PR #13、`codex/plastic-spatial-convergence`、起点 `1885f1f374ca417f6ceede181db2621015ccc0b8`。
保存先の2026-12-09は依頼ラベル、実施日は2026-11-13（日本時間）。マージしない。
元の [B-02](../2026-12-01-tri6-offset-composite-b02/README.ja.md) の失敗・限定受入を保持する。

診断の結論は次の3点である。

1. **残差超過は最後の再組立の和の順序だけでは説明できない。** 土の逆順/Kahan/拡張精度、板・梁の補償和/相対変位形式/拡張精度でも、保存された解の残差は残る。本体では線形停止精度だけを厳しくした入力対照で力残差が低下した。独立側は直接連立系と物理再組立の正規化が大きく異なり、小さい線形相対残差が物理再組立1e-10を保証しない。
2. **せん断・瞬間仕事の増加は比較点補間や荷重刻みが主因ではない。** 生回復点の再構成と解からの直接評価が一致し、4/8/16刻みの差は空間差よりはるかに小さい。支配的なのは角部への梁の点結合・先端荷重に対する離散応答で、接続回転の柔らかさと近傍せん断が細分化で増加する。
3. **明確な実装バグの確定や連続極限の発散証明ではない。** 3水準の診断である。回復法の交換、外挿、Richardson補正、新しい許容値による受入を行わず、生産修正を適用しない。

全数値と観測範囲は [measurements.json](measurements.json)、受理点別の詳細は [analysis](analysis/)、
荷重源・局在は [localization.json](localization.json)。再現コマンドは [REPRODUCE.ja.md](REPRODUCE.ja.md)。
