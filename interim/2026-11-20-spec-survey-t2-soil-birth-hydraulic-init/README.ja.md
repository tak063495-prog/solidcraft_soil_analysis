## 1　先行浸透計算と新設土の初期場

|案|採用例・出典|利点、欠点、本コードとの相性|
|---|---|---|
|A　配置時の σ′ と全水頭 H を別入力（推奨）|Abaqus の geostatic 初期有効応力・水圧 [3]、PLAXIS の新設土の指定状態 [1]、本コードの土のみの明示 H が部分ごとの先例。|締固め・搬入・敷均しを経た土の状態を指定できる。施工時測定または設計入力が要る。既存の初期応力6成分、基準配置、アフィン水頭・準備時保持荷重を利用できる。|
|B　水平堆積・一次元釣合いを仮定した K0 初期化|DIANA の新要素への側圧係数適用 [5]。PLAXIS 初期工程の K0 [2]。|層厚・上載・水位から再現可能。斜面、方向性のある締固め、初期せん断には別根拠が要る。既往 Kx≠Ky の定数入力だけでは自動化を検証できない。|
|C　層別の自重載荷・圧密で状態を形成|MIDAS GTS NX の自重・初期プレストレス [9]、OpenSees の対象材料での重力載荷後の段階切替 [19]、GeoStudio の段階盛土 [10]、Clough・Woodward の逐次盛立て FEM [13]。|非水平形状と施工履歴を表せる。排水条件・施工期間・材料則が要り、初期沈下や塑性仕事も経路依存。既に導入した自重を完成場へ再載荷すると誤る。|
|D　旧活動土の水頭トレースを境界に新領域の H を延長し、σ′ は別途指定|PLAXIS の前工程圧／定常再計算 [1,2] は近縁。この面からの延長と土量記帳を一体で採用した外部例は未確認。|連続する同種飽和層で接続しやすい。外部境界・透水係数・水頭基準がなければ延長は非一意。PLAXIS の「Interpolate」を旧非活動点のコピーと解釈できない [1]。|

**採用時の実装と判定。** 圧縮正、上向き z、共通基準面で飽和域は u=γw(H−z)、σ=σ′+uI。先行定常 Darcy の活動節点場と過渡 Richards のセル H・面トレースを入力種別と時刻で識別する。新領域では σ′ の6成分（kPa）、H（m）、配置、材料・水源を要求し、A の初版は完全水没した新規 MC に限る。旧場の支持域外を内挿した値で埋めない。持込水の状態と指定面水頭が不整合なら接続条件を明示して次の物理時間で緩和するか、その瞬間連続を要するモデルなら拒否する。定常解に経過時間や積算流入を与えない。[1–3]

受入用には独立な一次元飽和柱を二層とし、一定水頭の静水圧、および両端水頭差と各層の直列抵抗から H と Darcy 流量を得る。水平・無流の K0 対照では上載と全重量を深さ積分して u を引き、鉛直・水平有効応力を別計算する。過渡は飽和・一定容量の一次元拡散列で直前／直後／最初の正の Δt を比較。全 GP の σ′・u、自由残差、反力、旧セルの連続性、新設初期力・保持力と解放仕事を照合する。ゲージ違い・水頭欠落・新旧時刻違いも試す。

## 2　誰が面を所有し、いつ水と力を更新するか

|案|採用例・出典|利点、欠点、本コードとの相性|
|---|---|---|
|A　同時刻の活動変更・水量移送 → 力学再平衡 → 次の水理刻み（推奨）|土だけの施工記録、T1 論点8。ZSoil は掘削ごとに浸出面を移す [11]。この順序と二者の水量台帳まで同じ外部例は未確認。|面の誤所有、旧面荷重の残留、二重供給を一工程ずつ検査できる。急速非排水施工で応力変化が生む過剰間隙水圧はこの片方向モデルの範囲外。|
|B　新領域の定常水理を先に解き、確定水圧で力学を解く|PLAXIS の定常水圧生成、DIANA の流れ・初期平衡 [1,2,5]。GeoStudio には既存地盤で SEEP/W の最終水圧を SIGMA/W に渡す例がある [20]。|十分に排水した施工後の状態に適する。施工瞬間と無限時間後を区別し、初回定常場だけから移動水の積算量は決められない。|
|C　活性化を物理時間を持つ施工小段階にし、水・変形を同時更新|Abaqus の soils consolidation [4]、PLAXIS fully coupled [2]、GeoStudio の盛土・消散工程 [10]。|急速載荷と過剰水圧消散を表せる。施工速度・連成項・貯留／体積変化の整合と Δt 収束が要る。現行の土だけの片方向施工からは範囲が広い。|

**採用時の実装と判定。** 時刻 t の直前状態を保存し、要素・材料世代と新旧の面対応を確定する。面キーに隣接側・世代・役割を照合し、旧外面が内面に変わったら旧外水圧・流量境界を解除する。露出1側は明示外部条件、活動0側は無効。2側が活動した CONTINUOUS は共通水頭と反対符号の法線流量、SOIL は指定土側のみが水理を所有し相手の不透水構造への横断流量ゼロ、PRESCRIBED は各活動土面と指定リザーバの交換を記帳する。部分活動の接合、同じ外面への相矛盾する H、役割不明、無指定の露出条件は拒否する。[2,11] [T1 の面方針](../2026-11-20-spec-survey-t1-wet-joint-richards/README.ja.md)

追加水量と水源を論点6に従って一度だけ確定し、更新した活動域で重量、体積水圧内力、外水圧・接合水圧、接触初期力を再組立する。保持荷重は準備時内力−新物理荷重。施工解放率 λ の間は物理時刻・水状態と水量台帳を固定し、次の正の Δt で境界流量を積分する。工程途中で棄却・再開しても移送の二度目を発生させない。

二つのセルに一つの共有面を設け、露出→内部→再露出と左右交換を試す。独立した面表から owner 数・境界 ID・法線、内部流量対、面圧の合力とモーメントを検査。水源を搬入土／隣接セルに替え、外部正味流入の違いを検査する。水理の初回 Δt と力学 λ の分割を別々に半減し、静水無流と非ゼロ流束を含める。

## 3　新設要素が水面をまたぐ場合

|案|採用例・出典|利点、欠点、本コードとの相性|
|---|---|---|
|A　明示水面で上下に切り、上側の吸引を無視（限定推奨）|FLAC3D の水面・密度・飽和度の指定 [6] は近縁。Tet10 を水面で切る積分は本調査の提案。|静水圧だけを扱う A-03 の次の一歩として検査しやすい。毛管帯・乾湿履歴は表現しない。上側含水状態や湿潤単位重量を別途要する。|
|B　初期 H または含水状態と保水曲線から連続分布を求める|PLAXIS の新設時飽和度 [1]、van Genuchten の含水量–圧力水頭関係 [14]。|毛管帯と過渡浸透を表せる。材料別の残留／飽和含水量、保水・透水パラメータ、吸引の力学への伝達を要する。土だけの Richards の GP 出力と比較可能。|
|C　水面に適合する要素に分けて新設する|FLAC3D の高さ範囲ごとの密度指定 [6] は近縁。既存の A-03 は完全水没以外を拒否。混合要素の自動再メッシュを行う同等例は未確認。|単純な幾何なら片側ずつ検証できる。水位移動ごとの再分割、世代・接触・積分点の対応が重くなる。|

**採用時の実装と判定。** A は初期静水位 zw を境に、下側を u=γw(zw−z), Sr=1、上側をゲージ水圧 u=0、飽和度は明示した施工時 Sr とする。上側を完全乾燥とするには Sr=0 の入力が要る。これは毛管作用を除いた処方モデルであり、Richards 用の初期関係には用いない。粒子密度 ρs、間隙率 n、水密度 ρw を与えると空気質量を無視した混合単位体積重量は γ=g[(1−n)ρs+nSrρw]。上下とも全重量を積分し、水圧の体積内力・水に接する指定外面の圧力を別積分する。浮力を含む有効単位重量を同時に体積荷重へ入れない。独立に与えた密度・Sr・水量が両立するかを検査する。[1,6,14]

直線面を持つ単一四面体と12 Tet10 柱で、水位が要素外・頂点／辺／面上・内部にある場合を比較する。水面で切った多面体の体積・一次モーメントを幾何から求め、湿潤体積、水量、重量、重心、浸水面の圧力合力・作用点を独立積分する。切断位置を上下から近づけて連続性と二重面ゼロを確認。曲面や自由水面の位置自体が未知の経路には別参照が必要。B を選ぶ場合は静水 H 一定の吸引分布・保水曲線から θ(z) を積分する柱と、一方向浸潤の水量・水頭の細分化比較を加える。

## 4　新設 MCC 土の形成履歴

|案|採用例・出典|利点、欠点、本コードとの相性|
|---|---|---|
|A　材料試験・施工履歴に基づく整合した初期状態を配置（推奨）|FLAC3D MCC の初期応力・OCR・初期比体積 [7]。本コードにも同じ種類の材料点検査がある。|必要値・校正根拠をレビューでき、既存の初期保持力を使える。履歴が不明なら一意に定められない。|
|B　堆積・排水載荷・先行圧密・除荷の過程を小柱／層別施工で計算|層別盛立て [10,13]、MCC の圧縮・膨潤線 [7]。この組合せで同じ新設機能を持つ実装は未確認。|先行載荷が pc と e に及ぼす効果を追える。施工周期・排水境界・有効応力経路のデータが必要。p′=0 の新規 MCC を開始点にする方法は取れない。|
|C　締固め時のサクション履歴まで表す別の構成則|Alonso・Gens・Josa の不飽和硬化モデルと締固めカオリン試験 [16]。|吸引低下による変形まで評価したい場合に適する。飽和 MCC の状態変数では足りず、別の校正・検証課題になる。|

**採用時の実装と判定。** 圧縮正の平均有効応力 p′=tr(σ′)/3、偏差応力 s、q²=(3/2)Σᵢⱼsᵢⱼ² とし、初期 p′>0、pc>0、e>0、降伏面 f=q²+M²p′(p′−pc)≤0 を既存の材料検査精度で照合する。等方先行圧密圧力に基づく OCRp=pc/p′ と、現場の鉛直 OCR=過去最大鉛直有効応力／現在鉛直有効応力を区別する。q≠0 なら OCRp=1 でも一般には不適格。指定 σ′、pc と材料の正規圧密線から 1+e=vλ−λc ln(pc/pref)+κ ln(pc/p′) を照合する。λc は圧縮線の勾配。冗長に入力した e や OCR の不一致は自動修正しない。[7] [既存 MCC](../../src/mcc.rs)

堆積土なら排水条件と圧密試験、施工時に先行載荷した土なら最大荷重・除荷点と現在の応力、締固め盛土なら採取位置・乾燥密度・含水比と圧密試験を形成記録に付ける。密度だけから pc を推定しない。締固め後の飽和試料として校正できる場合だけ A に含める。形成前の塑性仕事と配置後に積算する仕事の原点を分ける。本コードの固定水理間隙率と力学の e は別管理なので、飽和初期の物量対応を宣言し、変形中の相互更新には別の連成仕様を要する。

受入は単一材料点の等方 NC 載荷と OC 除荷・再載荷（圧縮線／膨潤線、pc の保持・再硬化）、q≠0 の降伏面内外、p′=0、矛盾した e/OCR の拒否から始める。次に小柱で配置時の全 GP 状態、保持荷重解放後の釣合い、排水載荷歴と別プロセス再開を独立比較する。既往 p′=100、pc=200 kPa の妥当な seed も通常の BIRTH 入口では拒否された。材料点試験の成功はその解除条件の一部である。

## 5　撤去・再設置・材料置換の履歴

|案|採用例・出典|利点、欠点、本コードとの相性|
|---|---|---|
|A　撤去と再設置を別世代にする（推奨）|MIDAS の掘削後埋戻しと材料変更の注意 [9]、FLAC3D の null 化・新材料 [8]、T1 論点8。|同一座標でも別の土に旧応力・塑性仕事を付けずに済む。材料の製造・形成履歴と水の出所を新たに与える。既存の旧点保存・fresh 検査に適合する。|
|B　実体の残る休止／再開は全状態を保存する|Code_Aster の ETAT_INIT（応力、内部変数、前工程結果）[12] は解析継続の近縁例。本コードの checkpoint 再開。|同一材料・同一世代・同じ配置と境界を証明できれば経路が連続。物理的な除去なら保管中の変形・排水・搬出水の戻し方が必要で、単なる再開では扱えない。|
|C　項目別に引継ぎを指定する|Abaqus の多孔質材は再活性化で間隙率を初期値に戻し、飽和度は除去時の値を保持 [3]。土のみの MATSET に水頭保持／水量保持の例がある。|現位置改良に適する場合がある。e・Sr・体積の一部だけを引き継ぐと水量や降伏面との矛盾が起こり得る。異種材料間の塑性変数には対応則が要る。|

**採用時の実装と判定。** 同じ場所への埋戻しは新材料 ID／世代／配置基準を発行し、旧 σ′・pc・e・塑性ひずみ・塑性仕事・return 種別・Sr と水移送を撤去記録に凍結する。新世代には論点1・4の形成状態と新設水量を与え、旧世代の累積量を加えない。MATSET が現位置改良なら改良前後で同じ土が残るかを宣言し、個別の応力・内部変数の写像と水量方針を検査する。飽和で比貯留がゼロなら同じ水量に複数の H が対応するため、水量保持には独立な圧力基準も要る。変換未定義なら拒否する。旧接触面のすべり・力の扱いは T1 の接触世代に従う。[3,8,9] [土の水量変換](../../src/richards.rs)

小型の載荷→除去→別土を再設置→再載荷、別に同世代の保存再開、同位置 MATSET の水量保持／水頭保持を作る。旧 GP の履歴・旧面・新世代の原点を ID で照合し、異種 pc／塑性仕事の持込みを拒否する。水量保持は移送ゼロ、水頭保持で変わる水量は出所・行先で閉じることを調べる。除去直前／再設置直後／λ 途中からの再開、棄却後の再試行、外側 hash 再計算後の世代・台帳改変も確認する。

## 6　未定義水量と収支の合否

|案|採用例・出典|利点、欠点、本コードとの相性|
|---|---|---|
|A　定量評価では新設・搬出・内部移送を明示し、局所・全体で照合（推奨）|本コードの土のみの WaterChange と T1 の土／面台帳。Celia らの保存形 [15]、MODFLOW の独立収支 [18] は部分的先例。新世代まで同じ外部例は未確認。|水の増減の原因と位置が分かる。水量を決める材料則と供給元が必要。既存の added/removed、旧／新セル水量を土側の起点にできる。|
|B　水頭または圧力だけを規定し、貯留・水収支は適用外|A-03 の完全水没・処方水圧。PLAXIS の静水位による圧力生成 [1] は圧力規定の先例。|静水荷重の照合は可能。新設水量・通過水量の合否は判定不能で、要求が水収支なら受入保留。|
|C　外部リザーバだけに帰属させ、全体収支を検査|MODFLOW の外部境界とモデル全体の収支 [18] は近縁。施工分をすべてリザーバ供給とする外部例は未確認。|明示的に外部から充水する小型対照には簡明。内部転送の誤符号・局所欠損を相殺でき、一般の埋戻しの合格条件には足りない。|

**記帳と合否。** 非活動で水量の定義域外、静水荷重だけで量が適用外、活動中かつ必須なのに欠落、評価して 0 m³ と判明、の4状態を区別する。計算に必須ならイベント確定前に拒否する。既存記録の null は意味を保存し、後から水収支を合格にしない。基準密度一定の水等価体積でそろえる。現行 Richards のセル水量は Mᵢ=θs Vᵢ+Sᵢ（S は貯留オフセット）であり、飽和比貯留がある場合も含む。剛な空隙の含水体積だけを測る対照に限って ∫nSr dV と比較する。[土の収支式](../2026-11-29-richards-wet-joint-a04/SPEC.ja.md)

イベント番号・物理時刻・土／面世代・供給元・受取先・量を一組として保存する。搬入土中の水 B は外部供給、搬出水 R は系からの持出し。隣接土／容量を持つ界面からの移送は同じイベントで両側を −V/+V とし、B=0。外部リザーバの充水はイベント B か時間境界流入の一方にだけ計上する。正味外部流入 I は物理秒の境界流入−流出＋体積源の積算（イベント分を除く）。T1 と同じ符号で累積残差は **E=M土+M界面+R−M初期−I−B [m³]**。無容量面には独立貯留自由度がない。容量が必要で値が不明な面は全体系の合否を保留する。

局所は各セル・容量面で「水量変化＋積算外向き流量−体積源−イベント正味受取」、全体はイベント前後・各受理刻み・累積の残差を独立再組立する。例えば閉鎖二槽で旧槽から新槽へ v を渡せば全体水量変化0、外部搬入なら +v、同量搬出で元に戻る。これら、無流量、流入出の逆転、意図的な供給の二重計上、局所で +v/−v が相殺する改変、必須 null を検査する。符号・ID・一回性は厳密比較する。量には絶対誤差 [m³] と、ゼロでない移送量または総流通量を試験前に固定した相対誤差を併記し、無流・無移送時は絶対判定を使う。各上限は手計算・独立積分精度、丸め、物理 Δt／空間積分の細分化で分離した誤差を根拠にユーザーが事前指定する。既存土ゲートに加え、いずれかの必須局所・全体上限超過は不合格、新上限未決は受入保留とする。[15,18] [T1 論点8](../2026-11-20-spec-survey-t1-wet-joint-richards/README.ja.md)
