# 案1：Tet10辺で終わる部分亀裂先端

起点は PR #13 の `codex/plastic-spatial-convergence`、`3fb0f78b31e2f27ea391422086366ada99724400`。PLAXIS式の縮退先端として、宣言したTet10辺の両端頂点・中間節点だけを両側で共有する。XFEM、要素内部で終わる亀裂、亀裂進展、先端特異性の高精度近似は実装しない。PRをマージしない。

## 入力と検査

`tools/split_joint_mesh.py::split` の既存 `soil-fem-joint-split/1` に、次の明示形式を追加した。節点・要素番号は0始まり。`nodes` は分離前の実在する体積面の頂点3個、`owner_a` / `owner_b` はその面を所有する2要素である。同じボディ内でも指定できる。

```json
{
  "schema": "soil-fem-joint-split/1",
  "interfaces": [{
    "id": "Seam",
    "faces": [
      {"nodes": [6, 9, 10], "owner_a": 3, "owner_b": 13},
      {"nodes": [6, 7, 10], "owner_a": 4, "owner_b": 12}
    ],
    "tip_edges": [[7, 10, 35]]
  }]
}
```

`tip_edges` の順序は `[端点, 端点, 中間節点]`。先端は選択面集合の境界にある実在のTet10辺に限る。分離後に返す `summary.crack_tip_declarations.Seam` を、施工入力の `joint_system.joints[i].crack_tip` にそのまま設定する。そこには共有辺3節点と、**面集合全体の分離後 `face_a` / `face_b`・両所有要素**を保存する。準備CLIではこの宣言も `mesh.provenance.json` の `joint_split` に記録する。`examples/stages-joint-crack-tip.json` が完成例である。

未宣言面の節点スターを切らず、接着を保持する。既存の `body_a` / `body_b` による全面分離入力と既定動作は維持する。先端宣言がなければ共有節点を引き続き拒否する。Tet4先端、辺3節点の不足・誤った中間節点、内部辺を先端とする指定、非多様体の辺スター・分岐先端、実在しない面、重複面・曖昧対応、宣言外の共有、全節点共有でジャンプ自由度が消える面を拒否する。

Rustの `joints::Model` と独立NumPy参照器の双方で宣言を検査する。`−N_i + N_i = 0` を厳密に検査し、共有節点の係数を力・接線・接続自由度から除く。独立Tri6多項式による任意変位・仮想変位の仕事、合力・合モーメント、剛体運動不変性も試験する。verifyの許可リストだけを拡張する変更ではない。

## 支持と荷重

`ensure_supported` は共有先端を含む到達可能性だけを調べる。実際の支持は `rigidity::Geometry::constrained` の節点等値拘束と、圧縮圧力・摩擦状態に応じた接触支持行で区別する。直線共有辺でつながる二土塊は、下側を固定しても開口時に辺回りの1自由度を残す。無圧接触を支持と数えない。圧縮固着ではこのヒンジを接触が支持する。

両側活動中の内部面に外水圧・上載圧を二重載荷せず、片側撤去後は露出面の外水圧と接触力解放を再構成する。共有先端の存在によって接触支持を増やす処理は加えていない。

## 検証した範囲

小型の81節点・24 Tet10・648材料GP・32接触GPで、内部先端を持つ2面の亀裂、先端3節点共有、内部節点分離、未分離側接着、元の要素座標・材料・体積の完全一致を確認した。同一ボディ版も位相試験に含む。既存の部分Patch拒否例は、明示した適法なTet10辺だけを成功試験に分け、それ以外の拒否と全面未分離メッシュ拒否を保持した。

乾燥は圧縮固着32点、開口32点、正負のせん断ですべり32点となる別ケースを実行した。地盤を弾性枝に保つため、新しい検証入力のMC粘着力を `1e6 kPa` と明記している。入力から独立GL125体積積分・Tri6接触・Coulomb更新・Newtonで全節点/全GPを生成し、相対 `1e-7` で比較する。接線微分も相対 `1e-7`。初回の粘着力1000 kPaの開口例は地盤塑性が生じたため弾性比較を拒否した。失敗は保存し、独立塑性解の合格に読み替えない。

湿潤は完全水没・閉鎖固着・弾性MC地盤/構造に限定する。CONTINUOUSとSOILは非ゼロDarcy流れ、PRESCRIBEDは既存の固定水頭整合経路を含めた。独立水頭、物理面圧、土/構造の圧力区別、全変位・全材料GP応力・全接触GP、静水圧への復帰、片側撤去を照合した。水頭差の基準は `1e-8 m`。SOILの部分境界に対して線形水圧近似を用いた最初の参照は不十分だったため、独立Tet10水頭形状関数による積分に訂正した。この失敗も保存する。

乾燥と湿潤で意図した収束後棄却、棄却のない同じ受理列、途中工程からの別CLI再開を比較する。再開は `elapsed_seconds` だけを除くRun全体の完全一致を要求する。チェックポイントの外側ハッシュを再計算しても、先端宣言・面集合・所有側・GP配置の改変を拒否する。

局所h系列は24/96/288 Tet10（81/255/615節点）。亀裂口変位差は `5.1656e-6 → 5.2945e-7 m`、弾性エネルギー差は `2.3679e-4 → 1.0335e-4 kN m`、先端から0.5 m以上離れた同一領域の平均応力差は `0.35687 → 0.09356 kPa`。各メッシュで同じ独立弾性比較・再組立基準を満たす。これらは局所比較の観測値であり、新しい合格許容値や一般的な空間収束の完了判定ではない。特異な先端応力の点値は比較条件にしない。

基準は緩めていない。再組立 `1e-10`、非線形釣合い `1e-8`、線形残差 `1e-10`、独立弾性相対 `1e-7`、拘束 `1e-10 m` をそのまま検査する。新規小型入力は非線形許容値を `1e-11` に厳しくした。既存構造の並進/回転、板生値、水理の既存許容値は変更しない。

最終の件数・終了コード・受入値は `validation.json`、`acceptance.json`、各 `measurements*.json` を参照する。生入力/全Run/ログ/再開と失敗記録は `evidence.zip`、全エントリーのSHAは `evidence-manifest.json` に収録する。

### 過去の空間診断の隔離再計測

全Python試験の初回は、過去の空間診断が変更後の `joint_reference.py` を現在のソースとバイト比較して停止した。数値参照値や失敗記録は変更せず、`interim/2026-11-10-nc-spatial-release/remeasure.py` の再計測ラッパー1件だけを、SHA検証済みの封印ソースを新しい `-I -X utf8` プロセスで実行する方式へ修正した。元のラッパーは `retained-originals/` に保存する。

アーカイブに含まれない依存は、当時の `source-fingerprints.json` のSHAに一致するバイトだけを隔離ツリーへ補う。現行版が変わった `fem_reference.py` は、当時のSHA `79b8602a8a8b9f75d33720db45b383b4ba7476eab515be824950fbe152f937d3` に一致する元ソースを保持した。案3で追加した現行の既定板形式正規化を戻す変更ではない。測定値のJSON完全一致、全アーカイブSHA、不正な合格フラグの拒否は維持する。現在の実装を過去の参照値で認証せず、過去の `numerical_acceptance=false` を保持する。過去interimの変更はこの再計測ラッパー1件で、案3の30件・過去の全失敗JSON・参照値・アーカイブは保持する。

先端の分岐/重複はJOINT名ごとだけでなく宣言全体で検査する。既に対応付けた反対面も幾何候補から除かず、順序によって曖昧対応が隠れる場合を拒否する。両方とも修正前に失敗する再現試験を保存し、途中の全件再実行は中断扱いとして合格数から除外した。
