## 水収支の採用決定と実測

2026-11-20 16:57 JST にユーザーが T1b の検証用・実用用の両方を採用した。体積は m³、流入と供給を P、流出と搬出を N とし、ともに非負で記帳する。各刻みで e = ΔM + N − P、D = (P + N + |ΔM|)/2。判定は |e| ≤ max(a, r刻み D)。累積 E は初期・最終の水量と総流入出から再組立し、|E| と U = Σ|e| の両方に max(a, r累積 ΣD) を適用した。D = 0 の比は適用外。施工時刻での移送は体積のまま記録し、同時刻の解放増分に流量を重ねて積算しない。
