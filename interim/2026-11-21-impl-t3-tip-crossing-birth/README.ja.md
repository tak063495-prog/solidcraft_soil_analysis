# 先端を跨ぐ BIRTH と初期力（T3 実装）

2026-11-21 承認の T3 推奨案5件を、PR #13 の c65c89443e7e8be127d002e2bbf3760969798caa に追加した。対象は乾燥、非粘着、両側の所有要素と正の求積面積が定まる適合面。A-02 全体は未達。T3 調査時の「判断待ち」と旧 A-02 の失敗記録は、それぞれ当時の判定として残した。

## 施工時の動作と対応試験

|論点|実装した動作|検査|
