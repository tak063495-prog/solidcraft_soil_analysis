## 補間の変更が A1 の誤差に占める割合

格子・材料・断面・荷重・拘束・積分点・求解条件を固定した。各格子で既定と新方式を別々に求解し、各解の節点変位・回転を固定して両方の方式で A1 を読み出した。以下ではまず読み出しを既定に固定して求解時の方式を交換し、次にその新しい解で読み出しだけを交換した。誤差除去率は 100×(1−|新誤差|/|旧誤差|)。この問題・格子・測点での対照による割合である。

|---|---|---:|---:|---:|
|12×6|QX|+111.74412636 N/m|絶対 1.7×10⁻¹² N/m 以下|99.999999997%|

解析節点場を直接与えた対照でも、A1 要素の重心の QX は、12×6 で −424.647955 → −500.000000 N/m、18×9 で −466.510202 → −500.000000 N/m になった。新方式では両格子とも要素内6積分点で一定せん断を再現した。前回観測した重心差と根元差が異符号になる現象に対し、実際の求解を含めて補間1条件を交換した結果である。

## 方式と文献

既存の8係数の横せん断場と、各辺2点の接線方向の条件を使う。既定方式は残る2条件を重心のせん断2成分で決める。新方式では、各厚さ位置で同じ重心基底に写した生のせん断ひずみと仮定せん断ひずみの2成分が、それぞれ**参照三角形の面積平均**で一致するように決める。既存の6点則で補間側と観測側の両方を積分する。剛性、内力、応力、断面力は同じ演算子を使用する。膜の補間、材料・断面・せん断補正係数、剛性の面内6点・厚さ3点の積分は共通。[カーネル](../../src/curved_shell/mod.rs)

平面の一様片持ちでは w は三次、回転は二次。二次節点補間した w と解析 w の辺上の差は両端と中点でゼロとなる三次式で、辺上の積分はゼロになる。したがって発散定理により変位勾配の誤差もセル平均でゼロとなる。辺方向微分の誤差は辺上の2つの Gauss 点でゼロ。これらの条件と二次回転場から、解析節点値では一定の横せん断が再現される。曲面上の任意の解について同じ再現性を仮定していない。

- D.-N. Kim・K.-J. Bathe (2009), *A triangular six-node shell element*, Fig. 1・式(10)–(13)。6節点 MITC の既存の補間空間と辺条件の根拠。[T5 の文献確認](../2026-11-21-spec-survey-t5-curved-tri6-shell/sources.ja.md)・[論文](https://doi.org/10.1016/j.compstruc.2009.05.002)
- DefElement, *Nédélec (first kind)*、三角形・多項式副次数 k=1 の「DOFs」。辺上の次数1の接線モーメントと、内部の定ベクトルに対する2つのモーメントを用いる。今回の内部2条件はこの考え方に基づく。平面の二次生ひずみでは2点 Gauss の辺条件は次数1までの接線モーメントを一致させる。[固定版の定義・DOFs](https://github.com/DefElement/DefElement/blob/4f40dcc834653452cd27cf073ef8f2237c29c913/elements/nedelec1.def#L64-L72)
- Ko・Lee・Lee・Bathe (2017), *Computers & Structures* 193, 187–206、§3.3・Fig. 9・Tables 8–9。規則・歪み格子の円筒による比較を B-01 の回帰確認に用いた。公刊の MITC3+/4+ と本6節点方式は節点数・補間が異なる。論文の値を A1 の参照値には用いていない。[著者公開版](https://web.mit.edu/kjb/www/Principal_Publications/Performance_of_the_MITC3+_and_MITC4+_shell_elements_in_widely_used_benchmark_problems.pdf)

## A3 と B-01 の回帰確認

開始コミットと変更後の release バイナリを同じ Linux 環境でビルドし、同じ入力を実行した。片持ちの既定出力は10×5、12×6、18×9 の3つすべてで標準出力の SHA-256 が一致した。A3 の既定の差はそれぞれ −0.520785%（未達）、−0.481233%、−0.428878%（後二者は0.5%幅内）。新方式の A3 は12×6 で −3.921249999999287×10⁻⁵ m、18×9 で −3.921250000002612×10⁻⁵ m。どちらも同じ純曲げ参照 −3.90625×10⁻⁵ m に対し −0.384000% で、既存0.5%幅内だった。

B-01 は標準の屋根・円筒・穴あき半球の18条件と、追加の円筒2条件を再実行した。既定では20/20で変更前と一致した。出力を得た17条件は入力ハッシュ・全フレームのハッシュ・測点変位が一致し、半球で棄却された3条件は診断文まで一致した。旧円筒6点は3%超過の記録を保持する。追加円筒2条件では新方式でも C 点を照合した。

|円筒の C 点|既定の相対差|新方式の変位 m|新方式の相対差|既存3%幅|
|---|---:|---:|---:|---|
|正則16分割|+0.158015%|−1.793909294×10⁻⁵|+1.692827%|両方式で達成。新方式では絶対差が増加|
|EDF 原接続364 Tri6|−2.371831%|−1.797175277×10⁻⁵|+1.513849%|両方式で達成|

屋根・半球の新方式での精度は未評価。これらの既定結果に対する比較は、参照幅の新設や半球の受入を含まない。[全ケースの照合原票](regression.json)

## 選択と再現

本体 CLI では `curved-shell CASE OUTPUT --shear-mean`、片持ち例では `t10_layered_cantilever 18x9 --shear-mean` で選択する。省略時は従来の重心補間。チェックポイントを再開する場合も同じ選択を指定する。新方式を入力ハッシュに含めてモードの混在を検出する。Rust からは `Kernel::with_shear(..., ShearInterpolation::ElementMean)` を使用できる。[CLI](../../src/main.rs)・[チェックポイントを含む回帰試験](../../tests/test_b02_element_mean_shear.py)

リポジトリルートから以下を実行する。出力先は新規ファイルを指定する。回帰比較には開始コミットを別の作業ディレクトリに取得し、同じ Rust・Cargo.lock で同じ release ビルドを行い、その release ディレクトリを PARENT_RELEASE に指定する。最大648要素、今回の PC 実行は0件。

```text
cargo build --locked --release --bin soil-fem-3d --example t10_layered_cantilever
python interim/2026-11-24-b02-a1-shear-mean/study.py a1-replay.json
python interim/2026-11-24-b02-a1-shear-mean/regression.py PARENT_RELEASE target/release regression-replay.json
```
