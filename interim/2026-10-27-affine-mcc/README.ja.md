# 再開後の途中成果（2026-10-27）

ボディ属性からのMCC一次初期応力場、実SolidCraftの局所掘削途中での協調保存と別ワーカー再開、公式GPUの地盤/梁/板/断面表示を追加しました。無荷重掘削底面の粗密対照でも5工程の監査と保存再開が合格しました。面積平均底面隆起は23.837/23.850 mmです。

固定ソース591件のRust253件（無視0）・Python114件とfmt/clippyが合格しました。公開準備で変更した説明文はsnapshot-statusに列挙し、コードは検証版と同一です。SolidCraftの60ファイル差分は、実画面検証をした57ファイルと後続の試験/参照修正を区別し、全体CIの結果確認を継続しています。

元の中点参照のドリフト失敗、pcの厳密比較の不合格、空間収束の未達も残します。独立RK4は小さい二層地盤で検証し、大きい実壁の計算を継続中です。二次精度材料積分は別の研究用試作で、本体FEMへ未接続です。完成版ではありません。[詳しい進捗](../../docs/PROGRESS_20261027.ja.md)。

inputsは同じ実CADメッシュでの底面無荷重対照です。ビルドしたCLIで `solve-stages inputs/mesh.json inputs/ground.json inputs/stages-coarse.json <新しい出力JSON>` を実行できます。細かい施工刻みにはstages-timefine.jsonを使います。独立参照はtools/run_mcc_structural_reference.pyを使い、入力/出力/積分法を明示します。原入力・検証要約・試験ログを公開し、実行ファイル、全runデータ、所有ジョブのトークンを同梱しません。各報告の元パスとSHA-256を保持しています。
