# SolidCraft実画面と生値・改変拒否の追加検証

2026-10-30。Native73/Python628のソースは前の[固定版](../2026-10-30-native-source-point-view/README.ja.md)と同じです。今回の追補は表示と検査の証拠であり、材料則やFEMの精度を追加認定するものではありません。

自作の専用Windowsアプリを起動し、実CADの11ボディと、8,061 Tet10・217,647積分点・832板の受入済み結果を開きました。元結果1,459,184,313 bytesと45.3 MBの表示パケットの結び付きを保持しています。

- 掘削後の鉛直変位を「Stage increment」で表示し、上面と中央X=5m断面で底面隆起を確認しました。画面の範囲は約−0.397111～+12.8286 mmで、APIの範囲と表示精度内で一致します。
- 山留め壁の局所Mxxを3D表示しました。範囲は約−65.9243～+49.5484 kN m/m。板ごとの生のDKT標本を表示し、別板との節点平均は行いません。
- 画面から取得した積分点0の19項目は公開APIと完全一致しました。板0の全生値・設置基準・局所軸・標本も一致します。板照会の表示倍率はGUI1、API12.5で意図的に異なり、倍率メタデータだけを別に確認しています。API値は既存の独立GP/板VTUとの比較を完了済みです。
- 専用アプリをAlt+F4で通常終了し、プロセス消滅と入力・実行ファイル・表示manifest・元監査の不変性を確認しました。

画面記録はローカルで保存し、ハッシュをgui/terminal.jsonに収録しました。上流の生成画像非コミット方針に従い、画像やexeはGitHubへ含めません。GUIに断面面積の数値表示はないため、18 m²という面積検査は公開APIによる別の検査として記録しています。

実結果の複製で、再署名したactive数不整合、最後の値なら一致する重複JSONキー、8 KiB超のdescriptor、JSON意味を変えない元結果1 byte変更の4種類をNativeが拒否しました。複製の検証証明書を意図的に変更して内部検査に到達させた陰性対照です。実解析用パケットや元結果は変更していません。複製の巨大な結果本体は公開物に含めません。

検証ハーネスの初回失敗も残しました。過大ファイルの拒否文言の期待違い、表示倍率メタデータの全一致要求、補助比較のプロパティ名誤記を修正し、製品コードや元結果・閾値は変更していません。
