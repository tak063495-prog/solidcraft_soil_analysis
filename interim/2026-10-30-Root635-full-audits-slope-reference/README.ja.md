# 本体635版・大容量監査・2D斜面との比較（途中成果）

P0〜P6全体は未完了です。前回までの記録を保持し、合格と未達を分けて記録します。

本体へ14ファイル追加・7ファイル変更の保存形式/検証環境/監査改善を正式採用し、実際の本体環境で全219件のPython試験が合格しました。95個のRustソース、Cargo、ツールチェーン、CI定義、解析バイナリは変更していません。Root635/source.zipは試験時点の全635ファイルです。公開用READMEの追記は、この試験時点から文書だけの差分です。元621版をWindowsのGitHub Actionsで検証した記録は別に保存し、新635版のリモートCI合格とは扱いません。

実14,909 Tet10解析の全5工程について、公開APIの525照合と、実3D画面の掘削変位・断面・壁のMxx・積分点/板の生値を確認しました。これは容量対応Native版の実画面です。新しい所有解析の完了判定版や非同期読込み版のGUI検証は別です。元画面では大容量読込み中に応答が一時停止したため、非同期読込みを開発中です。スクリーンショットはローカル保存のみです。

元14,909要素の全600項目相当の数値監査は、全5工程の力・地圧・塑性履歴・生VTUを含め、元レポートと完全一致しました。8,061要素でも最適化した幾何監査の全レポートが元版と一致し、同じ入力を使用しています。観測されたピークワーキングセットは元版約6.49GB、改善版約1.27GBです。これは同一入力の記録であり、専有環境の速度試験、改善版14,909要素の実測メモリ、一般10万要素の証明ではありません。

独立2D参照は公開済みExcel計算の固定コミットから取得しました。元200 Q8・661節点・800積分点を別計算で再組立てし、力・全3D主応力・面外応力・ひずみ・Jacobianを照合しました。新たにExcelを実行した結果ではありません。せん断符号を逆にした対照計算は不合格になります。参照の探索区間は物理的破壊限界として採用していません。

同じ断面・材料・荷重・係数1.35を3Dの1,200 Tet10に対応させ、全積分点の独立監査は合格しました。しかし全661点を深さ3面で照合した変位L2差は約15.6％で、事前設定の5％基準は不合格です。最大変位差も約20.4％で10％基準を満たしません。応力平均差は約1.13％でした。基準や係数は変更せず、2,400/9,600要素の細分化、載荷増分だけの変更、材料積分幅だけの変更を別々に検証中です。原因を特定した、一般空間収束が成立した、安全率が求まった、とは扱いません。

同じ斜面の塑性履歴を含む87.5％載荷保存点から再開し、計算時間記録828項目だけを明示的に除いた全Runが一致しました。3,368,366値、うち3,129,161浮動小数値を符号ビットまで比較し、実際の切戻し5回で採用履歴が変化しないことも確認しました。この再現性合格は、上記の変位精度不合格を解消するものではありません。

残件は従来の全35必須項目を維持します。一般空間/境界収束、MC/IDHの広い塑性域、物理的上限を区別するSRM、構造/接触/水との全体連携、実地盤校正、一般CAD10万要素の全経路、入力UI・永続面参照、新PC/別GPU・完成配布などが残っています。本体の新規所有解析、修正版Native全体CI、実非同期読込みと実画面はobserved-pending.jsonに記録した別のゲートです。

evidence-driversは保存構成とハッシュに結び付く検証コードです。実行ファイル、依存wheel、数GBの生結果・VTU・保存点は含めません。週の残り利用量が20％を切った場合は、新しい長時間処理を始めず、採用済み保存点と検証結果を保全して安全に休止します。
