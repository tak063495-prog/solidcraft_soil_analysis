## 論点ごとの推奨一覧（ユーザー判断待ち）

|論点|推奨案|理由|
|---|---|---|
|1　停止の定義|終了理由と物理分類を別々に保存する|平行2面で証明されたのは、非平衡点の固定接触枝で補正方程式が不整合になることまで。|
|2　平衡枝|最後の受理点から比例荷重の擬似弧長を診断用に試し、単調な区間だけ局所変位制御で照合する|元の力の釣合いと拘束を保ちながら荷重の折返しを通過できる。|

|6　参照解と受入|解析解、公刊例題、入力からの独立解、元問題の刻み・メッシュ系列の順に照合する|分類器の正しさと、元の境界値問題について実証できた範囲を別々に判定できる。|

## 1　停止をどう定義するか

|選択肢と採用例|利点|欠点・本コードとの相性|
|---|---|---|
|A　既存の終了状態を報告する。FLAC3D の不釣合い力・局所／平均比 [12]、MIDAS の収束規準 [18]|真の線形残差、非線形残差、刻み・反復上限のどれが停止させたか監査できる。|数値手続きが止まったことだけで物理原因は識別できない。現行の cutback、line search、timeout、入力拒否をそのまま記録できる。|
|B　除荷の連続や剛性指標で破壊候補を通知する。PLAXIS の弧長・Safety の自動検出 [11]、強度低減の別例 [18]|候補区間を絞れ、多数の受理点を調べる負担が小さい。|強度低減係数と施工荷重係数 λ は意味が異なる。製品の閾値を移植すると、接触状態の切替・前史依存を誤判定する。|
|C　終了理由＋平衡枝に基づく物理分類（推奨）。Abaqus の停止条件と経路出力 [7]、固定枝の診断 [R2–R5] を組み合わせる本調査案|同一記録に「真の線形残差超過」と「物理判定 D」を同時に残せる。|再出発・独立解析が必要。旧 Run から取得できない欄は未取得とし、後から既存の終了コードを書き換えない。|

**採用後の試験。** 終了理由、最後の受理点、失敗試行、根拠と適用範囲を記録する。元の入力・拘束・前史・受理基準で別制御が同じ枝の停止区間を越え、両側で釣合いと場が再現できれば、その区間で元の求解法に起因する停止を支持する。力制御で越せない fold を弧長で通過した場合は fold と元解法の停止を併記する。局所限界点を「全系の物理崩壊荷重」とするには、対象とする荷重制御下の安定性・到達可能な枝・機構を定義し、独立の根拠と系列収束が要る。意図的な反復打切り、正則な一自由度問題、後述の fold、凍結接触枝を別々に入力する。

## 2　どの平衡枝を追うか

各施工段階内で、既存の死荷重、変化する比例荷重、保持力の解放と拘束を明記する。λ の定義は段階ごとに固定する。BIRTH/DEATH による次元・世代の変更を単一の滑らかな曲線として補間しない。

|選択肢と採用例|利点|欠点・既存構造との相性|
|---|---|---|
|A　荷重制御＋現行の自動刻み [11,12,R1]|現行の受理・棄却、再開、真残差をそのまま比較できる基線。|荷重に対し枝が折り返す区間を単調増分だけで通過できない。最小刻み到達は臨界荷重を与えない。|
|B　弧長制御（推奨）。Riks、Crisfield、Ramm [1–3]、Abaqus [7]、OpenSees の球形制約 [10]、NC の移動接平面 [R4]|変位と λ を同時に解き、荷重減少区間も追える。既存 NC の独立診断を対照にできる。|球形制約には複数根があり、接平面でも予測方向と尺度が必要。拘束式の正則性・枝の滑らかさは接触イベントごとに点検する。NC 専用解放式は移植しない。|
|C　節点変位／局所相対開口の間接制御。OpenSees DisplacementControl [10]、DIANA の間接変位・CMOD [8]、Code_Aster PILOTAGE [9]|機構が既知なら物理量で比較でき、弧長の単位選択への依存を点検できる。|制御量の経路微分が零になる、または対象接触が世代を替えると制御不能。平行2面の相対変位は面対・法線・符号を固定し、支持拘束の追加にしない。|
|D　擬似過渡・粘性安定化。PETSc TSPSEUDO [14]、Abaqus の接触減衰／自動安定化例 [7]|不安定区間の前後にある定常状態を探索できる。|人工慣性・粘性と時間尺度が経路・散逸を変え得る。不安定静的枝の独立参照には使えない。既存 NC では却下済み。T7 の推奨に含めない。|

**採用後の実装と参照。** 最後の受理 checkpoint を複製し、元の境界で R(u,λ)=0 と接平面制約を同時補正する隔離入口を設ける。変位・回転・荷重係数の尺度、前接線との内積による進行方向、弧長と局所接触小刻みを保存する。各試行は受理済み内部変数から積分し直し、棄却時は全 GP と世代を戻す。状態切替は両側を局所化し、各側の釣合いを取り直す。小型円弧で荷重制御・弧長・単調変位区間を同じ枝で比較し、A-01 の最後の受理点からは両実装がそれぞれ自身の前史で追う。

## 3　接線・仕事・局所化のどれを判定に使うか

全体の一意性・安定性と局所条件の理論的背景は [19,20]。以下の採否は対象の離散方程式と既存記録から判断する。

|選択肢と採用例|利点|欠点・適用条件|
|---|---|---|
|A　最小固有値と LDLᵀ の慣性。Code_Aster CRIT_STAB、Abaqus *BUCKLE [7,9]、DIANA の負ピボット [8]、Higham [13]|対称な物理自由度系では正定値性の喪失、負方向数、臨界モードを相互に照合できる。|自由部分へ縮約し、乗数・既知剛体モード、単位系を明示する。最小代数固有値と零に近い固有値は異なる。置換付き LDLᵀ の 2×2 ブロックは各固有値の符号を数える。線形座屈の荷重倍率と現平衡の接線固有値も別量。|
|B　行列式の符号・対数絶対値。特異性に基づく座屈式 [7]、音響テンソルの行列式 [6a,6b]|小次元の解析反例では零点を検算しやすい。|全体 det K は尺度・次元に依存し桁あふれや同時偶数交差の見逃しがある。音響テンソル det Q と別物。一般の A-01 に単独採用した例は未確認。|
|C　一般接線の最小特異値と左右弱空間。非対称の本体・独立行列 [R3,R5]、拡大系 [4]（A と条件分岐して推奨）|右が弱い運動、左が不整合荷重を表す。対称化で消える情報を保持できる。|特異値には符号がなく、安定・不安定の向きを決められない。非正規行列は小特異値と固有値の零接近が一致しない。複素固有値を実部順に並べて静的崩壊と判定しない。|
|D　二次仕事と音響テンソル。Hill [5]、Rudnicki–Rice／Borja [6a,6b]、NC の GP 解析 [R5]|許容擾乱に沿う全体仕事、材料点の負方向、局所化方向を切り分けられる。|保存弾性なら全ポテンシャルの第2変分を扱える。非関連塑性・摩擦では一般にそのポテンシャルはない。正値性の十分条件が失われても即崩壊とは決まらない。|

**採用後の診断。** 力と変位が仕事共役になる縮約・無次元化を宣言し、物理残差の整合接線、予測子後の実解法行列、弧長拡大系を別に出す。対称性のずれをノルムで併記する。一般系では小さい特異値の列、左・右特異ベクトル対の残差、左空間への R と ∂R/∂λ の投影を記録する。対称系では正規化計量を固定して枝上の固有値を対応付け、その符号・負の慣性の推移を照合する。乗数系の鞍点による負方向、T5 の drilling 成分を物理不安定に数えない。

全体二次仕事 δuᵀKδu は対称部だけを測る。材料では応力・ひずみの増分仕事を GP 別と体積積分で、接触では適合する片側摂動で traction と jump の増分仕事を面積積分する。これは累積摩擦散逸とも異なる。局所化は材料枝・応力測度を明示し、方向 n ごとの Q(n) の特異性を評価する。有限方向サンプルで全方向の安全は保証できない。対称対角の単一／二重交差、2×2 不定ピボット、非対称な左右零方向、解析と FD が異なる既存48自由度で検算する。

## 4　fold・分岐・判定不能の境界

|選択肢と採用例|利点|欠点・本コードとの相性|
|---|---|---|
|A　受理点の λ(s) の増減反転で折返し区間を示す。Riks [1,7]、NC [R4]|既存履歴から臨界点の両側を候補として保存できる。|サンプル最大と真の極値は異なる。活動枝の角や複数零方向もあり、型は確定しない。|
|B　単純 fold の拡大方程式と左右零方向（推奨）。Moore–Spence [4]、NC 近傍の rank 検査 [R5]|滑らかな一変数荷重経路なら、折返しが特異な平衡点として局所的に識別できる。|左右1次元の零空間と非退化性が前提。A-01 停止点は非平衡で零方向が2本あるため、その点への適用条件を欠く。|
|C　分岐候補からモードで別枝へ切替え（B と併用）。BifurcationKit の単純分岐予測子 [15]、Abaqus の不整を与える後座屈解析 [7]|異なる平衡解を作り、親枝との接続と機構を比較できる。|幾何不整を恒久入力した例は別問題。初期推定だけを摂動し、元の完全系で再平衡する。分岐後の動的選択は別途必要。|
|D　必要な証拠が欠けるときは型を保留（推奨の既定）。既存 NC の A/B/C/D [R5]、平行2面 [R3]|未試行と否定を区別し、候補・局所機構・停止理由をそのまま使える。|得られるのは判定可能な範囲まで。枝探索が失敗しても別枝の不存在は証明できない。|

**採用後の分類規約。** R はここでは内力−外力、K=Rᵤ、q=Rλ とする。既存保存 r=外力−内力の投影値は原符号を保持する。滑らかな受理枝上で Kv=0、wᵀK=0、左右零空間が各1次元なら、経路接線は Ku′+qλ′=0 を満たす。wᵀq≠0 は λ′=0 を強制する。さらに wᵀRᵤᵤ[v,v]≠0 と正則な弧長補正、両側の λ′ の反転を照合して単純 fold を判定する。wᵀq=0 は分岐の候補条件に過ぎず、高次退化もあり得る。零方向が複数のときは全左空間への投影と対応する部分空間を保存し、この単純点判定は保留する。

分岐候補では親枝の接線から独立な分岐方向を求め、±ε を初期予測にのみ加える。ε の縮小系列で元の R・境界・片側接触条件を満たし、臨界点に接続する別枝を複数点追えること、同じ親枝への戻りやモード符号の取り替えでは説明できないことを検査する。解析対照は R=x²−λ（fold）、R=x(x²−λ)（主枝と ±√λ）、R=x³−λ（退化、単純 fold としない）。これらは式から作る単体試験で、A-01 の参照値ではない。NC の分類 A（物理限界）・B（分岐）・C（数値失敗）を支持する根拠が揃わないときは D を保持する。

**包括判定案（ユーザー判断待ち）。** 同じ物理枝・制御・単位で、既存の非線形／真線形残差、接触不等式・世代、全体仕事収支、独立全場、再開・棄却整合を順に照合する。臨界荷重は最後の受理点・候補区間の両端・推定値を分け、細分ごとに区間幅、ピーク差、モード主角、追跡した固有値の誤差と固有対残差を示す。非対称系では対応する左右特異空間も追う。解析解がある場合は同じ計量の誤差 E(h) から隣接格子の観測次数を求める。既知解のない2水準は実差のみ。刻み／格子で枝や判定が変わる、誤差が参照の不確かさ以下で分離できない、厳密臨界点が未確認の場合は未達の欄とその理由を残す。量別の誤差上限・必要次数・許容主角・臨界区間幅は未設定であり、採用時に結果を見る前に決める。
