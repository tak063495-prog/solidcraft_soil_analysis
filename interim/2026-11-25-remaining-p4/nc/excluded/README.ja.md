ゼロひずみ増分で評価した接線から再開した予備計算は、荷重減少の向きが同じでも、MCC の除荷方向を選び得る。特に fine448 と aux480 の Δλ は P3 の入射割線と整合せず、物理的撤去区間の下限を越えたため中断した。aux448 も同じ初期化である。3列とも下降枝の成績・到達値から除外し、原票と起動時のスクリプト nc_zero_probe.py を保存した。採用列は親の全状態一致を検査した再生から得た入射割線を使う。

fine-extended の初回は指数メタデータを材料状態の JSON と一緒に読み込んで材料入力形式の検査に失敗した。再実行ではメタデータを材料状態と分け、同じ P3 保存点からやり直した。起動用の time コマンドが存在しなかった3件のログは checks/ にあり、これらはソルバーを起動していない。
