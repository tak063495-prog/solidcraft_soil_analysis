## C-02　採用参照との差が増える原因

P4・P5 と固定参照との差のうち、reverse と reload の2工程に、場の二乗差の 76.7%・74.9%、面積分の二乗差の 74.0%・69.8% が集まった。幅 0.1 m の外帯は共通求積で面積の 29.1% を占め、場の二乗差の 50.0%・47.7% を担った。同じ N256 で P3→P4 とすると外帯の寄与は 58.2%。これに対し P4 の時間格子変更では外帯は 11.8%、reverse・reload は場の二乗差の 30.8% で、差が蓄積する場所も異なる。面積分には空間的な相殺があるため、外帯率は場に対してのみ算出した。

P3 の同一 P3・Q10・N256 で Rust 本体と既存 Python 経路を突き合わせた P3 原票では、両量の相対差は 2.5×10⁻¹⁵ 以下だった。接触則そのものの不一致を主因とする証拠は得られなかった。両実装は同じ平面、水圧荷重、完全次数の体積基底、自由な内部変位の静的縮約を使う。次数を上げると面の変位分布と縮約剛性も変わる。接触の法線剛性 1,000,000、接線剛性 200,000 kPa/m、摩擦係数 0.3 は共通。Rust は各能動点で本体則を呼び、Python 参照は閉じている経路長に対して接線予測・Coulomb 円への射影を独立に実装している。双方とも固定した親履歴から Newton 試行を評価し、受理時にジャンプ・トラクション・すべりを更新する。履歴は各自の能動面点に所属する。符号付き面積分はその点の履歴を積算し、場の比較は各自の変位で受動 Q6 点を再生する。両者間の状態補間はない。Rust は Q10、参照は各面を64個の等面積三角形に分け、各小三角形上に正の対称7点則を使う。非線形な接触境界の面積分には次数5多項式の厳密性だけでは誤差保証がない。[本体](../../src/joint_p_cycle.rs)・[独立局所則](../2026-11-25-approved-six/c02_reference.py)・[面積分と履歴の再生](../2026-11-25-remaining5-p2/c02_face.py)

MOOSE の penalty mortar でも接線ペナルティの選択が固着・すべり精度と収束に影響する。INL の定式化は面区間上で積分して法線ギャップと接線相対運動を重み付けする。今回の比較でも剛性を固定し、局所すべり履歴と面の合力を別々に検査した。外部資料は方法の照合に用いた。これらのソフトで本ケースを計算した結果は含まない。[MOOSE PenaltyFrictionUserObject](https://mooseframework.inl.gov/source/userobjects/PenaltyFrictionUserObject.html)・[INL/RPT-22-69312](https://inldigitallibrary.inl.gov/sites/sti/sti/Sort_63602.pdf)

## C-01　荷重経路と予算を交差させた比較

**固定予算では元経路でも全場ゲートが通らなかった。** 元経路の reverse/reload は −0.10/+0.10、別経路は −0.075/+0.060。P3 の 2.186/+0.670 は別経路のまま水準別予算に戻した対照である。今回追加した元経路固定予算を含めると、予算の与え方による再現性の違いが両経路に現れる。[4条件・22場と工程別の原票](c01/summary.json)

固定値は丸め前の 9.5367431640625×10⁻¹¹ m。N256・512・1024で、元の水準別すべり予算のそれぞれ 1/16、1/4、1倍となる。散逸予算はともに 0.01/N² kPa·m。すべりと散逸を別々に、1全歩と独立2半歩の端点で比較する。この予算は各増分の局所上限であり、全工程の符号付きすべりの誤差を均等配分する式ではない。固定値への変更は主に粗い水準の棄却・二分履歴を変える。N1024 の元経路再計算は同条件の P2 保存すべりと一致した。別経路 N256 の再計算は P3 の保存マニフェストと全22場の SHA-256 が一致した。固定予算の元経路は20連続場中3場が減少かつ同方向、6場が両差ゼロ。両荷重経路で接触・材料分類の隣接不一致は共通座標でゼロだった。

端点を選ぶ条件は、粗終点・中点・細終点で一度解いた自由力残差比が 10⁻¹⁰ を超えたかどうかである。各再求解は同じ親から行い、細終点には受理候補の中点履歴を渡す。この選択に接触状態の切替や符号付きすべりの反転は直接入らない。別経路の N1024 reverse は1,024試行で粗終点・中点・細終点の再平衡は0/1,024/1,024回、reload は1,439試行で37/81/80回。最多は open の1,582試行だった。試行数の多い工程が全域の差を発生させたと解釈することはできない。[本体の選択と予算式](../../src/stages_joint_path_error.rs)・[別経路 N1024](../2026-11-25-remaining-p3/c01/fixed/summary.json)

別経路の固定予算では recontact の時点で粗差と細差の余弦は −0.3951。そこから reverse に持ち越した場を各時刻から差し引くと、残差ノルムは reverse の全差の 0.58% / 0.54%（粗差 / 細差）、reload でも 1.18% / 2.12% にとどまった。つまり逆方向の水準間誤差は反転前に成立し、その大半が多数の後続座標に残った。水準間で分類が揃っても、工程内で蓄積したすべりの符号と量は揃わない。

固定予算で最初の4工程のすべりは両経路で全3水準とも完全一致した。N256 では open の8～11/256で32点すべてが開き、recontact の236～239/256で再閉鎖した。元経路は reload の216～232/256で32点が再び開き、return で再閉鎖した。別経路では reload 中に再開口する点はなく、return は閉じたまま固着からすべりに移った。N256 の共通点で、shear 終端の合計すべり方向に増分を射影し、絶対値が固定すべり予算を超える時刻を抽出した。再接触中に逆向きすべりが始まり、reverse 中に継続する順序は両経路で共通。reload の正向き活動の開始は元経路の152/256から別経路の195/256に遅れ、return の負向き活動も49/256から104/256に遅れた。これはアンカーで観測した活動開始であり、サブステップ内の厳密な事象時刻は主張しない。

独立 N1024 の別経路上で open、最初の再閉鎖、reverse 中央、reload 中央の4試行の親・接触分割・外力を固定し、最弱・最強特異ベクトル方向の ±10 μm から再平衡した。16解すべてで分割は十分、自由変位差最大 1.72×10⁻¹³ m、すべり成分差最大 6.91×10⁻¹⁴ m。接線の最小特異値は 2,964 kN/m 以上（丸め値）、対称部の最小固有値は 1,359 kN/m 以上。元経路の既存12初期値と併せても、これらの親で近傍の複数根が原因という説明は支持されない。独立解の同一親での局所再現性、本体の有限3水準の傾向、全経路の極限の一意性は異なる問いであり、最後の一意性は未証明。[別経路の全初期値](checks/alt-local.log)・[元経路の検査](../2026-11-25-remaining5-diagnosis/c01-branches.json)

**次案。** recontact 終盤の同一親で、開閉座標と符号付きすべり差が最大の増分を選び、再平衡前後の局所誤差と後続への伝播を比較する。全域に厳しい予算を一律に配るより原因を識別できる見込みがある。固定親の検査は各事象数求解で済むが、予算配分や重要端点の選択を変える試験には2経路×3水準の全場再採点が必要。今回の元経路固定予算は各291.8～444.9秒、最大 RSS は約40 MiB。新しい制御の実装・採否と判定基準はユーザー判断とする。

## NC-01　再開条件と材料棄却の切り分け

最細・補助の2経路を P3 の折れ点から再生し、保存変位、λ、活動1,296点の全履歴、累積弧長がそれぞれの保存点と完全一致した。そこで得た直前の**入射割線**を保存して継続した。96 Tet10 のうち48活動、348自由変位と λ を未知とし、外力は元の物理荷重＋(1−λ)×単一保持荷重。各反復で物理行と拡大系の真線形残差、受理時に力残差と弧長残差を検査した。ゼロ増分で評価した接線は、不可逆な材料で異なる方向を与えた。この予備計算の数値は下降枝の判定に使っていない。[再生](nc_secant.py)・[割線からの継続](nc_restart.py)・[除外した試行と理由](nc/excluded/README.ja.md)

補助終端 λ=0.5484663961271269 から、P3 と同じ共通応力単位で幅 0.02 m から最小幅まで二分した17試行はすべて点351の初回降伏残差で棄却された。親の pc=3.20083×10⁻²⁹³ kPa。2⁴⁴⁸倍した計算単位でも pc²=5.41253×10⁻³¹⁶ は binary64 の非正規化数で、隣接値の間隔は pc² の約9×10⁻⁹に達する。局所式は応力の二乗とその差を含み、初回降伏の正規化残差に 10⁻¹⁰ を要求する。同じ親・ひずみ・分割を凍結した17入力すべてが、2⁴⁸⁰倍で pc²=9.98435×10⁻²⁹⁷ として同じ Rust 関数を実行すると通過した。全体再計算でも8増分を受理し λ=0.548453394203 に到達した。最細 P3 の保存点からの2⁴⁴⁸倍経路は81増分受理、λ=0.548465643072。従って元の補助停止は材料式を評価した数値範囲に依存する。[棄却入力](nc/aux448-incoming-failures.jsonl)・[同じ更新の対照](nc/aux-point-replays.jsonl)・[物理単位での再組立](nc/physical-checks.json)

さらに最細保存点から、各点の応力と pc を共通の2の整数乗と仮数に分けて保持した。コミット済み MCC 増分式ではひずみと体積・塑性ひずみ履歴を固定すると、応力・pc と整合接線は応力尺度の一次同次量である。局所則は仮数で元の Rust の主更新・接線を評価し、両者の更新状態の一致と元の状態許容性を確認する。物理的な kPa に戻して long double で力と剛性を集積し、完成した行を元の精度の全体ソルバーに渡す。この尺度は材料点の数値表現だけに属し、荷重・構成定数・降伏面・許容値・λ の係数に適用しない。同一親・非ゼロ増分で 2⁴⁴⁸倍法との全体力の相対差は 2.66×10⁻¹⁶、剛性は 2.49×10⁻¹⁶。同じ弧長系列の先頭69受理点で λ 差は最大 3.34×10⁻¹⁶。[材料計算](nc_homogeneous.rs)・[物理行の組立](nc_extended.py)・[独立検査](nc/extended-audit.json)

最大幅 0.02 m で前史を含む既定2,000試行まで進めた結果は λ=0.548117313607、継続1,600試行中1,214受理。終端の独立自由力残差比 1.83×10⁻¹⁶、最小 p′=6.25×10⁻¹¹⁷⁸ kPa、正規化降伏値最大 9.67×10⁻¹³。指数を別に保持することで、圧力下限を導入せずに以前の数値範囲を越えた。[全試行](nc/fine-extended-retry/trials.jsonl)・[終端](nc/fine-extended-retry/summary.json)
