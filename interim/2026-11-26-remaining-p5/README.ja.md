**予算の寄与。** 固定滑り予算 9.5367431640625×10⁻¹¹ m は水準別 10⁻⁴/N² の 1/16、1/4、1倍。散逸予算は共通の 0.01/N² kPa·m。再閉鎖域において、他の棄却条件がなく、固定滑り予算だけを超え、水準別なら幅内の候補は37 / 23 / 0件だった。同じ操作は235/256以前と239/256以後の再接触後半では0件。この片側再採点は候補の受理や親の置換には用いていない。実際の保存対照でも、水準別予算の再接触試行は431 / 797 / 1,450、固定では546 / 844 / 1,450。粗い水準の受理分割が変わり、開→滑りの小刻みのどちら側で滑りを積むかに差が生じる。両経路の再接触工程全体の余弦は水準別で +0.67349、固定で −0.39514。反転・再載荷の開始前に発生した差がその後も残る。固定予算の全工程余弦は元経路 −0.27139、別経路 −0.39597。両経路とも既存の有限3水準全場ゲートは未達。[4条件の保存対照](../2026-11-25-remaining-p4/c01/summary.json)

**対策案と承認事項。** 開→滑りをまたぐ中点・終点を候補に含め、その区間に既存予算内の比較を配分する案がある。力残差だけで選んだ端点より32点の切替を直接狙える。粗側の切戻し列が変わるため、誤差の減少や向きの改善は未確定。まず保存親の236～239番近傍で候補ごとに全歩と二半歩を照合する。実装後の効果判定には元・別の2経路 × 3水準で全22場の再採点が必要で、今回の共通部分だけの実時間は N256 / 512 / 1024 で310 / 366 / 421秒。選択条件や工程別配分を変える実装・実験、採用は別途承認事項。
