# C-01：湿潤JOINT全体荷重刻みの切替・履歴診断

保存先のラベルは2026-11-18、実施日は2026-11-11（日本時間）。PR #13、指定先端 `b069ec84da432f677c33fab5c984b6e680835bc4` から同じ `codex/plastic-spatial-convergence` で作業した。PRはマージしない。

**C-01の判定は「未達」、`passed=false`。** 16/32/64/128/256の全体刻み系列は単調収束していない。256で差が減っても、連続解・新しい合格値は作らない。今回の限定確認は、既存の小ケースにおける原因の切り分け、全受理場の整合、同じ実行版による実ファイル・別プロセス再開である。C-01を「限定受入」に変更したものではない。

## 原因の特定と、特定できなかったこと

1. **全体平衡経路の曲がりを、接触jumpの直線内分で置き換える有限刻み誤差が主因。** `joint_law::segment` は局所jumpの直線上で開閉点を正確に求めるが、その中間点で全節点の平衡を解き直さない。32点の開閉・すべり開始が異なる進行度で起きるため、端点を結ぶ変位経路は実際に解き直した平衡経路と異なる。同じ接触内総分割数でも塑性履歴は異なり、開口してtractionがゼロになっても履歴差は残る。
2. **介入対照がopen工程を特定。** 全工程64に対してopenだけ256へ細分化すると、open履歴は全工程256に近づく。逆に全工程256のopenだけ64へ戻すと、open履歴は全工程64へ戻る。初期平衡・shearからの微小差では主な再増加を説明できない。recontact以後にも別の刻み誤差があるため、openだけを直せば全履歴が合格するとはしない。
3. **履歴更新順の不具合を示す証拠はない（このケースの範囲）。** open/recontactの全Newton反復で、同じ試行増分の確定旧状態のSHAは不変。最終反復の点別分割数で全接触GPを独立の局所演算から再評価し、traction・塑性すべり・累積すべりを照合した。全工程の全材料GPは塑性ひずみ・相当塑性ひずみ・塑性仕事がゼロ、`last_return=elastic`。一般MCC/MC塑性への結論ではない。
4. **受理判定のすり抜けを示す証拠はない。** 全受理点の残差、本体の全線形求解の真の残差、入力から定まる `i/N` 列を検査した。全32点の切替区間に、該当増分の反復数・残差・受理理由・元の基準を結び付けた。端点が平衡であることと、その間の経路積分精度は別である。中間の不釣合いを端点受理ゲートへ転用したり、ゲートを緩和したりしない。
5. **独立参照にも同じ再増加がある。** 同じメッシュ・全体刻み・接触増分上限5e−5 mで本体と入力のみの独立3D系を新規求解した。両実装の差は各実装の64→128差より小さい。ただし256も有限刻みで誤差を持ち、厳密な参照解ではない。参照側の有限刻み誤差は残り、これを差し引いて合格にはしない。

「切替点の位置決め不足」は、局所直線上の根の丸め不具合ではなく、**開閉点までの全体平衡曲線が増分内に解かれていない**という意味である。保存イベントの時刻は工程進行度の前後区間と全体経路座標・境界係数λで示す。準静的ケースに物理秒は存在しない。区間内の厳密な切替時刻は未認定。線形gap交点は診断値であって、時刻整列・補間解・連続解として使わない。

## 修正の判断と次の選択肢

**生産数値経路の修正は採用しなかった。** 今回確認したのは既存の有限増分方式の精度限界であり、旧結果を保つ最小の不具合修正を特定したものではない。無条件に切替イベントを挿入すれば既定の受理列と結果を変える。既存許容値を維持したまま全履歴の単調性を証明できていないため、接触内分割の増加・端点ゲート・時刻整列を修正として提出しない。

次はユーザーPCで同一メッシュの256/512/1024以上を実求解し、全場と切替区間の漸近性を確認する。必要なら、旧既定を保つ明示オプションとして、切替を跨ぐ**全体増分**の局所誤差推定・全体平衡再求解を別途設計する。異なるGPのイベント順、棄却時の確定状態保持、工程端点、checkpointに適応刻み状態を一貫して保持する検証が必要。局所jumpだけの細分化では代用しない。今回その新機能は実装していない。

C-02〜C-04、一般バルク塑性、変動水位/Richards、空間/時空間、NC-01、P6全体は未達のまま。C-01の固定水圧・MC弾性枝の再開確認をC-03全体の完了へ転用しない。大規模・実CAD・GUI/GPUは実行していない。
