## 段階掘削付き Kirsch 円孔

半径1 m の円孔、半径10 m の有限外周、奥行き1 m の四分円領域を Tet4 で押し出した。平面内の水平・鉛直圧縮は15／30 MPa、K=3.9 GPa、G=2.8 GPa。面内は二つの物理対称面、軸方向は平面ひずみ。初めに芯部を含む全体を本体の `solve-mechanics` で平衡させた。芯部要素の実測応力から残存側に必要な界面トラクションを求め、芯部を除去し、全面を一つの係数で解放した。残存域の外周には [(1−λ)σ₀+λσK]n を三角形6点積分で与えた。公開例の近似遠方境界と区別し、有限領域に無限体の閉形式を制限した派生試験である。[Itasca 3DEC 9.5、Kirsch の応力・変位式と公開例](https://docs.itascacg.com/itasca950/3dec/docproject/source/examples/CylindricalHoleInAnIEM.html)・[入力生成と段階引継ぎ](kirsch.py)

12・96とも無孔、除去直後、半解放、全解放で、真線形残差と自由力残差を個別に 1e−10 以下と確認した。初期の保持合力は両メッシュとも (15000, 30000, 0) kN、半解放で半分、全解放でゼロ。96の全解放時、孔壁軸上の変位増分は −0.3141／−3.8445 mm、解析値は −1.1268／−6.9089 mm。周応力は各軸上の孔壁節点に隣接する積分点から体積重みで回復した値。粗格子の直線辺・一定要素応力の影響があり、両方の壁応力が単調に改善する結果も得られなかった。本文の「2.5半径まで良好」には数値許容幅がない。その範囲の全測点を記録し、該当する積分点がない12要素は空配列とした。**達成は離散施工平衡まで**。本体の静的弾性組立を用い、段階間の界面力受渡しは本試験のドライバが担当する。[各段の外力・反力・近傍測点](kirsch-results.json)・[8回の本体入力・出力](kirsch-native.zip)

## 排水 MCC 三軸圧縮

単位立方体、排水、初期 p′=p′c=5 kPa、q=0。等方圧密で8／40 kPaに達してから5 kPaに除荷し、セル圧5 kPaを保持して軸ひずみ0.5まで圧縮した。圧縮正、M=1.02、λ=0.20、κ=0.05、基準1 kPaで vλ=3.32。公刊例は各 OCR の状態から開始し、G=250 kPa 一定。今回の前史は解析可能な派生試験で、本体は一定νを使用した。共通初期状態の弾性係数 K₀=v₀p′₀/κ から G₀=250 kPa に合わせ、ν=0.173752395 とした。ひずみに対する応答全体を同一材料条件とみなさない。[Itasca FLAC3D 7.0 理論式・Table 1, 2・入力](https://docs.itascacg.com/flac3d700/flac3d/zone/test3d/VerificationProblems/TriaxialCompressionTest/TriaxialCompressionTest.html)・[試験入口](../../examples/t9d_mcc/main.rs)

各増分で本体 MCC の不変な親状態から側方圧を満たす一様ひずみを求めた。12／96 Tet4 の各セルは、自身の状態と実際の節点変位増分から独立に材料更新し、外表面荷重と全自由節点の力残差を組み立てる。対称面は法線方向、上面は軸変位制御で、側面接線方向は自由。三軸の数値はセル体積平均。これは一様解の運動学を利用した試験で、非一様な変形を自由に発生させる解析ではない。圧密128、除荷128、軸圧縮512増分とし、各格子で材料内最大刻み 1e−4／5e−5 の両方を実行した。

## 再現と台帳

リポジトリ直下で、依存は既存の Rust toolchain と `requirements-reference.lock.txt` を使う。出力には新しい作業ディレクトリを使う。

```bash
d=interim/2026-11-24-t9d-benchmarks
out=$(mktemp -d)
cp "$d/criteria.json" "$out/"
cargo build --locked --release --bin soil-fem-3d --example t9d_mcc
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python "$d/arch.py" "$out/arch-results.json"
python "$d/kirsch.py" target/release/soil-fem-3d "$out/kirsch"
cp "$out/kirsch/kirsch.json" "$out/kirsch-results.json"
target/release/examples/t9d_mcc > "$out/mcc-results.json"
python "$d/assess.py" "$out" > "$out/ledger.json"
python -m unittest discover -s tests -p test_t9d_benchmarks.py
cargo test --locked --release --example t9d_mcc
```

[追補台帳](ledger.json)は判定行、根拠ファイルと SHA-256 を持つ。各格子の fold と荷重読取り、段階ごとの平衡と場精度、MCC 終端と前史、元の NC-01 を区別した。T7 の最初の全履歴一括実行はメモリ強制終了（exit 137）。T7 の既存 restart で4受理増分ごとに Newton 行列を解放した。最初の分割実行は出力時の NumPy 真偽型の直列化で停止したため、型変換を修正して再実行した。弧長・増分予算・真線形残差の条件は元の T7 と同一。再現時には経路の受理・棄却や失敗もそのまま出力する。
