# 再開後の途中成果（更新9）

混合MCCのGP体積/P1投影体積に梁・板と施工履歴を接続しました。二層K0試験体のプレロード・硬化・除荷・上層掘削・設置/撤去を独立3D速度形FEMと比較し、Rustの細分化で最大変位差は約0.350％から0.088％未満へ縮まりました。16地点の別プロセス再開、4条件36フレームの生値出力監査、切戻し対照が合格。ローカルRust249件/Python94件とfmt/clippyも合格しました。[詳細](../../docs/MCC_STRUCTURES.ja.md)。

SolidCraftの内部共有面に置いた壁の弾性掘削・粗密/感度比較、固定した独立参照の工程単位再開ツール、研究用の参照計算高速化も含みます。公開親コミットf12d374のWindows CIは成功しましたが、今回の公開版のリモートCI成功は未確認です。SolidCraft全体CIの4形状基準差は元の上流engineでも再現し、未解決のまま記録しています。

実CADの塑性山留め、空間収束、全入力・水/JOINT・部材表示、性能などP6の残件は保持します。MCC実CADの6件の参照計算は継続中で、研究用高速化の厳密な成分別ゲートも未達です。完成版ではありません。

このフォルダは入力/実行ソース指紋・検証要約・試験ログを公開し、全runデータや実行ファイルを同梱するものではありません。各要約のoriginal_local_pathとSHA-256が元の記録を示します。入力例は準備ツールから再現できます。[全残件](../../docs/P6_STATUS.ja.md)。
