# C-01 湿潤7工程の event4 再試行と全場の刻み比較

開始時に取得した origin/codex/plastic-spatial-convergence の先端 SHA は `7a47af617041bf8a409baf77e0602af6cf1fbac0`。

**N1024 の結果。** 局所細分と能動集合の接線を組み合わせると、粗解補間なしで本体・独立とも全7工程を完走した。reload は本体 1,906 回、独立 1,861 回。粗解補間を併用した場合は 1,854 回、1,863 回。粗解補間なしの塑性すべりの差方向余弦は -0.386552、-0.499136。全場の刻み収束は未達。

2026-11-24 06:01 JST 決定による再試行。対象は同じ12 Tet10、54節点、324材料 GP、32接触 GP。全経路で工程上限は `settings.attempt_budget_policy="mesh_proportional"` の B(12)=2,065、未指定時は2,000。全工程は初期平衡、shear、open、recontact、reverse、reload、return の順。N は荷重進捗の分割数。旧2,000回の失敗と比例予算の未改良 event4 の停止は既報に残した。[2,000回の記録](../2026-11-23-c01-method-improvements/README.ja.md)・[2,065回の対照](../2026-11-23-c01-mesh-budget/README.ja.md)

## 選択式の改良

|再現用の mode|event4 に加える設定|実際に変わるもの|
|---|---|---|
|base|なし|従来のギャップ根による刻み提案と最少4内分割。|
|retry|`error_scaled_retry=true`|棄却時のすべり・散逸の最大正規化誤差 r を用い、刻み比を 0.9/√r と最初の対象ギャップ根の小さい方から決定。既存の範囲 [1/16,15/16] に制限。受理後は次の基準点までの残り長で切る。|
|local|`contact_history_bisection=true`|試行始点の局所状態で累積塑性すべりが正、または法線弾性ギャップが正の接触 GP で、最少内分割を4から8にする。その他の GP は4。幾何学的な上限長 5×10⁻⁵ m がより多くの内分割を要求すればそちらを使う。|

新しいフラグは `joint_system.global_step_control.path_error` 下で明示する。本体・独立とも、粗い1刻みと細かい2半刻みを平衡まで解き、各 GP のすべり誤差と累積塑性散逸誤差を元の予算（それぞれ 10⁻⁴/N² m、10⁻²/N² kPa·m）で検査する。局所細分の対象は各試行の始点履歴で定める。2番目の半刻みには平衡した中点の履歴を使い、棄却した履歴は引き継がない。局所内分割1回は外側の工程試行1回とは異なり、実行時間には両方が寄与する。

PETSc の TS event は指示関数の零点を局在化し、TSAdaptBasic は重み付き誤差と次数で次の刻みを提案する。MOOSE の MultiParameterPlasticityStressUpdate は材料点で局所増分を試し、失敗時に半減して再試行する（L250–365）。ここでの GP の選定と4→8は本件の検証用の選択で、公開ソースにはこの摩擦場の収束次数、完走予算、許容幅の参照値はない。確認した Git blob は順に `5201b4507bbc`、`bc6f30d96cff`、`d0916ec385d6`。[PETSc TS event](https://github.com/petsc/petsc/blob/main/src/ts/event/tsevent.c)・[TSAdaptBasic](https://github.com/petsc/petsc/blob/main/src/ts/adapt/impls/basic/adaptbasic.c)・[MOOSE の局所刻み](https://github.com/idaholab/moose/blob/next/modules/solid_mechanics/src/materials/MultiParameterPlasticityStressUpdate.C)
