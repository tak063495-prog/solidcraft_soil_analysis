**C-01全体は未達、`passed=false`。** 接触切替を跨ぐ全体増分を二分して平衡を解き直す明示オプションを実装した。既定はオフ。ソフトウェア整合・固定小ケースの改善を「限定確認」として記録し、全体の受入へ置き換えない。C-02〜C-04、NC-01、P6、A/B各項も未達のまま。

## 採用した方式

`joint_system.global_step_control = {"switch_bisections":4}` を指定したときだけ、確定旧状態と収束した試行の各接触GPの `open/stick/slip` を比較する。端点カテゴリが変化し、実増分が基準増分の1/16より大きければ、その収束試行も確定せず棄却し、実増分を二分して全体平衡を再求解する。局所jumpや保存解の内分で全体解を作らない。

基準 `i/N` の境界と工程端点を保持し、受理後は次の基準境界まで戻す。既存の最小刻み・2000試行/工程・Newton・残差の停止を保持する。二分後の実刻みが分解能の半分まで小さくなり得るため、明示入力の最小増分は `min(旧値,1/(32N))` とする。新設定の検証では最小増分が切替分解能の半分以下であることを要求する。**力1e−8・真の線形1e−10・独立系1e−10は不変。** 1/16は経路分解能であり、全履歴の受入許容値ではない。

追加状態を隠し持たず、次の増分・進行度・試行数は既存checkpointの継続情報に保存する。初期平衡の履歴再構成にも同じ制御を適用する。現時点の明示オプションはBoundary工程の経路に限定し、未検証の施工操作へは入力検証で拒否する。NCの実装・設定には触れていない。

**限界**：端点カテゴリ検出であり、両端が同カテゴリのまま増分内で複数回切り替わる場合の完全検出でも、イベント時刻の根探索でもない。滑らかなすべり区間の全体経路誤差を直接推定していない。最細256も有限刻み解であり連続解ではない。

## 先行事例と採否（実際に確認した一次資料）

- [Abaqus/Standard: Convergence Criteria for Nonlinear Problems](https://docs.software.vt.edu/abaqusv2026/English/SIMACAEANLRefMap/simaanl-c-convergcriteria.htm) と [Defining an Analysis / Severe Discontinuities](https://docs.software.vt.edu/abaqusv2026/English/SIMACAEANLRefMap/simaanl-c-over.htm)：開閉・stick-slip の剛性切替を SDI として平衡反復で扱う。自動増分では SDI 反復上限超過時に増分を捨てて小さくやり直す方式もある。今回採るのは全体増分の棄却・再求解という考え方。SDI の反復数や既定カットバック率を移植するものではなく、端点の平衡収束だけでは履歴の増分精度を保証しないため、収束後の状態切替も別に検出する。
- [DIANA 10.7: Structural Nonlinear Analysis](https://manuals.dianafea.com/d107/en/1181807-1182744-structural-nonlinear-analysis.html)、Iteration Based Adaptive Loading / Cutback Based Adaptive Loading：反復数に基づく刻み変更と未収束時のカットバックを明示的に分離している。未収束カットバックは既存のまま保持する。反復が少ない区間でも開閉で経路誤差が生じる本件では、反復数だけを精度指標にする方式は採らない。同文書を「接触状態変化を直接検出する実装」とは引用しない。
- EDF の公開 [Code_Aster DEFI_LIST_INST カタログ](https://gitlab.com/codeaster/src/-/raw/main/code_aster/Cata/Commands/defi_list_inst.py) と [TimeStepper 実装](https://gitlab.com/codeaster/src/-/raw/main/code_aster/Solvers/Main/time_stepper.py)：失敗時の DECOUPE、最小刻み・再分割深さ、強制時点を保つ管理が確認できる。今回も指定刻み境界・端点を保持し、下限を隠して受理しない。調査時の main カタログに COLLISION はなく、旧版の COLLISION 説明を現行仕様として採用しない。
- [Siconos: Event-Driven schemes](https://siconos.readthedocs.io/en/latest/Docs/sphinx/users_guide/event_driven.html)：根探索で非滑らかイベントを位置決めし、イベント間の滑らかな運動を積分する方式。切替位置決めは有力な次案だが、記載の対象は動的な片側拘束・衝突であり、本件の準静的な多点摩擦へそのまま適用できない。今回は全体系の再求解を伴う二分法を選び、厳密イベント位置を認定しない。
- P. Wriggers, [Computational Contact Mechanics, 2nd ed. (2006), DOI 10.1007/978-3-540-32609-0](https://link.springer.com/book/10.1007/978-3-540-32609-0) と J. C. Simo / T. J. R. Hughes, [Computational Inelasticity (1998), DOI 10.1007/b98904](https://link.springer.com/book/10.1007/b98904)：出版社の書誌・目次（接触界面構成式、解法、return mapping の数値解析）まで確認した。本文全体は未確認であり、特定ページの定理や今回の実装の収束保証を引用しない。「局所構成積分の整合」と「全体増分経路の収束」を分けて実測する設計判断は本作業の判断である。
