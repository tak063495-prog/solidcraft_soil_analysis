# 偏心板の複合をどう定義するか（T4）

## 論点ごとの推奨一覧（ユーザー判断待ち）

|論点|推奨する規約|理由|
|---|---|---|
|1　付着と接触の所有|板の片側を土 A に tie し、相手 B との接触は物理面対が所有する。同じ領域・相手・成分は一つの則に割り当てる。|片側が開いても反対側の付着を維持できる。|
|2　設置参照面と腕|土に付着する参照点を入力し、板中央面と接触作用点を符号付きの腕で求める。初期対象は小回転の剛体腕。|現行 Tri6 の節点座標、設置並進・回転、膜力と曲げの出力を引き継げる。|
|3　初期状態と世代|配置時に無応力で板を新設し、接触の無応力新設／明示力移行を別指定する。撤去世代を凍結し、再開は同世代とする。|変形済みの土へ板を置くだけで架空の曲げや旧すべりが生じるのを防げる。|
|4　荷重・モーメント・仕事|物理作用面で積分し、付着参照点の力と偶力へ移して照合する。瞬間の F·d と受理増分の累積仕事に別欄を設ける。|腕偶力の欠落と設置参照の欠落を独立に検出できる。|
|5　二重計上|一つの物理寄与につき組立経路を一つにする。局所仕事、全節点の力・モーメント、接線を別経路で再組立する。|全体合力が相殺されても局所の過剰拘束や剛性倍増を検出できる。|

## 1　どの面対が付着・接触を所有するか

|選択肢|採用例・出典|利点・欠点と既存構造への適合|
|---|---|---|
|A　領域・相手・成分別に拘束を排他化（推奨）|Abaqus general contact は実際に tie された節点と相手面の組合せを除外 [1]。FLAC3D embedded liner は両側を別リンクで管理 [5]。|付着側・露出側を独立に検査できる。現行の構造節点→土節点写像と JOINT の両側所有者に、板側の面・活動領域の指定が必要。|
|B　同一面対は一つの付着・破断・再接触則で扱う|FLAC3D liner の有限引張強度、せん断ばね／スライダ、開離・再閉鎖 [5]。|剥離して接触に移る施工を表せる。損傷・残留強度と散逸の履歴が増え、既存の完全付着／非粘着 JOINT だけでは物性を定められない。|
|C　全域を共有自由度で完全付着し接触候補を作らない|Code_Aster の鋼板とコンクリートの運動学的付着 [7]、現行乾燥板 [R1]。|入力・再開が簡単。すべりや開離、新たな相手面への接触は表せず、S12 の適用域が狭い。|

**採用後の実装範囲。** 土 A は体積セルと付着側局所面、板は要素 ID・面側・回転・設置参照を所有する。tie は土 A の面上並進と板の付着点を結ぶ拘束を所有し、土に独立な回転自由度を要求しない。接触要素は板の露出面と土 B の局所面の対、向き、積分領域・点（GP）、法線・接線力と履歴を一組だけ所有する。同じ幾何面でも相手または側が異なると別の対になる。候補自動生成時は有効な tie が覆う相手・領域・成分だけを除外する。両方を明示して重ねた入力は当該面対と成分を示して拒否する。拘束が成立しなかった部分を暗黙に付着扱いしない。部分重なりの領域を識別できない入力は保留する。

**受入試験。** 板1枚の片側を tie、反対側を接触とした平面パッチで、圧縮・接線載荷・開口・再閉鎖を与える。一定 traction ×面積と各節点の形状関数積分で対力・反力を独立計算する。開口側で接触力が消えても tie 側の並進拘束が保たれることを検査する。同じ面対の明示二重指定、逆順で再宣言、自己対、片側の活動欠落、異なる相手への正当な二面接続を対照にする。共有先端がある場合は T3 の判断を要し、両側が同一物理自由度で同じ写像を持つ点だけ jump の仮想仕事が零になる。

## 2　設置をどの面で記述するか

|選択肢|採用例・出典|利点・欠点と既存構造への適合|
|---|---|---|
|A　付着参照点＋符号付き剛体腕（推奨）|現行 Tri6 [R1,R2]、Abaqus の節点参照面・OFFSET [2]、OpenSees rigidLink beam の小回転行列 [4]。偏心補剛材の位置変換に査読例 [12]。|土の接続座標と checkpoint を保持できる。面側・符号・実際の荷重点を記録する必要がある。|
|B　板中央面を入力し、別の付着点を MPC で結ぶ|Abaqus の既定中央面と kinematic／distributing coupling [2,3]、DIANA の節点局所偏心 [6]。PLAXIS の部材間 Connection は回転等の選択の近縁例 [8]。|CAD の板中央面や支持位置を直接指定できる。土面との対応、補間、回転条件を再構成する必要があり、点を剛結する場合と領域平均で結ぶ場合では局所応答も変わる。|
|C　位置を分け、実際の接着層を有限剛性のばねで結ぶ|FLAC3D liner の面積当たり法線・接線剛性 [5]。偏心点まで腕を延ばす部分は T4 での組合せ。|層の変形を測定物性から与えられる。ばねエネルギーと相対すべりを新設するため、剛体腕の代用品としての任意の大剛性は参照条件を変える。|

**採用後の実装範囲。** 平面・小回転に限り、単位法線 n、板厚 t、中央面 p から付着参照面 s への長さ e [m] を入力する。xₛ=xₚ+e n、従って xₚ=xₛ−e n。s が板の実表面と一致するのは e=±t/2 の場合。物理接触面 c は板側を表す σ=±1 を明示し x꜀=xₚ+σ(t/2)n とする。中間の参照面を露出表面に使わない。土が実表面で付着すると宣言した入力は両面の配置整合を要求する。現行の一定かつ有限の abs(e)≤t/2 を前提とする。Abaqus の OFFSET は e/t に相当する無次元量で、法線と参照面の向きが一致する場合に換算できる。

付着点から任意の作用点 j への腕 rⱼ=xⱼ−xₛ に対し uⱼ=uₛ+θ×rⱼ。これを Aⱼ と書く。設置時並進・回転を各履歴で保存し、板の弾性ひずみには設置値との差を写す。T4 の最初の対象は定腕の適合平面。共有 ID で e n が不一致なら既存の拒否を維持する。折れ線に独立継手を入れるには両側の付着点・中央点、有限交差領域の有無、連続／解放する回転軸を別途決める。[R2,15]

**受入試験。** 1点の剛体並進、任意軸の微小剛体回転、正負・零の e と e=±t/2 を手計算する。単一平面要素の剛体6モードで物理ひずみを検査し、膜・純曲げパッチで非零の断面力を独立積分する。法線と e と表面側を同時に反転した別入力の世界座標結果、法線だけを反転した入力の実腕差を照合する。e=0 の折れ目、同じ土点に別構造 ID の独立回転、非零腕不一致の拒否を別ケースにする。

## 3　どの状態を新設・撤去・再開するか

|選択肢|採用例・出典|利点・欠点と既存構造への適合|
|---|---|---|
|A　変形済み配置で無応力新設（推奨する基本ケース）|Abaqus の無応力トンネルライナー [9]、GTS NX の新設応力零 [10]、T1 の無応力接触と T2 の新材料 [R3]。|板の設置記録を利用できる。解放された旧荷重を受け持つ他部材・反力の再平衡が必要。|
|B　初期断面力・初期接触力を施工条件として明示（力移行を要するときの推奨）|GTS NX の明示 prestress [10]、既存 A-02 と T3 の A/B の区別 [R3]。偏心板と接触を同時に初期化する製品例は未確認。|ジャッキ等の既知の保持力を表せる。全節点の並進・モーメント再現と各 GP の接触条件を満たす独立参照が要る。|
|C　基準を保持して再活性化|Abaqus の reactivation with strain [9]。|原配置に戻る既存部材を別の施工モデルとして定義できる。交換板に旧ひずみを継がせると初期力が変わる。適用部材・履歴移送は未確認。|

**採用後の実装範囲。** A は設置時の変位・回転・参照 jump を保存し、板の初期応力／N／M と新設接触の初期有効 traction・塑性すべりを零と明示する。自重・外圧・保持荷重を加えた後の平衡状態では力が生じ得る。B は板の初期場、接触有効 traction、力の供給者と初期蓄積を記録する。引張・摩擦限界超過、節点力や腕偶力を再現できない移行は棄却し、確定状態を更新しない。T3 の GP 投影を採用する場合も、偏心で生じる回転行を含む仕事共役写像で全節点を検査する。増分仕事・散逸を出生時に重ねて積算しない。

板・土・接触対の世代 ID と相互の参照を別に持つ。DEATH は確定済みの設置基準、材料／水理状態、接触の jump・traction・すべり、蓄積・累積仕事を旧世代に凍結し、活動域から外す。撤去直前の力・偶力を誰が保持し、どの経路で除くかを指定する [9,11]。再設置は新世代、開閉／すべりは同世代内の状態変化、別プロセスからの再開は同じ確定世代の継続。土の MATSET は同一材の履歴更新か置換施工かを明示し、変換則のない塑性履歴は拒否する。片側の土だけが活動する面や残存面の分割には T3 の仕様判断が必要になる。

**受入試験。** あらかじめ変位・回転を与えた土に無荷重板を置き、A の出生直後の N、M、面力・仕事増分の零と、次の微小荷重への応答を照合する。B は一定圧縮と既知のせん断の面積分・腕偶力を全節点で再現し、引張・摩擦超過・釣合わないモーメントを拒否する。載荷→撤去→新設を2世代、開閉、途中棄却、撤去直前／直後・再設置後の別 PID 再開で比較する。再封印した旧世代書換え、所有面の入替え、参照 jump／腕／初期力改変を検出する。

## 4　荷重と仕事をどの面で比較するか

|選択肢|採用例・出典|利点・欠点と既存構造への適合|
|---|---|---|
|A　物理作用面で積分し付着点へ移す（推奨）|B-03 の保存解で中央／付着両面と腕偶力を照合 [R2]。Abaqus の接触力の節点力・モーメントへの再配分 [1]、DIANA の偏心支持反力 [6]。|土の並進、板の回転、施工保持荷重を一つの節点平衡で比較できる。元の作用面と設置基準の保存が必要。|
|B　中央面を共通の比較面にする|現行の断面出力 N、Mₚ [R1]、Code_Aster の偏心と後処理 [7]。|板の膜・曲げの比較が容易。土の支持力・接触力と外部偶力を逆向きに移し直す必要があり、折れ目の中央点が一意でない場合がある。|
|C　接触面の traction と相対変位で比較する|DIANA の界面出力 [6]、Laursen・Simo の接触仮想仕事 [13]、Wriggers の弱形式 [14]。|開閉・すべりと散逸を追える。土の体積仕事、板曲げ、支持反力を含めるには別の全体系の会計が要る。A の局所検算として併用できる。|

**採用後の実装範囲。** 物理面 j の力 Fⱼ とその点まわりの固有偶力 Mⱼ を、同じ付着点 s で Fₛ=Fⱼ、Mₛ=Mⱼ+rⱼ×Fⱼ とする。力は kN、腕は m、偶力は kN·m、回転は rad。q=(F,M)、d=(u,θ) とすると qₛ=Aⱼᵀqⱼ で、任意の適合仮想変位に qⱼ·δdⱼ=qₛ·δdₛ が成り立つ。小回転・固定腕の範囲で同じ写像を荷重・残差・接線に用いる。断面結果は現行符号で εₚ=εₛ−eκ、Mₛ（付着面の単位幅曲げ）=Mₚ−eN。節点偶力と単位幅断面力には別の単位・列を割り当てる。板自重・現行板 traction は中央面、梁／節点荷重は宣言した位置、接触は c で積分する。水圧を拡張する場合は物理濡れ面・作用側と有効接触力を識別する。

各受理状態 i で旧指標「瞬間荷重仕事」Jᵢ=qᵢ·dᵢ を同一時点・原点・基底で照合する。これは kN·m の状態量で、仮想仕事や仕事率とは別欄とする。板の弾性内部仕事を比べるときは設置値 d₀ を差し引き、線形・無初期応力なら qᵢⁱⁿᵗ·dᵢ=2Uᵢ+qᵢⁱⁿᵗ·d₀。累積外力仕事は各世代の受理区間で Σ ½(qᵢ₋₁+qᵢ)·(dᵢ−dᵢ₋₁)。設置・撤去をまたぐ区間はイベント前後に分け、どの荷重をどの配置で解放したかを記録する。規定変位の反力、保持外力も各々一度だけ積分する。剛体写像が同じ区間なら中央・付着・接触作用点で同一荷重の仕事が一致する。

接触内部仕事には両側の**相対**変位を用いる。向きを固定した jump=uᵦ−u꜀ とその共役 traction q に対し、両側の和は ∫ q·δjump dA。固着・開口・すべり別に弾性蓄積・摩擦散逸・数値積分差を残す。既存接触則／T3 の終点和と外力の台形和は各方式で再現し、差を散逸に付け替えない。B-03 の自由パッチのように供給元の面別外力が保存されていない場合、その成分は未確認（null）とする。[R1–R3,13]

**受入試験。** n=+z、e=0.05 m、中央面に F=+10 kN·x̂ を作用させると付着点まわりの偶力は −0.5 kN·m·ŷ。uₛ=0、δθ=0.01 rad·ŷ で中央面の変位仕事と付着点の偶力仕事はともに −0.005 kN·m。法線荷重だけの零偶力、純偶力、e の反転も含める。線形ばねを零から F まで載荷した例で瞬間 F·u と累積 Fu/2 を区別し、除荷・再載荷・異なる設置変位を加える。平面パッチでは各履歴の全受理点で両面の仕事、支持反力と共通原点まわりのモーメントを独立積分する。腕偶力を一つ落とした場合と設置項だけを落とした場合の残りを別々に検出する。

## 5　同じ力・剛性・仕事を二度足さないための規約

|選択肢|採用例・出典|利点・欠点と既存構造への適合|
|---|---|---|
|A　物理寄与の所有を一意にし転置写像で一度組立（推奨）|B-02 は土 RHS に既に入った付着構造荷重を差し引いて構造仕事を分解 [R1]。FLAC3D の共役補間 [5]、運動学による付着をもつ Code_Aster 複合板 [7]。|既存の残差・荷重内訳・全場試験を使える。力の供給元と写像先の対応表が必要。|
|B　両側の未知量と拘束反力を保持する混合系|OpenSees の MP 拘束 [4]、Abaqus の tie [1] が拘束の先例。乗数付き独立解を使うのは T4 の検算案。|節点別の tie 対力を直接比較できる。重複拘束を許すと行列のランクや反力の一意性が失われる。|
|C　構造と土の間に一つの有限剛性界面を置き、履歴もそこで所有する|FLAC3D liner [5]、DIANA の界面出力 [6]。|実在する接合層の仕事・散逸を追える。完全付着の現行板とは異なる物性・参照解が必要。同じ相対自由度への並列 tie は重複となる。|

**採用後の実装範囲。** 寄与元（板・土セル・面対・荷重・施工イベント）、両側の物理 ID と局所面、部分領域・成分、世代、受理増分を記録する。板はその板材のエネルギー、土は土材の体積エネルギー、界面は相対変形に伴うエネルギー・散逸を持つ。板領域で土材を置換するモデルなら活動体積・自重も施工時に差し引く。埋設補強として両材が占める量を別途指定するなら、その材料量を入力から独立に積分する。土体積の置換・材料量が不明な組合せは受入保留とする。

剛体腕は運動学的変換であり、腕自身の質量・弾性エネルギーは零。板の寄与は Aᵀf と AᵀKA をそれぞれ一度組み立てる。完全 tie の対力は適合仮想変位で内部仕事の和が零となる。接触の片側力は他側に逆符号で戻すが、相対運動がある場合には界面の仕事が残る。土 RHS に集約済みの板荷重と集約前の板荷重は同じ荷重の二表現である。再構成した符号付き合計を本体 RHS と照合し、集計済みの列から内訳をもう一度加えない。湿潤の場合の有効 traction、間隙圧、外水圧、圧力仕事・水量は T1/T2 の所有者と物理面を突合するまで受入保留とする。

**受入試験。** 1点の偏心ばね k のエネルギー ½k(u+ℓθ)² を展開し、接線の行列成分 k、kℓ、kℓ² と力を独立に比較する。平面パッチでは拘束消去系と、乗数付きで両側の全節点を残した独立系で、全自由節点の力、回転残差、作用反作用、剛体モード、エネルギーを照合する。①同一面に tie と接触を重ねる、②腕剛性または板荷重を二度組み立てる、③等大逆向きで合力だけが零の誤配賦、④再開で前増分の仕事を再加算する、の四つを意図的な誤りとし、どの列・節点で検出したか記録する。

## 採用後の試験規模と判定の境界

GPD WIN Max 2（使用可能メモリ約48 GB）で、手計算1点→1枚／2小面→乾燥の12 Tet10＋平面 Tri6 に進む。両側地盤が必要な場合のみ最大24 Tet10 とし、経路を直列実行する。1経路で本体・子プロセス合計のピーク8 GB、経過2時間を計画上限とする。これは予算であり実測値ではない。到達時は打切り・未判定を記録する。768／6144 要素、40 GB 超、1日超の経路は計画しない。

独立系には入力・境界・荷重順・施工分割だけを渡し、設置配置と全場を自身の先行解から求める。本体の変位・内力・接線・受理列を参照解生成に使わない。各受理点で土全節点・材料 GP、板の変位／回転・膜／曲げ／せん断、接触全 GP、全節点平衡・反力、面積、仕事と世代を照合する。既存ゲートは対応する量にのみ適用し、新しい継手の合否基準は独立解とともにユーザーが決める。再開は計時を除く確定履歴を照合する。水・塑性・アンカーはそれぞれ独立な初期場・荷重経路と参照解を要する。乾燥パッチでの等価性から、それらの複合や全場の空間収束を認定しない。
