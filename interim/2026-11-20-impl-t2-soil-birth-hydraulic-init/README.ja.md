# 新設土の水理初期化と施工水量（T2）

2026-11-20 に承認された T2 調査の推奨案 (1)〜(6) を PR #13 の T1 最終台帳登録 `9e81e83a` に追加した。処方場の施工例は54節点・12 Tet10、過渡施工の世代試験は16節点・12 Tet4 の既往柱で計算した。A-03 と A-04（S12）の全体判定はそれぞれ未達。旧入力の診断と過去の記録を保持して、新しい入力を明示した場合の追加範囲を検査した。

## 入力と照合範囲

|論点|施工入口の動作|主な試験|
|---|---|---|

定常処方ケースの `placed_water` は配置時の水・重量の原票である。定常 Darcy の流量に仮の継続時間を掛けず、初期全域貯留と時間積分が未定義なら全域収支を保留とする。過渡ケースでは収支を各セル、全体、面対、施工イベント対で照合する。符号付き欠損は e＝ΔM＋N−P、D＝(P＋N＋|ΔM|)/2。各刻みで |e|、累積では独立再組立 E の絶対値と U＝Σ|e| を両方判定する。

|検証用|1e−7|1e−8|1e−12|

## 未実装・未達の範囲

吸引を伴う一般の不飽和施工、移動水面、締固めや形成過程の自動逆算、力学間隙比と水理間隙率の変形中の相互更新、任意材料間の内部変数の写像は対象外。形成履歴を明記した合成試料の動作確認と、現場材料の校正は別の検証である。一般の界面貯留・二方向連成は未達。大規模メッシュに外挿する検証は規模上限のため確認不可・未達。算定できない水量に数値の 0 を入れない。
