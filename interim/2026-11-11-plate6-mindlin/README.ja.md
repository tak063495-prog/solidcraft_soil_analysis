# 案3 高次板：直線・平面Tri6 Mindlin

PR #13の指定先端 `86d2e3c3972b9bc5ae17e77972911df755b58366` を起点とする。`formulation: mindlin_tri6` を明示した場合だけ新しい6節点板を使う。省略時と `cst_dkt` は従来方式のまま。PRはマージしない。

新しい板はTet10面と同一の二次並進補間、二次の面内回転2成分、梁と共有する明示的drilling回転1成分を持つ。MITC系の共変せん断補間を8条件から構成し、せん断補正5/6、正の6点積分、追加せん断安定化0を固定した。膜・曲げ・横せん断・drillingのエネルギーを分けて出力する。式、評価点、重み、幾何拒否条件と入力例は [PLATES.ja.md](../../docs/PLATES.ja.md) を参照。

## 受入と証拠

最終結果は `acceptance.json`、`validation.json` と `measurements.json` に保存する。Rustの要素試験は補間3成分（面内・辺内点）、従来区分線形との差、剛体6モード・ランク30、一定膜ひずみ・一定曲率/ゼロせん断・一定横せん断、座標客観性、整合荷重の力/モーメント/二次仮想仕事、曲線辺/非平面/暗黙方式・オフセット拒否、片持ちを検査する。従来 `tests/plates.rs` の精度と4分割契約は保持する。

片持ちはL=2 m、幅1 m、ν=0、E=2e8 kPa。純曲げはt=0.2/0.02/0.002 m、1/2/4分割でKirchhoffの二次たわみ・一次回転を既存DKTと同じ `1e-7×曲率` の絶対ゲートで検査する。先端せん断はt=0.8/0.02/0.002 m、2/4/8分割で `P L³/(3D) + P L/(κGt)` と比較し、最細の相対誤差1e-7以内を要求する。薄板のせん断寄与はt²に比例して消える。合力・合モーメントは0.002 kN / kN mで、小変形範囲の検証とする。

初回の予備試験には2 kN / kN mを使い、最薄で数十mの線形たわみを与えた条件があり、構造内部残差ゲートで停止した。そのログを `retained-failures/first-focused-failures.log` に残す。小変形の入力条件を明記した後の検証とは区別する。初回の「誤差が既に丸め誤差でも必ず単調減少」を要求する試験も不合格であり、丸め誤差未満の単調性を合格条件に使わない。既存の許容値・参照値・過去記録は書き換えない。この高荷重条件を合格に読み替えない。

Python独立参照は物理座標のLagrange多項式を節点条件から求め、辺積分モーメントと内部平均で別にせん断を構成し、GL5×5/Duffyで全エネルギーを積分する。Rustの剛性・解・設置参照を生成に使わない。12 Tet10、板2枚、梁1本の同一入力から地盤/部材の全未知数を保持した直接連立系を組み、静的縮約解と5フレームで比較する。保存場からの再組立残差1e-10、Newton力1e-8、線形1e-10、独立弾性相対1e-7、構造並進/回転絶対1e-9、板生値絶対1e-8/相対1e-7を維持する。

設置・載荷・除荷・撤去、意図した2棄却、棄却なし経路、キャッシュ0/64 MiB、初期平衡と各施工工程の途中からの5回の別CLI再開を検査する。再開比較で除くのは実測時間だけ。板設置参照・板種別の改変は既存checksum/input identityで拒否する。二次triangle6と混在triangle、生評価点VTUの再読込、Native用フィールドの独立照合も検査する。
