# 保持した不合格・途中停止

このディレクトリの `passed=false` は数値受入の不合格を維持する。ソフトウェア試験の成功と混同しない。

- `full-history-acceptance.json`：既存の再増加、同じ座標の負の観測次数、未達理由を保持する。元のL2や許容値を変更しない。
- `development-evidence.zip.part*` と `archive-sha256.json`：観測ドライバv1が完了フラグだけの再開を余分な受理点に数えた記録、既にaffine-cutの本体を旧GJとして再組立して失敗した記録、独立診断の可変分割数による線探索停止、重複起動・中止した途中場とログを保持する。
- `validation-pre-download/`：既存の大型証拠を取得中に試験して欠落・書込み途中を検出した初回ログ。正式な成功件数には含めない。全取得後の再実行は別の検証ログに保存する。

再使用した完了Runは主証拠アーカイブの該当 `native-raw/` に格納し、入力・メッシュidentity・受理点数・中断なしRunとの一致を確認した。途中の重複計算は別に保留し、その中断を成功扱いしない。実行時の出力元パスが記録されていても、再監査に同じ絶対パスは不要である。

開発途中のソースを各停止時に封印したとは主張しない。部分履歴の欠損を埋めたり、完了済みへ書き換えたりしない。正式系列の数値ソースは主アーカイブに545ファイルを保存し、全場・全計測の再監査を別に記録する。

開発証拠の確認は、JSONに列挙したpartを順に連結し、連結後のSHAとZIPの各エントリーSHAを検査してから展開する。新規求解や数値合格の手順ではない。
