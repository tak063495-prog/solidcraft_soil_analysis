## 入力と出典

円筒は半径300・全長600・厚さ3の1/8モデル。両設定とも EDF の E=3×10⁶ Pa と C 点 FY=−0.25 N を、本体単位で3000 kPa と −0.00025 kN に換算した。端隔板の A・B では SSLS104A の開区間拘束の指定に従う。正則格子は既存 T5 の曲面 Tri6 ビルダーを用いた。EDF 原接続は固定 MED の209頂点と364三角形を読み出した [原格子](ssls104a-grid.json) を使用する。頂点座標は軸を変換して保持し、共有辺ごとの中間節点を半径300の円筒面に置く。両ケースは本体 CLI の `curved-shell` で載荷した。[V3.03.104 v16、改訂 ac9e0da4aeea、pp.2–4、§3.3 番号なし結果表](https://code-aster.org/doc/v16/man_v/v3/v3.03.104.pdf)・[SSLS104A 固定入力、3%幅](https://github.com/Krande/code-aster-copy/blob/5f2556a0cb71bae14871734e76f2efba1e58d4af/astest/ssls104a.comm#L75-L85)・[元 MED](https://github.com/Krande/code-aster-copy/blob/5f2556a0cb71bae14871734e76f2efba1e58d4af/astest/ssls104a.mmed)

原 MED の SHA-256 は `ddcc273cf76626dc886c0c2c56d5ae66cf22e125472881e4bd9b834f25f630a9`。抽出には `NOE/COO` を成分順に3行へ整形して転置し、`MAI/TR3/NOD` を同様に転置して1始まりを0始まりに変換した。抽出済み JSON の SHA-256 は `609a8d0944fe8df99103650bf85a987c32fd199af61334627d444cc4188e9fcd`。

片持ちは10×5 m、各層厚0.4 m、偏心±0.2 m、E=200 GPa、ν=0。長さ・全荷重・測点を保ちながら、メッシュ間隔と各二次辺の等価節点力（辺長×−1 kN/m×(1,4,1)/6）を一緒に変更する。既存例の引数なしの10×5も引き続き再生できる。A3 の参照は純曲げ解析解。EDF モデル A は DSQ/QUAD4、当方は元 T10 と同じ曲面 Tri6 カーネルの平面配置である。[V3.03.111 v16、改訂 28dab45bd02e、p.5 §2.1.1、p.6 §3.3 番号なし結果表](https://code-aster.org/doc/v16/man_v/v3/v3.03.111.pdf)・[固定 SSLS111A 入力](https://github.com/Krande/code-aster-copy/blob/5f2556a0cb71bae14871734e76f2efba1e58d4af/astest/ssls111a.comm)

18×9 で全固定辺の節点反力和は +5.000000000005 kN、支持モーメントは −49.99999999991 kN·m。外力は自由辺で −5 kN、腕10 m。以下は両層で表示桁が一致した。

- **要素内と頂点を分けて確認した。** A1 に最も近い面内積分点は x=0.05088 m、QX=−528.514 N/m。解析せん断は x によらず −500 N/m で、すでに −5.703% の差がある。同じ要素の6点から二次場を A1 に戻すと −555.346 N/m となり、外挿でさらに26.832 N/m だけ負側へ動く。最近点の MXX は +5007.084 N·m/m、同じ x の解析値は +4974.562 N·m/m。曲げも外挿前から差がある。
- **固定辺全幅で分布を確認した。** A1、幅中央、反対端の QX は −555.35、−459.52、−508.30 N/m。固定辺の片側二次場を辺ごとに積分した層平均は −482.65 N/m、MXX は +5035.88 N·m/m。A1 の幅判定には元の点値を用いた。
- **内側の同一断面を左右から比較した。** x=10/18 m の幅平均は左／右で QX −483.19／−480.24 N/m、MXX +4690.88／+4755.69 N·m/m。同じ位置の解析値は −500 と +4722.22。要素ごとの片側回復値に跳びがあり、固定辺から1列離れても残る。2列内側の値と全幅の各辺端・中点も原票に保存した。全体反力が釣り合う一方、要素内の有限格子誤差と頂点への外挿の双方が局所値に現れた。補間と回復の最終的な寄与分離、根元精度の改善は未達。

調査は既存の層別せん断 Q と共通基準面まわりの M−eN を全体 x 軸へ変換して行った。3つの辺節点で得た二次場を Simpson 則で積分した。最近点・幅平均・左右差は原因調査の観測量であり、個別の合格幅を設定していない。[比較器](refined.py)・[片持ち例](../../examples/t10_layered_cantilever.rs)・[試験](../../tests/test_refined_shell_cases.py)
