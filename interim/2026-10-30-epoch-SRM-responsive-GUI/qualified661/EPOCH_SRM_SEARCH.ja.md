# 未低減の施工終了履歴から始める乾燥MCのSRM探索

`search-mc-epoch-srm MESH.json ORIGINAL_RUN.json SPEC.json NEW_REPORT.json`

この経路では、同じ実行ファイルの `solve-stages` で完成した未低減の施工Runを使います。起点のメッシュ・入力・実行ファイルID・確定状態と、再構成した物理外力・活動要素・ゼロ変位拘束を検査します。異なる実行ファイルで作られたRunを、自動で現在版へ読み替えません。

各率は同じ元Runから新しい `mc_epoch_path::Controller` を作り、c/F、atan(tanφ/F)、明示したψ/引張上限の方針へ材料を段階的に変更します。直前の率の塑性履歴を次の率へ使いません。荷重・施工段階・活動領域・表示RESETの基準は元Runから保持し、撤去済み積分点の履歴も凍結します。元のGroundを新材料へ書き換えた通常Runは作りません。

```json
{
  "schema": "soil-fem-epoch-srm-search/1",
  "search": {
    "schema": "soil-fem-srm-search/1",
    "material_ids": [1],
    "psi_policy": "zero",
    "tension_policy": "keep",
    "maximum_factor": 2.0,
    "required_factor": 1.1,
    "absolute_factor_tolerance": 0.002,
    "maximum_trials": 20,
    "through_stages": 1
  },
  "initial_increment": 0.25,
  "minimum_increment": 0.000244140625,
  "maximum_attempts": 128
}
```

これは単軸の試験入力例です。要求率は利用目的に合わせて指定し、規定値や設計安全率として自動採用しません。`through_stages` は与えた完成Runの全工程数と一致させます。途中工程を調べる場合は、その工程までを同じ実行版で完成させたRunを用意します。既存の新規初期化からの探索 `search-mc-srm` と、この施工終了履歴からの探索は異なる経路です。

分布拘束では `/2` の `virtual_displacements_m` を指定できます。既存と同じ全積分点の仮想仕事・平均応力の必要条件を使い、独立に排除できた率だけを上端へ使います。候補が不適用、Newtonや線形反復が不収束、材料経路の最小刻みや試行上限へ到達した場合は判定不能です。不収束を破壊側の上端へ変換しません。

出力 `soil-fem-epoch-srm-search-result/1` は、元の未低減Runを一度保持し、各試行を `trials[i].evidence` と `trials[i].epoch` に分けます。後者は最後に受理した材料パラメータ・全材料履歴・施工情報を持つ専用保存データです。`evidence.run` は常にnullです。完成した材料経路だけを現材料の力・降伏・変位拘束で再検査して釣合い成立とします。未完の経路に残る最後の受理状態を、完成した率の釣合いへ読み替えません。

`requirement=equilibrium_requirement_met` は要求率の数値的な釣合いを得たという限定した意味です。`independently_excluded` と `indeterminate` を区別します。区間の下側は釣合いを得た率、上側は独立に排除した率です。区間幅が未達、試行数上限、他の率の判定不能は `stop_reason` に残ります。これらを施工ゲートや安全性の合格として扱いません。矛盾する釣合い/排除の証拠がある場合は判定不能とし、区間を返しません。

現対象は既存と同じ乾燥MC、明示的なゼロ変位拘束、対応済み施工接頭部です。水・構造部材・JOINT・Davisの単調探索・MCC/IDHからの変換・材料置換などは拒否します。材料経路のλは補間座標であり、安全率ではありません。

この直接CLIには探索全体の協調停止・保存再開やNative施工ゲートをまだ接続していません。各試行の専用保存点を持つことと、長時間探索全体が途中再開できることを区別します。次の施工は元の未低減Runから行う必要があります。低減後の専用状態を通常の施工保存点へ変換しません。

検証は同じソース版の記録へ対応付けます。単軸の理論比4/3、要求率の実評価、未完を未知のまま保持、塑性プレロード・除荷後の柱の独立応力/ひずみ、工程起点と各率の履歴分離、撤去済み点の凍結、現材料の読取専用監査、不正起点・封印再計算後の施工情報改変の拒否、実CLIを対象とします。一般3D精度・空間収束・元の2D変位5％基準・全35項目のP6完成は別途必要です。
