# 2026-11-07：塑性掘削の面内空間比較

一般3D空間収束、Griffiths斜面の元2D変位5％、正確なFs、P6は未達のままです。GUI/GPUと長時間の大規模求解は実施していません。方法・表・ユーザーPC向けコマンドは [塑性空間比較](../../docs/PLASTIC_SPATIAL_CONVERGENCE.ja.md) に記録しました。

## 実測ファイル

- `plane.json`：24/96/384 Tet4、奥行き1層の押出し掘削。
- `finite.json`：48/192/768 Tet4、奥行き2層で固定した有限幅局所掘削。
- `plane-half.json`、`finite-half.json`：同じ全3段階で、施工増分1/16→1/32と材料積分幅1e−4→5e−5を同時に半減した対照。
- `increment-controls.json`：各対照と元の結果を同じメッシュ・同じ活動領域で積分した差。
- `source-verification.json`：起点コミット、追加ソースと既存の積分器のSHA-256、数値本体・依存定義の不変、開始時と再ビルド後の実行ファイルのバイト一致。

各reportには入力・生の結果のSHA、ソルバーSHA、ドライバーSHA、各段の物理ゲート、塑性体積、体積RMS・相対L2、次数と外挿の拒否理由があります。生の `mesh.json` / `ground.json` / `case.json` / `result.json` は新しい出力先へ再実行して生成します。数時間級の既存MCC掘削・斜面は再実行していません。

開始時の本体CLIと `cargo build --locked --release` 後のSHA-256は共に `56e4c9e5af6fe60b4b15d8bd696eb4e58887c7566eaa0d29d5c5c0ae9133afc9` でした。Rust本体、従来の検証コード、依存定義を変更していないことも照合しました。既存の参照値・許容値・過去の失敗記録を置き換えていません。

## 示せた範囲と未達

有限幅の掘削後全変位RMS差は0.036016→0.016846 mm、応力RMS差は2.507640→1.672348 kPaでした。次数1.0963／0.5845と最細誤差0.014802 mm／3.348226 kPaは、3段階の条件付き推定です。奥行き収束や漸近域の持続を認定していません。

押出し応力は2.787761→1.982204 kPaと減りますが、0.7倍条件に届かず外挿は判定不能。共通位置の掘削増分も0.140613→0.110561→0.114497 mmと振動するので外挿しません。これらの未達を記録に残しています。

Griffithsは同じ奥行き1層の1200/4800/19200 Tet10を準備し、本体の入力検査で全3段の体積220 m³を確認しました。形状・拘束だけの固定データを使用し、実求解とFs探索はしていません。F=1の別ケースであり、過去の低減済み約1.35の比較や元2D変位データを書き換えたものではありません。
