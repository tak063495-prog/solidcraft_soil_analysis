## 再現

リポジトリルートでロック済みの環境を有効にし、出力先に新規ディレクトリを使う。時間は並行負荷を含む Linux での単回計測である。

```sh
set -eu
d=interim/2026-11-24-ocr8-c03-split
out=$(mktemp -d)
cargo build --locked --release --lib
cargo build --locked --release --example t9d_mcc --example c03_bulk_return_trace
target/release/examples/t9d_mcc --compare-ocr8 > "$out/histories.json"
python "$d/mcc_compare.py" "$out/histories.json" "$out/mcc.json"
python "$d/c03_compare.py" target/release/examples/c03_bulk_return_trace "$out/c03.json"
```
