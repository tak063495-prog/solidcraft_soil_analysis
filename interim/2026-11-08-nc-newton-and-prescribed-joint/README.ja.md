標準経路は68.600秒で停止し、前回の最高経路と**実測時間と実行版の来歴 `provenance` 以外のRun全体が完全一致**した。最終ビルドのexampleと採取実行版のSHA256も一致した。保存点や封印を編集した再開ではなく、同じ物理/数値入力からの新規経路である。

最後の棄却先0.951296329498291の53反復について、活動162点×53＝8,586点を、保存されたRustひずみと点別固定分割で既存MCCへ再投入した。各小刻みを順に再積分した最終状態は全点でネイティブ状態と完全一致した。Pythonの別演算順でひずみを復元した開発段階の試行は丸め差で完全一致せず、最終証拠ではRust自身のひずみを使う。参照解の生成ではない。

- **降伏枝と接線**：再始動直後は零増分の弾性側選択と中央差分±摂動が枝をまたぎ、幅1e-9でも942列で塑性小刻み数が異なる。既存暗黙微分との最大相対差は約0.167985。切替点での一般化差分と片側枝の差であり、それだけで誤実装としない。最後の反復52は157/162点が塑性小刻みを含み、幅1e-9の±塑性小刻み数の差は0、暗黙微分との差は最大2.6727350451980615e-9。小刻み数が同じことを全枝列の同一証明とはしない。生の点別枝列も材料結果へ保存した。

## ユーザーPC（Windows）での再現と続行

同梱 `windows.ps1` はWindows未実測の手順で、指定起点の祖先確認、全検査、同じ5 kPa入力生成、標準反復計測、PRESCRIBED独立統合を新規出力先へ実行する。既存の `.venv` に `requirements-reference.lock.txt` の依存を導入してから、リポジトリルートで実行する。

```powershell
powershell -ExecutionPolicy Bypass -File interim/2026-11-08-nc-newton-and-prescribed-joint/windows.ps1 -OutputDir runs/NEW-nc-joint
```

診断exampleは180秒の受理境界予算を持つ。低速PCで時間切れになったら `nc-status.json` の `passed=false` と `run.complete=false` のまま記録し、終端試行の詳細がなければ計測器は失敗する。診断exampleの終了コード0は撤去合格を意味しない。Linux保存点の実行版封印をWindowsへ付け替えない。元保存点再開と別入力経路の違い、既存独立塑性参照と途中再開のコマンドは [NC文書](../../docs/LOW_PRELOAD_NC.ja.md) を参照する。
