## 降雨パルスの半解析参照と自作FV

構成式の出典はSrivastava–Yeh (1991), WRR 27, 753–762,
[doi:10.1029/90WR02772](https://doi.org/10.1029/90WR02772)と、構成式を明示する
[Tubini & Rigon (2022), Appendix C1, (C1)/(C2)](https://gmd.copernicus.org/articles/15/75/2022/gmd-15-75-2022.html#section11)。
ここでは同論文の有限柱の級数解を再利用せず、**半無限領域の境界問題から以下を導出**した。
原論文の未確認の級数係数や二層式は使わない。
逆変換に使うerfc積分の出典は [NIST DLMF §7.14.4](https://dlmf.nist.gov/7.14.E4)。

深さxを下向き、qを下向き正、標高z=−xとする。
u=exp(αψ)、K=Ks u、θ=θr+Δθ u、ψ<0。
`q=Ks(u−u_x/α)`、`Δθ u_t+q_x=0` より
`u_t=D u_xx−v u_x`、`D=Ks/(αΔθ)`、`v=Ks/Δθ`。
初期u=ui=.2、x→∞でもui、表面は基準雨Ks uiに流束パルスを加える。
Ks=1e-4 m/s、α=1 /m、θr=.08、θs=.45。
0 sに+2e-5 m/s、300 sに−2e-5 m/s、終端600 s。

単一ステップδrに対し、時間Laplace変数s、β=sqrt(v²+4Ds)として

```text
δu_hat(x,s) = 2 δr exp[(v−β)x/(2D)] / [Δθ s (v+β)]
δq_hat(x,s) = δr exp[(v−β)x/(2D)] / s
```

減衰する空間根を選び、表面q=δr/sを課すとこの形になる。
`1/(sqrt(s+b)+c)=∫₀∞exp[-cy−y sqrt(s+b)]dy` と熱核の逆変換、
b=v²/(4D)、c=v/(2sqrt(D))を使い、時間積分として評価する。

```text
δu(x,t) = δr/(Δθ sqrt(D)) ∫₀ᵗ exp[−(x−vτ)²/(4Dτ)]
             × {1/sqrt(πτ) − c erfcx[(x+vτ)/(2sqrt(Dτ))]} dτ
δq(x,t) = δr/2 {erfc[(x−vt)/(2sqrt(Dt))]
             + exp[−(x−vt)²/(4Dt)] erfcx[(x+vt)/(2sqrt(Dt))]}
```

パルスは時刻をずらしたステップの和。積分はτ=y²で表面初期特異性を除き、SciPy quadで求める。
確認はLaplace変換への数値再変換、Darcy則、局所保存、表面流束、独立な連続貯留積分、
積分許容値感度。式を未確認の既成の解名で呼ばない。

数値側は自作のセル中心保存形FV。未知量u、実貯留差ΔθΔuを使用。
内部面 `q=Ks[(uL+uR)/2−(uR−uL)/(αΔx)]`。
表面は指定流束、深さ4 mはui固定。600 sで半解析解の底面u増分は約2.31e-13。
半無限解に対する有限領域打切りの大きさを併記し、底境界を厳密に同一とはしない。
u≤0またはu≥1は例外で、飽和枝へ外挿・クリップしない。

空間系列16/32/64/128セルはCN・Δt=.5 s、各水準でΔt=.25 sとの差も記録。
時間系列は128セル固定、後退Euler 20/10/5/2.5 s、共通終端の隣接差から次数を計算する。
パルス端点へ必ず刻みを合わせ、CN/BEと同じ時間則で面流量を積算する。
数値残差やquad許容値、自己検査の次数幅は参照実装の検査用で、本体の受入許容値ではない。

## 旧条件の1D類似柱と水位・有効応力の分離

`vg_column` は旧Ks/VG/Ss・初期H=0・底H=0・3期間を保持するが、**上面全体に雨を与える1D類似柱**。
自作の貯留差BE、調和平均K、減衰Newton、半セル底境界。
上面は `q=min(rain, q_capacity(ψ_surface=0))` とし、超過雨を別台帳へ置く。
表面貯留/表面流出の動力学は解かない。
12/24/48セル・100 sで各工程のH、θ、貯留、浸透・超過雨を出す。
旧3DとのRMS/貯留差・元空間差比には使えず、すべてaccepted=null。
1Dでは横流れがないため、元の無湛水3Dとは異なる浸透制限が生じることも結果に残す。
VG出典：[van Genuchten (1980), SSSAJ 44, 892–898](https://doi.org/10.2136/sssaj1980.03615995004400050002x)。
本参照で採用する具体式・飽和比貯留の定義は旧入力とRICHARDS文書にも照合した。

別の1D診断ではGardner柱の深さ.5 mの**過剰流束**を一方向に地下水貯留槽へ渡す。
`Sy dHwt/dt=q(.5,t)−Ks ui`、Sy=.2、Hwt(0)=.2 m。
基準地下水流出はKs uiで固定。これは降雨の遅れ→涵養→地下水位上昇の明示的な小型モデルであり、
移動する地下水面をRichardsへ戻す双方向の自由境界解ではない。
貯留槽は物理的な井戸を同定したものでもない。

受け手は標高z∈[−1,0]の全域水没弾性柱、一定全圧縮応力50 kPa、E=10000 kPa、γw=9.81 kPa/m。
小ひずみTerzaghi則 `σ'=50−γw(Hwt−z)`、圧縮ひずみσ'/E。
下端固定・上端全荷重を自作1D FEで解き、線形水圧の厳密積分と照合する。
応力の比較位置は要素平均（線形水圧の中心値）、変位は節点。
要素内の定数応力近似まで連続場と丸め精度で一致すると主張しない。
骨格自重と水重量変化は固定全荷重へ含めた理想化で、新しい荷重履歴を暗に追加しない。
有効応力の定義は [ONE_WAY](../../docs/ONE_WAY.ja.md) と区別して明示し、
非飽和のBishop χu、塑性/MCC、JOINT、3Dの受入へ転用しない。

水理解の誤差は `M[Hwt_FV]−M[Hwt_半解析]`、力学誤差は同じ数値水位での
`FE[Hwt_FV]−M[Hwt_FV]`。同じ圧力を入れる力学確認と、独立な涵養の確認を混ぜない。
最細128セルでは水位約.211604152 m（半解析.211604505 m）、
水理由来の応力差約3.47e-6 kPa、力学由来の応力差は丸め程度。
粗い16→32の水位誤差は符号が変わり単調ではない。全結合2次収束とは認定しない。

PC用 `pc_rainfall.py` は同じVGを用いる自作のCartesian 2D/3D FV。
3Dでは元の有限正方形雨を設定できるが、クラウドでは3Dを実行していない。
確認したのは8×8の2D帯状雨・200 sだけ（最大水収支欠損約3.21e-18、反射対称性）。
色分けした疎Jacobianと減衰Newtonを使い、失敗は例外と失敗JSONに残す。
3Dの実行・収束・旧RT0結果との対応付けはPC残件で、旧5行の未定義を解消したとはしない。
