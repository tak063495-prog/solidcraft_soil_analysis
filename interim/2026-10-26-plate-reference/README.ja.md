# 板・実CAD外壁・独立参照の途中成果物（更新6）

P0〜P6全体は未完了です。最新ソース、入力例、環境構築・実行手順、検証ログと限定した検証要約を掲載します。

- FEM本体はRust全247件・Python全67件が合格しました。現在のRust83ファイルとCargo定義は試験実行版に一致します。
- CST膜・DKT曲げの板、梁との共有回転、設置基準・撤去・切戻し・保存再開を接続しました。独立計算と5地点の別プロセス再開を照合しています。
- 実SolidCraftの外壁面からTri6節点を保持して板へ接続し、2メッシュとdrilling係数の感度を含む4条件・20フレームを独立3D計算と比較しました。CSV生値3384点も読み戻しました。これは弾性・節点付着の外壁対照例です。掘削山留め壁、地盤と板の点ごとの変位一致、一般空間収束、native板表示は未受入です。
- MCC独立参照に、元方程式を保持するLU再利用とmatrix-free補正を研究オプションとして追加しました。既定のfresh LUと元の残差基準は保持しています。小規模塑性試験は合格しましたが、実CAD近傍の厳密な成分別比較は未達で、全非線形経路の受入も未完了です。局所ベンチマークの速度比を解析全体の速度比へ読み替えません。
- SolidCraft総合CI v9は終了コード1です。engineの形状基準値比較seed 13/23/36/67が失敗しました（engine内2021件合格・4件失敗・7件無視）。基準値や許容値を更新して合格扱いにはしていません。保守版アプリの配布・実画面受入は未完了です。
- 過去の限定検証と未達記録を保持しています。reports内のpendingは当時の状態で、最新状態はsnapshot-status.jsonを参照してください。ローカルrunパスは由来であり、巨大な全解析結果を同梱したものではありません。
