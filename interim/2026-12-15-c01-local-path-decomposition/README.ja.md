## 3. 解析可能な局所経路

全4経路の法線は(0,0,1)、kn=1,000,000 kPa/m、kt=200,000 kPa/m、mu=0.4。
各入力頂点は(x,gn) [m]、開始値は(0,0)、正のgnは開離。
局所則は本体と同じ機械的なCoulombばねであり、水圧は全体系の荷重を介してjumpを決める。本節の合成経路を水荷重まで含む全体平衡求解とは呼ばない。
§4では保存された機械的法線圧と物理水圧を別々に対応付ける。

|経路|区分線形の頂点|
|---|---|
|rising_pressure|(0,-0.0001) → (0.003,-0.0005)|
|reverse_variable_pressure|(0,-0.0005) → (0.0015,-0.0001) → (-0.0018,-0.00035) → (0.0025,-0.00015)|
|opening_recontact_reverse|(0,-0.0002) → (0.002,-0.0002) → (0.0035,0.00015) → (-0.002,0.0001) → (-0.003,-0.0002) → (0.002,-0.0003)|
|pressure_release_at_fixed_slip|(0,-0.0005) → (0.002,-0.0005) → (0.002,-0.0001) → (-0.001,-0.0003)|

独立解析解は1接線方向のばね＋Coulomb則を使う。閉区間でp=-kn gn、上限c=mu pとし、stickならtau=tau0+kt(x-x0)。
この直線と±cの交点から降伏時刻を求める。slip区間ではtau=±c、ds=dx-dtau/kt。
入力が線形なのでdsの速度は一定、散逸は `D_inc=abs(ds)*(c_yield+c_end)/2` で厳密に積分できる。
gn=0で区間を分け、開いている区間のtractionと仕事を0とし、再接触で接線tractionを0から始める。
開離までにばねの接線力が解放される際の塑性すべり・散逸を含める。開離時に塑性履歴そのものを消さない。
これらは入力だけから導出し、Rust出力のtraction・すべり・分割数から解析解を作らない。

`wet_joint_local_path_probe`は本体の`Material::partition`・`integrate_partition`・`validate_state`を直接呼ぶ。
外側分割1/2/4/8/16/32と内部固定1/2/4/8を交差させ、端点下限 `ceil(norm(Delta jump)/5e-5)`（最小1）、
および凍結された分割の拡張 `needed>frozen` の時 `min(2*needed,50000)` も比較する。
後者は`stages.rs`と同じ規則を診断用の処方trial列へ適用した**規則再生**で、Newtonを実行したという意味ではない。
余分なtrialを処方した場合としない場合を区別する。実際の全体Newtonでの分割数は§4で前回の観測値を使う。
計168経路について全増分・全端点の塑性すべり、traction、増分散逸、累積散逸を保存する。
独立実装の離散端点則も同じ分割数で評価し、本体の離散更新と、連続経路の解析積分の違いを分ける。

独立解析解の細分不変性、定圧の厳密解、変動圧の降伏交点、固定すべり位置で圧力を解放する解析解、
往復・開閉を含む経路を軽量試験で検査する。ここでの丸め誤差検査はC-01の新しい受入許容値ではない。
