## 独立積分の式と適用範囲

`v=1+e`、`p=(σa+2σr)/3`、軸対称圧縮枝で`q=σa−σr>=0`、`εv=εa+2εr`、`εs=2(εa−εr)/3`。応力は有効・圧縮正、kPa。S1より

```
f = q² + M² p(p−pc)
K = vp/κ,  G = 3K(1−2ν)/[2(1+ν)]
A = ∂f/∂p = M²(2p−pc),  B = ∂f/∂q = 2q
D = diag(K, 3G),  z = D [A,B]ᵀ
H = M² p pc v A/(λ−κ)
D_ep = D − z zᵀ / (K A² + 3G B² + H)
dΛ = (zᵀ [dεv,dεs]ᵀ) / (K A² + 3G B² + H)
d ln pc = v A dΛ/(λ−κ),  dv = −v dεv
```

これはS1の一般応力速度式を軸対称の仕事共役対へ代入した導出で、別の構成則を仮定していない。G/Kの式はS1の一定νの等方弾性変換で、S6の拘束弾性率と体積弾性率からも導ける。分母非正、p<=0、e<=0、未対応の塑性除荷枝は失敗とし、応力射影・体積接線下限・pcのクリップを行わない。

- **等方圧密・除荷**：弾性は`Δv=−κ ln(p1/p0)`、降伏後のNC載荷は`Δv=−λ ln(p1/p0)`、pc=p。pcを跨ぐ増分は弾性/塑性区間を閉形式で分ける。`εv=ln(v0/v)`。閉形式には刻み次数を付けない。
- **弾性部分**：`v=v0 exp(−εv)`、`p=p0 exp((v0−v)/κ)`。K0圧密はεr=0なので`q=2(G/K)(p−p0)`。排水ではσr一定より`q=3(p−p0)`かつ`εv=εa/(1/3+K/G)`。体積一定ではp/v一定、q=3Gεa。これらからOCR=4の初回降伏位置をSciPy brentqで求める。NCは開始点から塑性枝。
- **塑性部分**：軸ひずみを独立変数とし、K0は`(dεv,dεs)=(1,2/3)dεa`、体積一定は`(0,1)dεa`。排水は`d(p−q/3)=0`を満たす半径方向ひずみ速度を2×2接線から解く。p/q/ln(pc)等を陽的中点法で積分し、vは各中間点・終点で閉形式`v=v0 exp(−εv)`から求める。K0のεv=εaと体積一定のεv=0も閉形式を使う。降伏位置を各水準で同じ閉形式イベントに整列する。
- **刻み系列**：εa=0〜.08、共通17出力点。各出力区間の内部128/256/512分割、最大軸ひずみ刻み3.90625e−5/1.953125e−5/9.765625e−6。降伏を含む最初の塑性区間だけ短くなる。p/q/pc/e/εvを単位ごとに別々に外挿し、混合単位のノルムで次数を作らない。生の全水準、降伏ドリフト、NCL誤差、体積ひずみ整合誤差を残す。

Richardsonは既知の答えとの誤差から次数を作らず、同じ物理点の差から `r_obs=ln(||U1−U0||/||U2−U1||)/ln 2` を求める。`U_ext=U2+(U2−U1)/(2^r_obs−1)`。主誤差場が同じ方向という条件付きの診断であり、3水準だけで漸近域を証明しない。S5の次数0.5〜8・差の縮小率0.7未満を推定成立性のガードとして引用するが、MCCの合格基準へ流用しない。反転、発散、丸め域では外挿を拒否し、生の次数・差方向cosineを残す。定数のe/εvや閉形式には次数を捏造しない。

非排水は**体積一定の材料点**であり、間隙水圧DOF・時間依存の排水・過渡圧密を解かない。εa=.08は材料点試験で、小ひずみ3Dの使用範囲の認定ではない。S2の限界状態式は漸近値として別記し、有限ひずみ終点の正解値にはしない。

## 将来のCSV/JSON比較契約

`compare_history.py`はGPのp/q/pc/e/εvと節点のux/uy/uzを比較する。生成済みの`*-gp-reference.json`、CSVと`.metadata.json`、`documented-mcc-column-{gp,node}-reference.json`、`original-mc-column-node-reference.json`を形式例に使える。MCC柱の交換例は**残存下層の共通点だけ**であり、上層全履歴や3D全GPの比較ではない。柱の交換例は初期・載荷・除荷・撤去の4フレームで、内部全受理増分の参照ではない。`format-self-comparison`はファイル形式の往復確認で、本体比較ではない。

JSONは`metadata`と`rows`、CSVは明示したJSON sidecarを必須とする。GP列は`step,id,load_coordinate,p,q,pc,e,eps_v`、節点列は`step,id,load_coordinate,ux,uy,uz`。全step×全ID、明示的な初期状態と共通荷重座標を要求する。`load_coordinate`は物理時間ではなく、明示した単調な履歴添字/負荷パラメーター。除荷も履歴座標は増加する。

メタデータはschema、kPa/m/無次元、圧縮正・有効応力、体積ひずみの測度、変位の全体座標符号、case_id、同じ物理入力のphysics_sha256、参照/本体のsource_sha256、全ID、全荷重座標、`run_status=completed`、`history_origin=explicit_initial_state`、`history_completion=none`、`pc_policy=nondecreasing`を必須とする。単位・符号は明示値だけを受け付け、暗黙換算しない。虚偽の単位ラベルを数値だけから常に見抜けるとは主張しない。本体のCSV/JSONに必要な測度や前史がまだなければ対応外として拒否し、勝手に作らない。

p'<=0、pc/e非正、q負、NaN/Inf、重複、欠測、余分な未知履歴列、初期状態なし、pcの減少、eと`ln(v0/v)=Δεv`の不整合、異なる物理条件/座標/ID、timeout/cancelled/partialを拒否する。forward fill・ゼロ補完・節点平均化・自動補間・丸めpc修正はしない。e/εvの1e−7ガード、根探索精度、丸め判定はソフトウェア入力/積分の整合検査であり**物理の受入許容値ではない**。不整合を受入基準緩和で通す設定はない。真のOC軟化は上記の理由で交換契約の対応外。

比較出力は各量の絶対最大差と相対L2、参照ノルム0では相対差null、全て`accepted=null`、`tolerance=未定義`。正常終了コード0は診断ファイル生成の成功だけで、数値受入の成功ではない。拒否は終了2。既存基準を上書きする引数はない。

`assess_series.py`は将来の空間/全体荷重/材料内分割の3水準を別々に診断する。空間系列では深さ・拘束・物理入力・荷重/材料刻みと共通点を固定し、荷重/材料系列ではメッシュも固定する。奥行き系列を面内h系列へ混ぜない。対応する入力例と具体的コマンドは[REPRODUCE](REPRODUCE.ja.md)にある。
