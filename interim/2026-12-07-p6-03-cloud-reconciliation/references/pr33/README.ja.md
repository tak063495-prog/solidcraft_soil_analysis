## 独立押出し参照

円筒軸を**新座標z**にする。a=1 m、b=2 m、内圧100000 Pa、外圧0、E=30 MPa、ν=.25。四分円の対称辺は面内法線変位0。軸方向はεzz=0の平面ひずみと、εzz=1e−4を全域に指定する一般化平面ひずみ（GPS）。閉端の軸力条件は課さない。静的・乾燥・線形等方弾性で、旧MC掘削とは異なる。

Lamé解を半径方向釣合い `dσrr/dr+(σrr−σθθ)/r=0`、`εrr=du/dr, εθθ=u/r` と3D Hooke則から確認する。引張正で：

```text
A=(pi*a²−po*b²)/(b²−a²), B=(pi−po)*a²*b²/(b²−a²)
σrr=A−B/r², σθθ=A+B/r²
u_r=[(1+ν)(1−2ν)A/E−νεzz]r+(1+ν)B/(Er)
σzz=2νA+Eεzz=ν(σxx+σyy)+Eεzz
```

平面ひずみのσzzは16666.666666666668 Pa、GPSは19666.666666666668 Pa。文献[1]の厚肉円筒解を上式の境界牽引・釣合い・構成則で検査する。未確認の半無限体公式は使用しない。

自作Q4/Hex8は全積分2×2／2×2×2、工学せん断、正Jacobian検査。面内は直線辺の円弧近似で半径2/4/8、角度4/8/16分割。3Dは長さ1 m・1層、**全節点uz=εzz*z**として同じ押出し条件に拘束し、3D構成則と組立を別次元で評価する。この3D対照は軸方向自由端の検証ではない。

2Dの力・仕事・エネルギーには奥行き厚さ**1 m**を採用する（面積積分と辺荷重へ掛ける厚さの数値は1）。2Dの報告N/Jはこの1 m厚さに対する値で、単位奥行き当たりのN/m・J/mと混在させない。有限箱のQ4対照も同じ厚さ1 mである。

誤差は各積分点の解析解に対する体積重みL2。変位は2D/3Dで共通の面内(ux,uy)、全応力は6成分Frobenius重みを使う。指定した3Dのuzはこの変位誤差に加算しない。変位次数は約1.92→1.98、全応力は約.92→.98。直線境界近似を含むQ4/Hex8の結果であり、応力の2次収束を主張しない。σzz単独の誤差・次数、2D/3D、GPS、全水準の値は `results/summary.json` の `rings`。点ごとの関係残差、自由DOF残差、全反力＋荷重、ひずみエネルギーを保存する。非零指定変位/GPSの仕事は反力仕事と軸方向仕事を含めて `.5∫ε:σ dV` と比較する。

最細でも平面ひずみの全応力相対L2は約6.384%、σzz単独は約11.333%（GPS約9.604%）を残す。σzzの観測次数は約.9713。関係式残差が丸め程度であっても応力場の精度が十分だとはしない。解析解への収束を観測する小型参照であり、任意の精度基準の達成は宣言しない。

## 独立振動参照

旧静的モニターに存在しない物理条件を推測せず、明示した別問題で変位・速度・加速度・周期・エネルギーの診断能力を確認する。

- 1自由度自由応答：m=2 kg、k=400 N/m、u0=.01 m、v0=.02 m/s、ζ=0と.03、c=2ζmω。ω=√(k/m)、ωd=ω√(1−ζ²)、周期2π/ωd。解析解は `u=e^(−ζωt)[u0 cos(ωdt)+(v0+ζωu0)/ωd sin(ωdt)]`、vを微分、a=−2ζωv−ω²uとする。
- 固定自由の縦振動棒：L=2 m、A=.01 m²、E=2 GPa、ρ=2000 kg/m³。u(0)=0、EAu,x(L)=0。PDE `ρA u,tt = EA u,xx` の第1形状 sin(πx/2L)、`f1=√(E/ρ)/(4L)=125 Hz`。曲げ柱のモードではない。初期先端振幅/速度は同じ。分布減衰は質量比例 `C=2ζω_cont M`。文献[2]とPDEへの代入で確認する。
- 棒は自作線形2節点FE、整合質量（要素M=ρAh/6 [[2,1],[1,2]]、K=EA/h [[1,−1],[−1,1]]）、4/8/16/32要素。固有値は `Kφ=ω²Mφ` を解く。連続125 Hzに対する周波数誤差は2次。時間収束は16要素の**半離散固有振動数とその減衰率**に対する誤差として、空間差と分ける。

自作Newmark平均加速度法 β=1/4、γ=1/2 [3]。5周期、20/40/80/160刻み/無減衰周期。u/v/aの誤差と観測次数をすべて保存する。動的釣合いの外力は0。各刻みで

```text
E=1/2 vᵀMv+1/2 uᵀKu
D_n=Σ Δt * v_midᵀ C v_mid, v_mid=(v_n+v_n+1)/2
E_n + D_n − E_0 = 0
```

を検査する。これは平均加速度法の**離散**エネルギー恒等式で、連続減衰積分や位相精度が厳密であるという意味ではない。無減衰と減衰の両方を検査し、応答誤差の2次収束と分けて保存する。`*-history` はNewmark時刻歴、`*-analytic-history` は同じ時刻の連続解析解。rodの場合は連続空間誤差も含む。旧記録から動的周期等を再現したとはしない。

## 有限幅・有限奥行き参照

自作Hex8の有限弾性箱：x∈[−2,2] m、y∈[−2,0] m、z∈[−L/2,L/2] m。E=30 MPa、ν=.25。底面全変位0、x側面ux=0、**z端面は無荷重の自由端**。上面の|x|≤B/2、全zへ100 kPaの鉛直下向き圧力を与える。剛な基礎板・接触は無く、与圧の有限長矩形フットプリントである。旧MCの変位拘束端・部分掘削と区別する。半無限地盤の解ではない。

B=1/2 m、L=2/4/8 m、h=.5/.25 m（level1/2）。幅と奥行きとhを一つずつ比較できる12条件。最大4096 Hex8・5049節点・15147 DOF。全条件の圧力合力、反力平衡とエネルギーを検査する。別のQ4平面ひずみ箱に同じ断面・支持・hを使う。

観測点は**固定した(x,y)=(0,−1) m**、z=0〜L/2の9点。元の有限要素形状関数を指定物理点で評価し、メッシュ境界では+x/+y側の片側トレースを使う。zも要素境界なら+z側、外端z=L/2では内側を選ぶ（候補要素の下端座標をz,y,x順で辞書式最大にする実装）。σzz/σyyの分布、`σzz−ν(σxx+σyy)`、中央−同メッシュ平面ひずみ、自由端−中央を分離する。外部CSVの補間や応力平滑化はしない。z端面の応力回復値を厳密な点ごとの無牽引値とはしない。

例：B=1 m、h=.25 mの中央σzzはL=2/4/8 mで約−3.009/−8.815/−13.605 kPa。同じhの平面ひずみとの差は約13.387/7.581/2.791 kPaへ減るが、端部−中央は約.749/6.619/11.484 kPaと別の挙動。L=8 mでも平面ひずみ極限を達成したとはしない。B=2 mやメッシュ差も全値を保存する。
