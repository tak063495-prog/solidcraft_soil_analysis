## A-01　原因と比較の範囲

初期予測では法線・接線剛性を持つ固着側接線を使う。弾性を仮定するのはこの予測だけで、棄却試行から接触履歴を引き継がない。支持、材料、線形ソルバ、各段階の8分割、Newton・候補列の上限と力残差条件は同じ。

|Tet4|元の独立系 BIRTH|新しい独立系 BIRTH → shear|元の open 進捗0.125への試行|別の短経路で元の open 0.02 に対応する終点|
|---|---|---|---|---|
|18|受理0、到達0|各8増分、各1.0|初回を line search が棄却。受理0|両系が8増分。変位絶対 L2 差 5.47×10⁻¹⁶ m|
|144|受理8、到達1.0|各8増分、各1.0|初回を line search が棄却。受理0|両系が8増分。変位絶対 L2 差 8.16×10⁻¹² m|

元入力の本体は両格子とも BIRTH・shear を各8増分受理し open で停止した。18 の BIRTH 終点では世代 [1,1]、活動枝不一致0、変位絶対 L2 差 4.46×10⁻¹⁵ m、traction 絶対 L2 差 1.04×10⁻⁹ kPa。初期予測だけを変えた対照により、18 の元の BIRTH 停止には新設時の接触枝の扱いが寄与したと判断できる。

短経路は BIRTH と shear をそのまま解き、open の終点荷重係数を 0.04 + 0.96 × 0.02 に置いた別入力である。全支持成分、荷重係数、受理進捗の増加方向、世代、面・所有側・位置・法線・重みの一対一対応、全 GP の活動枝を検査してから変位・応力・traction・jump を比較した。T7 の弧長系列の 0.125 では引き続き同枝の対応を保留する。**平行2面の物理分類は D**。崩壊・分岐荷重と工学量の受入幅は保留。[T7 の停止・弱空間・方向の記録](../2026-11-22-impl-t7-physical-instability/README.ja.md)

## A-02　先端を跨ぐ力移行

面一定場を、GP の変数に面積重みの平方根を掛けて物理節点力に写す。得られた面一定場に対して同じ全節点力を再現する最小補正を加える。既存の SVD 切断値 1e−12、各節点成分の絶対差 1e−10 kN、各 GP の無引張・摩擦条件で検査する。両側で共有する節点の仮想仕事は相殺する。

|24 Tet10・32 GP|既定の力移行|明示設定|判定|
|---|---|---|---|
|S1-A 元入力|継手 BIRTH 受理0、進捗0|同じ要求力で拒否、受理0、進捗0|未達。節点75・76・79・80で摩擦条件との非両立を確認|
|同じ先端メッシュの一軸圧縮施工|土の新設4・継手 BIRTH 4、終点1。解析 traction に対する最大 GP 差97.8436 kPa|同じ4+4増分、終点1。最大 GP 差2.70×10⁻¹³ kPa、全節点力最大差4.26×10⁻¹⁴ kN|節点力の再現を限定受入。GP 誤差はこの解析パッチでの測定|
|同じ先端の小面に −100、−10 kPa を与える節点力パッチ|最小ノルム場に引張が生じ拒否|両小面が受理、最大 GP 差2.56×10⁻¹³ kPa、全節点力最大差3.55×10⁻¹⁵ kN|再現可能な力移行を限定受入。単一の誕生イベント|
|引張・円外・合力とモーメントが零の非再現要求|3件拒否|3件拒否|旧拒否を維持|

元 S1-A の節点80は、面の全積分点で形状関数が非負である。各点のせん断力ノルムが μp 以下なら、正の重みで足した節点のせん断力も μ 倍の節点圧縮力以下になる。必要なせん断 5.130717 kN に対し上限は 0.3 × 4.673816 = 1.402145 kN。この要求を実現する Coulomb 場は存在しない。S1-B への変更や節点力の再配分は行っていない。

一軸例の解析参照は、重力平衡済みの下層に、無応力の土を配置し、先端に残る tie の力を新設継手へ移す場である。ν=0、上面変位 −0.001 m、高さ1 m、上層厚0.5 m、E=100000 kPa、単位体積重量20 kN/m³。既存下層の追加圧縮と上層の自重勾配から境界面の traction は (E u上 − γ h上²/2)/H = −102.5 kPa。継手は非零力を引き継ぐ S1-A である。開発時に上層土の配置入力へ非零の初期応力を与えた試行は、従来の乾燥・無応力土配置規約で拒否された。

## A-04　開口貯留と全連成参照

面 f の水量は V_f = Σ w_q (b₀ + n_q·[u]_q)。2つの所有セルから外向きの RT0 流量には Q_a + Q_b = (V_fⁿ⁺¹ − V_fⁿ)/Δt を課す。両壁へは共通水頭による圧力荷重が作用する。全規定継手が活動中の CONTINUOUS で、面は水に満たされ、求積点の水理開口が正の範囲に限る。負開口を数値的に切り上げない。施工で活動領域が変わる経路、面内流れ、未飽和亀裂は対象外。

独立 Python 参照は入力から Tet4 の RT0 質量、土・固着ばねの剛性、壁圧と間隙圧の荷重、開口変化行列を別組立する。自由変位・セル水頭・面水頭を各時刻で同時に解き、圧縮固着・飽和の仮定を検査した。Rust の水頭・変位・受理履歴を参照への入力に使わない。以前の停止原因は省略可能な `flow.head_datum_m` の `KeyError`。省略値を 0 m とし、明示 0 m と基準面を1.5 mに変えた場合も同じ物理場を照合した。
