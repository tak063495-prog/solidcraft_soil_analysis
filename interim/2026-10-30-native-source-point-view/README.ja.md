# 大容量MCC結果とSolidCraft Native表示の接続

2026-10-30の途中成果です。目標は再開中です。正式採用・P6全体の完成・新PC向け配布の受入はまだです。FEM本体の公開Rust・Pythonコードは変更せず、このフォルダに試作ソースと検証記録を保存しています。

## 実装と確認できた範囲

新形式 `soil-fem-solidcraft-view/4` をPython出力・外部VTU検証・Native読取へ接続しました。積分点の値を表示用JSONへ再複製する代わりに、元結果全体のSHA256、段階、配置点数、活性点数、単位・符号・成分順へ結び付けた参照記述子を保存します。Nativeの生値照会は同じ元結果の応力・塑性ひずみ・間隙比・先行圧密圧力を使い、射影値を別に再構成します。セル平均と生の積分点値を区別し、節点への応力平滑化は加えていません。

8,061 Tet10要素、217,647積分点、832平板の実解析結果で、元CAD・入力・生成記録・ソルバー・既存の全力学監査との結び付きを保って全5段階を出力しました。元結果は1,459,184,313 byteのままです。表示パケットは45,314,921 byteで、従来方式の実測840,638,926 byteから重複出力を減らしました。**表示パケットだけで元結果を置き換えるものではなく、元結果ファイルも必要です。** 単一表示ファイル256 MiB・パケット合計512 MiBの制限を維持しています。

- 外部検証は全5段階の全活性積分点・節点・セル・構造部材を既存VTUと照合しました。新たな独立非線形解法の精度検証を追加したものではありません。
- 実Native公開APIでも全5段階を開き、生値・節点135項目、射影積分点300項目、平板の生値90項目が独立に読んだVTUと一致しました。非有効積分点の拒否、断面・変形倍率・量の変更後も生値が変わらないことを確認しました。積分点と平板のAPI照合は材料・位置を分けた代表点の検査です。
- 既存の535,711,781 byteのMCCケースも、従来形式で全5段階・代表75項目が一致しました。
- Native差分73ファイルでfmt、engine全target確認、関連39試験、clippy全targetが合格しました。既存の無視設定1件を残しています。
- Python試作628ファイルは全208件が合格しました。重複JSONキーの最後の値だけを採用する旧挙動を負例として確認し、新読取で拒否します。参照先の相対パス、段階一覧、ファイル一覧、単位・符号・未知キーの改変も検査します。強化後の外部検証でも同じ実ケースの全5段階が合格しました。

保持予算は元結果の型付き保持と射影キャッシュ等の個別予算です。512 MiBをプロセス総メモリ保証とは扱っていません。元結果上限2 GiBやPython分割成分の上限もあり、一般の10万要素CAD結果の読取を受入済みとはしていません。

## ソースと再現条件

`native/source73.zip` はSolidCraftの差分です。上流 `tangency-labs/solidcraft` の `edf57cec293dcea301201f1d5173b33e16351466` を通常のGitチェックアウトで用意し、上書きします。`.git` のない展開ではビルド識別子unknownのキャッシュ拒否が起きます。unknown拒否は緩めていません。実験中の差分は未コミットで、実際に検証した各ファイルのハッシュをsource73.jsonに保存しています。ライセンス・帰属も同梱しています。

`python/source628.zip` は別フォルダへ展開する外部FEM・検証ツールの試作スナップショットです。Rust計算コードと受入済みA4実行ファイルは変更していません。既存依存に加えて `ijson==3.6.0` が必要です。同梱のwheelハッシュ固定は検証に用いたWindows CPython3.13向けであり、他OS用lockではありません。

`real8061-inputs.zip` は既存のCAD捕捉・メッシュ・地盤・施工入力と生成記録です。元の受入記録を書き換えず保存しています。元結果1.459 GB、VTU群、コンパイル済みバイナリ、画像は含めていません。元ケースの再作成と新しい計算・検証記録の生成が必要です。このフォルダだけを展開して大容量の全試験が直ちに再実行できる状態とはしていません。`local-procedures` は検証時のローカル配置を前提とした手順保存です。

この既存ケースの板生成記録は旧600ソースの版に結び付いていました。現行の板ツールで初回照合が正しく拒否されたため、保存された `plate_surfaces.py` をハッシュ確認して明示選択し、元記録との照合を通し直しました。使用した旧版と600ソース一覧を `historical-preparation` に保存しています。記録の書換え・ハッシュ検査の省略は行っていません。

続きは、新形式の実画面・全体CI、14,909要素の完了と比較、大容量一般ケースの読取・配布、一般の非一様塑性の独立比較、構造と水の組合せ、降雨細分化ケースの再開・力学、入力UI・永続面ID・新PC検証などです。P6全体を、ここで合格した表示・保存の範囲へ縮小していません。
