## 極限平衡の式・探索の意味

鉛直スライス、乾燥、単一材料だけ。αは右下がりを正、`s=sinα, q=cosα, μ=tanφ, C=c*l` とする。底面反力は `(N*s-T*q,N*q+T*s)`、`T=(C+μ*N)/F`。左/右側力を `(E_L,X_L),(-E_R,-X_R)` として `X_j=λ f_j E_j`、`a=s-μ*q/F, b=-C*q/F` とおくと、各スライスの二方向釣合いから

```text
E_R = E_L + a*N + b
N = [W - C*s/F - λ(f_L-f_R)*E_L + λ*f_R*b]
    / [q + μ*s/F - λ*f_R*a]
```

を得る。`E_0=0` から伝播し、`E_n=0` と全体の原点周りモーメント
`Σ[x_b*(N*q+T*s)-y_b*(N*s-T*q)-x_g*W]=0` をF/λについて解く。Spencerは `f=1`、MPは端点間の `f=sin(πξ)`。側力は共有面で打ち消し合う。局所モーメントから側力作用高も再構成し、推力線を診断する。簡易Bishopは円弧だけで
`F=Σ[(c*b+W*μ)/(cosα+sinα*μ/F)] / Σ(W*sinα)`。非円弧へこの円弧式を流用しない。

円弧は天端進入a、斜面退出b、弦からの矢高dで定める下側円弧。非円弧はその円弧に `A*sin²(πξ)`、A=-0.5/0/+0.5 mを加えた**限定した族**で、一般自由形状の最小化ではない。各スライス底を弦で近似し、地表折点x=12で分けたGauss積分で多角形の重さ・重心を求める。底面下/地表上、空スライス、特異な式、未解決のrootは件数を保持する。探索内の有限候補最小であり、探索外や他のroot枝を除外した大域下限/厳密区間ではない。

引張N/Eや推力線逸脱を黙ってクリップしない。`min_normal/min_interslice/thrust_inside_mass` と、追加の圧縮のみ診断 `compression_only_minima` を保存する。**元のRankine面なしMCは有限の引張を許すため、圧縮のみ診断を元モデルの受入基準にしない。** 追加診断はFsの物理的排除証明でもない。root残差や圧縮診断用の丸め幅は数値制御であり、新しい物理的合格しきい値ではない。

## 小規模な独立平面ひずみSRM

`srm.py` は領域を写像したCST三角形、面外ひずみゼロ、微小ひずみ、弾完全塑性MC。各Fで無応力から自重を8増分で載荷する。`c_F=c/F, φ_F=atan(tanφ/F)`、ψ=0固定。引張正の主応力で全6面
`(1+sinφ_F)*σ_i-(1-sinφ_F)*σ_j-2*c_F*cosφ_F<=0 (i≠j)` を使う。流れ勾配はφをψへ置換する。主応力空間で、弾性試行から `σ=σ_trial-D_pr*G^T*Δλ`、活動面の `A*σ=k` を連立し、Δλ非負と全降伏面を検査する後退Euler。1/2/3面の活動集合を列挙し、固有ベクトルで戻す。この式は構成則と離散整合条件からの直接導出で、未確認の平滑化MC式ではない。ψ=0のapex等で集合が得られなければ未確定で停止する。

2D内部力は奥行き1 mを掛けた数値としてkNで扱う（単位幅表示のkN/mと数値は同じ）。比較の応力はkPa、変位はm、塑性ひずみは無次元であり、厚さを変えた3D力へ黙って転用しない。

全体Newtonは数値整合接線、疎行列直接解法、残差減少の線探索。数値制御は相対自由度力残差1e-8（既存Griffiths比較文書の力残差基準と同じ）、Newton35回、接線差分ひずみ1e-8、局所降伏丸め幅1e-7 kPa。これはこの探索器の停止制御であり、既存本体の残差基準やP6受入を置き換えない。試験では剛体/アフィンパッチ、面積220 m²、自重4400 kN/m、Tresca限界、MC降伏・ゼロ膨張・仕事・回転客観性、実重力求解を検査する。
