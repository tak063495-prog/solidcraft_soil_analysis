## 対象と比較の意味

ユーザー PC の xy2（4,800 要素）は geostatic 進捗 0.4717、`||r_free||/max(||F||,1)=1.109e-7 > 1e-8` で失敗。0.44 付近から GMRES が 3,000 回、続いて Newton が 35 回の上限へ達する。細分化時の `1.33e-8 → 3.47e-8 → 1.11e-7` はユーザー報告の観測であり、今回クラウドで再現した数値ではない。

今回再組立するのは、既存の pinned Griffiths 形状・同じ Tet10 順序・27 点積分・全 y 拘束・同じ x/z 支持による**零応力種での弾性初期接線**。xy1-ny1 の 1,200 要素、2,583 節点、32,400 GP、4,860 自由度、210,204 CSR スロット、体積 220 m³。E=100000 kPa、ν=0.3、γ=20 kN/m³。`K=Σ BᵀDB w` と重力 `b=Σ Nᵀγ w` を既存 Python 積分器で組む。正の cohesion を持つ零種の最初の接線では、強度低減の有無によらず弾性 D が同じ。塑性が進んだ接線や 2D Q8/hourglass 行列へ置き換えない。

小さい 24 Tet10 の別モデルでは、同じ Python 行列による解と、既存 Rust `solve-stages` の弾性 geostatic 変位・自由度釣合いを試験で照合する。これは実組立・拘束・重力の対照であり、失敗地点の塑性接線の一致を認定するものではない。

`compare` は凍結 CSR A/b の読み書きと、任意の元 GP アルゴリズム接線の再組立にも対応する。失敗反復の元行列はまだ提供されていないため、**xy2 の失敗原因を確定したとも、ILUT で xy2 が完了したとも主張しない**。確定 Run の応力から continuum 接線だけを作り、それを本体の有限差分・固定 partition のアルゴリズム接線だと扱わない。

## 前処理の比較

生の前処理なし対照 `none_raw` と、行最大スケーリングだけの対照 `none` を別に置く。ILU/ブロック系は行最大スケーリングと右前処理を使い、restart=60、内部反復上限=3000、初期解ゼロ。受入は元 A/b の `||Ax-b||/||b|| <= 1e-10` と、`||Ax-b||/max(||F||,1) <= 1e-8` の両方。既定の弾性重力系では `F=b` のためこの二つの値は一致する。後者は**線形補正の残差**であって、非線形 Newton の力残差そのものではない。

## 条件数・スペクトルと細分化の解釈

弾性 xy1 の非対称比 `||A-Aᵀ||F/||A||F` は約 `6.45e-17`。疎 LU の inverse action と `onenormest` による 1-ノルム条件数の粗い推定は約 **4.9e4**。確率的な試行方向で推定は多少変わり、厳密値や保証上限ではない。ARPACK の最大側・零近傍の固有値標本は約 `2.1650e6` と `1.6566e2`、比は **1.3069e4**。この対称な弾性行列では κ₂ の粗い推定として読めるが、塑性の非対称・非正規行列では固有値比を条件数に読み替えない。

同一形状・支持で通常の変位型楕円問題を h 細分化すると、未前処理の条件数は概ね O(h⁻²) に増える。ILU(0) と節点 Jacobi は遠距離の fill・粗格子補正を持たず、低周波の誤差モードを十分に除去できない。restart 後に必要な Krylov 情報を失うことも停滞を助長する。今回も節点ブロックだけでは 1182→947 回に留まり、ILU(0) 229 回に対し ILUT は 6 回まで減った。ILUT の分解量は ILU(0) の約4.2倍であり、メモリーとの交換になる。

短い別対照として、単位ブロックの乾燥弾性接線を x/z だけ細分化し、ny=1 と支持を固定した。これは Griffiths の h 系列や塑性経路ではなく、幾何学的な悪条件化だけを調べる 24/96/384 要素の実験である。全7手法・全3水準が元の線形基準を満たした。生結果は `refinement-probe.json`。

h 半減ごとに固有値比が約3.4～3.6倍となり、行スケールのみ・ILU(0)の反復数も増加した。小さい弾性問題での傾向であり、これから xy2 の塑性停止の原因や反復数を外挿しない。

MC 非関連流れの塑性域拡大では D が非対称になり、低い接線剛性、載荷/除荷枝や局所 substep の変化が加わる。このため弾性 h⁻² だけから実際の悪化率を予測できない。線形反復が上限に当たると Newton 補正も不十分となり、刻みを小さくしても同じ難しい接線方向が残り得る。カットバックで材料の枝・partition・RHS が変わるので、残差列の増大を「細分化そのものが物理的に不安定化した」証拠にはしない。

観測は前処理不足という仮説と整合するが、戻り写像の枝、接線整合性、局所 partition、行列の特異化、非線形停滞も切り分ける必要がある。特に直接法が小残差で解いても、その後の Newton が改善しなければ線形解法だけが原因ではない。今回の κ は失敗時刻の κ ではない。

## 推奨と Rust での次の確認

第一候補は **元の右前処理 GMRES を維持して、順序変更を伴う ILUT を実験比較すること**。まず drop=1e-4 / fill 目安10を今回の比較点とし、採用値と断定せず、同じ凍結塑性行列で fill/残差/反復数/ピボット/メモリーを確認する。全結合 ILUT を第一候補とし、メモリー不足時は成分別 ILUT を比較対象とする。成分ブロックだけでは材料の x/z 連成を落とすため一般解にはしない。

節点2×2だけを本命とする根拠は弱い。AMG は将来の大規模候補だが、弾性系の剛体 near-nullspace、成分連成、塑性の非対称・不定性、粗格子解法を扱う必要があり、今回は未比較。疎直接法は xy1 の診断対照として有効だが、xy2 以降の fill とメモリーを測らず本体既定へ入れない。

具体的な観測点、元 A/b と外力ノルムの保存、Rust 実験案、PC コマンド、想定時間、出力と合否基準は [REPRODUCE.ja.md](REPRODUCE.ja.md) を参照する。**この PR は診断と提案だけで、`src/linalg.rs` / `src/stages.rs` は変更しない**。xy2 本体、大規模メッシュ、長い系列はクラウドでは実行しない。
