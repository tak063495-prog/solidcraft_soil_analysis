# C-03　MCC 塑性仕事の片軸比較

開始時の origin/codex/plastic-spatial-convergence 先端は `acb8dea7ea7a77ee5e52c29754b6f9f83c2a6249`。

ユーザー決定に基づく比較量は、各材料内増分の終端有効応力と塑性ひずみ増分の内積を、ガウス点の物理体積重みで積算した仕事。圧縮正、Voigt 順序 xx, yy, zz, xy, yz, zx、応力はテンソルせん断、ひずみは工学せん断である。主値は直接の6成分内積から求めた。1 kPa·m³ = 1 kN·m。

各材料内増分で、別途 p′=tr(σ′)/3、q=√(3s:s/2)、Δεᵖᵥ=tr(Δεᵖ)、Δεᵖₛ=√(2Δeᵖ:Δeᵖ/3) を計算した。s と Δeᵖ はそれぞれの偏差テンソル。後者のノルムでは工学せん断三成分の二乗和に1/2を掛ける。qΔεᵖₛ は直接仕事から体積仕事を引いて作らず、関連流れ・後退 Euler のその材料内増分における方向整合を検査できる。一般の非共軸増分でこの2項の和が同じになるとは仮定しない。棄却や Newton の仮状態は積算に含めない。

固定した入力は既報の12 Tet10・324材料 GP・32接触 GP、open 係数0.12、7工程×32受理座標。前回の MC の数値は保存し、既報の標準湿潤 MCC の塑性ケース（pc=105 kPa、初期 p′=100 kPa、e=0.7、M=1.2、λ=.2、κ=.04、ν=.3）をこのメッシュに用いた。材料上限 m0=1e−4、m1=5e−5、接触上限 c0=1e−4 m、c1=5e−5 m。本体は実際に受理したひずみ増分・分割数を本体 MCC で再生し、独立系は独立求解中にその系の受理変位と材料分割から再生した。6経路の全受理点で応力・塑性ひずみ・pc・間隙比の材料終端を各系の受理値と完全一致照合した。
