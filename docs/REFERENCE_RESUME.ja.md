# 中断した独立MCC参照の工程単位の再開

`tools/resume_projected_sparse_study.py runs/<study>` は、`run_projected_sparse_study.py` が保存した固定入力・参照ソースを使い、完了済みの初期化を再利用して施工計算を続ける。未完了工程の途中増分を復元する機能ではない。初期化が未完了なら初期化から、施工が未完了なら施工工程全体から再計算する。

ルートで開発中の参照ソースをコピーし直さず、各studyの `reference-sources` を実行する。元の刻み数、計算方式、依存固定、入力と保存済み結果の由来を照合し、不一致や途中書込みのJSONは上書きせず拒否する。過去の200分割と同じコードを明示的に維持した400分割については、履歴の版対応表、元の完了結果、そこで使用したコード指紋を照合する。

各再開の進捗は `resume-attempts/<UTC>/progress.json`、最新の場所は `latest-resume.json` に残す。従来の `progress.json` や使用量による中断記録は保持する。同時実行はロックで拒否する。強制終了でロックが残った場合は所有プロセスの終了を確認してから処理する。

この工程再開は、Rust本体の受理増分チェックポイントとは別の機能である。参照の実行完了だけで、精度・空間収束・全P6の受入とはしない。
