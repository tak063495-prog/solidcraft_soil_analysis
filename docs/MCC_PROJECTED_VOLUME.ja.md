## 後続Rust開発版：P1体積と凍結適合差

累積体積は材料別の節点値と全GP値を照合し、元の間隙比との指数関係を検査する。局所DEATHでは既存pc・間隙比・塑性ひずみ・GP累積体積を変更せず、残存領域の `∫Nᵀ(div uold + θold)` を凍結して保存する。再開時は施工起点からも凍結値を再構成する。圧力整合は材料別P1の弱形式とし、生GP平均応力との最大差は診断値として別保存する。従来GP方式の点ごとの圧力整合基準を変更したものとして扱わない。

反力・釣合い・保持力は材料の偏差応力と一次圧力から計算する。領域変更後は投影自体が変わるため、旧全体内力から撤去要素内力を差し引く方式を流用せず、既存履歴を保った残存領域の内力と新しい外力との差を段階解放する。全242 release Rust試験（40試験対象、失敗/無視0）、all-targets clippyと書式検査が正常終了した。26ライブラリ試験には新3場接線の全ブロック差分を含み、新3施工試験では局所DEATHの非ゼロ適合差、凍結履歴、密/疎、棄却後の対照経路、再封印した不正体積・不正適合差・方式変更の拒否を確認した。

## GP独立体積の斜面初期化で判明した問題

材料ひずみ上限を追加した開発実行版59207c2cの実斜面再開は、初期平衡進捗77/512 = 0.150390625でラインサーチが停止した。最大材料ひずみ0.0468926は入力上限0.05以内だが、自由表面付近のGP5208で平均有効応力が0.000235845 kPaへ低下して塑性化した。柱での限定受入と区別し、この結果を一般斜面の平衡・破壊判定へ使わない。

`tools/mcc_geostatic_fraction_reference.py` は同じ元入力と進捗から、保持力を種応力・形状から独立に再構成し、従来の適合ひずみを使う速度形MCC全体FEMを計算する。Rustの変位・圧力未知量・履歴・保持力ベクトルは入力しない。独立25→50分割の変位変化は最大6.092e−10 mであり、塑性GPは0点、最大ひずみ0.00184520、GP5208の平均応力は0.0473888 kPaだった。混合版との全節点変位相対差は0.0262958、最大成分差0.000286588 mである。

`tools/compare_mcc_initial_fraction.py` と `runs/mixed-mcc-initial-fraction-20261025-v1/comparison.json` に全場・GP対応・種応力一致を記録した。種応力のP1投影誤差は最大1.745e−8 kPaで、初期圧力の投影ずれを主因とする修正の根拠にはならない。GP体積空間とP1圧力制約による局所モードが疑われるが、空間細分化による切り分けは未完了である。

## 比較用のP1体積投影

`tools/mcc_projected_volume_diagnostic.py` は、変位をTet10、体積ひずみを材料境界で分離した連続P1場として計算する。既存の独立MCC連続体接線・イベント付き中点積分を使い、Rustの材料更新や解状態を使わない。密な縮約計算を使うため自由変位1500 DOF以下に制限する。安定化係数、剛性追加、圧力の下限処理は導入していない。

引張正のひずみ行列をB、その偏差成分をBdev、体積成分をbdiv、材料別P1形状関数をNとする。

```text
M = ∫ Nᵀ N dV
D = ∫ Nᵀ bdiv dV
A = M⁻¹ D
Bbar = Bdev + I/3 N A
εmaterial = Bbar u
```

圧縮正の材料平均応力pmを `p = M⁻¹ ∫Nᵀ pm dV` と投影すると、仮想仕事に共役な内力は `−∫Bbarᵀ σmaterial dV = −∫Bdevᵀ σmaterial dV − Dᵀp` になる。材料GPの平均応力とP1圧力は別の場であり、圧力整合は弱形式である。生の材料応力を通常のBへ掛けた内力は、一般には同じ節点釣合いを満たさない。従来GP方式の点ごとの圧力整合ゲートや生応力の釣合いゲートを、この方式へ黙って緩めて適用しない。

体積ひずみを独立な節点値にして材料則へ渡す考え方の参考は[Rossi・Zorrilla・Codinaの原著](https://doi.org/10.1016/j.cma.2021.113701)。原著の安定化された低次u–体積ひずみ法と、ここで試す無安定化Tet10/P1投影は同じ離散化ではない。この文書の縮約式・局所掘削時の履歴方針は比較用モデルとして定義したもので、原著によるMCCの一般安定性保証と解釈しない。

## 基礎照合と局所撤去の履歴

アフィンひずみ、ランダムな仮想仕事、独立に作用させた接線を検査した。実斜面の最大アフィンひずみ誤差は2.254e−14、仮想仕事の相対誤差5.249e−15、接線作用の相対誤差5.492e−16だった。

`tools/verify_projected_volume_diagnostic.py` は同じ幾何節点にある異材料の10/30 kPaを区別し、最大圧力誤差1.066e−14 kPaで保持した。NC等方圧縮100→130 kPaは `v1=v0−λ ln(130/100)` と `pc=p`、体積ひずみと塑性体積ひずみを理論照合した。初回50分割のpc誤差0.000244108 kPaは1e−6 kPaの基準を満たさず、失敗ログを保持する。基準を変えず1000→2000分割へ細分化し、細かい計算のpc誤差1.514e−7 kPa、比体積誤差1.856e−10、変位誤差2.336e−11 m、塑性体積ひずみ誤差6.540e−11となった。

局所DEATHでは投影空間の積分領域が変わる。既存の累積体積ひずみθoldを、新領域で計算した全変位の投影値へ置き換えると、過去の間隙比・材料ひずみ履歴を変更してしまう。二層柱のランダム変位で、材料ブロック全体の撤去では投影差2.168e−19、同一材料内の1要素撤去では0.00162814の差が生じた。

将来の施工接続では、撤去時の `c = ∫remaining Nᵀ(div uold + θold) dV` を凍結し、次の試行に `∫remaining Nᵀ(div unew + θnew) dV = c` を課す方式、または等価な増分体積適合を定義する必要がある。圧力・反力・掘削解放力も新しい仮想仕事の定義に揃え、切戻し・保存再開にはcとその対応を含める。これは設計上の残件であり、現Rustの施工コントローラへの実装済み機能ではない。

## 斜面の計算と残る検証

77/512の段階では25/50分割とも塑性GPは0点となり、50分割の最大材料ひずみは0.00200718、最小平均応力0.0463835 kPaだった。適合ひずみの独立解に対する変位相対差は約2％残る。初期平衡全体は25/50/100分割とも完了し、塑性GPは10点、最大材料ひずみ約0.0115173であった。適合ひずみの独立100分割解では7点であり、両形式の塑性域は一致していない。25→50分割の最大変位変化1.186e−7 mは、この診断の1e−7 m基準を満たさず、失敗ログを保持した。50→100分割では2.982e−8 mとなり、積分細分化の同じ基準を満たした。

100分割の投影形式と適合ひずみ独立100分割解の差は、全節点変位相対差0.0189875、最大成分差0.00111915 m、応力相対差0.00610526、pc最大差0.0214842 kPa、e最大差0.00401000、塑性ひずみ最大差0.000702602だった。小さい塑性場に対する相対差は1.057であり、変位差が約1.9％であることだけから塑性履歴の一致を主張しない。投影形式の仕事共役力残差は1.535e−15だが、生GP応力に通常Bを掛けた残差は0.0229740、GP圧力とP1投影の最大差は6.97019 kPaである。両応力場を同じものとして出力・判定する仕様は採用できない。
