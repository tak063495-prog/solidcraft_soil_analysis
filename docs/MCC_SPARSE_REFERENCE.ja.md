# P1体積MCCの独立疎行列参照計算

一般地形の空間細分化に向けた独立検証用であり、Rust実装やP6全体の受入を追加で宣言するものではない。[既存の体積投影の記録](MCC_PROJECTED_VOLUME.ja.md)を引き継ぐ。

`tools/mcc_projected_sparse_reference.py` は、独立MCC連続体接線とイベント付き中点積分を使い、圧縮体積θ・変位u・平均応力pの3場を縮約せず解く。既存の密行列参照の `A=M⁻¹D` を全体の密配列として保持せず、投影の質量行列と3場行列をCSCとして組み立てる。ここでDは体積発散、Mは材料別P1質量、Cは連続体弾塑性接線、m=(1,1,1,0,0,0)/3である。

```text
Kdd = ∫ Bdevᵀ C Bdev       Kdt = ∫ Bdevᵀ C m N
Ktd = ∫ Nᵀ mᵀ C Bdev      Ktt = ∫ Nᵀ mᵀ C m N

[ Ktt  -Ktd  -M   ] [θdot]   [ 0    ]
[-Kdt   Kdd  -Dᵀ  ] [udot] = [ fdot ]
[ -M    -D    0   ] [pdot]   [ 0    ]
```

Dirichlet拘束の局所基底を変位ブロックへ反映する。材料境界では同じ幾何節点の圧力・体積を分離する。安定化係数、人工剛性、応力クリッピング、密行列へのフォールバックは導入しない。線形解は[公式SciPyのsplu](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.splu.html)を使い、元の3場全体と力・体積適合・平均圧力の各ブロックで真残差を検査する。因子化が失敗したことを地盤の破壊判定に使わない。

参照計算のみ追加依存が必要になる。

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-reference.lock.txt
```

NumPy 2.5.4を維持し、SciPy 1.18.1を導入した。wheel SHA256は `559ed65f60c1af5a03f3912605a1b5114f522c7c32fb23c3376ae8f03219fe28`。導入記録は `runs/projected-sparse-reference-20261025-v1/install-report.json`、依存関係の `pip check` は合格した。現CLIは両ライブラリーの版を2つのlockと照合し、計算結果へ使用版を記録する。元の密行列診断は既定のまま残す。

## 方程式・演算子の照合

`runs/projected-sparse-rate-equivalence-20261025-v2/` に500ファイルのソース固定版、12条件の実行結果とログを保存した。実CAD斜面224 Tet10を使い、全領域／局所Pit撤去後、同一材料／共有節点で材料別自由度を持つ2材料、元の独立初期場の弾性接線／NC等方塑性接線／混在する活性集合を照合した。質量・発散・投影ひずみ・圧力・内力の演算子、全節点変位速度、全GP応力・硬化・間隙比・塑性ひずみ速度、載荷方向判定を密な縮約版と比較した。

変位速度の最大相対差6.173e−12、材料状態速度3.068e−11、載荷方向5.713e−11で、1e−10基準を満たした。アフィンひずみと仮想仕事も検査した。これは線形速度段階の同値性であり、非線形経路や空間収束の合格を代用しない。

## 非線形経路と空間細分化

`tools/run_projected_sparse_study.py` はソースと入力を固定し、初期平衡と載荷→除荷→局所掘削を別プロセスで実行する。各段階の保存・終了コードは `progress.json`、失敗時はログを保持する。元入力の種状態から計算し、Rustの解・材料履歴・保持力を初期値へ使わない。局所撤去では元の材料履歴を保持し、残存領域の適合差を凍結する。

## 適合ひずみ方式と同じ物理位置での空間比較

`tools/mcc_compatible_sparse_reference.py` は従来の適合ひずみB・MCC連続体接線を保ち、線形求解だけをCSC/SuperLUにした。P1圧力・体積投影を導入するものではない。全領域／局所撤去、ローラー／斜め方向の明示拘束、弾性／NC塑性／混在する活性集合の12条件で、要素ごとに独立加算した密行列解との変位・全材料状態の速度差は8e−15未満だった。`runs/compatible-sparse-rate-equivalence-20261025-v1/` に固定ソースと結果を保存した。

224要素の独立100分割全施工も完了し、受入済みPCG版の固定結果と全場20項目で一致した。最大差は変位3.979e−14 m、応力1.464e−10 kPa、pc 3.625e−11 kPa、e 3.651e−13、塑性ひずみ1.477e−13。`runs/compatible-sparse-cycle-20261025-v1/backend-equivalence.json` に記録した。確定した4工程の全GP状態を別ファイルへ保存し、終了解との完全一致と撤去部の履歴凍結を検査した。工程保存は途中増分の再開チェックポイントとは区別する。413要素の適合ひずみ方式も全工程を正常終了した。

`tools/probe_mcc_spatial.py` は元の斜面領域を覆う同じ960点を使い、Tet10写像の逆計算と二次形状関数で変位を補間する。P1一次圧力・体積は別フィールドとし、生GP応力の置換はしない。座標の補間誤差は最大5.330e−15 m。掘削後の撤去域8点は無効とし、残存する952点を比較した。有限な共通点での標本ノルムであり、撤去後の体積積分の厳密値や一般曲面・材料境界での受入を意味しない。標本則の細分化も必要である。

224→413要素で、掘削底面の面積平均増分はRust +5.945434→+6.603797 mm、独立計算 +5.945441→+6.603813 mmに変化した。共通点での掘削後変位相対差は約4.013％、最大成分変化約2.616 mmとなった。同じ413要素でのRust／独立計算の標本相対差は2.328e−6以下である。現在のメッシュ依存性を記録し、723要素のRust解析、適合ひずみ方式の別細分化、投影方式の参照刻み200分割を進める。空間収束を合格へ変更しない。

現初期・施工の入力同一性検査は、数値刻み設定と分けて `kinematics` を比較する。ローラーから明示拘束への変更を初期参照へ継ぎ足す入力は、行列組立前に拒否し、結果を生成しないことを検証した。P6全体の残件は [受入一覧](P6_STATUS.ja.md)に保持する。

再メッシュの要素配置変化を切り分けるため、[Tet10一様細分化](TET10_NESTED_REFINEMENT.ja.md)を追加した。実CAD・人工曲面・2材料共有面・分離接触面の形状と境界を検査し、224→1792要素の新しい48384積分点初期入力を準備した。非線形解と空間収束は未判定である。

## 方式間の体積積分と残る差

`tools/compare_mcc_discretizations.py` は同一メッシュ上の2方式の二次変位差を、各軸5点と7点の独立積分で体積積分する。積分点の生材料応力・pc・e・塑性ひずみを変位補間へ置き換えるものではない。2つの積分次数による変位差RMSの変化は最大1.356e−19 mだった。`runs/mcc-discretization-spatial-20261025-v2/` に結果と固定ソースを保存した。

体積積分した方式間の変位相対差は、初期平衡で224要素1.1274％→413要素0.9076％、掘削後で1.5167％→1.4422％となった。掘削底面の面積平均増分は、投影方式5.945441→6.603813 mm、適合ひずみ方式5.852091→6.483500 mm。粗密と方式の両方に差が残り、一般地形の連続体精度を受入済みへ変更しない。

累積塑性履歴の積分点指標を正の重みで積分した残存域体積は、掘削後の224要素で投影0.6631／適合1.6502 m³、413要素で投影1.0485／適合1.9316 m³だった。これは `||ep||>1e−10` の積分点指標であり、塑性域境界の厳密な測定値ではない。生GP塑性ひずみの最大差も約0.00945残る。変位差だけを使って塑性履歴の空間収束を認定しない。

共通評価点を960点から7680点へ増やすと、413要素の掘削後方式間変位相対差は標本ノルムで1.6650％→1.3402％に変わった。同一メッシュの体積積分値は1.4422％である。共通点の少ない切断域付近の標本誤差も記録し、異なるメッシュ間の標本ノルムを厳密な体積積分値として扱わない。面積平均は同じ物理面の積分を継続する。

異なるメッシュ同士にも、[交差領域の体積積分](MCC_MESH_OVERLAP.ja.md)を追加した。既知二次場の4条件で検証し、完了した723要素のRust結果まで評価した。掘削増分の相対L2差は224→413で17.91％、413→723で8.75％。初期平衡の差は単調には減っておらず、空間収束は未達である。1792要素のRust解析と723要素の適合ひずみ独立計算も開始した。
