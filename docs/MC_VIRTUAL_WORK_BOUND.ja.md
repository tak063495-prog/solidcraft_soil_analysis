# 点ごとの仮想仕事によるMC釣合い排除条件

`mc-virtual-work-bound MESH.json PROBLEM.json NEW_REPORT.json` は、物理的な節点力と仮想節点変位を入力し、全有効積分点のMC支持関数を評価します。一般の分布した底面/側面拘束も対象にします。現候補は軸方向の斉次拘束と乾燥MCを扱い、斜め拘束・水・構造等の仕事は別の方針が必要です。MCC/IDHをMCへ変換しません。

圧縮正応力σに対し、MC領域を`−aI+K`と表します。`a=c cotφ`、`R=(1+sinφ)/(1−sinφ)`です。引張正の仮想ひずみテンソルDについて、固有値の正部分の和とR倍した負部分の和が非負なら、許容応力による仕事`−σ:D`の上限は`a tr(D)`です。これはMC式と凸支持関数から本実装で導いた必要条件です。参考は[ItascaのMC式](https://docs.itascacg.com/itasca950/common/models/mohr/doc/modelmohr.html)と[Boyd/Vandenbergheの双対錐・支持関数](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf)です。Itascaの圧縮負と本体の圧縮正を区別します。

上限が有限かを平均ひずみだけで判断しません。実際のTet4/Tet10のB行列と正の体積積分重みを使い、全有効GPで数値的な余裕を持って条件を確認します。工学せん断をテンソルに変換するときは1/2を掛けます。各要素の共通並進を差し引いて計算し、剛体並進による数値的な微小ひずみを避けます。支持される仮想変位成分は各節点で正確に0と確認し、不明な反力の仕事を無視しません。

外力の仮想仕事が全GPの上限和を数値余裕付きで超える場合、離散FEMの許容応力場では釣合いを作れないことを示す上端候補です。Newton/線形計算の失敗は入力ではありません。1点でも有限上限を確認できなければ適用不能とし、上端へ変換しません。φ=0または極小φでは、発散ゼロの場を独立に証明する方針を導入するまで適用不能です。微小な非ゼロ体積ひずみを0へ丸めません。Rankineがある場合は純MCの大きい許容領域を使うため、排除条件は保守的になります。Davisは実際の有効c/φを使います。

通常APIは定数サイズの集計と、全GP診断列の長さ付きSHAを返します。CLIの完全監査は点ごとのひずみ・双対余裕・支持関数も保存します。適用不能時の点列は途中までの場合があり、`complete_point_audit`はfalseです。連続体の厳密な崩壊荷重、非関連流れの安定性や設計安全性を証明しません。

`soil-fem-srm-search/2`は任意の候補場`virtual_displacements_m`を最大16個明示し、各Fの実際の低減材料と元施工終点の再構成外力へ結び付けて評価します。試行の履歴は毎回元入力から再生し、以前の変位を候補場として自動転用しません。既存の`/1`は候補場なしの方式を維持します。固定した候補場があるFで適用不能になっても、破壊や安定を意味しません。探索は数値的な判定不能を正直に保存し、上端を捏造しません。

候補場の自動生成、実斜面での全GP照合、保存型SRMジョブ、固定水圧、斜め拘束、φ=0の一般場、有限幅3Dの一般収束、SolidCraft入力・途中ゲート、全P0〜P6は別の受入項目です。ここに実装・試験予定を列挙しただけでは合格としません。
