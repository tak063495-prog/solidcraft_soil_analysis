# 異なるメッシュ上の変位差の体積積分

MCCの粗密比較に、同じ物理領域を覆う2つの四面体メッシュの交差領域で変位差を積分する方法を追加した。固定した評価点数だけに依存せず、初期種状態からの変位、施工起点からの変位、各工程の変位増分を分けて比較する。生の材料応力・pc・間隙比・塑性履歴の移送や置換は行わない。

## 方法と適用範囲

`tools/tet10_overlap.py` は、直線辺を持つアフィン幾何のTet10を対象とする。各要素対を8個の半空間で表し、3平面の交点から交差多面体の頂点を求める。[SciPy ConvexHull](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.ConvexHull.html)の境界三角形と内部点から積分用四面体へ分ける。形状への揺動は加えない。

各メッシュの二次変位を交差領域で共通の二次多項式基底に表す。正の積分重みを付けた基底のQR因子を使い、差の係数から平方ノルムを直接求める。ほぼ等しい2つの変位エネルギーを引き算して誤差を作る方法は使わない。

```text
E² = ∫Ωactive |uA(x) − uB(x)|² dV
RMS = sqrt(E² / volume(Ωactive))
relative L2 = sqrt(E² / ∫Ωactive |uB(x)|² dV)
```

各交差四面体で二次変位の積を積分する。交差領域の体積和を両メッシュの各要素体積と照合し、領域の不一致を拒否する。曲面の二次幾何はこの方法の対象外として拒否する。CRS・座標原点・軸等の不一致も拒否する。

`tools/compare_mcc_mesh_overlap.py` は完了したRustジョブまたは独立MCC結果を入力し、原メッシュ・実行版・入力版・終了結果の対応を検査する。材料・工程設定のヘッダーも比較する。メッシュ別の初期GPデータが同じ物理的定義から作られたかは、汎用ヘッダー比較だけでは証明できないため、別の由来検証を必要とする。

## 既知解による検証

`runs/tet10-overlap-verification-20261025-v1/verification.json` に固定ソース520ファイルと結果を保存した。実CAD由来の224要素と413要素で、全領域768 m³とPit撤去後752 m³を対象にした。既知の二次多項式の変位差を、斜面領域の単項式積分の閉形式と比較した。積分次数3／4とメッシュ順序の反転を含む4条件が合格し、最大相対誤差2.719e−15、同一二次場のRMS誤差1.634e−13 mだった。定数場、片側だけの撤去、曲面、座標原点の変更も検査した。

これは変位の幾何積分の検証であり、MCC材料則や地盤の空間収束を単独で受入するものではない。

|224→413要素|2.9679％|17.9136％|0.21569 mm|

今回の斜面については、各メッシュの全初期GP位置と種応力 `p=20(10−x/3−z)`、K0x=K0y=1、pc/p=4、MCC基準線の間隙比、初期塑性ひずみ0を別途照合する。元体積768 m³、撤去16 m³、同じ斜面上の5 kPa面圧・ローラー拘束・載除荷履歴も検査する。この特定ベンチマークの由来検証を、任意の入力初期場の同一性へ一般化しない。

## 塑性を抑えた追加対照（元の受入とは別）

初期応力と間隙比、およびκとνを保ち、先行圧密圧力を10000倍にした対照を追加した。NCLの基準比体積にも `(λ−κ) ln(10000)` を加え、初期状態の整合と初期K/Gを保持した。これは材料条件を変更した別問題であり、元の条件の合格や独立解の代用にしない。

723/1792要素の全4フレームでは、塑性ひずみ成分もpc変化もゼロだった。底面の掘削増分は6.837722/6.750294 mm。交差領域で積分した掘削変位増分の相対L2差は8.995579％、RMS差は0.108035 mmで、元の同一メッシュ対の8.975289％に近い。したがって、この2メッシュ間の差を塑性履歴だけには帰属できない。小さな塑性軟化域があるという元の観測だけで、局所化が収束不良の原因だとは判定しない。5784要素の対照と、掘削領域付近の局所細分化を継続している。

記録：`runs/mcc-spatial-high-ocr-control-20261027-v1/{material-723-1792,723-1792,surface-723-1792}.json`。


## 弱形式の残差と積分点での差

723/1792/5784要素の全工程で元の力・弱体積・弱圧力ゲートを保持し、材料平均圧とP1圧力、材料体積ひずみと変位勾配の差を積分点で測定した。最終工程の圧力差RMSは0.485572/0.357649/0.197833 kPaと減少する。一方、体積ひずみ差RMSは0.000361599/0.000622237/0.000455338で単調減少しない。これらの強い差が全積分点でゼロになることは現在の弱形式の条件ではないが、残差の小ささだけでは空間精度を保証できない。

最終工程の最大変位勾配由来の工学ひずみ成分は1.3381/5.1635/4.8271％だった。最小材料平均有効圧は0.019056/0.014221/0.011308 kPa、対応する最小体積剛性は2.74394/2.11412/1.64003 kPaで、低拘束圧域も観測された。これらは離散解の観測であり、非収束の原因を確定したものではない。小ひずみモデルの実用適用範囲と空間収束は引き続き評価する。剛性下限や圧力補正を加えて元の問題を置き換えてはいない。

記録：`runs/mcc-midpoint-overlap-20261027-v1/{projection-defects,stiffness-strain-diagnostic}.json`。


## P1一次圧力の局所アンダーシュート

MCC材料の平均有効圧は全て正だが、別未知量であるP1の固体平均圧力には負の外挿・補間値がある。723/1792/5784要素の最終工程で、積分点でのP1圧力の最小値は−2.163410/−1.396001/−0.885425 kPa、負の値を持つ積分点の積分体積和は0.665346/0.144488/0.045243 m³だった（活動域752 m³）。負部分の体積RMSは0.016743/0.005377/0.001815 kPaと減少した。これは積分点を用いた体積測度であり、負領域の厳密な幾何体積ではない。

一次圧力は間隙水圧ではなく、仕事に共役な応力の平均成分に使う別の固体場である。材料点の正圧・降伏条件合格を、一次圧力の点ごとの非負性へ読み替えない。原方程式の残差は合格しているが、空間精度・低拘束圧域・実用適用の検証課題として保持する。負値のクリップや方程式の変更はしていない。記録は `runs/mcc-midpoint-overlap-20261027-v1/primary-pressure-diagnostic.json`。
