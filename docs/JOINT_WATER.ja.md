# 静水圧・定常Darcyと湿潤3D JOINT

`joint_water.rs`を、既存のTri3/Tri6接触とMC/MCCの施工FEMへ接続した。水圧を有効接触ばねとは別の両側荷重として積分する。乾燥JOINTのすべり・開閉・仕事の履歴則を使い、摩擦上限へ水圧を重ねて差し引かない。小ひずみ、静的な力学とONE_WAY水圧である。

## 水圧の指定

各JOINT定義へ`water`を追加する。湿潤設定を使う場合、全JOINTで明示する。乾燥の既存入力は省略したまま利用できる。

```json
{
  "id":"Seam", "side_a":"Seam:a", "side_b":"Seam:b",
  "material":{
    "normal_stiffness_kpa_m":1000000,
    "tangential_stiffness_kpa_m":200000,
    "friction_coefficient":0.3
  },
  "water":{"kind":"continuous"}
}
```

|water.kind|入力と意味|
|---|---|
|`soil`|`soil_side:"a"`または`"b"`を必須指定。片側がSOIL、反対側が明示した不透水構造体。物理水圧は地盤側の面から取得|
|`continuous`|両側SOIL。定常浸透では対応する水頭だけを共有し、変位と接触履歴は分離したまま|
|`prescribed`|`level_m`の水位を指定。`null`は現在の水位（定常浸透工程では`exterior_water_level_m`）へ追随。定常浸透では有効な接合の隣接SOIL面へ同じ固定全水頭を設定|

構造体は`joint_system.structure_bodies:["Wall"]`のように明示する。内部間隙水圧を0とし、透水領域から除外する。構造体には全応力として定義したMCパラメータと重量を指定し、MCC/土の圧縮硬化モデルを割り当てない。内部水圧が0なので、材料核が保持する応力と構造体の全応力は一致する。地盤の有効応力強度を構造体の全応力強度へ自動換算しない。

水位を固定したPRESCRIBEDと、隣接SOILの静水圧または定常浸透の固定水頭が競合する入力は拒否する。両側水圧を平均して整合させない。PRESCRIBED面の固定水頭を自動生成するのは両側が有効な接合だけで、片側撤去後の露出面へ固定水頭を残さない。露出面の水頭・外水位はその工程の入力で指定する。

## 応力と荷重

全体平衡は`I_material + I_pore + I_contact,effective = F_bulk + F_exterior + F_joint,water`。接合の法線をa→bとすると水圧荷重はa側が`−p n`、b側が`+p n`となる。有効接触ばねに水圧を含めた後で、さらに外力として加える処理は行わない。

圧縮正の出力は`全法線圧 = 有効接触圧 + 物理水圧`。摩擦上限は`μ max(有効接触圧,0)`で、現在の接触則は粘着力0・ダイレイタンシー0である。開離すると有効接触力・摩擦抵抗が0になるが、宣言した水圧は残る。水圧の仕事を接触ばねの摩擦散逸へ混ぜない。

静水圧は曲面の部分水没を`hydrostatic.rs`の領域誤差管理付き積分で求める。表示GPの`max(h−z,0)`だけを固定次数で積分しない。水圧のGP値と、面ごとの等価節点荷重を別に保存する。

定常Darcyは機械用の分離メッシュとは別の水理メッシュを作る。CONTINUOUSの対応節点だけを水頭共有し、元節点→水理節点の写像、実際の水理メッシュ・境界入力・解と、元の分離メッシュ上へ戻した水頭を保存する。機械節点・要素・材料・接触DOFは変更しない。飽和定常解析の非負圧条件に失敗した解を、負圧の切捨てで自由水面へ読み替えない。

## 工程と履歴

静水圧工程は実際の増分水位から部分水没荷重を再計算する。定常浸透へ切り替える工程では、旧物理圧力場から新しい定常圧力場と面荷重へ比例移行する。定常浸透後に指定水位へ戻す場合も、保存した旧圧力と新しい静水圧を比例移行する。解放進行度λに物理時間を割り当てない。

確定状態の`joint_water`にはGP水圧、各面のa側節点荷重、両側合成荷重、出典と合力・モーメントを保存する。切戻しで材料、接触すべり、圧力、面荷重、領域、保持力を戻す。部分DEATHでは消失した接合面の水圧荷重だけを除き、残る接合の値を保持する。消失した接触の材料履歴は凍結し、水圧荷重とは分ける。掘削面の外水圧と接合水圧を二重に作用させない。

保存再開では水理メッシュと水頭写像も再構成して照合する。非ゼロ保持力の掘削途中、圧力移行途中と初期平衡途中から続行できる。数値解が不成立の場合は、最後の確定状態と失敗理由を保存する。外側ハッシュを付け直しただけの節点荷重・水頭写像の改変も検査する。

## 実行と出力

```powershell
target/release/soil-fem-3d.exe solve-stages `
  examples/joint-water-column-tet10-mesh.json examples/ground-joint-water-mc.json `
  examples/stages-joint-water-flow.json runs/NEW-wet-joint.json
pwsh -NoProfile -File scripts/Invoke-Joints.ps1 `
  -Design examples/joint-water-local-cylinder.json `
  -GroundFile examples/ground-joint-water-local-mc.json `
  -StageFile examples/stages-joint-water-local.json `
  -SplitFile examples/joint-column-split.json -MeshSizeM 4
pwsh -NoProfile -File scripts/Test-JointWater.ps1
```

`Invoke-Joints.ps1 -Live -Connect HOST:PORT`は起動中のSolidCraftから形状を取得する。地層・掘削ボディ・接合名が入力と一致する必要がある。検証はportable CLIを使った新規取得で行い、Liveアプリの画面内解析パネルを実装したとは判定しない。実行版はジョブ先へ固定コピーする。

新結果schemaは`soil-fem-stage-result/13`。`joints.pvd`のGP値では物理水圧、有効接触圧、全法線圧、摩擦上限と出典コードを区別する。コード表は`joint-water-fields.json`。連続体の`material_stress_reference`は0がSOIL有効応力、1が不透水構造体の全/材料応力。水理メッシュは`flow-xxx`、元節点との対応は`joint-flow-map-xxx.json`へ出力する。生GPと体積平均を区別し、出力後にVTU/PVDを再読込する。

## 検証ゲートと残る範囲

追加9 Rust試験は、接合面の面積平均による柱の力釣合い、開離時の水圧、部分水没面の解析合力、2層直列透水、SOIL構造体除外、PRESCRIBEDの競合拒否、静水圧/定常浸透の途中再開、定常浸透後のDEATH、すべり履歴変更後の切戻しを含む。各GPが一様であるとは仮定しない。独立Python参照の3試験は直列流、固定水頭の接合、不透水構造体、傾斜面合力の理論値と照合する。

独立検証は入力から別の水頭共有とNumPy Darcy FEMを組み立て、Rustの水頭を参照解の生成に使わない。水理PDE比較と、保存した材料/接触応力からの力・仕事・剛体支持の再組立を区別する。後者を一般3D塑性変位の独立解とは呼ばない。実CADの地層境界を横切る円柱掘削では、有効な接合を一部残し、部分水没と消失面の荷重を検査する。

総合受入は全既存試験を同じ凍結ソースで取り直し、各実行先の`final-validation.json`と`integrity.json`で採否を判断する。新規15ケース・34地点再開・既存乾燥JOINT2ケースの比較が対象。事前確認と最終受入を分けて記録する。

Richardsの水頭トレースと湿潤接合の接続、有限の透水抵抗・沿面流・開口依存透水、接触BIRTH再有効化、部材との総合独立検証、板/杭、一般3D塑性変位の独立解、2D実行照合、SolidCraft内UIとP6全体は継続作業である。
