# Tet10変位・P1平均圧力の混合弾性

ほぼ非圧縮時の変位型Tet4/Tet10の評価で見つかったロッキングを受け、`mixed_mechanics.rs`と`solve-mixed-mechanics`を追加した。小ひずみ・有限体積弾性率の線形弾性であり、MCC/MCの施工解析への接続やP6全体の完了ではない。

## 定式化と入力

変位uは既存のTet10、平均圧力pは四面体の頂点P1で補間する。引張正の応力と工学ひずみを用い、

`σ = 2G dev(ε) − pI`、`div u + p/K = 0`、`K=E/[3(1−2ν)]`

とする。pは**圧縮正の平均全応力**であり、間隙水圧の未知量ではない。体積条件はP1試験関数に対する弱形式で満たし、積分点ごとの `p=−K div u` を強制しない。

行列は `[Adev, −Dᵀ; −D, −M/K]`。非ゼロ強制変位の持上げを変位・圧力の両方の行へ反映する。既存の方向拘束、物体力、節点荷重、面トラクション、面圧を使用する。過少積分・剛性シフト・圧力の後処理置換は加えない。求解は明示された密LUまたはCSR/GMRES/ILU0を使い、元行列の真残差に加えて、再組立した物理的な力残差と圧力式残差を検査する。

材料境界で圧力が不連続になれるよう、圧力DOFは `(頂点番号, 材料番号)` で区別する。同じ頂点でも材料が異なれば別の圧力を持つ。変位の連続性は維持する。一般の複雑な材料配置に対する安定性の保証とは区別する。

混合形式の一般的な動機は[一次論文：変位・圧力形式と高次変位形式の比較](https://doi.org/10.1016/j.camwa.2023.08.025)、材料境界の圧力・応力の不連続性は[一次論文：多材料混合形式の比較](https://doi.org/10.1016/j.cma.2024.117354)を参照する。今回のpは上式で定義した3D平均応力であり、Lamé定数λだけで定義する圧力変数と混同しない。

## 検証結果

Rustの4試験で、直線/曲面要素のアフィン変形と剛体運動、ν=0.4999の単軸応力、疎/密求解、二層の圧力差と直列剛性を確認した。Tet4・不足する積分次数・ν=0.5は明示的に拒否する。

異なる物体力を持つ二層柱と回転した同じ柱を、理論解および別のGL5/Duffy積分・節点SVD・NumPy密全体求解と比較した。変位の最大理論誤差は1.27e−14 m、圧力の最大理論誤差は4.07e−11 kPa。全節点変位・反力、全積分点のひずみ・応力・圧力を比較した。詳細は[mixed-column記録](../runs/mixed-column-verification-20261025-v1/verification.json)。

[発散ゼロの既知3D解](INCOMPRESSIBILITY.ja.md)を、同じG・物体力・境界・メッシュで比較した。

|分割|ν=0.3 変位相対L2誤差|ν=0.49|ν=0.4999|
|---|---:|---:|---:|
|2|42.22％|43.18％|43.69％|
|4|6.62％|6.70％|6.72％|
|6|2.00％|2.01％|2.01％|

全9ケースが疎求解で完了した。従来の変位型Tet10は同じν=0.4999・4分割で、密解でも変位誤差39.84％だった。今回の混合形式では同じ条件で6.72％となり、νの増加に伴う誤差の悪化が小さくなった。

2/4分割では別実装の全体解とも比較し、全節点変位の相対差は最大2.01e−11。全周変位固定で圧力結合行列の零空間は定数1個のみ、正の離散inf-sup指標は0.1734/0.2186だった。この検査は該当するメッシュと拘束の証拠であり、任意地形での安定性証明ではない。

共通評価の`energy_error_relative`は**変位型のエネルギーノルム**であり、混合形式のエネルギー誤差には使わない。[別の評価](../runs/mixed-incompressibility-assessment-20261025-v1/mixed-assessment-v2.json)で、偏差ひずみと `p²/K` から有限Kでの混合エネルギー指標を計算し、両者を区別する。1/K重みの指標はK→∞で圧力誤差を制御しないため、圧力自体のL2誤差も調べる。ν=0.4999では2/4/6分割で1.17932→0.155680→0.0418813 kPa·m^(3/2)と減少した（既知の圧力は0）。積分点の強い体積関係の残差と、弱形式の圧力式残差も区別する。

既存の受入済みCAD出力から、円柱ツールで曲面に分割された595節点・312 Tet10の二層メッシュを使用した。全要素を有効とし、底面固定・上面横トラクションを与え、上層のνを0.4999に変更した。元メッシュと受入記録、ボディのSTEPハッシュ、メッシャーのprovenanceを照合し、実際に曲面中間節点を持つことも確認した。この試験は掘削工程ではない。

## 実行

既定のreleaseビルドから利用できる。全210 Rust試験とclippy/fmtが合格した[混合弾性の限定受入](../runs/mixed-mechanics-acceptance-20261025-v1/final-validation.json)に加え、既定実行版でも混合9ケース・二層柱と回転・実曲面CAD・従来MCC施工の13ケースを実行し、版ハッシュと経過時間以外の結果が受入版と完全一致した。[既定ビルドの照合](../runs/default-solver-equivalence-20261025-v1/final-validation.json)と[保存記録の整合検査](../runs/default-solver-equivalence-20261025-v1/integrity-verification.json)を保持する。旧MCC検証版も記録内に保持し、版の異なるチェックポイントのハッシュ制約を回避して再開しない。

```powershell
cargo build --release --locked --offline
target/release/soil-fem-3d.exe solve-mixed-mechanics MESH.json CASE.json NEW_RESULT.json
```

CASEは`soil-fem-mechanics/1`を使用する。MESHはTet10、積分次数は3以上。結果は`soil-fem-mixed-mechanics-result/1`で、従来の変位・反力・生の積分点値に、材料番号付きの圧力DOF、積分点圧力、圧力式残差を加える。

```powershell
.venv/Scripts/python.exe tools/export_mechanics.py MESH.json RESULT.json NEW_EXPORT_DIRECTORY
```

VTUは連続体の体積平均、全積分点の生値、一次未知量の圧力DOFを別ファイルへ出力する。`pressure-dofs.vtu`と`pressure-dofs.csv`は頂点・材料番号の組を保持し、共有頂点の異なる材料圧力を平均化しない。圧力は平均応力として明記し、間隙水圧と区別する。二層柱の9共有頂点、曲面CADの20共有頂点、従来の一般弾性の出力を読戻し検査した。欠落/重複DOF、積分点圧力の不一致、平均応力の不一致、界面圧力の入替えの5入力は、出力を作る前に拒否した。[出力検証記録](../runs/mixed-export-verification-20261025-v1/verification.json)。

## 残る作業

任意の曲面・支持条件・材料境界での安定性と積分収束、圧力が支配する荷重経路、MCC/MCの非線形履歴・施工・切戻し/保存再開への接続、SolidCraftの入力/結果表示を進める。有限Kの検証を、そのまま完全非圧縮・非排水連成・一般的なロッキング解消の認定には使わない。

MCCでは別の[3場混合バックエンド](MCC_MIXED.ja.md)を開発し、全体方程式・初期地圧平衡・載除荷・掘削・切戻し/保存再開へ接続した。新規6施工試験、全体接線の方向微分試験と全221 Rust試験は合格したが、独立3D比較の全精度ゲートは未合格である。MC/水理/部材/接合・一般地形とnative接続は残る。
