# 固定版Excel 2DとRust 3Dの実行比較

P6の2D照合を、固定版Excel/VBAを実際に実行して進めている。現時点は乾燥・側方拘束MC柱の検証であり、掘削・斜面・接合・水理・SRMを含む2D版全機能との一致ではない。

## 固定入力と実行

2D版は `440d246d9e32f5892c79539d4a7b797ad29442ee`。そのGitオブジェクトから公開XLSM、同梱DLL、BUILD_RECORDを抽出し、Git blobとSHA256を保存する。外部チェックアウトのファイルやVBAプログラムは変更しない。

`scripts/Invoke-2DReference.ps1` は専用コピーを、新しい非表示Excelで開き、公開マクロ `P0_RunAnalysis` を呼ぶ。既存Excelがあれば開始を拒否する。計算前後の全VBAモジュールのコードを照合し、結果シート追加に伴う空のdocument moduleだけを区別する。Office設定・数値収束許容値の変更は行わない。結果表とCSVの全節点・全積分点の出力を突き合わせる。

柱は幅0.2 m、高さ0.2 m、奥行き1 m。E=1000 kPa、ν=0.25、γ=20 kN/m³、c=2 kPa、φ=10°、ψ=0°の非関連MCとする。側方変位を全節点で固定し、底面の鉛直変位を固定する。工程は重力→上面12 kPa載荷→載荷だけ除去。除荷後も自重を保持する。2DはQ8の2/4要素、3DはTet10の48/384要素を使用する。

2Dの重力解析には自重沈下が含まれる。3Dは同じ弾性応力場のK0=ν/(1−ν)を変位ゼロで初期化するため、比較時は**実際の2D重力工程の変位を差し引く**。初期応力、累積塑性ひずみ、絶対変位と工程増分を別々に保存する。

## 独立した柱理論

zは底面からの高さ、Hは柱高、Pは載荷圧、K=E/[3(1−2ν)]、M=E(1−ν)/[(1+ν)(1−2ν)]とする。重力工程の変位は

`ug(z) = −γ(Hz − z²/2)/M`。

ψ=0と側方拘束により塑性体積ひずみはゼロ。載荷終点で全点がMC圧縮稜線上にあり、`σv = A p + B`、`A=3(1+sinφ)/(3−sinφ)`、`B=4c cosφ/(3−sinφ)`、`εv=p/K`から

`ul(z) = −[(P+γH−B)z − γz²/2]/(A K)`、

弾性除荷後は `uu(z)=ul(z)+Pz/M` となる。応力は `σv=P+γ(H−z)`、`σh=(3p−σv)/2`。除荷時はσvからP、σhからνP/(1−ν)を引き、塑性ひずみを保持する。弾性ひずみとの差から累積塑性ひずみも検算する。

3Dの全節点・全積分点をこの理論と比較し、さらに2DのQ8変位を要素内二次補間、積分点応力・累積塑性ひずみを要素内一次補間して3D位置へ写す。材料境界を跨ぐ平均化や節点平滑化はしない。2Dの `gauss.csv` の塑性量は最後の増分分なので、累積履歴には `plastic_cumulative.csv` を使う。

## 現在の結果と判定基準

2Dの両メッシュは正常終了した。頂部の絶対変位は重力−0.333333333 mm、載荷−2.700167230 mm、除荷−0.700167230 mm。全節点の理論誤差は最大4.14e−13 m、全積分点応力は5.87e−10 kPa、累積塑性ひずみは4.33e−13。載荷・除荷の累積塑性履歴は完全一致し、鉛直反力は0.8→3.2→0.8 kNだった。

3Dの合格基準は全節点変位5e−8 m、全積分点応力5e−4 kPa、累積塑性ひずみ1e−6。48要素・施工刻み1/16・材料刻み1e−4の最大誤差は3.255e−8 m、9.781e−4 kPa、3.115e−6で、応力と塑性ひずみが不合格だった。この記録は `assessment-v1.log` と当時の評価器ソースに保持する。

同じ48要素で施工刻み1/32・材料刻み1e−5にしても、最大誤差は3.599e−8 m、1.037e−3 kPa、3.338e−6だった。刻み細分化による改善は確認できていない。384要素・729節点・10368積分点では同じ許容値に合格した。全節点変位差は最大6.988e−9 m、全積分点応力差は2.624e−4 kPa、累積塑性ひずみ差は8.186e−7。48要素の細分化ケースからの誤差比はそれぞれ0.1942、0.2532、0.2452で、全て減少した。載荷/除荷の塑性履歴は完全一致し、2Dとの全場比較・反力・元の入力/実行版の対応も確認した。[拘束柱の限定受入](../runs/2d-3d-column-acceptance-20261025-v1/final-validation.json)として保存し、粗いケースの不合格と刻み細分化で改善しなかった履歴も残す。理論解が要素で表現できるこの柱の結果を、任意3Dの空間収束・塑性変位の一意性へ一般化しない。

実行記録は `runs/2d-3d-column-20261025-v1/`、評価器は `tools/verify_2d_column_reference.py`。全P6の残件は [受入要件一覧](P6_STATUS.ja.md)を参照する。

## 途中の弾塑性境界の診断

同じ48 Tet10で上面荷重6 kPaまでの別計算を行った。理論上の鉛直降伏応力は9.052878 kPa、弾塑性境界は底面から0.0473561 mで、粗い最下層要素の内部にある。区分積分した理論変位の微分も別途確認した。全節点の変位差は最大3.961e−6 m、全積分点応力差は0.146124 kPa、累積塑性ひずみ差は6.654e−5。最大せん断応力は0.017774 kPa、力の相対残差は1.904e−11だった。

これは途中の場の診断であり、元の終点の受入基準の緩和ではない。要素内に弾塑性境界があることだけで差の原因を断定せず、途中状態の空間感度と2D版の挙動を引き続き確認する。記録は `runs/2d-3d-column-20261025-v1/yield-front/diagnostic.json`。

同じ6 kPaの途中状態をExcelでも実行した。Q8二要素/四要素の全節点変位の理論誤差は1.408e−6→2.592e−8 mへ減少し、誤差比は0.01841。全積分点の応力差は最大2.98e−10 kPa、累積塑性ひずみ差は1.73e−14だった。3D粗メッシュの途中状態の差は、この2Dの結果とともに追加診断として保持する。384要素の終点受入を、途中の一般3D経路の受入へ広げない。記録は `yield-front/excel-diagnostic.json`。
