# 定常飽和浸透とONE_WAY地盤力学

2026-10-24。透水係数・水理境界から水頭を求め、間隙水圧をMC/MCCの施工解析へ渡す。受入試験は`scripts/Test-Seepage.ps1`で実行する。P6全体、未知の自由水面・浸出面・降雨浸透の完成を意味しない。

## 水理方程式と入力

全水頭`H=z+u/γw`、Darcy流束`q=−K∇H`、保存則`div q=S`を解く。Kは対称正定値の3×3**透水係数テンソル（m/s）**。固有値1e−20〜1m/s、条件数1e12以下を受け付ける。固有透過率m²とは異なる。重力方向はZ上向き。流束m/s、境界流量m³/s、体積源Sは1/s、力学側のγwはkN/m³であり、`u=γw(H−z)`はkPaになる。

水頭形式は[OpenGeoSysのDarcy定式化](https://www.opengeosys.org/stable/docs/benchmarks/hydro-thermal/constant-viscosity/HT-Process.pdf)の圧力・重力ポテンシャルを定密度条件で変換したもの。体積源と外向き正のNeumann流束に対し、弱形式は`∫∇N·K∇H=∫NS−∫Nq_out`となる。

`soil-fem-darcy/1`、`units:"m-s"`の入力で、`materials`に力学と対応する材料番号とK、`heads`に面集合と全水頭を指定する。水頭は定数または物理座標のアフィン分布。`fluxes`は外向きスカラー流束、または物理座標のアフィンベクトル流束を指定できる。無指定の露出面は無流束。例：`examples/flow-seepage-column.json`。

面集合は現在の有効要素に対して露出している必要がある。空集合・不明面・内部面・撤去済み面、面の水頭/流束重複、節点水頭の矛盾を拒否する。面を共有する水域ごとに水頭境界を要求し、任意ゲージで境界不足を隠さない。点・辺だけで接する別領域は節点を分離する必要がある。

Tet4/Tet10、層別・回転異方性、共形共有面、現在の材料番号と有効領域を扱う。正重み体積積分と曲面Tri6の面写像を用いる。密LUとCSR＋GMRES/ILU(0)を選択でき、対角シフトや別ソルバーへの自動置換はしない。

## 残差と水収支

水域ごとの基準水頭との差を未知量として、大きな一様水頭による相殺を避ける。独立した水域は別々の行列で求解し、透水係数や流量の大きな水域が小さな水域の誤差を隠さないようにする。縮約系の真残差に加え、各水域の元の方程式の自由行を物理的な流量スケールで検査する。縮約系だけが収束した場合は、元の残差から同じ行列・同じソルバーで最大3回の反復改良を行う。各補正の求解履歴と最終元行残差を保存し、許容値を満たさなければ未完了とする。

`HeadField`の`datum_head_m`と`relative_head_m`が水頭の安定した表現で、`head_m`は両者を加えた絶対値。流束は相対水頭の差から、圧力水頭は`datum−z+relative`から求める。大きな基準値への加算で小さな水頭差が丸められても、流束の情報を失わない。VTUにも基準・相対・絶対水頭を分けて保存する。求解履歴と残差は`balances`内に水域ごとに保存し、単一水域では`linear`にも初回求解を記録する。

水頭固定節点の流出量は`−(KH−rhs)`。水域ごとに`Q_D,out+Q_N,out−∫S=0`を検査する。正規化には`∫|S|+∫|q_N|+Σ|Q_D,node|`（下限1e−30m³/s）を使い、流入と流出、湧出源と吸込み源が相殺する循環流も扱う。境界の反力流量と、有限要素の水頭勾配を直接積分した境界流量は別項目として出力する。連続Galerkinの生の勾配流束は一般には要素ごとに保存的でなく、局所保存流束の再構成は今後の課題。

本実装は非負の圧力水頭を持つ飽和領域に限定し、負の圧力水頭があれば候補水頭・失敗理由を`complete:false`で保存する。Tet10の`H−z`には2次Bernstein係数の下界を用い、全域の非負を十分条件で検査する。下界で証明できない場合も未完了とし、節点値だけで飽和と判定しない。圧力の切り詰めで自由水面を代用しない。Bernsteinの十分条件は保守的であり、浮動小数点演算の厳密保証ではない。

## 力学への接続と保存再開

工程の`kind:"steady_seepage"`に`flow`入力と`exterior_water_level_m`を与える。工程開始時の有効形状・材料番号で浸透を解き、`u=γw(H−z)`を力学の全積分点へ渡す。外水圧は別途指定した外水位から求める。水頭境界と外部に作用する水圧荷重を混同しない。

工程途中は、起点の圧力と求めた終点圧力を補間する**数値的な荷重経路**であり、浸透時間や圧密時間ではない。MC/MCCの有効応力と剛性・硬化更新は全体Newtonで解く。変形・間隙比を透水係数へ戻す二方向連成は含まない。土の入力単位体積重量は固定。

確定圧力は`Committed.pore_pressure_kpa`へ全積分点番号順で保存する。試行棄却では材料・変位・圧力・外力・有効要素を復元する。撤去済み要素の材料履歴と保存圧力を凍結し、新たな流れ工程では残存点だけを更新する。水理場と力学履歴、工程起点・解放途中の保持力を保存し、再開時に流れの入力・水頭・流束・監査を再構成して照合する。計算時間のメタデータは数値的一致の比較から除く。

掘削工程そのものでは既存の圧力場を保持する。掘削後の定常状態は、その後に明示した`steady_seepage`工程で求める。新しい床面・壁面を水理境界へ登録できる。中間の凍結圧力状態を排水の過渡解と解釈しない。Darcy後の指定静水位工程も接続する。湿潤JOINTの水理方針、浸透状態からのBIRTHの初期水理状態は別途必要で、現在は黙って推定せず拒否する。

水理VTUは節点水頭・圧力水頭、体積平均値、生の積分点流束・勾配を区別する。境界勾配流量、指定流量、水頭節点反力、水域水収支も保存する。力学VTUの間隙水圧と全応力は確定した圧力場に対応し、出力を再読込して照合する。

追加の材料・水理試験は、層状直列透水の抵抗理論、2次水頭と体積源、異方性・曲面上のアフィン解、水域別の境界不足、飽和の拒否、元行残差のCAD反例を含む。柱は上向き/下向き流、静水圧への復帰、全上層掘削、残存層排水の理論変位と比較する。MCCでは圧力変更後の塑性試行を棄却し、正常刻み列・全工程途中の保存再開と比較する。
