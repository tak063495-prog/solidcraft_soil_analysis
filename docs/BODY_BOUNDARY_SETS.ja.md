# SolidCraftボディの基準平面を荷重面へ渡す

`mesh_layers.py` は、材料を対応させた各ボディについて `body:<ボディ名>:boundary` と `:exterior`、および `:xmin` / `:xmax` / `:ymin` / `:ymax` / `:zmin` / `:zmax` の面・節点セットを生成する。平面セットは基準メッシュの軸平行外接箱の平面上にある実際の要素面だけを含む。Tet10の中間節点も判定し、曲面を外接箱の平面へ投影しない。

`examples/stages-solid-pile-body-planes.json` は、SolidCraftで `Soil` と `Pile` を作成・材料対応した場合の施工入力である。杭頭の荷重面と監視面に `body:Pile:zmax`、杭先端に `body:Pile:zmin`、地表に `body:Soil:zmax` を指定する。SolidCraftの地盤解析設定へこの施工入力を保存し、通常の解析ジョブでメッシュ生成・計算・結果表示へ渡せる。有限断面単杭の物理条件と限界は [単杭例](SOLID_PILE.ja.md)を参照。

`boundary` は材料界面も含み、`exterior` は所有要素が一つの外表面だけを含む。内部共有面への通常の外力指定はソルバーの検査で拒否される。生成済みセット名の衝突は変更を加える前に拒否する。Gmshの所有ボリュームの一部でも四面体が欠落した場合は、メッシュ書出し前に拒否する。メッシュ寸法の変更や形状修復は利用者が明示して再実行する。

実SolidCraftの2ボディ例は857節点・436 Tet10でGUIから完了し、公式Viewerで載荷段階とX=5 m断面を表示した。断面積は80 m²。元入力から別に組み立てた疎3D弾性計算と、全節点変位・全積分点応力・間隙比・反力を比較した。これは完全付着・弾性単杭の限定検証であり、MCCの空間収束、杭支持力、すべり、杭列換算の受入ではない。

この対応は基準形状の軸平行平面に限る。任意の傾斜面や曲面をGUIで選ぶ機能、CAD編集前後の面IDの永続対応は未完了である。全残件は [P6一覧](P6_STATUS.ja.md)に保持する。
