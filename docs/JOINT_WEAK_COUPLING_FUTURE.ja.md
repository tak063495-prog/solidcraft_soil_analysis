# 案4：mortar／界面ばねの弱結合（将来オプション、未実装）

今回の案2「接触BIRTH」は、適合する節点対の誕生前等変位を厳密に消去し、誕生時に有効接触則へ切り替える。非適合面を結ぶ案4は実装していない。既存JOINT、Tet10亀裂先端、Mindlin Tri6板の既定動作を案4へ変更しない。

mortarは両側の補間・面積積分・伝達条件を弱形式で整合させる離散化である。界面ばねは有限の法線・接線剛性による相対変位と蓄積エネルギーを持つ物理モデルであり、両者を同一視しない。大きな界面ばね定数を等変位拘束の代用にしない。

乗数型mortarは変位と乗数の鞍点系を生む。正定値を前提とする現行Cholesky縮約へ、そのまま組み込めない。双対空間、inf-sup条件、縮約または不定値ソルバー、反力回収、剛体モード、接触・摩擦の能動集合、チェックポイントの保存単位を別途設計・検証する必要がある。単なる面合力の一致では、全節点仕事・モーメント・パッチ試験の代わりにならない。

これは水のONE_WAY（流れを先に解き、水圧を力学へ渡す連成順序）とは別課題である。mortarを将来追加しても、流量連続・水圧境界・体積間隙水圧と面荷重の分離はそれぞれ必要となる。Richards湿潤JOINT、非飽和接触、誕生面の水理初期化を暗黙に含めない。
