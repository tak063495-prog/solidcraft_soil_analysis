# 膜・DKT曲げを持つ平板と地盤・梁の結合

コンパクト宣言の展開後は、新しく生成した単一点集合だけを一意な座標結合へ変換します。照合距離は既存のRust/参照と同じ1e-8 mで、複数候補は拒否します。元からある集合と既存の部材結合は変更しません。元の91集合を保ち、172接続を座標で表す945要素モデルで、263集合を表示へ渡すことによる上限超過を解消しました。粗274・細945の全物理履歴が従来入力と完全一致しています。


Nativeの所有ジョブは、起動時のCADに `beam_system` またはオブジェクト形式の `plate_surfaces` があれば構造結果形式 `/3` を要求します。簡略宣言の認識を追加した後続62ファイル差分が必要です。旧差分ではワーカーの数値・表示監査が成功しても、所有ジョブが形式不一致として結果を拒否します。入力SHA・実行ソルバー・表示manifest・監査のハッシュ照合は維持します。


コンパクト宣言によるNative連携では、CADのstages JSONに `plate_surfaces` オブジェクト（既存の `soil-fem-plate-surfaces/1`〜`/3` の宣言）を保存する。例えば掘削集合の壁は `/3`、`face_set: "Pit:wall"`、`owner_body: "UpperSoil"`、`attachment: "shared_excavation_interface"`、`opposite_excavation_set: "Pit"` とする。下層の根入れは既存の明示共有面を用いる。同じ宣言のままメッシュを変えると、そのメッシュの全二次節点から板を展開する。CADへ詳細な節点/板配列を焼き込まないため、64 KiBの属性上限を変更せずに済む。局所掘削例の宣言2747 bytesから274 Tet10/128板と945 Tet10/320板を準備し、従来の詳細入力と結合点の指定を解決した後の全条件が一致した。これは入力準備の検査で、細分モデルの力学・独立比較の合格を意味しない。

plate-surfaces/3の掘削集合指定を、実Nativeの有限幅二層モデルへ適用した。同じ上層ボディの内部切断面でも保持側を選び、下層の共有ボディ境界と合わせた四周壁72 m²・128板を保持地盤へ結合した。274 Tet10の5工程、掘削途中保存再開、公式GPUの曲げと12 m²の壁断面、生の板値を確認した。従来v1外面・v2共有面の実144要素モデルについてはmesh/case/bindingが旧処理と完全一致し、Python全128件も合格した。一方、945要素の細分モデルは詳細な板属性のNative64 KiB上限と、外部ソルバーの縮約構造結合の記号接続サイズ上限で拒否された。全非局所結合を保つ別作業用修正を検証中で、接触・すべり・一般空間収束の受入と同一視しない。

平板三角形を連続体地盤と梁に接続した。局所軸のCST膜ひずみとDKTの曲げを組み合わせ、節点並進3成分・回転3成分を既存の構造モデルで共有する。構造内部の自由度を静的縮約してMC/MCC共通の全体Newtonへ加える。板は線形弾性、小変形、平面要素であり、厚板の横せん断、材料塑性、座屈、幾何学的非線形を含まない。

DKTの辺接線方向回転をHermiteたわみの辺中央微分から定め、辺法線方向回転は線形にする。膜は平面応力。公開定式化は [Code_Aster R3.07.03](https://code-aster.org/doc/v17/manuals/man_r/r3/r3.07.03/index.html) を参照し、コードは独自に実装した。独立Python参照は頂点・辺条件から12個の二次回転多項式係数を解き、別の5×5 Gauss/Duffy則で剛性を積分する。

面法線回りの回転には、膜のスピンとの差に対する明示的なペナルティを使う。`drilling_factor` は G×板厚に対する係数で、入力必須、許容範囲1e−8〜0.01である。これは曲げ材料則ではない。膜・曲げ・drillingのエネルギーを別々に出力する。この係数と接続部回転の感度を確認せず、特に面内ねじりを受ける梁と板の接続剛性を確定したと扱わない。

## 入力と出力

既存の `beam_system` を共通の構造モデルとして使い、`schema: soil-fem-structures/1`、`plate_sections`、`plates` を指定する。節点IDを梁と共有すると並進・回転を共有する。地盤とは、`match_soil_node` または一節点の `soil_node_set` で並進を結ぶ。地盤連続体の回転付着や任意の面全体への自動結合ではない。

板断面にはID、E、ν、板厚、単位体積重量、drilling係数を指定する。板ごとに3節点ID、断面ID、初期有効状態、一定/比例載荷のグローバル面トラクションを指定する。自重は板厚×面積×単位体積重量から加える。曲面は平板を並べた近似になる。

設置・撤去は `install_structures` / `remove_structures` の `members` に板・梁IDを指定する。既存の `install_beams` / `remove_beams` も同じ処理を呼ぶ。設置時の全並進・回転を部材ごとの基準として保存する。確定/試行状態、切戻し、チェックポイントにも板の有効状態と設置基準を含める。板を含む結果は `soil-fem-stage-result/14` で識別する。

`examples/stages-plate-beam-column.json` と `examples/ground-plate-beam-column.json` は、既存 `hardening-column-tet10-mesh.json` の形状に板2枚・梁1本を接続する弾性対照例である。地盤はMCの弾性枝に留める強度を明示しており、実地盤の強度同定例ではない。板・梁の設置、自重、載除荷、撤去と意図した切戻しを含む。

ルートでrelease build後、次のように計算・出力する。出力先は新しい名前を使う。

```powershell
New-Item -ItemType Directory -Force runs | Out-Null
target/release/soil-fem-3d.exe solve-stages examples/hardening-column-tet10-mesh.json examples/ground-plate-beam-column.json examples/stages-plate-beam-column.json runs/plate-control.json
.venv/Scripts/python.exe tools/export_stages.py examples/hardening-column-tet10-mesh.json runs/plate-control.json runs/plate-control-vtu
```

通常の施工出力に加え、`plates.pvd` は基準三角形と全節点変位・回転、`plate-samples.pvd` / CSVは三つの生の曲率・膜力・曲げモーメントを出力する。局所軸と単位を保持し、節点への応力平滑化を行わない。非有効時は空フレームを明示する。SolidCraft内の板結果専用レイヤーは未接続である。

## 掘削集合で保持側を選ぶ同一ボディ内の壁（開発版 /3）

`tools/plate_surfaces.py` の `soil-fem-plate-surfaces/3` では、同じ材料ボディ内部を切る掘削集合に壁を対応させられる。`attachment: "shared_excavation_interface"` と `opposite_excavation_set` を明示する。面ごとに、指定した `owner_body` に属して掘削集合の外にある保持要素が一つ、集合内の掘削要素が一つ隣接することを要求する。ボディ名が両側で同じ場合も、この集合から向きを確定する。

```json
{
  "schema": "soil-fem-plate-surfaces/3",
  "sections": [{"id":"wall","young_kpa":30000000,"poisson":0.2,"thickness_m":0.2,"unit_weight_kn_m3":24,"drilling_factor":0.0001}],
  "surfaces": [{
    "id":"pit_wall", "face_set":"Pit:wall", "owner_body":"Soil",
    "attachment":"shared_excavation_interface", "opposite_excavation_set":"Pit",
    "section_id":"wall", "initially_active":false
  }]
}
```

`face_set` は入力メッシュ上に用意する。底面を含めず壁面だけを選ぶ場合も、呼出側で面集合を分ける。`opposite_body` との重複指定、空・不正・重複した要素集合、保持側がない面、集合の内部同士の面を拒否する。Tri6の全中間節点、両側の同一節点と逆向き法線を検査し、保持側の向きで四つのTri3板へ分ける。元の座標・接続・入力を変更せず、生成した構造節点と部材群を返す。

既存の /1 の外面、/2 の二ボディ共有面の出力契約は保持する。接触・すべりや、CAD編集後の永続的な面対応を追加する機能ではない。保持側と掘削側の共通並進、板の回転自由度、二次地盤と区分線形板が節点間では同一の補間にならない制約も従来どおりである。同一ボディの保持側支持、掘削集合の反転に伴う向き、集合不備、掘削側中間節点不整合を4試験で検査し、既存7件を含む11件が合格した。有限幅の実CAD・力学・独立解との受入は継続する。

## 2026-11-11 案3：同じ参照面の二次Mindlin板

従来の `cst_dkt`（省略時もこの方式）は変更しない。Tri6面を4枚のTri3へ分ける既存契約と、過去の4.740/3.466 μmの記録は従来方式の記録として保持する。新方式は部材または面宣言の `"formulation": "mindlin_tri6"` で明示的に選択する。6節点を指定するだけでは選択されず、方式と節点数の不一致を拒否する。

新方式の節点順は頂点0,1,2、中間01,12,20。節点ごとのグローバル並進3成分、回転3成分の計36自由度である。うち物理的Mindlin回転は面内2成分、残り1成分は梁との共通回転を表現するdrilling自由度。全並進は地盤Tet10面と同じ `Li(2Li−1), 4LiLj` の二次補間である。回転も二次補間し、局所 `β=(θy,−θx)`、曲率は `(βx,x, βy,y, βx,y+βy,x)`、横せん断は `γ=grad(w)+β` とする。

保証対象は**同じ参照面**の並進3成分である。板厚オフセット付着は未対応であり、面宣言の非ゼロ `thickness_offset_m`、部材の未知のoffset指定を拒否する。面宣言で `load_distribution` を指定する場合は `consistent` のみを許す。6節点均等配分は拒否する。単位面荷重の整合節点荷重は頂点0、中間節点それぞれA/3（回転荷重0）。自重にも同じ荷重則を使う。

### 固定したせん断補間とエネルギー

これはMITC系の共変せん断補間であり、単なる低減積分ではない。参照座標を `(r,s)=(L1,L2)`、平面へのアフィン写像のJacobianをJとする。生のせん断を共変成分 `Jᵀγ` に写し、次の8次元空間へ補間する：

`span{(1,0),(r,0),(s,0),(0,1),(0,r),(0,s),(−rs,r²),(−s²,rs)}`。

各辺0→1,1→2,2→0におけるパラメータ `(1±1/√3)/2` の接線方向2条件（合計6条件）と、参照三角形上の共変2成分の面積平均（2条件）を一致させる。内部平均は二次式に厳密な3点則 `(2/3,1/6,1/6)` の巡回配置で計算する。8×8の補間方程式を解き、物理成分へ `J⁻ᵀ` で戻す。したがって定数せん断・一次せん断は再現され、二次wと一次βによる一定曲率・ゼロせん断も再現する。これはこの実装で固定したMITC型Tri6であり、既存の特定製品のMITC6実装との同一性を主張しない。

面内・曲げ構成則は平面応力のCを用いた `t C` / `t³ C/12`、せん断係数は `κ G t`、**κ=5/6**。drillingは `θz−(v,x−u,y)/2` に対する `drilling_factor G t` のペナルティであり、従来と同じ入力範囲1e−8〜0.01。追加のせん断安定化や対角シフトは**0**。エネルギーはそれぞれ `1/2 ∫ εᵀtCε dA`、`1/2 ∫ χᵀt³Cχ/12 dA`、`1/2 ∫ κGt γᵀγ dA`、`1/2 ∫ drilling_factor Gt mismatch² dA`。4項を別々に出力する。

全エネルギーは正のDunavant6点・4次厳密則で積分する。面積で規格化した点と重みは `(a,b,b)` の巡回配置、a=0.816847572980459、b=0.091576213509771、重み0.109951743655322、および `(c,d,d)` の巡回配置、c=0.108103018168070、d=0.445948490915965、重み0.223381589678011。係数は `src/plates/mindlin.rs` に固定する。せん断補間後も二次式なので積分次数を下げない。剛体6モードと剛性のランク30を検査し、追加の零エネルギーモードを認めない。

### 入出力・保存・対象範囲

直線辺・平面Tri6専用である。カーネルは中間点と両端の算術平均との差を `64 ε_machine × 最大辺長` 以下に制限し、曲線辺・非平面Tri6を拒否する。面準備側の従来幾何検査に加え、このカーネル検査を通る必要がある。曲面シェルや参照面を移動する処理は含まない。

板ごとの設置参照は18または36成分で保存し、実際の板種別・節点数に合わせて状態長を検査する。チェックポイントの既存の入力identityは明示的な板種別を含み、run checksumは全設置参照を含む。旧バイナリの保存点を新バイナリへ無検査で移行しない。

板VTUは従来のtriangleに加えtriangle6を使う。二方式の混在、6個の生評価点、横せん断ひずみ・力とせん断エネルギーを再読込して照合する。生評価点の位置は同じ平面の重心座標で求め、応力の節点平滑化は行わない。旧方式だけの出力は既存の3評価点・4分割契約を保持する。Nativeへ渡す構造フィールドにも方式を付加するが、新しい二次板の実GUI/GPU表示受入は未実施である。

検証範囲と実測値は `interim/2026-11-11-plate6-mindlin/` を参照。曲面、板厚オフセット、一般塑性の板/地盤界面、JOINT・水・土BIRTHとの新しい組合せ、一般空間収束、実壁・大規模モデルとNative表示は残件。従来の拒否条件は維持する。P6全体は未完のままとする。

## 範囲拡張(b)：平面Tri6の付着面オフセット（明示方式）

`mindlin_tri6_offset` と直接部材の `attachment_offset_m=e` を追加した。未指定eは0。既定CST/DKT、既存 `mindlin_tri6`、4.740/3.466 μmの記録は変更しない。新方式の受理範囲は直線・平面Tri6、有限 `|e|<=t/2`、共有節点で同じe n、乾燥MC弾性枝＋線形板/梁、設置・載荷・除荷・撤去に限定する。JOINT、水、土BIRTH/DEATH/MATSET、アンカー、塑性土、MCC/IDH、曲面・折れ目・段差は拒否する。

節点座標と未知並進は地盤付着面 `x_s,u_s`。向き付き幾何法線n、グローバル3回転θを使い、中立面は `x_p=x_s-e n`。剛体リンク `u_s=u_p+θ×e n` を変換 `A_i=[[I,e[n]×],[0,I]]` で実装し、剛性AᵀKA・荷重Aᵀf・回復Adに同じ変換を使う。`ε_p=ε_s-eκ` により膜曲げブロックは `[[Ct,-eCt],[-eCt,D+e²Ct]]`。中立面の4エネルギーと中立面N/Mを報告し、付着面モーメントは `M_s=M_p-eN`。traction/板自重は中立面、直接節点荷重/梁は付着面基準である。

平面の法線/接線・回転基底・drilling・MITCの結び点は従来Mindlinのまま。二次地盤面と付着面並進が面内/辺内点でも一致する。e=0の剛性・荷重・生値と全物理履歴は既存平面板と完全一致を検査する。片持ち/単純支持の偏心軸力による連成解析解、正負オフセットの独立直接系、保存場再組立、棄却/同じ受理刻み列、別CLI再開、再ハッシュ後の板種別/e/局所軸/設置参照改変拒否、二次VTU再読込を検査する。既存許容値は変更しない。
