# 実SolidCraft地盤・MCC・内部板壁の検証記録

2026-10-26。実SolidCraftから取得した三つのボディを、311節点・144 Tet10・3888積分点と32枚の内部板壁へ接続した。形状・整合メッシュ・材料・初期種状態を保持したまま施工刻みを細分化している。独立比較と空間収束は未完であり、実務適用やP6全体の完成を意味しない。

## 入力と施工の区別

全体は10×4×6 m。右側上部の60 m³を掘削し、右側底面20 m²、左側の周辺地表面20 m²、完全付着の内部板壁24 m²を評価する。このケースの三ボディは施工の分割であり、いずれも同じMCC材料である。異なる材料を持つ二層地盤の検証は[MCC_STRUCTURES.ja.md](MCC_STRUCTURES.ja.md)の別ケースを参照する。

初期有効鉛直応力は100+20(6−z) kPa、水平比K0=0.6、pc/p=1.8、M=1.4、λ=0.12、κ=0.025、ν=0.2とし、間隙比はNCLから求める。一般地形へK0を単純代入したものではなく、この直方体の原入力種状態について独立な離散力釣合い残差2.175e−15を確認した。初期変位はゼロであり、Rustが解いた初期状態を独立計算へ移していない。

元の経路は180 kPaプレロード→壁設置→掘削と同時に上載圧を100 kPaへ除荷→壁への載除荷→上載圧ゼロ→壁撤去である。この掘削工程の地表面隆起には上載圧除荷の影響も含まれる。対照経路では、掘削の前に100 kPaへの除荷を別工程にした。変位の符号に合わせて材料や境界を変更していない。

この入力は `pressure_on_original_surface_only=false` であり、新しく露出する掘削底面にも100 kPaの指定面圧が作用する。撤去土の応力解放とこの外力は別に組み立てる。上載圧をゼロにする最終工程まで、自由な無荷重掘削底面のベンチマークではない。この条件を変える場合は別の原入力ケースとして比較する。

## 独立参照計算の修正と再検証

最初の100/200分割参照はプレロード・設置・掘削まで進んだが、次の壁載荷開始時にイベント判定が進まなくなった。許容範囲内の正の降伏面ドリフトを、除荷中でも新しい塑性載荷と扱う参照計算の不具合を回帰試験で再現した。弾性試行の載荷方向も正であることをイベント条件に加え、従来の降伏面/切替/ドリフトの許容値は変更せず、応力の射影も加えていない。元の固定コード・ログと所有プロセス停止記録を保存し、原入力から再計算する。旧計算を物理的な破壊や非収束とは判定しない。

修正版では工程完了ごとの独立状態保存・再開を追加した。入力・数値ソース・分割数・内容ハッシュを照合し、全材料状態、変位、部材設置基準、活動領域、体積適合オフセットと完了工程履歴を復元する。塑性二層地盤の設置後・掘削後からの再開は、連続参照計算の全物理場と完全一致した。改変した入力・刻み・保存内容は拒否する。保存粒度は工程完了時であり、Rust本体の受理増分単位の保存とは異なる。

修正版を含むPython全108件は合格し、ソース583件を固定した。記録は `runs/mcc-cad-wall-reference-v2-20261026-v1/quality-verification.json`。同じ固定コードで100/200分割の実CAD壁の再検証を進めている。独立全場比較、空間収束、nativeでのこの壁ケースの受入は残る。板は完全付着の線形薄板であり、接触・すべり・壁の塑性・座屈を含めていない。
