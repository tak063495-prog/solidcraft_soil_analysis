# MCC連続体接線の診断

既存の完成FEM結果から、積分点のMCC状態を読み取る後処理です。応力順序は
`xx, yy, zz, xy, yz, xz`、圧縮正・kPaとします。接線は、その点で塑性載荷が
続くと仮定した小ひずみの有効応力骨格のものです。実際の載荷分枝、流体連成、
離散混合FEMのアルゴリズム接線や全体安定性の受入は別に検証します。

```powershell
.\.venv\Scripts\python.exe tools/mcc_acoustic_diagnostic.py mesh.json ground.json JOB/result.json runs/acoustic.json
.\.venv\Scripts\python.exe tools/mcc_acoustic_exact_report.py runs/acoustic.json runs/acoustic-exact.json
```

出力先には新しいファイルを指定します。第一段は既定577方向の標本検査で、
第二段は入力と実装SHAを再照合し、全方向のランク1判定を計算します。
降伏面近傍の候補だけを対象にし、正の平均有効圧力と正の整合分母を要求します。
圧力・pc・間隙比の補正や、FEM状態の書換えは行いません。
有効主応力も別に調べ、負の最小主応力を持つ積分点の数・体積・最小値を報告します。
圧縮正の定義で`-1e-8 kPa`より小さい値を数え、平均有効圧力の正値と区別します。

## 全方向の判定式

`A = C_elastic : dPhi/dsigma`、正の整合分母を`D`とすると、単位法線`n`に対して

`Q_elastic = G I + (K+G/3) n n^T`

`Q_plastic = Q_elastic - (A n)(A n)^T / D`

です。正定値性のランク1判定比は

`R(n) = [n^T A^2 n - beta (n^T A n)^2] / (G D)`

`beta = (K+G/3)/(K+4G/3)`

となります。Aの主値を`a_i`、`w_i=n_i^2`とすると、`w_i>=0`、`sum(w_i)=1`です。
平均`x=sum(a_i w_i)`を固定した二次モーメントの最大値は、凸性により最小・最大
主値を結ぶ割線上にあります。従って、全方向の最大化は

`f(x) = (a_min+a_max)x - a_min*a_max - beta*x^2`

の区間`[a_min,a_max]`上の最大化へ帰着します。放物線の頂点を区間へ制限し、
極端な二主軸の混合で法線を構成します。実装では二次モーメントの差を分散と
平均の二乗へ分けて評価し、独立な3×3収縮と負のRayleigh値も検査します。
この帰着はここで導出したもので、商用ソルバーの機能として引用していません。

`R_max > 1+1e-10`を負の候補、`R_max < 1-1e-10`をこの固定連続体分枝での
全方向正定値の候補、その間を数値的に不定とします。区間演算による形式証明では
ありません。証拠法線での最小固有値を、全方向での最小固有値とは区別します。

## 検証と使い方の範囲

参照計算用の固定依存を導入した環境で、次の回帰試験を実行します。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-reference.lock.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_mcc_acoustic*.py" -v
```

独立Voigt収縮・降伏勾配の差分、回転、応力尺度、正負の対照、主値の退化、
全3×3行列の正定値性、多数方向の標本との比較を含みます。圧縮軟化しても正の
対照を保ち、軟化だけで負の音響テンソルと判定しません。

固定の945/1324要素モデルでは、標本検査の負の候補11/7点に対し、全方向判定は
11/9点でした。いずれも底面直下Lower11にあり、1324要素では標本が捉えなかった
2点を確認しました。これは未収束の空間差の診断に用いた仮想材料の例です。
構成則の正則化、現地同定や一般形状の空間収束は、別の検証・開発項目として残ります。

同じ掘削後の主応力検査では、945/1324要素で31/86点、0.542761/0.650068 m³に
負の最小有効主応力があり、最小値は約-36.86/-37.40 kPaでした。正の平均有効圧力
だけで材料の引張域の適用性を保証せず、この状態も検証範囲に残します。負の音響
候補と引張点の集合は同一とは限らず、原因を一つに帰属しません。
