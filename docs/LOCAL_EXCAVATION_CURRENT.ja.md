# SolidCraft局所掘削：現行版の実行と検証

2026-10-24。SolidCraftで地層とは別の閉ソリッド`Pit`を作り、その地盤内の交差領域をRustのMCC施工解析へ渡す。K0初期状態から局所撤去し、残存地盤の3方向変位と全積分点の応力・pc・間隙比・塑性ひずみを保存する。

## 実行

```powershell
cd D:\Work\soil-fem-3d
pwsh -NoProfile -File scripts/Invoke-LocalExcavation.ps1
# 起動中のSolidCraftで指定した地層・掘削ボディを取得する場合
pwsh -NoProfile -File scripts/Invoke-LocalExcavation.ps1 -Live -Connect 127.0.0.1:7879
# 全受入試験を新しい出力先で再現
pwsh -NoProfile -File scripts/Test-LocalExcavationAcceptance.ps1
```

地層名・材料・掘削ボディは`examples/ground-local.json`、工程と監視集合は`examples/stages-local-sparse.json`で指定する。`excavation_bodies:["Pit"]`と、工程の`kind:"excavate", bodies:["Pit"]`を対応させる。SolidCraftでは掘削前の地層を残し、撤去範囲を別ボディにする。名前付きSTEPとBoolean祖先情報により地層・撤去領域を対応させ、境界箱や要素重心だけで選別しない。

現行の入口は外部スクリプト。今回の形状受渡し試験はSolidCraft portable CLIを実行した。Live接続のポートは起動中アプリの設定に合わせる。SolidCraft画面内への解析パネル追加は本受入に含まれない。

## 応力解放と履歴

確定応力から撤去要素の内力を組み立て、仮保持荷重`H=F_old−F_new−I_removed`を構成する。解放進行度λについて`F(λ)=F_new+(1−λ)H`を解き、λ=0の残存地盤平衡とλ=1の保持力消失を監査する。撤去土の自重を除き、元の地表の残存面だけに上載圧を作用させる。乾燥掘削面は自然境界条件で外力ゼロとなる。

失敗・棄却した試行から応力、pc、間隙比、塑性ひずみ、変位、有効要素、外力、保持荷重を確定状態へ漏らさない。撤去要素の全積分点履歴は凍結する。保存再開では解放途中の非ゼロ保持荷重と工程起点も保存し、入力・実行版・履歴の改変を検査する。

## 独立3D比較

同じ箱形Tet10メッシュでpc/p=10とし、MCCの弾性除荷枝を比較した。参照解は解析的K0、`K=vp/κ`の材料速度式、陽的中点積分、NumPy密求解から作り、Rustのreturn mapping・数値接線・変位を参照解の生成に使わない。参照経路の降伏面内部を検査し、100/200分割を比較した。

|照合項目|相対L2差|
|---|---:|
|全残存節点3方向変位|0.0129504％|
|全残存積分点応力|0.000662446％|
|参照100→200分割の変位|0.0000342151％|

一般3D塑性変位を独立ソルバーで全面照合した検証ではない。塑性履歴の復元は前述の別プロセス・正常刻み列との一致で検査した。
