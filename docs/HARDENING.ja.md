# 不変量二重硬化モデル IDH

MCC/MCとは別の`invariant_double_hardening`材料。せん断・圧縮の独立した硬化、圧縮履歴に依存する剛性、除荷再載荷を静的・小ひずみFEMへ接続する。Hardening Soil、PH、CYSoilと同一のモデルではない。実装仕様と、受入済みの範囲を区別し、受入は実行フォルダのfinal-validation.jsonとintegrity.jsonのpassedで確認する。

## 操作

```powershell
cd D:\Work\soil-fem-3d
# 材料点
target\release\soil-fem-3d.exe hardening-path examples\hardening-path.json runs\new-hardening-path.json
# 実SolidCraftの局所掘削。例示用の粘着的な材料で、乾燥砂の自立鉛直掘削ではない。
pwsh -NoProfile -File scripts\Invoke-LocalExcavation.ps1 -GroundFile examples\ground-hardening-local.json -StageFile examples\stages-hardening-local.json -MeshSizeM 4
# 再現用の一括検証
pwsh -NoProfile -File scripts\Test-Hardening.ps1
```

`examples/hardening-parameters.json`が全パラメータ。地層ごとの初期capは`hardening_cap_over_mean_effective`（pc/pの比）または`hardening_explicit_cap`で指定する。MCCのpc・鉛直OCR・NCL間隙比とは交換できない。間隙比は明示する。K0から作る初期応力がせん断面・capの内側に入ることも検査し、矛盾を自動補正しない。一般形状の種状態は専用IDH履歴型で読み込めるが、その全地形への適用は別途検証する。

## 式と履歴

応力・工学ひずみは圧縮正、順序xx,yy,zz,xy,yz,zx。pは平均有効圧力、q=√(3/2 s:s)。土粒子の非圧縮を仮定し、比体積はv_new=v_old exp(−Δεv)で更新する。初期間隙比はMCCのNCLから生成しない。

せん断面は`fs=q−M(κs)(p+c*)≤0`、非関連ポテンシャルは`gs=q−D p`。`M=M0+(M∞−M0)κs/(γref+κs)`、`0≤D≤M0<M∞<3`。せん断塑性乗数の累積がκsになる。Dは一定で、密度に応じたダイレイタンシーや限界状態へのD→0は実装しない。Drucker–Prager型の円形偏差断面で、MCのLode角依存やRankine面は持たない。三軸圧縮に限る摩擦角換算は`M=6sinφ/(3−sinφ)`。

capは`fc=rc−pc≤0`、`rc=√(p²+q²/α²)`で、関連流れを使う。capによる塑性体積増分は`Δκc=λc p/rc`。せん断の膨張をcap圧縮履歴に加えない。硬化は`dpc/dκc=Href(pc/pref)^m`を解析積分し、m=1では対数形になる。pc0、κc、pcの整合と、塑性体積ひずみのトレース`tr εp=κc−Dκs`を検査する。

除荷再載荷の剛性は**現在の平均圧ではなくcap圧力という圧縮履歴の応力尺度**に依存する。`Eur=Eur_ref(pc/pref)^m`、`K=Eur/[3(1−2ν)]`、`G=Eur/[2(1+ν)]`。K/Hは一定になり、等方初回圧縮の接線は`K H/(K+H)`。降伏面内ではpcと弾性係数が固定されるため、閉じた弾性ひずみサイクルは可逆となる。

このcap硬化と履歴圧に基づく剛性の構成は[Itasca Cap-Yieldの公開定式化](https://docs.itascasoftware.com/itasca980/common/models/cysoil/doc/modelcysoil.html)を参考にした。ここでは独自の不変量q・双曲型M硬化と一定Dを使用する。PHのE50/Eoed/Eurを入力する同名モデルの移植ではない。E50等は応力経路に沿った試験結果から求める量で、Eur=3E50等を既定しない。

## 数値更新と適用外

各サブステップで直前のcap履歴からK/Gを固定し、せん断・cap・同時活性の各集合でp,qと2つの塑性乗数を求める。4変数Newton、ラインサーチ、乗数の非負性、応力更新の閉合、降伏条件と履歴の整合を検査する。全増分の6×6接線は固定サブ分割の中心差分。非関連流れの接線を対称化しない。

弾性試行平均圧が負でも、ダイレイタンシーによる塑性補正で正圧へ戻る場合は、その解を探索する。正値を使うのはNewton開始反復だけで、元の試行応力と釣合い式は変更しない。最終状態が明示されたp_min以下、間隙比0以下、硬化/降伏条件不整合なら拒否する。pやpcを下限へ書き換える処理はない。ゼロ応力BIRTH、引張、微小ひずみG0、繰返し減衰、液状化、異方性、軟化・せん断帯正則化は対象外。

応力仕事`plastic_work_kpa=Σ σ_new:Δεp`を保存する。これは塑性応力仕事であり、硬化自由エネルギーを含む全熱力学散逸という名称にはしない。閉じた弾性サイクルの応力残差・仕事が0に戻る検査も別に行う。初期のE(p_current)案には残留せん断応力が消えない反例が出たため採用していない。反例と当時のソース・exeは`runs/hardening-elastic-cycle-counterexample-20261024/`へ保存した。

## 検証範囲

- 圧縮則の独立積分、せん断硬化の閉形式、任意3D回転、cap/せん断/同時活性、非対称接線の方向微分、弾性サイクル、適用外と履歴改変の拒否。
- Rustの4変数Newtonとは独立に、p/qを消去し、せん断の二次方程式とcapの区間二分法で解く材料点参照。6経路を3段階の刻みで比較する。高νの過剰膨張は、独立な最終圧力上限が負になる元経路を適用外試験として保持し、圧縮域に収まる載除荷も検査する。
- 拘束圧25/100/400kPaの排水三軸。独立参照側で側方有効応力を制御して作ったひずみ経路をRustへ与える。E50と除荷剛性を測定し、合成データからEur_refと指数mを回収する。これは現地の実測データによる砂の同定ではない。8％の材料点試験を8％の小ひずみFEMへ転用しない。
- Tet4/Tet10の全体載荷・除荷・再載荷・掘削、疎/密、現在荷重に対する力残差、塑性試行棄却、同じ受理刻み列の完全一致、別プロセス保存再開。圧縮/せん断硬化・e・変位・有効要素・保持荷重と撤去履歴を保存する。
- 独立全体参照は3D Tet4メッシュに水平面を拘束した柱。入力だけから組み立て、独立材料更新とNumPyで載除荷・掘削を解き、保持荷重も独自に作る。参照64/128/256分割、Rust材料刻み1/4を比較する。最終変位が相殺で小さいため、履歴最大変位による規格化に加え、絶対誤差と工程増分の誤差も示す。一般の自由な3D塑性変位の独立参照ではない。
- 実SolidCraftの2層・箱形Pitを持つTet10地盤。90kPaプレロード、30kPaへ除荷、局所掘削。例示用の圧力切片c*=30kPaを持つ材料で、乾燥・無粘着砂の鉛直掘削が自立することを認定しない。

新材料は結果schema/10、VTUのmaterial_model=2で区別し、全積分点のpc0/pc/κs/κc・e・塑性ひずみ・仕事を出力する。これまでのMCC/MCのschemaと履歴表現は保持する。全体収束は現在の外力（段階解放中は保持荷重を含む）のノルムと1kNの大きい方を基準にし、旧荷重が大きい除荷工程で判定を緩めない。

P2b-03とP6全体の完成を、このモデルの限定的な受入だけで認定しない。現地データによる校正、一般3D塑性変位の独立照合、低拘束圧・メッシュ・拘束・材料感度、他機能との統合は残る。
