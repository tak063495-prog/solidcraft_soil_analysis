# 施工履歴を毎回再生する乾燥MCのSRM探索

本体656版へ接続した乾燥MCの限定機能です。同一数値ソースのRust347件・Python219件が合格しました。一般斜面・水圧・施工安全認定・P6全体の完了を意味しません。実行結果は版を固定した検証ログで確認します。

`search-mc-srm MESH.json GROUND.json CASE.json SPEC.json NEW_REPORT.json` は、元の未低減材料で指定した施工接頭部まで計算し、外力・有効要素・拘束・全体力・降伏・拘束誤差を再監査します。施工終点の外力は既存の物理荷重処理で再構成し、受理状態の荷重と照合します。残留する保持荷重や解放荷重を黙って物理外力へ置き換えません。

全ての低減率で、同じ元のGroundと施工条件から新規に初期化・施工を実行します。直前の試行の変位、塑性履歴、有効領域、荷重を持ち越しません。低減は既存replayのc/F・atan(tanφ/F)と、明示したψ/引張カットオフ方針を使います。MCC/IDHをMCへ置換しません。現候補はDavisの探索単調性、構造・JOINT・水・材料置換・誕生を未対応として拒否します。圧力・境界荷重・掘削・表示RESETの接頭部が対象です。

SPECは`soil-fem-srm-search/1`、対象材料ID、ψ/引張方針、最大低減率、要求低減率、率の絶対許容差、最大試行数、施工工程数を持ちます。要求低減率は必ず実際に評価します。上端が独立に成立する区間だけを二分し、宣言した率幅または試行数で停止します。数値失敗は判定不能として保存し、破壊側の上端にしません。

従来の物理的排除条件は平均応力の凸性です。乾燥・単一有効MC材料・正の積分重み・独立6反力という限定条件で、元の施工終点の物理節点力を結び付けて評価します。通常の地盤側面/底面の分布拘束では、この平均応力だけの判定は適用不能です。

後続の入力`soil-fem-srm-search/2`では、明示した仮想変位場を元の施工終点の外力と各Fの実材料へ結び付け、全GPの支持関数を検査します。[仮想仕事判定](MC_VIRTUAL_WORK_BOUND.ja.md)を参照してください。独立に検証できた場だけが上端を作り、適用不能な場やNewton/線形失敗からは生成しません。候補場なしの`/1`入力と数値方式は保持します。自動的な実斜面の候補生成や一般3D精度の受入は別工程です。

結果の`equilibrium_requirement_met`は、指定率で既存の数値的な釣合い・降伏・拘束の監査を満たしたという限定した意味です。非関連流れの安定性、厳密な連続体下界、設計上の安全性を認定しません。`independently_excluded`は結び付いた必要条件による離散的な排除、`indeterminate`は判定不能です。区間の下側は「釣合いを得た率」、上側は「独立に排除した率」と明示します。両者が矛盾する場合は認定せず、判定不能とします。

元のF=1施工Runを出力に保持し、探索後の次施工は未低減の入力・履歴から進めます。保存型の協調中断/再開は[保存型CLI](SRM_SEARCH_JOBS.ja.md)へ接続しました。施工後の材料epochから始める探索との統合、固定水圧SRM、斜め拘束を含む一般支持条件、塑性斜面の2D精度・一般3D収束・SolidCraft入力UI/途中ゲートは別の受入項目です。ソースを追加しただけでこれらを完成とは扱いません。
