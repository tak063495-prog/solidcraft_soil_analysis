# 有限断面の3D単杭：完全付着・弾性の対照例

SolidCraftの有限体積ボディとして単杭を作り、周辺地盤と共有節点で結合する入力例・メッシュ準備・独立3D検証を追加した。既存の連続体FEMを使うもので、線梁を点で地盤に結合したモデルではない。P3b-05は部分実装のままである。

通常のSolidCraft解析ジョブから、ボディ名の平面セットを荷重・監視へ渡す経路も追加した。[ボディ平面セット](BODY_BOUNDARY_SETS.ja.md)と `examples/stages-solid-pile-body-planes.json` を参照。独立検証器の `--mesh-labels native` は実ジョブ一つのメッシュを照合する指定であり、粗密比較を実行したことにはならない。

```powershell
pwsh -NoProfile -File scripts/Invoke-SolidPile.ps1 -SolverPath target/release/soil-fem-3d.exe -OutputDirectory runs/my-solid-pile
```

新しいフォルダーへCAD capture、粗密Tet10、固定ソルバー、ソースsnapshot、計算、VTU/生GP、独立比較、3地点の別プロセス保存再開を作る。既存フォルダーは上書きしない。`-CliPath`、`-PythonPath`で導入済み環境を明示できる。粗密は既定3/2 mで、`-CoarseMeshSizeM`、`-FineMeshSizeM`で変更できる。

## 固定した物理条件

地盤の外形は10×10×8 m。杭は中心(5,5) m、1×1 mの正方形断面、先端z=2 m、杭頭z=8 m、長さ6 mである。SolidCraftの`solid.combine`のcutとkeep_toolsで杭体積を地盤から除き、杭を残す。STEPの材料別体積は地盤794 m³、杭6 m³。両領域をGmshで一括分割し、界面を共有する。杭頭・杭先端・地表の面/節点セットは所有要素・材料ID・座標から作る。

側面は法線方向ローラー、底面は鉛直拘束。乾燥条件で、地盤γ=20、杭γ=24 kN/m³。Eは地盤30,000、杭30,000,000 kPa、νは0.3/0.2。MCのc=1,000,000 kPa、φ=ψ=0、引張カットオフなしを明示し、全積分点で塑性ひずみ・塑性仕事が0であることを検査する。これは弾性の対照計算を既存MCの弾性枝で実行する設定であり、実地盤強度やコンクリート破壊の同定値ではない。

初期応力0から、杭が既に存在する領域全体へ自重を与えて平衡を作る。K0施工履歴、杭の打設・掘削・設置、負の摩擦の塑性履歴を再現する例ではない。施工基準は自重平衡後とする。杭頭1 m²へ面トラクション(10,0,−100) kPaを載荷し、水平10 kN・鉛直100 kNを加え、除荷する。地盤自重による変位と杭頭載荷増分を分ける。

独立計算は元入力の種応力・荷重から、GL/Duffy125点の剛性・体積力、節点SVD拘束、SciPy疎LUで全体3Dを解く。Rustの変位・応力を参照解の生成に使わない。全6フレームの全節点・全GP応力/e・反力を照合し、元行列の真残差を検査する。さらに従来の独立力・モーメント監査とVTU/生GP再読込を両メッシュで実行した。

杭サブ領域の内力から杭自重・杭頭外力を差し引き、全界面の整合節点力を合計する。杭自重144 kNに対する地盤から杭への支持は鉛直144 kN、載荷後は244 kN、水平は−10 kNとなり、全体反力とも整合した。この量は弱形式の全界面伝達力である。杭先端と周面の共有稜線の節点力を恣意的に割り振って、先端抵抗・周面摩擦力を別々に同定したことにはしない。

自重途中、載荷進捗0.125、除荷進捗0.125の3地点から別CLIへ保存再開し、実行時間以外の全結果・材料履歴・全試行が連続計算と完全一致した。2回の意図した切戻しは確定状態を保持する。記録は `history/verification.json`。初期試作での重量0指定はGround検査に拒否され、正の実重量へ入力を修正した。ソルバーの検査は緩めていない。

後続で検証器へ入力・CAD・ソルバー・結果のSHA、実行中の不変性検査を追加し、既存2メッシュを再照合した。5つの改変条件（ソルバー、CAD、入力、結果の実行版、フォルダー外の参照）を計算前に拒否した。`runs/solid-pile-integrity-20261026-v1/verification.json` と `independent-bound-verification.json` は、この後続版の別記録である。実行スクリプトにも通常の力/VTU監査を組み込み、追加細分化を継続する。

後続の `runs/solid-pile-acceptance-20261026-v2/final-validation.json` は、537ソースを固定し、公開スクリプトの全工程を2/1.4 mの指定で実行した。819要素の結果は前回と一致し、2279要素・3893節点・61533積分点も自重/載除荷の独立全場・通常の力/モーメント・VTU/生GP監査に合格した。後者の杭頭追加沈下は0.365780 mm、独立全節点変位の最大相対差は9.76e−12。再開検証はこのペアの819要素側で、重力・載荷・除荷の3地点について全非時間項目が完全一致した。2279要素の別プロセス再開を受入したという意味ではない。ソルバー・入力・参照ソースのSHAと実行中の不変性を検査している。

## 残る検証と杭列との違い

杭頭の追加沈下は436→819→2279要素で0.325217→0.348525→0.365780 mm、隣接する細メッシュ基準の差は6.687→4.717％であり、空間収束は受入済みにしない。より細かいメッシュ、外側/底面境界、回転と非目標方向変位、材料/界面剛性、先端/周面の荷重分担を評価する。塑性地盤、JOINTのすべり・開離、支持力、設置履歴、群杭、梁杭との比較は未検証である。

この例は有限幅3Dの単杭である。平面ひずみの杭列へ使う場合は杭間隔・単位奥行き・軸/曲げ/せん断剛性・荷重・地盤との伝達則の換算と検証が必要で、単杭の3D解をそのまま転用しない。間隔換算をした線材と、群杭の3D相互作用は別モデルとして扱う。この換算と群杭比較はまだ実装・受入していない。全P3b/P6の残件は [P6一覧](P6_STATUS.ja.md)に保持する。
