# MCCのNC/OC三軸材料点検証

2026-10-24。検証先は`runs/mcc-triaxial-20261024-040424-4c4907c9/`、実行版SHA256は`32de6502bcfbbbea4b9e4ddcbf68b05701cab6458b490078873a4b883a80bc77`。`final-validation.json`で入力・参照計算・Rust結果・実行版・ソースを結び付ける。

対象は等方初期有効圧100kPaからの軸対称圧縮、pc/p=1と4。排水は側方有効応力σ′3=100kPa、非排水材料点は体積ひずみ0を保つ。M=1.2、λ=0.2、κ=0.04、ν=0.3、参照圧1kPa、NCLの比体積切片3.5を使用した。ここでOCRは等方状態のpc/pであり、一般K0状態の鉛直OCRと無条件に同一視しない。

## 独立計算と結果

Rustの4変数implicit returnを使わず、p–qの弾塑性速度式、硬化と比体積の微分式を陽的中点法で積分する。OCの弾性→塑性切替位置を独立に求め、その後は単調圧縮の塑性枝をたどる。参照20000/40000分割と、Rustの最大材料刻み1e−4/1e−5を比較する。Rustへは参照経路から求めた2000個のひずみ増分を入力し、側圧・体積条件とp/q/pc/eを全出力点で照合する。

|経路|p/q/pcの経路全体の相対L2差・細刻み|参照20000→40000分割の差|
|---|---:|---:|
|NC・体積一定|0.000706％|0.0000459％|
|NC・側方有効応力一定|0.000626％|0.00000306％|
|OC・体積一定|0.000635％|0.00000178％|
|OC・側方有効応力一定|0.001017％|0.000000370％|

4経路すべてでRustの刻み細分化により参照との差が減少した。細刻みのNCL比体積関係の最大誤差は1.65e−6以下。非排水経路の間隙比一定、排水経路の側圧一定も検査する。参照の塑性枝における最大降伏面誤差は正負を含め1.73e−7以下。

## 限界状態の理論値

初期等方圧p0、比r=pc0/p0として、一定体積の限界状態圧は`p_cs = p0 (r/2)^((λ−κ)/λ)`。一定側方有効応力では`p_cs = σ′3/(1−M/3)`。いずれも`q_cs=M p_cs`、`pc_cs=2p_cs`。降伏式・硬化則の定義は[ItascaのMCC仕様](https://docs.itascacg.com/itasca920/common/models/camclay/doc/modelcamclay.html)を参照し、比体積関係から上記の極限を求める。

|経路|理論p_cs / q_cs kPa|計算終点p / q kPa|
|---|---:|---:|
|NC・体積一定|57.43492 / 68.92190|57.43459 / 68.92151|
|OC・体積一定|174.11011 / 208.93214|174.10917 / 208.93100|
|NC・側方有効応力一定|166.66667 / 200.00000|166.33791 / 199.01351|
|OC・側方有効応力一定|166.66667 / 200.00000|166.74294 / 200.23128|

終点は軸ひずみ0.5までの**材料点だけ**の漸近試験であり、排水NCはまだ極限との差が約0.5％ある。この大きな累積ひずみを小ひずみ3D FEMへ適用できることを意味しない。非排水材料点は過剰間隙水圧DOF、排水速度、圧密時間を解くものではない。

## 再現と証跡

```powershell
.venv\Scripts\python.exe tools\verify_mcc_triaxial.py --solver target\release\soil-fem-3d.exe --output runs\my-new-mcc-triaxial
```

出力先は新しいフォルダを指定する。粗/細参照、全Rust経路・結果、各CLIログ、実際に使用した参照コードを保存する。受入版ではexeも別フォルダへ固定し、`record_mcc_triaxial.py --run 実行フォルダ`で全証跡を照合して凍結する。

最初の軸ひずみ0.15では排水NCが限界状態に十分近づかなかったため受入しなかった。続く一次の陽積分は参照誤差が大きく、細分化によるRustとの差の減少を判別しにくかったため、中点法と降伏切替位置の検出へ改善した。これらの試行・失敗フォルダは保持する。最終記録は上記の実行先を使用する。
