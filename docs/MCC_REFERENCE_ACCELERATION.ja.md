# MCC独立参照の因子再利用・行列作用の研究版

多数の降伏点イベントで疎行列の組立・LU分解を繰り返す独立参照に、明示的に選ぶ二つの研究用バックエンドを追加した。Rust本体の材料則や計算済み結果、既に実行中の固定参照プログラムは変更していない。既定は従来の新規LU分解のままである。

```powershell
.venv/Scripts/python.exe tools/run_projected_sparse_study.py runs/projected-k0-reset-reference-20261026-v1 runs/my-reference --steps 100 --matrix-free-factor-reuse
```

入力フォルダーは `inputs/mesh.json`、`ground.json`、`case.json`、`mesh-identity.json` を持つ。ソース・入力・NumPy/SciPyロックを新しい出力先へ固定してから、初期化と施工を別プロセスで実行する。`--factor-reuse` は組立を維持してLUのみ再利用、`--matrix-free-factor-reuse` は材料積分からその時点の元の3場行列作用を計算する。両方の同時指定は拒否する。

再利用したLUは、その時点の元の方程式を解く前処理として使う。元の行列/作用による力・体積・平均圧力の各相対残差1e−10を維持し、再利用補正ではさらに厳しい基準を使う。材料接線の正定値性を確認できない経路、新しいactive set、補正の失敗では、その時点の行列を組み立てて新しくLU分解する。対角シフト、人工剛性、圧力床、応力/塑性履歴の修正を加えない。材料の正定値判定の閾値は計算法の選択にだけ使い、材料を置き換えない。

## 検証と未達

任意方向拘束を持つ回転Tet10で、作用と独立組立行列の一致、因子再利用、急な剛性変化時の再分解、非正定値のMCC経路での従来LUへの切替を検査した。K0からの塑性載荷・除荷の全状態も従来参照と照合した。専用9試験を含む全Python67件が合格した。Rustの83ソースとCargo定義は、総合247試験・clippy・release build合格版から変更していない。

`runs/mcc-reused-factor-20261026-v4/assessment.json` は、実CADの550節点・288 Tet10・7776 GPのK0近傍で、12回の弾性速度計算を測定した。今回の測定では因子再利用が約2.13倍、行列作用版が約3.53倍だった。新規LU回数は13回から1回へ減った。これは近傍の速度計算の測定であり、全施工の高速化率ではない。

速度全場の差は相対約3.76e−11以下で、元の3残差基準も満たした。一方、微小なせん断成分を含む成分別の厳しい比較（rtol=1e−8、atol=1e−10）は未合格として記録した。v1/v2の失敗ログを保持し、合格へ変更していない。別の順序付けで新規LUを行う参照同士でも同じ比較は未合格だった。解析的な一様剛性スケーリングに対しては、新方式の相対差は約1e−15、従来新規LUは約1e−11だった。丸め差と参照そのものの精度を区別するための診断であり、成分別の未合格を消すものではない。

同じ実CADの全施工を100分割・行列作用版で開始したが、現時点では全経路の独立精度・時間刻み収束を受入していない。従来の固定100/200分割参照等も別プロセスのまま継続し、結果や版を混在させない。近傍速度試験や小さい塑性柱の合格だけで、実斜面の全変位やP6全体を完了としない。
