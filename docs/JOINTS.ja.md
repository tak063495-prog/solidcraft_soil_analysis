# 乾燥した履歴JOINTと3D地盤の連成

2026-10-24。対応するTri3/Tri6面対に独立した変位節点を与え、法線開閉と接線2方向の摩擦すべりをMC/MCC全体Newtonへ接続する。P3bの乾燥接触を対象とし、P6全体の完了とは区別する。

## SolidCraftモデルと実行

```powershell
cd D:\Work\soil-fem-3d
pwsh -NoProfile -File scripts\Invoke-Joints.ps1
pwsh -NoProfile -File scripts\Invoke-Joints.ps1 -Mcc
pwsh -NoProfile -File scripts\Test-Joints.ps1
```

標準例はSolidCraftの`LowerClay`/`UpperClay`という2つの閉ボディ。地層をまとめて共形メッシュ化した後、`joint-column-split.json`で指定した全共有面だけの変位節点を分ける。元の節点座標、要素形状・地層/材料番号・CAD体積を保持する。ボディ別の独立メッシュを後で接合する方式ではない。

`Invoke-Joints.ps1`には`-Design`、`-GroundFile`、`-StageFile`、`-SplitFile`、`-MeshSizeM`、`-ElementOrder`を渡せる。取得元はSolidCraft portable CLI。元の共形データを`conformal/`、分離後を`split/`、解析を`analysis/`へ別保存する。`prepared-model.json`を更新し、元メッシュ・分離仕様・STEPの来歴をハッシュで結び付ける。

分離仕様の例：

```json
{"schema":"soil-fem-joint-split/1","interfaces":[
  {"id":"Seam","body_a":"LowerClay","body_b":"UpperClay"}
]}
```

作成される`Seam:a`/`Seam:b`の面セットを工程入力の`joint_system.joints`から指定する。対応面の全3/6節点で座標が一致し、節点番号は異なり、外向き法線が反対であることを検査する。二次要素の辺中間節点も対応検査する。未指定の共有面は接着を維持する。部分的な亀裂先端で同じ節点を共有する構成は明示して拒否する。

## 材料則と履歴

`normal_stiffness_kpa_m`/`tangential_stiffness_kpa_m`はkPa/m、`friction_coefficient`は無次元。単位はm–kN–kPa。法線はCAD基準で側aから側bへ向ける。相対変位`jump_m = u_b − u_a`の法線成分が正なら開口する。

有限法線剛性の圧縮ばね`q_n = K_n min(g_n,0)`を用い、引張力は伝えない。接線は2方向の摩擦円`|τ| ≤ μ(−q_n)`へ戻す。粘着力0、ψ=0、一定摩擦係数を対象とする。大変形での接触探索、法線回転、ダイレイタンシー、ピーク/残留強度の軟化は含まない。

全体座標で残留塑性すべりベクトル、累積塑性すべり、摩擦散逸、数値積分による散逸、端点仕事、開口/固着/すべり状態を保存する。開口の自由移動は摩擦すべりに加算しない。開閉を跨ぐ増分は法線隙間0で分け、再接触はせん断無応力から始める。`contact_reference_offset_m`は開口中の移動に由来する接触基準位置であり、塑性すべりとは別の量。

弾性エネルギーと摩擦散逸を数値散逸と分け、各履歴で端点仕事との釣合いを検査する。法線だけを切り詰めて接線応力を残す処理はしない。`maximum_increment_m`で接触の経路積分を細分化する。Newtonとラインサーチでは同じ分割数を使い、分割数を増やす場合はその試行の開始変位から解き直す。非対称な法線–接線連成をCSRへそのまま組み立てる。

## 初期化・拘束・施工

現在の入力は`initialization.method: equilibrate`、固定CAD形状、乾燥状態を必須とする。初期接触力0・隙間0の履歴から、地盤の初期応力と物理荷重に対する平衡を形成する。斜面へK0を単純代入した初期平衡とは扱わない。

接触両側は独立した自由度を持つ。JOINTがある場合は拘束と現在の接触支持を合わせ、各面連結成分の剛体モードを検査する。標準往復載荷例は下端を固定し、上端に3方向の変位を与える。`stages-joint-normal-column.json`は`side_rollers`で、`stages-joint-explicit-normal-column.json`は同じ側方・底面拘束を明示形式で与え、上層の鉛直移動をJOINT法線力で支える。圧力が力学精度以下の面と、摩擦限界でのすべり方向は支持として数えない。[判定方法・検証](JOINT_SUPPORT.ja.md)を参照。全6方向が自由な上部土塊を無応力接触から初期化する予測と物理平衡ゲートも追加し、MC/MCC・傾斜面・実CADの7条件を検証した。[操作と適用範囲](FREE_CONTACT.ja.md)を参照。

`pressure_on_original_surface_only: true`を必須とし、双方が有効な接触面を外表面荷重の自動処理から除く。掘削で片側が消えた接触力は、撤去土の内力とは別に保持荷重から差し引く。掘削開始時の残存領域の平衡を検査し、保持荷重を段階的に0へ解放する。消えたJOINTの全履歴は凍結し、力は組み立てない。BIRTHでの再有効化には接触基準の更新方針が必要なため、現在はJOINTとBIRTHの組合せを拒否する。

試行変位・地盤材料・JOINT履歴は確定状態から独立して作る。非収束や検証用棄却では確定履歴を保持し、縮小刻みで再試行する。チェックポイントは全接触点と面対応、初期平衡・工程の進行度・保持荷重を保存する。再開時には構成・幾何・相対変位・摩擦限界・仕事/エネルギーの整合も検査する。

## 結果の読み方と検証

`analysis/results/stages.pvd`は地盤、`joints.pvd`は生の接触積分点。開口量、法線圧、3方向せん断応力、残留/累積すべり、両側の変位、摩擦/数値散逸を出力する。`active=0`は掘削で凍結された履歴で、現在作用している接触力ではない。`displacement_m`は両側の平均した表示変位、`jump_m`は実際の両側差。接触応力は体積の平滑化応力と分けて表示する。

`stages-joint-column.json`は閉合→せん断→完全開口→元位置で再接触→反転→再載荷の基準問題。`stages-joint-verification.json`は同じ工程へ収束後の棄却を入れる検証専用入力。受理刻み列の正常計算と最終状態・全フレームを比較する。

`Test-Joints.ps1`は材料則、Tri3/Tri6の力/モーメント/仕事と接線方向微分、MC/MCCの全体連成、片側掘削、幾何分離、CLI保存再開、実SolidCraftモデル、独立3D計算を実行する。合格時だけ`final-validation.json`とソースZIPを保存する。過去の試作・失敗記録は上書きしない。

独立3D計算はGL125の弾性MC地盤、別に組み立てた摩擦接触とNumPy Newtonを用いる。入力と受理した荷重割合から参照解を生成し、Rustの変位・接触力・接線を参照解の生成に使わない。接触経路100/200分割を比較する。MCCの塑性域は力学監査・切戻し/再開で確認し、全体塑性変位の独立照合とは区別する。空間収束、接触支持だけの土塊、湿潤JOINT、2D互換モデルはP6の残項目として保持する。

法線支持柱は、拘束弾性係数`E(1−ν)/((1+ν)(1−2ν))`による自重・上載圧の変位と、法線剛性による閉合`−p_n/K_n`を独立に足し合わせる。上下層ともE=100000kPa、ν=0.3、γ=20kN/m³、面積1m²、総高1m、接触面Z=0.5m。初期上載圧100kPa、追加50→0kPa、上層撤去を検査した。撤去時の保持荷重の合力は下向き110kN。全有効節点の変位差は相対L2で9.1e−12以下、積分点応力誤差は7.1e−10kPa以下だった。理論解、力学監査、4地点の別プロセス再開をそれぞれ保存する。

小型Tet10往復載荷の局所接触刻みを0.0005→0.00005mへ細かくすると、同じ受理した全体刻み列における独立参照との最大変位差は0.043404→0.001741％へ減少した。参照側も100/200分割を比較する。この照合は局所積分の確認であり、空間メッシュの収束とは区別する。
