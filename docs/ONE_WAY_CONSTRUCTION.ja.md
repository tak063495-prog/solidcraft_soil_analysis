# 不飽和ONE_WAYと局所掘削の領域変更

2026-10-24。`one_way_construction.rs`は、SolidCraftのBoolean分割で保存した掘削ボディを使い、土と水理領域を同時に撤去する。既存の固定領域ONE_WAYの初期平衡、Richardsの混合RT0、MC/MCCの全体Newtonを再利用する。小ひずみ・静的な力学、固定した水理間隙率、明示した乾燥かさ重量と水の貯留質量という[ONE_WAYの仮定](ONE_WAY.ja.md)を引き継ぐ。

## 入力と実行

外側のschemaは`soil-fem-one-way-construction/1`。`one_way`に既存の入力を置き、`excavations`に施工の順序を指定する。

```json
{
  "name": "cut",
  "before_period": "after",
  "bodies": ["Pit"],
  "water_boundary_policy": "explicit_period_boundaries",
  "cut_traction_policy": "explicit_period_reservoirs"
}
```

`before_period`は水理期間名を参照する。期間開始時に、直前の確定状態から掘削する。同じ期間に複数のイベントを重ねない。現在は物理時刻0の掘削にも対応する。`initial_increment`を省略すると力学設定の初期増分を使う。解放失敗時はこの増分を半分にし、成功後は1.5倍まで戻す。初期非有効地盤、湿潤MC BIRTH、MATSETの追加入力は[施工履歴の拡張](ONE_WAY_LIFECYCLE.ja.md)を参照。

地層と`Pit`は[局所掘削の形状受渡し](LOCAL_EXCAVATION_CURRENT.ja.md)と同じ。地域の境界箱・重心で撤去要素を選ばない。元の面集合をその時点で露出した面に交差させる。新しい掘削面の全てに、当該期間と後続期間の水理条件を明示する。例えば`Pit:floor`と`Pit:wall`を大気圧浸出候補にする。面集合が消滅した期間にその集合への条件を残す入力、二重条件、未知面、再撤去、支持から切り離した土塊、埋没空洞は拒否する。全将来工程を最初に検査する。

水頭境界と外水トラクションは別に入力する。期間の`exterior_periods.reservoirs:[]`は外水トラクションなしであり、水頭から水圧荷重を自動追加しない。水没した掘削では、外水の作用する面と水位をreservoirsへ指定する。上載圧を元地表だけに残す場合は`pressure_on_original_surface_only:true`とする。

保存再開は`checkpoint-one-way-construction MESH GROUND CASE ACCEPTED_COUNT NEW_CHECKPOINT`、`resume-one-way-construction MESH GROUND CASE CHECKPOINT NEW_RESULT`。既存出力へ上書きしない。数値的に未完了の場合は最後の確定状態と失敗理由を保存し、終了コード1を返す。入力不正は受理結果を作らない。

## 水量と時間

`richards::remove_domain`は、残存要素のH、貯留オフセットW、局所流束をそのまま複写する。新旧面は元節点IDの三角形キーで対応させ、新しい掘削面のトレースには元の内部面の値を引き継ぐ。座標の近傍探索や補間による再初期化は行わない。

撤去した各セルのH・W・4面流束・体積と水相当体積を保存する。水相当体積は`theta_s V + W`で、正圧の比貯留`Ss max(psi,0)`も含む。全経路で

`残存水相当体積 + 累積撤去水相当体積 − 初期水相当体積 − 積分した正味流入`

を監査する。ここでSsは既存ONE_WAYと同じ水の質量貯留の解釈であり、骨格圧縮を水理へ戻す連成圧密ではない。

掘削面の境界条件が新しくなる瞬間には、引き継いだ水頭が新しい境界と釣り合わない場合がある。このフレームの水理収支を`null`にし、水理平衡済みとは表示しない。新条件を使ったRichardsの解は、その後の正の物理時間刻みで求める。撤去そのものや力学の解放進行度λに物理時間を割り当てない。

## 応力解放と履歴

残存域だけの乾燥自重、水重量、χuによる内力と外水圧を再組立する。材料核へ渡す等価右辺を`R=Fphysical−Ifluid`とし、`H=Rold−Rnew−Iremoved,material`から仮保持荷重を求める。旧平衡を満たすλ=0から、`R(λ)=Rnew+(1−λ)H`を解き、λ=1で保持力をゼロにする。孤立DOFの保持力を除去し、λ=0の残存域平衡も検査する。水圧や浸透力を重複加算しない。

各試行は新しい領域、水状態と材料状態を候補として持つ。力学試行が失敗または棄却されたら確定状態に触れず、保持力と解放増分を元の工程起点から再計算する。撤去GPの応力・pc・間隙比・塑性ひずみは以降も凍結する。複数の撤去は別アーカイブを持ち、水量を二重に累積しない。解放途中の保存には非ゼロ保持力、旧水理状態、面写像、撤去水量、進行度と次刻みも含む。

保存データ全体をハッシュで封印し、入力と実行ファイルを含む受理経路の再生で照合してから、保存した実状態を使って続行する。改変後に外側ハッシュだけを付け直したデータも拒否する。再生は工程先頭からなので、再開コストは過去の経路長に依存する。

`oedometer`の平面拘束は水平層の撤去ベンチマーク用。局所的な傾斜切断面には3Dの支持条件を使う。支持条件変更の一般的な移送は本実装の対象に含めない。

## 曲面上の雨の投影

曲面Tri6では、1面内で法線の鉛直成分が正負に変わる場合がある。`max(nz,0)`を固定次数のGauss則だけで積分すると、鉛直に近い壁でも誤差が残る。新しい`surface_projection.rs`は二次Bernstein係数で符号を検査し、曖昧な領域を線形クリッピングして、その領域近似の誤差上界を累積管理する。最大10万セル・深さ30で停止し、要求精度に届かなければエラーとする。丸め誤差は領域誤差上界に含めない。

通常の曲面積はGauss次数4→8→12→16→24の差を確認する。この差は収束推定値で、厳密な区間上界とは表示しない。独立側は鉛直成分の二次式の根を各レイ上で解く積分と、別のGauss–Legendre則による面積収束を使う。符号が変わる曲面の解析積分`7/192`と、面の向きを反転した`23/192`を照合する。

## 検証と出力

新規の施工9試験と幾何2試験で、水没掘削の飽和柱理論、正圧の比貯留、MCC履歴、2回の局所撤去、実際の掘削後水理反復上限、棄却後の正常解放経路への完全一致、保存再開と改変拒否を検査する。同一領域の幾何を共有しても期間ごとの境界が更新されることを、独立に呼び出した既存Richards計算との水理状態完全一致で確認する。総合受入は上記スクリプトで新しく実行し、従来の全試験・CAD再取得・既存6ケースの一致、固定域ONE_WAY、定常3D水理と時空間比較も同じ版で取り直す。証拠の採否は各実行先の`final-validation.json`と`integrity.json`で判断する。

`analysis-frame.pvd`とGP用PVDの時刻は解析フレーム番号。CSVに実際の物理時刻・工程・λを併記する。`physical-time.pvd`は同一物理時刻の最後の確定状態を選び、解放λを秒として混ぜない。有効なセルとGPだけを表示し、元要素IDと節点IDを保存する。撤去履歴は別VTUとする。水圧の節点平滑化は行わない。転送GPを省略した入力では、再構成した派生出力であることを明記し、元の材料履歴は置換しない。

独立3D比較はMCの弾性範囲で、水頭を入力として変位を別に解く。MCCの一般3D塑性変位を独立ソルバーで全面照合した検証ではない。非収束だけを崩壊や安全率の上端にしない。

湿潤MC BIRTHとMATSETの明示水理方針は[後続の拡張](ONE_WAY_LIFECYCLE.ja.md)へ接続した。湿潤JOINT・部材との統合、無応力MCC誕生、湛水・流出動態、有限幅の過渡降雨前線、一般3D塑性の独立比較、SolidCraft画面内操作とP6全体は引き続き未完。

### 掘削前後の増分による追加照合

初期変位の大きさに依存しない比較として、実CADの掘削直前100秒から、掘削・降雨後200秒までの変位差を独立に評価した。[増分照合の証跡](../runs/construction-increment-reference-c5b801f4/verification.json)に全有効574節点の3成分を保存した。相対L2差は増分自身のノルムで正規化し、**0.011644％**。最大成分差は**3.1882µm**だった。底面の3成分相対L2差は0.015391％、周辺地表は0.010565％。独立積分7→9の増分差は5.241e-08（比率）だった。

この比較も水頭を入力としたMC弾性3D解であり、水理PDEの独立解やMCC塑性3Dの全面照合へ置き換えない。
