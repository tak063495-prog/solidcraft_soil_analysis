# ボディに保存するMCC初期応力の一次場

2026-10-26。`equilibrate` の種状態へ `seed.kind: mcc_affine_fields` を追加した。SolidCraftの解析属性へ全積分点の状態を並べる必要をなくし、同じ物理的な入力定義をTet4/Tet10の別メッシュへ評価する。これはメッシュに依存する確定履歴の移植ではない。履歴の読込は従来の `integration_points` を使う。

各 `fields` 行は一つのボディを指定し、全材料ボディを重複なく覆う。全ボディがMCCであることを要求する。座標は解析のm、応力は有効・圧縮正のkPa、成分順は `[xx,yy,zz,xy,yz,xz]`。`reference_position_m` をX0、基準応力をS0、`effective_stress_gradient_kpa_per_m` をGとすると、積分点XでS=S0+G(X−X0)を評価する。Gの列は全体座標x/y/zで、局所軸への自動回転はしない。

`pc_over_mean_effective` はMCCの等方的なpc/pで、鉛直OCRとは異なる。1以上の有限値を明示する。pは三つの直応力の平均、pc=(pc/p)pとし、間隙比はMCCのNCLと除荷線から求める。

```
e = N − λ ln(pc / p_ref) + κ ln(pc / p) − 1
```

`void_ratio.mode: from_mcc_reference` を通常用いる。`explicit` の場合も同じ関係との整合を各点で要求する。塑性ひずみはゼロから開始する。全積分点で正のp/pc/e、有限な弾性係数と降伏面内の応力を検査する。圧力の下限置換や降伏面への自動投影は行わない。

一次応力場を指定しただけでは地圧平衡を受理しない。自重・水圧・外力・拘束に対する従来の初期平衡Newtonと力/体積/ひずみの検査を通す。斜面のK0をそのまま平衡済みとする経路は追加していない。

## 実CAD壁の例

`examples/ground-geostatic-mcc-affine-wall.json` は `examples/plate-excavation.json` の三ボディに対応する。高さ6 mの初期直方体全域へσv=100+20(6−z)、K0x=K0y=0.6、pc/p=1.8を与える。三つの幾何ボディは同じMCC材料であり、三種類の地層材料を表す例ではない。地表の100 kPa面圧と底面/側面の拘束を含む対応する施工入力が必要で、種応力のJSON単独では解析を定義しない。

メッシュごとの数千点の状態表を64 KiBのSolidCraft属性へ押し込まず、各ボディの係数を保存する。CADを変更した場合は新しい指紋で再取得・再メッシュ・再初期平衡を行う。既存の施工チェックポイントは種状態の係数変更でも失効する。
