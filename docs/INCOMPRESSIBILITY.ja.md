# ほぼ非圧縮時の変位要素の評価

P1-04/P6の未完項目を調べるため、既存の変位型Tet4/Tet10を、発散ゼロの既知3D解で評価した。これは混合要素の実装・合格記録ではない。解析器本体とバイナリは変更していない。

## 問題と独立荷重

単位立方体で、`f(t)=t²(1−t)²`、変位を
`u=(f(x)f′(y)f(z), −f′(x)f(y)f(z), 0)` とする。
全外周でu=0、全領域でdiv u=0であり、せん断弾性係数G=1000 kPaを固定すると、必要な物体力は `b=−G Δu`。この既知解はポアソン比によらない。Eは各ケースで `2G(1+ν)` とした。

解析式の物体力を、変位の独立な5点差分Laplacianで検査した。等価節点荷重はRustの剛性行列・既知節点変位から作らず、別実装の形状関数とGL8/Duffy積分で作る。最粗メッシュではGL7との一致を確認した。誤差の二乗ノルムは、既知解の全領域ノルムを独立に積分し、有限要素解との交差項をGL8で積分して評価する。

各方向2/4/6分割、立方体ごと6四面体、ν=0.3/0.49/0.4999の18ケースを評価した。最粗のTet4は自由節点が中心1点のみで、今回の反対称な変位モードを表せない。この最粗結果を非圧縮ロッキングの証拠には使わない。

## 残る実装と受入

1. ほぼ非圧縮でも安定な変位・圧力混合形式を検討・実装し、圧力の不定モードと安定性条件を確認する。
2. 高い体積剛性での前処理・求解を改善し、元の物理行列で真残差を確認する。今回の失敗ケースを回帰条件として保持する。
3. 同じ既知解でメッシュ細分化とνの増加を別々に評価し、3D塑性・排水条件・施工への適用範囲を確認する。
