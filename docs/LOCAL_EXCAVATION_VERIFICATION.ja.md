# 局所掘削の実装検証記録

2026-10-23、Windows x64、Rust 1.99.1、SolidCraft portable 0.20.0、Gmsh 4.15.2、NumPy 2.5.4。

実行：`scripts/Test-LocalExcavation.ps1`。記録先：`runs/local-test-20261023-212555-4835aa44/`。ソース、ツール、既存の施工・材料点検証も併せて確認した。

## 検証内容

- Rust 27試験：既存20試験に局所掘削7試験を追加。材料/有効要素/荷重の切戻し、塑性を残すプレロード→除荷→局所掘削、実際の非収束時の最終確定状態保持、水中床面/側壁の水圧、重複撤去/空洞/不正集合の拒否、既存床面から進める2段掘削。
- Python/Gmsh 4試験：ツールの地表上部分の除外、円柱が境界箱とは異なる範囲を選ぶこと、地層境界を跨ぐ掘削の材料保持、交差なし/改ざんSTEPの拒否。実STEPと実Boolean演算を使う。
- `cargo fmt --check`、`cargo clippy --locked --all-targets -- -D warnings`、releaseビルド。
- SolidCraftの地層2体＋掘削ツール1体を名前指定で取得し、初期化→局所掘削→VTU/PVD/CSV出力→独立した力/モーメント・降伏条件・VTU再読込検査。
- 独立3D速度式計算との比較と参照積分100/200分割、Rust積分の細分化。
- 独立1D塑性MCC速度式との回帰比較。最大変位プロファイル差0.1274％、pc比較・失敗CLIの終了コード1と完全復元も合格。こちらは全層除去の基準問題であり、局所塑性3D解の独立比較ではない。

## SolidCraftの局所掘削例

初期地盤10×10×8m、水平2層各400m³。乾燥、γ=下層20/上層18kN/m³、K0x=K0y=1、MCC pc/p=2、初期上載圧30kPa。K0=1はこの過圧密ベンチマークに指定した値で、自動推定値ではない。掘削体4×4×3mのうち地盤と交わる4×4×2m=32m³を撤去し、周辺84m²の元地表だけに上載圧30kPaを維持する。床面上載圧0。

|---|---:|---:|
|節点 / Tet4|230 / 784|499 / 1774|
|撤去 / 残存要素|70 / 714|122 / 1652|
|切断面積（床16＋壁32）m²|48|48|

|最大工学ひずみ成分（通常積分）|0.3945％|0.4727％|

MCCの弾性除荷枝を対象とし、参照計算は全経路で降伏面の内部にあることを検査した。Rustでもpcが初期値のまま保たれる。塑性硬化を伴う局所3D計算はRustの履歴復元試験で検証し、その塑性域の変位まで別実装の3D解と照合済みとは扱わない。

保持荷重の自由度成分は、独立した残存領域の初期内力と掘削後物理荷重から再構成して比較する。λ=0の平衡残差を`excavation_audits`に記録し、最終仮保持荷重0を確認する。水中試験では壁面にゼロでない水平節点水圧が発生し、床面の鉛直水圧は16×2×9.80665=313.8128kNとなる。

## メッシュ依存性と残る作業

2m→1.5mの変更で、床面の**面積平均**隆起は3.54561→3.87853mm、相対差8.58％。床面中心(5,5,6)mの補間変位は5.29514→5.37003mm。全3方向変位を同じ位置へ補間して比べた差は24.69％。周辺地表の沈下極値と局所分布には大きなメッシュ感度が残る。

したがって今回の一致は、同一メッシュでの積分・全体求解と応力解放処理の検証結果である。2つのメッシュだけで空間収束を主張せず、実務値への適用には疎求解・高次要素・掘削縁の局所細分化を進め、変位分布のメッシュ収束を確認する必要がある。現在は自由度1500を標準上限、2000を設定可能な上限とする密求解。

小ひずみ、静的、水平多層初期地盤、固定静水圧を対象とする。掘削排水、過渡圧密、支保・接触、底面破壊の安全率評価は後続工程。
