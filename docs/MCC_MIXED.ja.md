# MCC混合形式の材料応答と施工FEM

`mcc_split.rs` の材料応答を `stages_mixed.rs` へ接続し、既存の施工コントローラで乾燥MCCの混合FEMを解く開発実装を追加した。Tet10変位、材料境界で分離した頂点P1平均有効応力、積分点ごとの独立体積ひずみを同時に解く。初期地圧平衡、載除荷、掘削、切戻し・保存再開の小モデル試験は合格した。独立3D比較・広い地形/支持条件の検証、MC/水理/部材/接合とSolidCraft入力/表示への接続は未完である。従来の変位型MCCと[混合弾性](MIXED_MECHANICS.ja.md)の受入範囲を維持する。

## 応力と体積の分離

材料への入力は圧縮正の偏差ひずみ増分 `Δεdev` と体積ひずみ増分 `Δθ`。

`Δε = Δεdev + Δθ I/3`

を既存MCCの固定分割された全増分写像へ渡し、平均有効応力 `pMCC=tr(σ′)/3`、偏差応力 `s=σ′−pMCC I`、pc・e・塑性ひずみを含む全履歴を返す。呼出し元の確定状態は変更しない。材料帰着後に平均応力を別の値へ置き換え、降伏条件や硬化履歴が不整合になる実装にはしない。

全接線Cから、工学せん断の規約を保って

`P = I6 − n nᵀ/3`、`n=(1,1,1,0,0,0)ᵀ`

`∂s/∂εdev = P C P`、`∂s/∂θ = P C n/3`

`∂pMCC/∂εdev = nᵀ C P/3`、`∂pMCC/∂θ = nᵀ C n/9`

を得る。接線を対称化しない。正でない体積方向の接線を切り上げたり、その逆数を必須にしたりしない。旧開発版では分割数を固定して差分を取り、摂動によるceil分割数の切替を避けた。新しい開発版は同じ固定分割の材料更新を陰関数微分する。どちらも降伏面の切替点を含む滑らかな全体Newtonの保証ではなく、ラインサーチと切戻しを保持する。

### 陰関数微分による材料接線

`mcc_sensitivity.rs` は既存の `mcc::Parameters::substep` を各分割の主値更新としてそのまま呼び、弾性予測と履歴の感度を6方向へ伝播する。塑性時は収束したp・q・log(pc)・塑性乗数の4変数の帰着式を微分する。応力・間隙比・pc・塑性ひずみ・塑性分割数は従来の固定分割更新と完全一致する。応力の偏差倍率を `1/(1+6 G Δλ)` として計算し、q=0や体積塑性流れが0の限界でqや体積流れを除算しない。塑性乗数や体積接線を切り上げず、再構成残差が不正なら失敗として返す。

NC/OC、載除荷・せん断・等方塑性・限界状態・主軸回転・不正入力の6試験に加え、分離応答4試験、全体施工6試験が合格した。差分幅2e−7/1e−7の照合では接線相対差は約3.25e−11～6.22e−10。1000分割の材料点の局所測定は差分法より約6倍速かったが、これは全体FEMの速度保証ではない（`runs/mixed-mcc-implicit-tests-20261025-v1.log`）。

確定状態に `tangent_method=implicit_branch_fixed_partition` を保存する。旧結果で省略された場合は `finite_difference_fixed_partition` として読み、現在の実行版と異なる方式での再開は拒否する。新混合方式は `tangent_perturbation` を材料接線に使用しない。従来の変位型と有限差分APIでは引き続き使用する。

## 全体方程式

変位u、圧縮正の平均有効応力p、独立した圧縮正の体積ひずみθについて、力の釣合いに加えて

`∫ Np (div u + θ) dV = 0`

`p − pMCC(−dev(sym grad u), θ) = 0`

を満たす必要がある。前者は弱い体積適合、後者は材料圧力との整合である。後者を満たさず出力応力の平均だけ置換する方法は採らない。これらは平均有効応力の方程式であり、間隙水圧や圧密の連成方程式とは区別する。

全体接線は4つの材料接線を用いて組み立て、θ・変位・pの全連立系を解く。θを材料接線の逆数で縮約せず、接線の逆行列が存在しない状態を剛性シフトで隠さない。疎CSR/GMRES/ILU0と明示された密LUを使用する。疎求解のピボット失敗や反復上限は失敗として返し、別方式へ自動で切り替えない。力の残差は一次未知量pを使うものと、MCCが返した全応力を使うものの両方で確認する。圧力整合は全積分点、体積適合はP1試験関数に対して検査し、3つの残差が合格するまで確定しない。

体積適合は原CAD座標からの累積変位と累積θに課す。掘削後も同じ原基準を保ち、撤去した積分点のe・pc・塑性ひずみ・累積θを凍結する。確定状態の `mixed_mcc` に材料番号付き圧力DOF、全GPの累積θ、基準間隙比、直前の材料分割数、圧力/体積残差を保存する。再開時は圧力DOFの在庫と重複、pとMCC平均応力、累積θとe、弱い体積適合、記録された残差を再検査する。

## 一次未知量と凍結履歴の出力

`export_stages.py MESH.json RESULT.json NEW_DIRECTORY` は新混合結果にも対応する。体積平均の要素場、生の有効積分点、材料別のP1平均有効応力DOFを別VTU/PVDへ出力する。同じ幾何節点にある異材料の圧力を平均化しない。材料の累積体積ひずみと変位から計算する体積ひずみは点ごとには一致を課していないため、両値と差、両方の6成分ひずみを別フィールドとして保存する。`material-history-NNN.csv` は撤去済みの全GPも保持し、撤去点の一次圧力は空欄、材料履歴・基準間隙比・pc・塑性ひずみは凍結値を保存する。

全フレームの圧力在庫、形状積分、p–材料平均応力、弱い体積適合、e–累積θ、降伏、撤去履歴と最終確定状態を出力先作成前に検査する。不明な接線方式や途中での方式変更も拒否する。出力記録に方式、入力・ソース・出力ハッシュを保存する。これは独立解との物理精度認定ではない。
