# h細分による変位・応力・一様応力SRMのFs

一般3D空間収束の認定ではない。掘削・斜面・非一様な塑性機構の粗密差は、従来の未達記録のまま残す。P6は完了にしない。数値基準、許容値、参照値、過去の失敗記録は変えていない。

平滑な線形弾性は生産側の`mechanics::solve`で解き、次数とRichardson外挿を出す。一様な乾燥MCのFsは、既存のφ=0・一軸15 kPa・6個の剛体ゲージと、受理済み未低減Runを起点にするepoch探索で求める。不収束は上端にしない。

## 問題

立方体は一辺1 m。各辺をn等分し、直方体を対角0–6まわりの6個の四面体へ分ける。Tet10は直線辺の中間節点を既存の`elevate_straight`で足し、積分次数は5。

自重の側方拘束柱はE=10000 kPa、ν=0.25、γ=20 kN/m³。厳密解は

`u_z = −γ(Hz − z²/2)/M`、`M = E(1−ν)/[(1+ν)(1−2ν)] = 12000 kPa`、

`σ_z = −γ(H−z)`、`σ_x = σ_y = ν/(1−ν) σ_z`（引張正）。上面の厳密変位は−1/1200 m = −8.333333333333334e−4 m。変位は二次、応力は一次なので、Tet4は次数を持ち、Tet10はこの多項式を要素空間に含む。

製造解は同じ生産剛性へ、厳密な物体力の等価節点荷重を渡す。境界は厳密変位0。

`u_z = A sin(πx) sin(πy) sin(πz)`、A=1e−3 m、E=1000 kPa、ν=0.3。

物体力は応力の発散と一致することを、独立な中心差分で相対残差4.03e−11まで確認している。これは第二の構成則ではない。

SRMはc=10 kPa、φ=ψ=0、E=100000 kPa、ν=0.3、上下面のトラクション±15 kPa。φ=0の一軸圧縮強度は2c=20 kPaなので、解析的な低減率は20/15=4/3。平均応力の必要条件が上端を作り、探索幅の中に4/3が入る。この応力は要素内で一定であり、Tet4にもTet10にも入る。斜面のFsではない。

変位・応力の誤差は、Tet4では4次の体積積分、Tet10では求解と同じ積分点での自乗平均平方根。モニタは、自重では上面節点の鉛直変位の平均、製造解では中心に最も近い節点の`u_z`。次数は隣接する誤差の比の二進対数。Richardson外挿は、その観測次数を最も細かい2段へ使う。次数が探索幅や求解許容の床に埋もれるときは外挿次数を出さない。

モニタのRichardson推定は、次数を観測できた3系列とも厳密値と浮動小数点で一致した（差0）。推定に使った次数は、自重Tet4が2.7027、製造解Tet4が1.7231、製造解Tet10が3.2983。自重Tet10の推定は最細の計算値そのもので、厳密値との差は7.113e−16 m。

## ユーザーPCのプロファイル

CIより1段細かい。自重と製造解のTet4は16分割（24,576要素、4,913節点）、Tet10は8分割（3,072要素）。SRMはTet4の1/2/4とTet10の1/2、探索幅0.01、最大試行16。このLinuxのrelease実行は約8秒で終わった。数時間級の既存斜面・掘削メッシュは回していない。

```text
cargo run --release -- spatial-convergence user runs/spatial-convergence-user.json
```

出力先が既にある場合は拒否する。CIと同じ確認は次のとおり。

```text
cargo run --release -- spatial-convergence ci runs/spatial-convergence-ci.json
```

## 後続の2D 5％比較に使える量

使えるのは、この一様ブロックについて次の3つに限る。

- 解析的Fs = 4/3。
- 探索が返した区間。CIでは[1.3250000000000002, 1.3531250000000001]、ユーザープロファイルでは幅0.00703125の区間。中点を点推定にする場合、解析値との差はそれぞれのバイアス0.005729と0.002214。
- 弾性モニタのRichardson推定。上の平滑問題では厳密値と一致したので、同じ外挿手順を後で非一様問題のスカラー量へ使うときの手順確認にはなる。

2D版の変位5％基準との比較は、この記録では行っていない。斜面の正確なFsも決まっていない。

## 残件

一般3Dの空間収束、掘削・斜面・有限幅の塑性変位、元の2D変位5％、水・構造・JOINTを含むSRM、Native UI、P6全体は未達である。一様応力でFsのメッシュ差が探索幅未満であることは、その問題の離散解が要素空間に入っているという結果であり、一般の安全率の収束ではない。
