# 工程水位と部分水没面

`hydrostatic_water`工程で、指定した水平水位に対応する最終排水状態へ力学平衡を求める。MCC/MC/IDHの既存全体FEMへ接続する。自由水面を未知量として求める浸透解析、降雨前線、過剰間隙水圧の消散時間をこの工程で代用しない。

```json
{"kind":"hydrostatic_water","name":"drawdown","target_level_m":6.7,"initial_increment":0.5}
```

```powershell
cd D:\Work\soil-fem-3d
pwsh -NoProfile -File scripts\Invoke-LocalExcavation.ps1 -GroundFile examples\ground-water-local.json -StageFile examples\stages-water-local-mcc.json -MeshSizeM 4
pwsh -NoProfile -File scripts\Test-Water.ps1
```

地形・地層・掘削範囲は従来と同じSolidCraftボディで指定する。例は上下2層とPit。MCC例はプレロード→除荷→水位上昇→局所掘削→水位低下→再湛水。`ground-water-local-mc.json`と`stages-water-local.json`は、MC弾性枝に留めた独立3D照合用の例で、現地の粘着力を推定した入力ではない。

## 有効応力と外力

水位は工程の始点から終点へ増分進行度で移動する。間隙水圧は各体積積分点で`u=γw max(h−z,0)`。材料更新は有効応力とひずみで行い、全応力内力にはその増分の水圧を加える。水位を変更しても、確定した有効応力・pc・間隙比・塑性ひずみを直接書き換えない。新しい水圧と外力に対する変位・材料状態をNewtonで求める。

初期水位Noneは水圧0を表す。水位工程を使う乾燥初期状態は、メッシュ底面の高さを初期hとして保存する。その高さからの進行度であり、実時間ではない。水位工程がない従来入力は、この追加状態欄を持たない。

外水圧は`−u n`で、露出した掘削床・壁、元地表または一般地形の明示hydrostatic面へ作用する。外周の支持面を自動的に露出水面にしない。部分水没面の荷重は水位に対して非線形なので、始点/終点の荷重の直線補間を使わず、各試行の実水位から再構成する。地表上まで湛水した柱では、外水圧増分と間隙水圧増分が有効鉛直応力に対して相殺することを検証する。水中掘削でも撤去土の自重と床面/壁の水圧を区別する。

土の入力単位体積重量は固定で、自動的に乾燥重量と飽和重量を切り替えない。必要な密度変更は既存の材料変更と明示的に組み合わせる。水位変化だけから吸水質量・体積変化・サクションを生成しない。水と土の二方向連成・時間圧密は任意工程P4dとして残る。

## 曲面Tri6の部分水没積分

Tri3/Tri6の元の写像、形状関数、向き付き面Jacobianを使用する。辺の中間節点を平面へ移動させない。

参照三角形の各パッチで、高さと面Jacobianベクトルの2次Bernstein係数を求める。高さの凸包から完全水没/乾燥を判定するため、6節点がすべて乾いていても内部の水没域を見落とさない。部分水没パッチは角点の線形水位で参照領域をクリップし、その領域上の**元の多項式**を積分する。水位面を線形化する誤差は、実高さと線形高さの最大差δ、パッチ面積、面Jacobian上界と形状関数上界から制御する。

全節点力を連結したL2ノルムの領域近似誤差上界は、各部分パッチで`γw δ Aref max|Jsurface| √n`。誤差上界の大きいパッチから4分割し、上界の総和が許容値以下になってから確定する。湿潤領域内の積分は元のTri6形状関数2次×水圧2次×面Jacobian2次までの多項式で、Gauss積則により積分する。水没領域の近似に伴う上界であり、丸め誤差やFEMの空間誤差の上界ではない。予算超過は失敗で、粗い結果へ自動的に切り替えない。

独立参照は別方式で、各参照座標のレイに沿って高さの2次式の根から水没区間を直接求め、外側の座標を適応Gaussで積分する。平面、曲面、全節点乾燥の内部水没円、3方向へ曲がる面で、全節点力を比較する。閉じた多項式理論の力・モーメントも併用する。`hydrostatic-face CASE.json NEW_RESULT.json`で荷重、領域誤差上界、細分化数を単独出力できる。

## 体積積分と収束

材料積分点には実際の`max(h−z,0)`を与え、内力は入力したTet4/Tet10体積積分則で評価する。水面が要素内部にある場合、水圧の折れ曲がりと変位近似の両方に離散化誤差がある。面荷重の誤差上界を体積誤差や変位精度へ転用しない。

検証では水位0.37mの1m柱を、厚さ方向2/4/8/16層と積分次数3/4/5で計算する。連続体の変位積分に加え、水位位置で区間を分割した正確なQ2有限要素荷重と直接解を作る。これにより、2層Q2の中間節点に残る変位補間誤差と、体積水圧の積分誤差を区別する。実CADの独立3D照合は同じ体積積分則の離散方程式を別実装で直接解くもので、実CAD形状の空間収束を意味しない。

## 保存再開と出力

水位工程のある結果はschema/11、確定状態の`hydrostatic_water_level_m`に水位を保存する。従来の固定水位結果の状態表現を維持し、旧MCC/IDH入力の再計算と全状態・全フレームの完全一致を回帰条件とする。

棄却試行は水位、変位、材料履歴、有効要素、保持荷重を確定しない。水位が変わっても外力が変わらない工程があるため、荷重の変化だけで水圧状態の復元を判定しない。チェックポイントは水位と工程始点も保存し、再開時に水位と部分水没荷重を再構成して一致を検査する。履歴や水位を改変し再ハッシュしたチェックポイントも拒否する。

VTU/PVDには工程の水位から求めた生の積分点水圧、有効/全応力、変位を保存する。CSVにも水位を記録する。撤去要素の材料履歴は凍結し、表示・集計では有効領域を使用する。

初期水平K0の水位は、従来どおり地層境界と整合する範囲に制約がある。その初期化後は水位工程で任意の高さへ移動できる。一般地形は地圧平衡による初期化を使う。湿潤JOINTは水圧連続/指定の方針と有効接触力を別に実装するため、現段階ではJOINT付き水位工程を拒否する。自由水面・浸出面、Darcy、Richards降雨はP4a-02以降の未完要件として保持する。
