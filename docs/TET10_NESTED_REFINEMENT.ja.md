# 同じCADメッシュのTet10一様細分化

一般地形の粗密比較に、元の要素を8個のTet10へ分ける経路を追加した。SolidCraft由来の同じ地盤・掘削形状を保持し、要素配置の変更と要素寸法の変更を切り分けるために使う。初期状態は元の物理的な種応力の定義から新しい積分点へ生成し直す。解析済み変位・pc・間隙比・塑性履歴のメッシュ間移送や、施工途中のリメッシュは実装していない。

## 形状・境界・領域の継承

`tools/refine_tet10.py` は、親要素の4隅と6中間節点を子要素の隅とし、中央八面体を1本の対角線で分割して8個の子を作る。子の二次節点は親の二次写像で評価する。親の写像と子のアフィンな参照座標写像の合成も二次式なので、曲面のTet10写像も保持される。

新節点の同一性は、親の隅節点IDと分母4の整数重みの組で定義する。座標一致による節点結合はしない。同じ材料境界の共有節点を共有したまま、接触面で分離された同位置の節点は分離したまま細分化する。

材料ID・地盤領域ID・掘削選択は親子の対応を保存する。三角形の面セットは各4面へ分ける。同名の節点セットが元の面全体のTri6節点と一致する場合は、細分化後の面全体へ更新する。全節点セットも更新する。その他の節点セットは元の明示節点IDを保持し、新しい幾何選択を推定しない。各セットの方針は `.refinement.json` の `node_set_policies` に出力する。任意の線や部分節点選択を、連続した境界条件と自動解釈する機能ではない。

```powershell
.venv/Scripts/python.exe -X utf8 tools/refine_tet10.py PARENT_MESH.json NEW_MESH.json
```

親ごとの二次形状再現、共有節点座標、体積の保存を検査する。入力は整合した `soil-fem-mesh/3` のTet10とする。解析へ渡す前にはRustのメッシュ検査・積分点ID生成も必要になる。

## 検証と実CADの入力準備

`runs/tet10-nested-refinement-verification-20261025-v2/verification.json` に、514ファイルの固定ソースと次の4条件を保存した。

- 実SolidCraft斜面：224→1792要素、2997節点。親形状の再現誤差最大8.882e−15 m、親体積の保存誤差最大7.106e−15 m³、局所Pit体積16 m³。
- 人工の二次せん断写像で曲げた斜面：曲面形状・体積・二次場を保持。この曲面は実CADの検証例とは区別する。
- 2材料の共有面：Tri6の6節点が、共有を保った15節点へ細分化される。材料・領域・撤去選択の親子対応を保持。
- 分離した接触面：両側の座標は一致し、細分化した各15節点のIDは交わらない。接触力学の受入とは区別する。

ランダムな親節点値による二次場の再現誤差は最大1.111e−15、共有面の値の差は4.441e−16以下だった。全4ケースで固定Rust実行版の `validate` が正常終了した。初回v1は人工例の掘削選択名が地盤ボディ名と重なってRust入力検査に拒否された。選択名を分けたv2で再実行し、v1のログと入力も保持した。refiner本体の数値式や判定値はこの修正で変更していない。

実CAD斜面の1792要素について、`tools/prepare_nested_mcc_study.py` で48384積分点の新しい地盤初期入力を生成した。親の種応力が `p=20(10−x/3−z)`、K0x=K0y=1、pc/p=4、MCC基準線による間隙比であることを検査し、同じ定義を新しい位置に適用した。平衡済み状態とはみなさず、初期地圧平衡を実行する入力である。

保存先は `runs/projected-mcc-nested-inputs-20261025-v1/`。メッシュ・初期地盤・主ケース・細かい施工ケース・Rustの積分点ID・固定実行版を対応付けた。`ultrafine-job` は準備済みで、非線形計算はまだ開始していない。初期平衡・載除荷・掘削・独立計算と粗密比較の合格は未判定である。

## 空間収束の判定との関係

NASAの[空間収束の解説](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)は、複数の細分化水準と観測次数、反復・時間刻みの誤差を分けて扱う方法を説明している。これはCFDの検証資料であり、このMCC離散化や地盤の実挙動を保証するものではない。ここでは一様な親子メッシュの系列を用意する根拠として参照する。

現在の224／413／723要素の再メッシュ結果に、要素数だけから誤差上界やGCI合格を自動付与しない。1792要素の準備・形状検査が合格しても、変位・応力・硬化履歴の空間収束は別に検証する。共通物理点、同じ面積平均、独立計算の刻み細分化と適合ひずみ方式の別細分化は [MCC疎行列参照](MCC_SPARSE_REFERENCE.ja.md)の計画を継続する。
