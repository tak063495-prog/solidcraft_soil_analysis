# SolidCraft結果表示への受渡し基盤

2026-10-24。外部の表示用データ生成と照合に加え、ネイティブ結果読込・GPUコンター・変形・断面・主方向のコードを追加した。**追加コードは現在検証中であり、実画面を含む受入済みとは扱わない。P5/P6完了の記録ではない。**

`Invoke-SolidCraftCapture.ps1`は、解析と既存の独立内力検算・VTU再読込が成功した後に、`view/`と`view-verification.json`を出力する。失敗時は途中出力を保持し、エラーを返す。力学結果が既に完成していた場合、その結果は`analysis/`に残る。

既存の完成したnative-captureジョブにも、次の外部コマンドを使える。出力先は新規フォルダーに限る。

```powershell
.venv\Scripts\python.exe tools\export_solidcraft_view.py runs\MY-NATIVE-JOB runs\MY-NEW-VIEW
.venv\Scripts\python.exe tools\verify_solidcraft_view.py runs\MY-NATIVE-JOB runs\MY-NEW-VIEW runs\MY-NEW-VIEW-VERIFICATION.json
```

## 入力版と解析結果の対応

表示出力は、元のCAD/解析入力スナップショット、native-capture、個別STEP、メッシャーのボディ対応・出典、コピーされたprepared inventory、解析入力と結果、使用ソルバー、既存の検算記録をSHA256で結ぶ。解析結果のハッシュだけを書き換えて別のCADメッシュへ差し替えた場合は、prepared geometryとの不一致を拒否する。

移設前の受入記録に絶対パスが残っていても、それを読みに行かない。ジョブ内の所定のファイルと対応するハッシュを照合する。表示出力側のパスとprepared inventoryも対象フォルダー内に制限する。元設計は実行しない。

追加したネイティブ読込コマンドは、現在の`analysis.soil.snapshot`の入力SHAとの一致を必要とする。元のprepared mesh・施工状態から、節点変位の各基準と積分重みによるセル平均も再照合する。CADや解析入力が変われば描画と照会を拒否し、対応する入力がUndoで戻れば適用を回復する。これらの自動試験と実画面検証は、下記の受入記録が揃うまで未完了とする。

## 表示用ファイル

|ファイル|内容|
|---|---|
|`view-manifest.json`|最後に書く完了マーカー。入力/CAD/実行版、各表示ファイルとジョブ出典のSHA256、工程一覧と量の定義|
|`geometry.json`|元座標m、Tet4/Tet10接続、地層・監視節点集合、CRSと原点。暗黙の座標変換をしない|
|`frame-NNN.json`|その工程の有効節点/要素、外側Tri3/Tri6面、節点変位、要素平均、監視値、収束診断|
|`points-NNN.json`|有効な積分点の元ID・所有要素・位置・積分重みと、保存された材料履歴の生値|

工程ごとのファイルを分け、将来の表示側が選択工程だけを読める形にした。入力の対応版は`soil-fem-stage-result/1`〜`/13`。旧Tet4版の1要素1材料点は、四面体重心・実体積と保存値を使う。Tet10は保存された全積分点と曲面中間節点を保持する。

初期上限は257フレーム、JSONファイル各256 MiB、表示出力合計512 MiB。超過時は黙って間引かず、完了マーカーを作らずに停止する。大規模な履歴結果のストリーム変換とバイナリ化は今後の性能・配布要件に残る。

## 表示量を混同しない

- Z上向き正。沈下は負、隆起は正。変形倍率はビューア側の表示指定であり、保存変位を変更しない。
- `displacement_m`は累積変位から明示した表示基準を引いたもの。`total_displacement_from_seed_m`は元の種状態からの累積値を保持する。
- `stage_displacement_increment_m`は前工程との差。BIRTH工程では新設直後のprepared stateとの差とし、設置前の値を誤って増分に含めない。
- セルの応力・間隙比・硬化状態は積分重みによる体積平均で、節点への平滑化ではない。生の積分点値を別ファイルに保持する。
- 材料モデルに存在しない量は`null`とし、ゼロの測定値として出力しない。実際に保存された非有限値は拒否する。
- 応力・塑性ひずみは圧縮正、成分順はxx, yy, zz, xy, yz, xz。応力の単位はkPa。
- 掘削後の有効要素から境界面を作り直す。共有Tri6面の中間節点不整合は拒否する。表示側でのTri6分割は表示近似として明示する。

梁・アンカー・接触結果の専用レイヤ、水理量、主方向グリフはこの最初の表示形式に含めていない。マニフェストにも不足分を記録する。追加ビューアの主方向は、保存済みのセル平均有効応力テンソルから計算する。生の積分点の方向、または積分点の固有値・固有方向を平均したものではない。

## ネイティブ結果ビューア（限定範囲）

以下の5コマンドは、同じJSON経路を画面とAPIで共有する。API操作はファイル選択画面を開かず、`ui.start`による対話的操作だけが選択画面を使う。結果と表示設定はCAD文書やUndoへ保存しない。

|コマンド|内容|
|---|---|
|`analysis.soil.results.open`|`manifest`と`expected_input_sha256`を指定して、完了済みジョブを読込|
|`analysis.soil.results.status`|工程・入力版・量・範囲・断面面積・現在入力への適用可否|
|`analysis.soil.results.configure`|工程、量、変位基準、倍率、分割、断面、凡例範囲、エッジ・主方向を指定|
|`analysis.soil.results.query`|元IDによる節点・セル平均・生の積分点、または表示三角形のレイ照会|
|`analysis.soil.results.close`|結果を解放。画面では保存していたCADカメラへ戻る|

コンターの変位単位はmm、応力はkPa。照会した保存節点変位はmで、変形倍率を掛けない。結果照会には工程名・入力/結果マニフェストのSHA・変位基準・表示倍率を付ける。セル平均を節点へ平滑化しない。

断面は基準座標の平面`normal · x = offset_m`を使い、交差後に表示変形を適用する。`slice_only=false`では負側を残す。Tet10は参照四面体を2/4/8分割し、二次形状関数を評価する。曲面と断面の三角形分割は表示近似であり、元のFEM解を変更しない。

検証対象は、曲面Tet10の独立面積・二次変位場、重複しない断面、重根時に方向を捏造しない主応力、改変・異なる入力の拒否、保存設計/Undoの保持に加え、既存実CAD掘削ジョブの中央断面72 m²と重心照合である。GPU描画・凡例・操作の確認は別に実画面で行う。大規模な表示、部材/水理レイヤ、ジョブの協調中断などは引き続き残る。
