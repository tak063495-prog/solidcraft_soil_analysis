# MCCの中点積分：選択式の精度改善

2026-10-27開発版。従来の後退Euler積分を既定に保ち、MCC材料の `integration: "midpoint"`、または施工ケースの `settings.mcc_integration: "midpoint"` で選択する。施工設定は解析内に複製したMCC材料へ適用し、原地盤入力を書き換えない。設定は保存再開の入力照合対象となる。水理のfixed-stress分割とは別の、材料応答の積分方法である。

弾性経路では、間隙比に対応する比体積の指数更新と応力依存の体積・せん断剛性を積分する。塑性経路では6応力、対数先行圧密圧力、塑性乗数の8未知量を同時に解き、中点の流れ則と硬化則、終点の降伏条件を満たす。非共軸経路と硬化・軟化を保持し、降伏面への追加射影、体積接線の下限、接線の対称化は加えない。

全固定分割の履歴と弾性初回降伏時刻を自動微分し、局所方程式の陰関数微分から整合接線を得る。全体Newtonの各試行は同じ確定履歴から再計算する。局所失敗、ラインサーチ、施工切戻しで試行履歴を確定しない。

`tests/mcc_midpoint.rs` の10試験で、OCR初回降伏・除荷の閉形式への二次収束、28条件の全分割接線差分、任意回転、除荷時のpc・塑性履歴保持、不正試行の不変性を確認した。GP独立体積とP1投影体積の両方について、Tet10の等方NC載荷・除荷を理論解と照合し、塑性途中の保存再開と積分方式変更の拒否も検査する。

この試験で、既存のほぼ静水圧の全体Newton入力が丸め誤差による偏差ひずみトレースで拒否される問題を発見した。偏差成分の最後を他の2成分の和の負値として形成し、トレースをゼロに保つ。材料入力の検査値や全体収束基準は変更していない。従来積分の弾性等方載荷も回帰試験へ加えた。

独立した速度形MCCをSciPy Radauで積分する比較は次で実行する。参照の許容誤差細分化と、本体の128/256/512材料分割を比較し、全6応力・pc・間隙比・塑性履歴と二次収束を確認する。参照は本体の局所帰着式を使用しない。

```powershell
python tools/verify_mcc_midpoint.py --solver target/release/soil-fem-3d.exe --output runs/NEW-midpoint-rate-comparison
```

材料点と単要素の理論試験を、一般地形の空間収束や実CAD全体の受入へ読み替えない。実CAD斜面・壁の全場、掘削解放力、刻み・境界・空間収束を引き続き比較する。公開bed5e8aはこの新方式を含まない。全P6の完了は[受入表](P6_STATUS.ja.md)で管理する。

実CAD壁では、施工刻み1/16・材料刻み1e-4と、施工刻み1/32・材料刻み2.5e-5を独立RK4の100/200分割と比較し、全8工程の全場・部材・保持力・刻み細分化の原基準を通過した。細かい解析の全節点変位の相対差は最大0.003743％。施工刻み1/8では設置時の微小回転が1％基準を超え、Newton/線形許容値を100倍厳しくしてもほぼ変わらなかった。この失敗と対照計算を保持し、材料刻みと全体の施工刻みを区別する。記録は `runs/mcc-midpoint-cad-wall-20261027-v1/verification-refined-construction.json`。空間収束や全P6の受入ではない。

同じ実CAD壁の掘削0.03125、除荷0.0625、壁撤去0.0625の3地点から、別プロセス再開後の全結果が連続実行と一致した（線形求解の実測秒数のみ除外）。撤去1134積分点の履歴保持、3試行の切戻し、方式を変更した再開の拒否も確認した。記録は `runs/mcc-midpoint-wall-checkpoints-20261027-v1/verification.json`。

固定版のRust全263件、Python全116件、fmt/clippy/CLIビルド、独立Radauの3経路が合格。Radau参照自体の細分化差を確認し、128/256/512分割で全状態の誤差がほぼ4分の1ずつ減少した。最初の比較スクリプトは軟化経路の64分割が材料刻み上限を超えて拒否されたため、上限を保ったまま比較刻みを修正した。Rust入力は全試験版から不変で、変更したPython/説明文を別ソース版として全Python試験と比較を実行した。記録は `runs/mcc-midpoint-quality-20261027-v2/quality.json`。
